# 阳明心学与当代人生 · 学习讲义

王德峰《阳明心学与当代人生》60讲及课程介绍，以第一人称授课口吻整理。每讲保留关键论证、课堂例子和回看时间，可对照来源视频阅读。

[打开全课目录](https://nocoder0.github.io/yangming-notes/catalog.html) · [从第01讲读起](https://nocoder0.github.io/yangming-notes/)

目录按主题分组，可用讲次、标题或章节关键词搜索。每讲提供可折叠的本讲目录、相邻讲次和 Markdown 下载。手机端可直接阅读，宽表格支持横向滚动。

## 文件

- `catalog.html` 是全课目录。
- `index.html` 是第01讲。第02—10讲沿用原有页面地址。
- `intro.html` 是课程介绍。`lecture-11.html` 至 `lecture-60.html` 是第11—60讲。
- `notes/` 收录可下载的讲义正文。`assets/` 提供样式、交互和图标。

讲义为课程内容的文字整理，非逐字实录。经典引文附原文链接。
