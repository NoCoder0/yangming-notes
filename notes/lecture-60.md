## 孟子不动心与告子不动心

**回看 00:00—02:10**

<span id="p-60-001" class="reading-anchor"></span>

课程的第四部分讲养心的功夫，人性与万物无间。我们找到《钱德洪录》第十二节，也是录了阳明的原话。先生曰，「孟子不动心与告子不动心」，都说不动心，「所异只在毫厘间」。他们有差异的，看来差异似乎很小。

<span id="p-60-002" class="reading-anchor"></span>

「告子只在不动心上着功，孟子便直从此心原不动处分晓。心之本体原是不动的，只为所行有不合义便动了。孟子不论心之动与不动，只是集义。若是集义，所行无不是义。」

<span id="p-60-003" class="reading-anchor"></span>

集义就是做事情，做种种事情。这个义就是天理。所行、所做，无不是天理的实现，「此心自然无可动处」。

从告子的角度看，只要此心不动，便是把捉此心，把住它，不要让它动，将它生生不息之根反而阻挠了。

<span id="p-60-004" class="reading-anchor"></span>

「此非徒无益，而又害之。」这样做不但没什么好处，反而又害了这个心体了。「孟子集义功夫，自是养得充满，并无亏欠，自是纵横自在、活泼泼的，此便是浩然之气。」

## 性和物不可分作两边

**回看 02:10—05:49**

<span id="p-60-005" class="reading-anchor"></span>

好，我们再看下一段，阳明继续讨论。告子的错误在哪里？「是从性无善无不善上见来。」告子认为人性非善非恶，性无善也无不善。「虽如此说，亦无大差；但告子执定看了，便有个无善无不善的性在内。」

<span id="p-60-006" class="reading-anchor"></span>

「有善有恶，又在物感上看，便有个物在外。却做两边看了，便是差」，差错的差。一个有在内的人性。它谈不上善，也谈不上不善。一个呢，又有一个物在外。对物的感应上看呢，有善有恶。这样呢，就把人性跟外物分开。

<span id="p-60-007" class="reading-anchor"></span>

「无善无不善，性原是如此。」这倒是阳明同意的。阳明的四句教当中第一句，「无善无恶心之体，有善有恶意之动」了。看来就是意向起来，是因为有物嘛，遇到事情了啊。我们看下去，「悟得及时，只此一句便尽了，更无有内外之间」。

<span id="p-60-008" class="reading-anchor"></span>

这个「间」，是间隔的意思。「告子见一个性在内，见一个物在外，便见他于性有未透彻处。」

无善无恶心之体，叫心之本体。但人性本善，又是孟子的原则。人性本善的根源在哪里？根源于情感。人性本善，在孟子那里其实是人心本善。

<span id="p-60-009" class="reading-anchor"></span>

心是什么？善端。心自己不分善恶，心之本体不分善恶，但心体一旦应事——物者事也——就会有区分：或在善端之中，或离开善端。人要恢复自己本来的人性，这个恢复叫复性功夫。

<span id="p-60-010" class="reading-anchor"></span>

复性功夫在哪里做？不是在内做，在外面做。所以人性与外物本无间隔。

这是个大讨论，到现在还在争论：人性究竟是善的，还是……讲人性本善也罢，本恶也罢，若脱离物、脱离事情，就人性自己而言，永远讲不清楚。

<span id="p-60-011" class="reading-anchor"></span>

告子干脆说无善无不善，就人性是中性的。他也是因为把外物跟心分开了，一个内，一个外了。而孟子讲人性本善，是不分性在内、物在外，这种间隔是没有的。于是人性怎么体现的？就在应事中体现。

## 应事时怎样体现人性

**回看 05:49—10:00**

<span id="p-60-012" class="reading-anchor"></span>

这种应事呢，有可能偏离人性，那就是恶了。如果在人性中，那便是善的。所以我们要做的是一个功夫，不要偏离，在应事的时候不要偏离人性，因为人性本是善的。尽心便知人性，所以性、人性要归为什么？人心来说。

<span id="p-60-013" class="reading-anchor"></span>

阳明四句教第一句呢，「无善无恶心之体」。这只是就未应事而言，我们别讨论善恶了，但是一旦应事就有善有恶。然后呢要有一个功夫下，那就是良知，知善知恶了。能知善恶的良知。然后让良知实现是什么？格物。

<span id="p-60-014" class="reading-anchor"></span>

这样呢，就能借助这一节的讨论来理解四句教，这样就坚定了一点，人不要把自己跟外部世界隔开，然后再说如何统一。不要分主观世界、客观世界，客观世界好像跟人性没关系。如果跟人性没关系，人性如何实现呢？人性不就实现在世界中吗？

<span id="p-60-015" class="reading-anchor"></span>

离开这个物，离开这个人世间，谈人性就是空的。所以这是一个人生的最高目标，让自己的一生成为人性的实现。人性的实现就是人在做事情当中，此心纯乎天理之极，那就是至善。这样达到人性与物本来的统一，它本无间隔。

<span id="p-60-016" class="reading-anchor"></span>

所以人活在这世界上，就是把世界做成人的世界，本来也没世界。良知是造化的精灵。我们从良知，我们在做事中致良知，这天地万物就有了，就跟人性统一。这是心学讲的最高理想，也是我们人生的信仰的基础。

<span id="p-60-017" class="reading-anchor"></span>

这样就算讲完了。当然还有许多内容，各位自己经常看，有些内容自己去读。读了之后，把我们的生命感受和生活经历放进去体会，这就是从心体上领会天理。

## 本讲总结｜整理附录

本讲从看似毫厘的差别展开：一个只求把心固定不动，一个在集义中使心自然无可动。浩然之气由此被说明为充满而活泼的力量。

后半讲保留人性善恶的追问，再以未应事、应事和格物贯通四句教。最后把课程落回自己的生命感受和生活经历，继续体会经典。
