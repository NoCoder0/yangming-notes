# 第24讲 毁不灭性

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—15:58

**阅读导引｜整理附录**　陆澄接到儿子病危的家信，是本讲全部讨论的起点。正文逐步辨别忧患与有所忧患，解释「毁不灭性」，再比较儒、道、佛面对亲人死亡的不同方式。阅读时应保留「自是至情」与中和之间的联系。

## 一分钟速读｜整理附录

1. 人生重大变故被视为养心功夫真正需要用上的时刻。
2. 父之爱子是至情，课堂没有否定悲伤本身。
3. 「有所忧患」被解释为受到具体对象的束缚，无法走出。
4. 毁不灭性、无以死伤生，要求生者继续承担人生责任。
5. 庄子鼓盆而歌与佛家超度的讨论，保留各自的思想角度。

## 陆澄接到家信

**回看 00:00—02:48**

<span id="p-24-001" class="reading-anchor"></span>

我们还在课程的第四部分，现在接着来讲第十条。我们打开书，找到《陆澄录》的第二十七节。当年陆澄追随着阳明先生，阳明先生为官，陆澄就伴随其左右，住在这个衙门里边。有一天接到家信了，信中说陆澄的儿子病危。

<span id="p-24-002" class="reading-anchor"></span>

接到这个家信，我们看二十七节里边说，就陆澄「心甚忧闷，不能堪」。这是人之常情。他的儿子面对这个死亡的威胁了，阳明知道了这件事，就跟他这么说，「此时正宜用功，若此时放过，闲时讲学何用？」平时我们一直都在讲学，讲学是为了下养心的功夫。

<span id="p-24-003" class="reading-anchor"></span>

而你遇到这件事了，儿子病危的事了，这正是用功的时候，就是下功夫的时候，「人正要在此等时磨练」。我们看阳明怎么跟他讲，在这样的一种情况下，如何用功呢？

<span id="p-24-004" class="reading-anchor"></span>

「父之爱子，自是至情」，当然是人类最高的情感。「然天理亦自有个中和处」，人的生命情感的本真就是天理，天理本是中和的，也就是儒家强调的过犹不及。一旦过了就是私意。「人于此处多认做天理当忧，则一向忧苦，不知已是有所忧患不得其正。」

## 忧患和有所忧患

**回看 02:48—07:24**

<span id="p-24-005" class="reading-anchor"></span>

这「有所忧患不得其正」是引用了《大学》中的话。我们先看一看注释二，说这句话语出《大学》。底下引用了比较完整的段落，「所谓修身在正其心者，身有所忿懥，则不得其正；有所恐惧，则不得其正；有所好乐，则不得其正；有所忧患，则不得其正。」

<span id="p-24-006" class="reading-anchor"></span>

《大学》中这样几句话究竟何意？难道我们就不能忿懥，不能恐惧，不能好乐，不能忧患吗？不能误解了啊。就像我们都记得孟子说过那句话，「生于忧患，死于安乐」。这样看来，《大学》的话跟孟子的话矛盾了。

<span id="p-24-007" class="reading-anchor"></span>

孟子说，在忧患中好啊，我们才有生命的力量。我们在长长久久的安乐中慢慢也就死了。孟子是这层意思。《大学》偏却要说「有所忧患则不得其正」，而这里阳明又引用了。这时候的陆澄忧闷了，人之常情，阳明不会否定的，自是至情。

我们就要讨论一下，引用的《大学》所说「有所忧患」和孟子所说「生于忧患」，区别在哪里？

<span id="p-24-008" class="reading-anchor"></span>

阅读哲学的经典文本有一个好处，至少提高了我们用词的准确性。在「忧患」前面加「有所」，这个忧患是有具体对象的。这种有所忧患意味着什么？被这个对象控制住了，被它所支配了。

<span id="p-24-009" class="reading-anchor"></span>

我们可以忧患，但不是因为具体对象。总是〔[听辨待核 1](#editorial-note-1)〕因为具体对象让我们忧患，我们可以摆脱对象对我们的束缚。若我们仍然忧患，此忧患就是圣人的情感。如忧天下，并不是忧一个具体的东西。

<span id="p-24-010" class="reading-anchor"></span>

就像范仲淹在《岳阳楼记》里这样说，做一个君子是怎样的？「居庙堂之高，则忧其民；处江湖之远，则忧其君。是进亦忧，退亦忧。」问何时而乐耶？「先天下之忧而忧，后天下之乐而乐。」这是天下关怀。

不是被某一个具体的对象所束缚的那种忧，或者被具体的对象所束缚的那种乐。

<span id="p-24-011" class="reading-anchor"></span>

离了这对象就乐不了，那才叫「有所好乐，则不得其正」。关键是「有所」二字，用上去了，便说这样的忧患是不正的了。这层意思呢，其实佛教也明白，特别禅宗讲的叫执念。执了一份喜悦之念，也是执念，叫有所好乐；执了一份愤怒之念，也是有所忿懥，也是执念。

<span id="p-24-012" class="reading-anchor"></span>

执了一份忧患的念，因为这个念是因某件事而起，某一个对象而起，那么也是执念。有忧患正常，人之常情，但从中总走不出来，那叫不正。想一想是不是这个理？

## 毁不灭性

**回看 07:24—12:35**

<span id="p-24-013" class="reading-anchor"></span>

在生活中，我们会遇到这样的人，比如说深爱着自己的父母，后来父母走了，这是无可挽回的，天天流泪。这是真实的，不用虚构啊。有的人就这样，他的母亲一走，他的生活就全乱了，做任何事情都没心思了。当然是深爱着母亲，也表现出他对母爱的深深的依恋。

这种情况就是过了。

<span id="p-24-014" class="reading-anchor"></span>

中国人后来就强调这一点，儒家讨论生死的问题要比道家要多。儒家最初起源于什么？丧葬的仪式的执行者。所以儒家的思想在中国老百姓当中，后来每每表达出这样一种安慰别人的话，某人的亲人去世了，我们会跟他讲，节哀顺变。

<span id="p-24-015" class="reading-anchor"></span>

「节」就是节制，就不要过。亲人的死亡是难以避免的，「变」，变故，要顺。节哀顺变这个词就这么来。当然说起来容易一点，做起来很难，因为这是身在此哀之中的人。阳明说，此时正是用功的时候。

<span id="p-24-016" class="reading-anchor"></span>

我们再看下去，阳明说，「大抵七情所感」，我们中国人不是说七情六欲吗？「七情所感，多只是过，少不及者」。情感上来，我们大多数情况是什么？过分强烈。「才过，便非心之本体」，就偏离了心之本体了。「必须调停适中始得」，才对。

<span id="p-24-017" class="reading-anchor"></span>

「就如父母之丧」，父母亲去世了，「人子岂不欲一哭便死，方快于心？」爱着自己父母的孩子，恨不得自己也跟着死了。中国儒家的一部书叫《孝经》，《孝经》当中有「丧亲」这一篇，阳明就引用了，叫「毁不灭性」。

<span id="p-24-018" class="reading-anchor"></span>

我们看注释三，《孝经·丧亲篇》，其中有这样的话，「孝子之丧亲也，三日而食」。因为父母亲去世的话，我们真吃不下饭了，但不能老不吃，不能就此绝食了。三日而食，三天之后得吃东西了。这就是「教民」，教导民众，「无以死伤生，毁不灭性，此圣人之政也」。

<span id="p-24-019" class="reading-anchor"></span>

这里用了一个政治的「政」，其实是通那个字，政就是正。亲人已经走了，活着的人还在继续生活，走他下面的人生道路，应负的责任还得承担。不能一毁了之。这样的一毁了之是什么？违背了人性呢。所以要毁不灭性。

<span id="p-24-020" class="reading-anchor"></span>

亲人走了，是生命当中的一次重大的灾祸，灾难吧，算是毁了，但是不灭性。「无以死伤生」，死者已去，生者还得继续生。这样一个讨论，恰是在陆澄接到家信之后，阳明跟他说的一番话，这番话实际上很重要。

<span id="p-24-021" class="reading-anchor"></span>

每个人都难免，总有自己的亲人，亲人总有走的时候。怎么面对人生这样的重大变故？一个合适的态度来自我们生命情感的本质，不能偏离，不能过，继续走自己的人生道路。该承担的责任要继续承担好，对未来仍然要有信心。这儒家的态度。

## 儒、道、佛怎样看待生离死别

**回看 12:35—15:58**

<span id="p-24-022" class="reading-anchor"></span>

那么道家有道家的，最典型的庄子，认为要顺应天道。庄子的妻子走了，死了，他后来鼓盆而歌。不是说妻子死会让他高兴的，不是。鼓盆而歌，歌的是什么？天道。

<span id="p-24-023" class="reading-anchor"></span>

他就跟他的友人惠施这么讲。惠施前来吊唁了，发现庄子不但没有哭，还在那里唱歌呢，这惠施受不了的，跟庄子说，你不哭倒也罢了啊，你还唱什么歌呢？庄子就如实说，说他妻子刚走的时候，他也十分的难过。

<span id="p-24-024" class="reading-anchor"></span>

但是后来一想，他本来也没有这个妻子，妻子原本也未出生，就像我们所有的人都一样。慢慢地气聚集起来，聚气成形。有了身体，那么它也要变化，慢慢地这个形也就解体了吧，然后最后气也没了呀。这不就是天道吗？庄子这么一说。

<span id="p-24-025" class="reading-anchor"></span>

这个说法呢，是跟儒家的角度有不同。儒家讲的是人固然必有一死，但是还活着的亲人该怎么看这件事？要在本真的生命情感之中，要中和，来强调过犹不及。而道家的角度呢，顺应天道，过分难过是人为的，来自人自己的因素，那就是我们的烦恼、麻烦的来源。

<span id="p-24-026" class="reading-anchor"></span>

这是讲了一件重要的事，关键是四个字，「毁不灭性」。毁不灭性的意思就是什么？无以死伤生。后来来了佛家，让中国人获得一种方法，得到宽慰，那就在寺庙里做佛事。做佛事帮助死去的亲人超度，在心灵中也得莫大的安慰。

<span id="p-24-027" class="reading-anchor"></span>

就儒、道、佛三家，让我们怎么面对亲人的死亡这样人生难以避免的大事。养心的功夫时时要做，特别是在人生关键的时候要做，正是用功的时候到了。如何面对、正视我们不可避免地遇到的人生的苦难？人生最不堪的事情是什么？与亲人的生离死别，这是最不堪的嘛。

今天就到这里。

## 本讲总结｜整理附录

陆澄的忧闷使平时讲学遇到了真实的考验。本讲先区分有情与执念：悲哀、忧患本是人之常情，问题在于是否被困住而失去中和。

「毁不灭性」把讨论落实到失亲之后如何继续生活。随后对比顺应天道与佛事超度，不将三家的立场合并成同一种安慰。
