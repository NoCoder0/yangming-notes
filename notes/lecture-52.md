## 心无恶念，还须存个善念吗

**回看 00:00—04:50**

<span id="p-52-001" class="reading-anchor"></span>

好，各位，我们继续讨论《传习录》指点给我们的养心功夫。现在进入《黄修易录》，一共十一节。我们把书翻到第一节。黄修易也是阳明的弟子，他用文字记录了与阳明先生的对话。

<span id="p-52-002" class="reading-anchor"></span>

我们看第一节。勉叔是黄修易的字。黄勉叔问，「心无恶念时，此心空空荡荡的，不知亦须存个善念否？」就这样一个问题。我们若了解禅宗的修行的原则，恐怕还会记得那句话，就禅宗修行有经验的人说的，「无需求真，但须去妄」。

<span id="p-52-003" class="reading-anchor"></span>

禅宗是修心的法门。它说，我们别认为我们要去追求所谓人生的真谛，去发现人生的真谛，这不必求。为什么？本心起来，即能见我们本有的佛性啊。所以修行的功夫不是下在追求真理这件事情上，真理我们本具备的。

<span id="p-52-004" class="reading-anchor"></span>

本心自悟，就是佛了，那叫即心即佛。妨碍本心自悟的是什么？覆盖在本心上的妄念。把妄念除了，我们便在真理中了。与此同理，为什么阳明的意思也是这层意思呢？阳明心学上承孟子。孟子是不是主张人性本善？荀子主张人性本恶。

<span id="p-52-005" class="reading-anchor"></span>

既然人性本善，你要求善吗？你在人的本性中，你便就在善中了嘛，何需求？人性本善，为什么天下会有罪恶呢？罪恶从哪里来？按照禅宗的说法，我们的心用错了。心有两种用法嘛，一种用法用出烦恼，还有一种用法用出智慧。

<span id="p-52-006" class="reading-anchor"></span>

那么禅宗的修行，就改变心的用法，这改变叫转识成智。我们如果被业识所控制了，我们的行为每每就是恶的。业力造成的识，这是佛教的说法。那么按照儒家，良知是我们的本心，是心之本体，也就是说是生命情感的本真。

<span id="p-52-007" class="reading-anchor"></span>

我们人人都有良知，为什么有善有恶呢？人的区分，大人和小人的区分，其实不是本质上的区分。小人把自己弄小了，他守住了自己这个小我，守住了自己与别人的形骸间隔。你的身体是你的身体，我的身体是我的身体。

<span id="p-52-008" class="reading-anchor"></span>

你享受荣华富贵，不等于我享受到了。我还在贫贱之中，我就要追求荣华富贵。这种念头起来，叫躯壳上起念：从我们身体的欲求出发起念。这样就会把人与人分开。分开之后，为了实现自己的欲求，就把人与人本来的关系破坏了。

<span id="p-52-009" class="reading-anchor"></span>

因为每一个人实现自己的愿望，都必须通过与他人在一起。没有一个人单个地活在这世界上。我们只要活在这世界上，一定处在与他人的关系中了。人与人的关系，每一种关系都有人性的价值在其中。由于我们从躯壳上起念的话呢，我们就把这份关系的人性价值给泯灭了，这就是恶的起源。

## 初念与转念

**回看 04:50—07:56**

<span id="p-52-010" class="reading-anchor"></span>

每个人都本有良知，用《大学》的话说，本有明德。比方说就如孟子讲的，见孺子入井，我们初见之时必惊恐而同情，情不自禁要去救孩子。这叫最初的念一定是好的，本就是善的。这叫仁心发动，感通到小孩身上。

<span id="p-52-011" class="reading-anchor"></span>

但千万不可转念。这转念就是从躯壳上起的念，想到什么？若去救这孩子，结果会对自己有利还是不利。由于这样一个考虑发生了，这叫转了念。「初念是圣贤，转念是禽兽。」恶就这么来了。

<span id="p-52-012" class="reading-anchor"></span>

所以跟禅宗的原则一样，阳明也说这样的意思，「既去恶念，便是善念」。为什么便是善念呢？「便复心之本体矣」，就是回归心之本体了，心之本体就是良知啊。「譬如日光被云来遮蔽」，云去，把云驱散了，「云去光已复矣」，阳光自然又照射出来。

<span id="p-52-013" class="reading-anchor"></span>

「若恶念既去，又要存个善念」，这个想法的荒谬，有如「在日光之中添燃一灯」，还要添加一盏灯，没有这件事。道理很简明。养心的功夫提醒我们，要关注什么？关注哪些念头是躯壳上起念，把它去了。

<span id="p-52-014" class="reading-anchor"></span>

比方说做事情，我们每每自然而然地要求一个有利于自己的结果，这已经是躯壳上起念。开始还不自觉，其实随着事情演变、展开，这件事变成恶了，不是善事，倒是恶事了，自己最初不知道。

<span id="p-52-015" class="reading-anchor"></span>

所以要提醒自己的就是，去做事情，不要问这个结果是否有利于自己。若只为了有利于自己的结果而去做事，做着做着，已不知不觉之间恐怕就在行恶。各位可以自己体会嘛。

## 上半夜想自己，下半夜想别人

**回看 07:56—10:43**

<span id="p-52-016" class="reading-anchor"></span>

尤其是我们今天这样一个资本的时代，市场竞争的时代，我们把市场竞争看成是理所当然的嘛。同样在做这一个行业的事，你要跟同行竞争的。竞争最后导向什么？你采用一切手段，来达到自己这样一个商业目的。

<span id="p-52-017" class="reading-anchor"></span>

在这种过程中，本来想做一件有益于社会的事——商业有理由存在，是因为社会需要——做着做着却变成恶。细想想，这类事还少吗？都在于那个恶念未能发现、未能除掉。

<span id="p-52-018" class="reading-anchor"></span>

有儒家这个精神很重要。我们别把儒家看成是一种高头讲章，跟我们不断地进行道德教诲，迂腐之论，不对。别的不说，我就想起胡雪岩呢。高阳不是写了小说吗？叫《红顶商人》，讲的就是胡雪岩吧。

<span id="p-52-019" class="reading-anchor"></span>

胡雪岩做生意。他总有一句话这么说，做生意的人会考虑自己的，没错，「上半夜想想自己，下半夜想想别人」，这很重要。上半夜想想自己，是非想不可的了。因为比方说你这个企业就得生存，生存就得有利润，这叫想想自己。

<span id="p-52-020" class="reading-anchor"></span>

下半夜想想别人。别人就是我的竞争对手吗？不，我们在这同一个行业中，想想别人，也就是说让这行业继续存在。那叫要与竞争对手共生啊，这个道理。

<span id="p-52-021" class="reading-anchor"></span>

所以我们要警觉的，就是我们的念，从心体上还是从躯壳上起念。拿这个分别来判断，我们的念是恶的还是非恶的。如果它不是恶的，它一定就是善的了。那么什么是恶的？从躯壳上起的念，从小我的得失考虑起的念。好，就到这里。

## 本讲总结｜整理附录

性善与良知本有，是本讲解释「既去恶念，便是善念」的基础。禅宗去妄、转识成智与儒家的去恶在课堂中被并列讨论，不能只剩一个保持积极心态的结论。

后半讲具体说明转念如何发生：关切事情，逐渐变成只问结果是否有利于自己。胡雪岩的说法把思考推进到企业生存与同行共生的关系。
