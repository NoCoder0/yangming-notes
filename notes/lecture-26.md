# 第26讲 人生如走路，走得一段方认得一段

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—09:31

**阅读导引｜整理附录**　陆澄担心尚未了解天理人欲，便无从克己。阳明以走路作比喻，让问题转向实际用功。本讲的后半段由此讨论孩子的弯路、犯错与父母怎样给予帮助。

## 一分钟速读｜整理附录

1. 陆澄问的是判断尚不完备时，克己如何可能。
2. 真实切己、用功不已，使天理精微与私欲细微逐渐被看见。
3. 走得一段，方认得一段；有疑便问，问后继续走。
4. 人生经验不能由上一代预先全部交付给下一代。
5. 挫败之后的改过、鼓舞与指点，同童年培根相联系。

## 陆澄问如何用得克己功夫

**回看 00:00—03:03**

<span id="p-26-001" class="reading-anchor"></span>

我们继续在阳明的《传习录》中讲养心功夫。《陆澄录》的第四十八节，先是陆澄提这样一个问题，在四十八节里，「知至，然后可以言诚意。」否则意如何诚呢？「今天理人欲，知之未尽」，还没有完全搞清楚呢，「如何用得克己功夫」？

<span id="p-26-002" class="reading-anchor"></span>

标准在哪里呢？我怎么知道我这份意是被我诚好了呢？那我先得了解天理人欲吧，要了解得完备了吧。现在没了解完备呢，又怎么下克己的功夫呢？这问得也很真切。

<span id="p-26-003" class="reading-anchor"></span>

阳明回答，「人若真实切己，用功不已，则于此心天理之精微，日见一日。」我们每天要下功夫，不停下来。真实切己用功，就是领会自己的心，本心，心体。这样呢，此心不是跟天理一致的吗？则于此心本有的天理之精微。天理没写在天空上让我们去认识它，在我们心里，心即理。

<span id="p-26-004" class="reading-anchor"></span>

所以每天下真实切己的功夫，此心天理的精微处啊，每天都会看得比前一天更清楚了，「日见一日」。「私欲之细微」呢，也同时「日见一日」。这话说得是很真实的，有时候我们的那些私意呀，真是我们毫无觉察，就在我们心里来了。你还辨别不到，辨别不出呢，它就会出问题。

它会长，就像萌芽会长，长到一定程度已经不行了。

<span id="p-26-005" class="reading-anchor"></span>

这要求真是蛮高的。「若不用克己功夫，终日只是说话而已，天理终不自见。」你怎么见天理啊？心即理嘛，你在养心上用功夫嘛。天理不见，私欲也不见，就没发现自己的私欲，它已经在那里，却无法觉察。

## 走得一段，方认得一段

**回看 03:03—05:55**

<span id="p-26-006" class="reading-anchor"></span>

然后做了一个比方，这比方非常好。「如人走路一般，走得一段，方认得一段。走到歧路时，有疑便问，问了又走，方渐能到得欲到之处。」

<span id="p-26-007" class="reading-anchor"></span>

这话特别有意思，就他的这个比方，其实在比方人生啊。人生有如走路，走一段，认得一段。所谓走一段，这么一段我们过来了，知道了，知道了。我们还在往前走，会走到歧路的，该往哪里走？不知道了。这种情况下，需要得到人的指点。

<span id="p-26-008" class="reading-anchor"></span>

比方说他们那些弟子就得到王阳明指点。我们如果找不到人指点，没有良师益友的指点，我们还得看书。来自己检查，该往哪里走，问啊，有疑便问啊。问了又走，继续往前走，这样慢慢地就能到得欲到之处。这欲到之处，就我们的生命情感达到了至善。

<span id="p-26-009" class="reading-anchor"></span>

那么由此引申出来的一层意思，就是人生得自己经历。不是任何人，或你的高明的父母，或你遇到的学校里高明的老师，可以把人生的所有经验都预先教给你的，这是不可能的事。教给你，你也没用。

<span id="p-26-010" class="reading-anchor"></span>

我们为人父母的爱自己的孩子，总怕他走弯路，是不是这样？所以把自己积累的人生经验，急急忙忙地全要给他的，让他记住，以免走了弯路。这种想法很真诚，但太天真，肯定天真。

<span id="p-26-011" class="reading-anchor"></span>

如果按这种想法的逻辑推演下去，一代人把他的人生经验教给了下一代。下一代人呢，又把自己的人生经验，加上上一代的经验，又传给再下一代。最后这一个再下一代，一出来就是个人精。这是不可能的。为人父母，我们可能吗？

## 跌倒以后，再爬起来

**回看 05:55—09:31**

<span id="p-26-012" class="reading-anchor"></span>

所以，痴心的父母们，让孩子自己走路，他会跌倒的，跌倒了再爬起来。走到歧路，他自然会问。问明白了，继续走，走了还会跌倒，是吗？哪里跌倒，哪里爬起来。正如惠能在《坛经》里边，惠能不是讲吗？在家修行的十个要点，其中有一个要点叫什么？改过生智呀。

<span id="p-26-013" class="reading-anchor"></span>

智慧哪里来？虽然我们慧根会有深浅不同，但是慧根很深的人也会有过错。有了过错以后，这个慧根才发挥作用，叫生智了。没有不跌倒的，没有不犯过错的，没有不受到挫败的。关键在于能改。换句话说，跌倒了，能爬起来。就不要跌倒了就在地上不动了，那么没智慧。

<span id="p-26-014" class="reading-anchor"></span>

阳明就鼓舞了陆澄了。你不要先把天理人欲都全了解了，才谈得上下功夫。不是的，就在下功夫当中了解了，包括自己的许多过错，种种的妄念、私心杂念全有过，有时候过错还很大，能改就是起来了。

<span id="p-26-015" class="reading-anchor"></span>

中国人有一句话说得是对的，「浪子回头金不换」。不要怕你的孩子有一段浪子的阶段，只是你能提醒他，当他在浪子阶段中遇到痛苦了，你告诉他看什么书，他自然也就去看了。叫有疑便问了，是吗？

<span id="p-26-016" class="reading-anchor"></span>

所以我们为人父母的不要天真，不要想象自己的孩子在人生的道路上没有挫折、不摔跤，不要这么想。他可以摔，只是你要鼓舞他。你不能说孩子犯了过错，你就狠狠地只知道责骂他、否定他。这不对，是帮助他。

<span id="p-26-017" class="reading-anchor"></span>

这时候你的人生智慧才到发挥用处的时候，不是预先给他的。到这时候你来启发他，这就是对的，这是父母的责任。自己不行，另请高明，叫「易子而教」。「易」就是交换。把这个孩子在关键的时候叫别人指点一下。自己恐怕也不行。

<span id="p-26-018" class="reading-anchor"></span>

那么这种情况下，我们就不用害怕孩子走了弯路，遇到了挫折。也不要随便否定他，他在这个阶段上的想法恐怕就是很奇怪，按照你的常理看来不能这样。不能这样，也得让他经历一下。

<span id="p-26-019" class="reading-anchor"></span>

当然一开始培根很重要的。培根让根扎得深，人就正了，正了以后再遇到挫折，他也能解决问题。所以童年的教育，儿童教育是根本。我们的这一段课就先讲到这里。

## 本讲总结｜整理附录

用功与认识不是彼此等待的两件事。正是在切己的实际功夫中，我们才越来越认识自己，辨明原先没有觉察的私欲。

走路的比喻把这一点带到人生与教育。父母不能代走全部路程，但可以在孩子跌倒、困惑时帮助其改过、继续前行；童年培根仍是结尾强调的根本。
