## 日常生活里为什么要养心

**回看 00:00—03:52**

<span id="p-44-001" class="reading-anchor"></span>

我们在这个课程的第四部分是讲养心的功夫，一条一条讲。因为《传习录》就是讨论得比较细致，养心的功夫在日常生活中养。那么为什么会有养心的功夫要下？因为我们的心经常会乱，我们的情感经常有闲思杂虑。闲思杂虑之后呢，我们就每每会遮蔽我们的心之本体。

<span id="p-44-002" class="reading-anchor"></span>

这样做事情只是应付应对，或谋自己的私欲的实现，这就不能成为道德自觉的主体。整个社会，所有的中国人，都能成为独立的人格、道德自觉的主体，这并不是很高的要求。这是一个正常、健康的民族应当达到的。

<span id="p-44-003" class="reading-anchor"></span>

你开烟杂店就开烟杂店，为周遭的居民服务，来立一个诚字。无论干哪一行，都应当如此。这样这个民族才有它光明的未来。马路上不是三句话嘛，经常写在墙上的那个标语，叫「人民有信仰，国家有力量，民族有希望」。前提就是信仰。国家的力量扎根于人民的信仰中。

<span id="p-44-004" class="reading-anchor"></span>

而中国人的信仰，以本心立信仰，不是以上帝立信仰，也不是以真主立信仰。所以我们聚集在一起，一起讲读《传习录》，也就是我们在我们这一代人身上，能否立我们的信仰？这代表中国的未来。

<span id="p-44-005" class="reading-anchor"></span>

那么如何立呢？我们不在宗教信仰中。我们也没有星期天到教堂做礼拜，我们也没有固定的祷告，饭前祷告、睡前祷告。我们也不是定时地去做忏悔，这是宗教徒的事。但是我们要做我们中国人的事，时时地省察我们的生命情感，这叫养心的功夫。《传习录》讲得很仔细、很真切。我们就跟着《传习录》来一条一条讲。

<span id="p-44-006" class="reading-anchor"></span>

第二十七条的讨论，我们要见多识广，我们要有越来越丰富的知识，究竟为什么？我们需要知道那么多吗？不需要。但凡我们有所闻、有所见，都是为了什么？为了我们做事情，让这件事情成为良知的呈现、天理的实现。这样我们就保持在人的世界这个水平上，而不是往下掉。

<span id="p-44-007" class="reading-anchor"></span>

这对每一个人的生活都是真切的。我们不希望生活在一个人欲横流的社会，我们也不希望生活在一个他人之道德底线随时可能被突破的社会里边。所以这就是一个大事情，兹事体大。先立其大者，这个大者是什么？本心，这才叫大。大到什么程度？与天地山河同。

## 黄以方问一节之知与全体之知

**回看 03:52—09:49**

<span id="p-44-008" class="reading-anchor"></span>

现在讲第二十八条，进入《黄直录》。黄直字以方，所以《传习录》下卷还有一篇叫《黄以方录》，其实就是黄直，他留下了两个录。

这个《黄直录》共十五节。我们把课程所用版本的《传习录》打开，找到《黄直录》第一节。

<span id="p-44-009" class="reading-anchor"></span>

我们曾经引用过王阳明那句话，「人心是天、渊。心之本体无所不该」，源出于《黄直录》。我们先看黄以方提了怎样的问题，也就是黄直，阳明的弟子。他也考中了进士的，但是后来因为上书表示对朝廷的某项政策的反对，所以后来就下狱。出狱之后，他也就不做官了。这样一个黄直，阳明的一个很好的弟子。

<span id="p-44-010" class="reading-anchor"></span>

黄直问先生，「先生格致之说」。你阳明对格物致知有新的说法，跟朱熹不一样。「随时格物以致其知，则知是一节之知，非全体之知也。」

<span id="p-44-011" class="reading-anchor"></span>

你阳明说随时格物。我们都知道，阳明讲的格物不是观察事物吧，是做事，把事情做对了。格者正也，物者事也。我们随时都在做事，我们要把做事都当成什么？格物，就把事做对了。

<span id="p-44-012" class="reading-anchor"></span>

我们平时格物吗？恐怕很少。我们就这件事要把它做完，要达到一个预期的结果，无非如此做事了，岂有它哉？所以从未格物过。所以阳明提出要随时格物，也就在我们所做的事情中采取格物的态度。

<span id="p-44-013" class="reading-anchor"></span>

什么叫格物的态度？让我们所做的事情成为天理的实现。「正事」，我解释过，不是「正确的事」。世界上的事情，要区分正确的事还是错误的事，还难有标准呢；遇到事就得做。

什么叫正确和错误？不在于外在的标准，而在于我们的内心把事做对了。这叫格物的功夫，把做事变成什么？正事。

<span id="p-44-014" class="reading-anchor"></span>

这跟禅宗的想法一样的，把世法做成佛法。你可以炒股，也是做事，把炒股变成格物，可以吧？你就这样想，就明白了阳明什么意思。把炒股这件事做对了，让炒股这件事也成为天理的实现，就是帮助祖国建设。这叫随时格物。否则哪有随时格物的事？叫随时做事罢了，随时做事，你始终如此。

<span id="p-44-015" class="reading-anchor"></span>

各位来听课也是做事，我讲课也是做事。那么我要把这事做对了，怎么叫做对了？我就是阳明心学的传声筒，不要传错了。然后我们教学相长，学不是被动地接受。读书也是格物。

<span id="p-44-016" class="reading-anchor"></span>

我们上次还讨论到，生病了怎么办？格病物，把生病这件事做对了。怎么做对了？常快活。病来了能常快活吗？能。你只要不脱离心之本体，因为心之本体本就是乐的，乐是心之本体。

<span id="p-44-017" class="reading-anchor"></span>

所以你遇到了疾病这样的困扰，你仍然不脱离心之本体，你还是乐的。这用毛主席的话说，叫革命的乐观主义。我们今天还有此精神吗？一旦生了病就不得了了，萎靡不振，求神拜佛，low，太 low 了。你看我们现在习惯的用词，low，就这样。

## 人心是天、渊

**回看 09:49—14:55**

<span id="p-44-018" class="reading-anchor"></span>

好，我们看黄以方究竟想问啥。格物致知，那么我格此物，也就做此事，得了知。这一知只是什么？一节，并非全体呀。既然如此，如何可以达到如《中庸》中的话呢？「溥博如天，渊泉如渊」。

<span id="p-44-019" class="reading-anchor"></span>

天之广大叫溥博，「溥」就是广大的意思。后来那个皇帝叫什么？溥仪，大概也是广大的意思了。溥博如天，天之广博吧。渊泉如渊，渊泉就如其深一样地深。能达到这种境界吗？我们平时不就在做此事彼事吗？此事彼事能够致知，此知也亦只是一节之知，如何能够如天、渊呢？

<span id="p-44-020" class="reading-anchor"></span>

阳明说了，天、渊在哪里？人心嘛。「人心是天、渊。」天之高远，泉之深沉，一个叫天，一个叫渊。「心之本体无所不该」，这个「该」不是情态动词，不是「应当」。是什么？涵盖，无所不涵盖，「原是一个天」。

<span id="p-44-021" class="reading-anchor"></span>

「只为私欲障碍」，那小我之欲障碍，「则天之本体失了」，也就是我们通常所谓心胸狭窄。心胸为什么会狭窄呢？是自己弄成的。心本来大，「心之本体无所不该」，本来大，自己弄小了。不是有人天生就是心胸狭窄的，没有。我们大概忘了，孩提时代，天真烂漫，淳淳朴朴，这个童心其实很大。现在长大了，就心胸小了，因为私欲障碍。

<span id="p-44-022" class="reading-anchor"></span>

我现在依稀还能回忆，小时候真是很好。昨天晚上还被父亲冤枉了一次，责骂了一场。早晨一醒，就想到今天要去读书，还有音乐课、两节音乐课，欢天喜地地起床。

昨天那个所谓委屈，早已丢到爪哇国里去了。成年人做不到，耿耿于怀。

<span id="p-44-023" class="reading-anchor"></span>

各位肯定也能回忆自己的孩提时代，生活未必舒适，环境未必很好，还会有小小的挫折之类的，但都无所谓的。童心就是这样。我们度过了比较幸福的童年，那个时代。今天的儿童就不是如此了。这个时代的变化，心胸极其狭窄的父母，把自己的孩子弄得也一样地狭窄起来，是吗？

<span id="p-44-024" class="reading-anchor"></span>

所以阳明说得对，不是说要求大家心胸宽广，本来就宽广。「只为私欲障碍，则天之本体失了。心之理无穷尽，原是一个渊。」心中的理就是天理，它本是映在所有的事物上的。

<span id="p-44-025" class="reading-anchor"></span>

就像陆九渊讲的是吧，「万物森然于方寸间」，满心而发，充塞宇宙。什么东西充塞了宇宙？天理呀。充塞宇宙，无非是理，那就是无穷无尽。就像人世种种的变化，这件事，那件事，新的事物又层出不穷，天理也无穷尽。

<span id="p-44-026" class="reading-anchor"></span>

所以这就是个渊嘛，「原是一个渊」，深渊那个渊。「只为私欲窒塞，则渊之本体失了。」那怎么办？要下功夫了。「如今念念致良知，将此障碍窒塞一齐去尽，则本体已复」，恢复了。儒家下的功夫，都是复性的功夫，不是在养心的功夫中另外添加一些什么本没有的东西，不是。

## 昭昭之天与房子墙壁

**回看 14:55—20:24**

<span id="p-44-027" class="reading-anchor"></span>

底下很形象的说明，「乃指天以示之」。现在就跟弟子们、跟黄直讲，你看我现在手指着天了，「比如面前见天」，是昭昭之天。「四外见天」，四外见天也只是昭昭之天。「只为许多房子墙壁遮蔽，便不见天之全体。」若我们设想一下，「撤去房子墙壁，总是一个天矣」。不可道，也不可这么说，眼前的天是昭昭之天，外面又不是昭昭之天，哪能这么说呢？

<span id="p-44-028" class="reading-anchor"></span>

我们如果没有站在旷野上，而是站在街巷中，街巷有许多房屋，隔出了一个比较小的空间。但你从这个小空间往上看，那个天与你看不到的天，是不是同一个天？同一个天嘛。

不能说我看到的只是一节之知，我只是知了一点点天。没有。此天与室外之天，同是什么？昭昭之天，哪里有差别？

<span id="p-44-029" class="reading-anchor"></span>

比方说呢，你做知县吧。这个「知」什么意思？这个知就是知天的意思。所以中国官的名称有道理的。然后你做再高一点的职位，知府或知州，那比县大了。知县这官，芝麻绿豆官了，小官了。小官归小官，县也是个天，也是人民生活所在的地方嘛。人民生活在哪里，天就在哪里呀，哪有一个一部分和全体的区分？

<span id="p-44-030" class="reading-anchor"></span>

一个知县都做不好的，他由于某种原因，青云直上，到了内阁了，行吗？不行，他本未知过天。你哪怕在一个小地方知过天了，你就是知了天的全体。所以从小要知天，以前怎么知的？学工、学农、学军。什么叫知天？体察人民生活。天道在哪里？在人民生活中嘛。

<span id="p-44-031" class="reading-anchor"></span>

心之本体就是天之全体。所以你去做知县，你用心，叫尽心。你尽了心，也便跟天道一致。不管这个行政区域是大还是小。我们做事情，无论大事小事，天理总是一个。我们有时候做的是细微的小事，不引人注意的，在平凡的岗位上默默地工作，我们就看不起自己了吗？

<span id="p-44-032" class="reading-anchor"></span>

所以我一直讲，复旦大学不培养社会精英的，大家以为是培养社会精英的。复旦大学培养的是民族的脊梁。这个民族的脊梁，是在日常的平凡的工作岗位上，默默无闻地努力，着实地推动民族的进步，就在你身边所谓的小事中。因为他的心是大的，你做小事，心也是大的。小事做了，大事来了也一样做，不用担心。

<span id="p-44-033" class="reading-anchor"></span>

人要有志气嘛，志气从哪里来？从心之本体中发出来。所以阳明说了，贩夫走卒、引车卖浆者流，都要做收拾精神、自作主张的大英雄。凭什么？贩夫走卒的心，也是如天、渊，无所不该。

<span id="p-44-034" class="reading-anchor"></span>

我们这个时代的病症，是职业、行业的高低贵贱分得太清楚。有的人在很高的社会地位上，做看上去很大的事，但他失了心之本体，他就小。有的人做小事、平凡的事，却没有失了心之本体，他就大。

人的自我评价，不在于社会地位的价值等级中居于哪一个层面，这不是自我评价的根据。

## 一节之知即全体之知

**回看 20:24—24:03**

<span id="p-44-035" class="reading-anchor"></span>

所以这一节我们就明白了，我把它概括为心之本体与天地山河同。于是阳明说，「于此便见一节之知即全体之知，全体之知即一节之知，总是一个本体。」

<span id="p-44-036" class="reading-anchor"></span>

总是我们的本心。本心仁体，简称本体。「本体」这个词的意思要明确：体是指仁体，本是指本心，合起来是本心仁体，简称本体。

仁体大不大，如何大？程颢讲：「仁者以天地万物为一体也。」仁心发动，感通万物，这叫仁体。

<span id="p-44-037" class="reading-anchor"></span>

我们学阳明心学，要前后融会贯通，不是一条一条割裂的知识。所谓融会贯通嘛，在孔子的学说的核心观念，「仁」，不得了地大。因为最初启发我们了解孔子这个仁的观念的，就是孟子。「亲亲而仁民」，后面还有一句呢，「仁民而爱物」。

<span id="p-44-038" class="reading-anchor"></span>

物就是天下万物。天下万物，我们如何能去爱呢？你能爱鸟兽吗？你能爱瓦石吗？瓦石无端地被毁坏，我们也会生顾惜之心。这顾惜之心就是仁心发动了，感通到瓦石上去了。于是我们与瓦石为一体了，这个体是仁体。本来我们跟瓦石不是间隔的嘛。

<span id="p-44-039" class="reading-anchor"></span>

祖国的一草一木都是我们所爱的，是吗？推而广之，天下，突破国家的范畴，天下无不是我们所爱的。这叫「明明德于天下」。三纲领第一条纲领跟最后一个条目贯通了。八条目最后一个条目，「天下」嘛。三纲领第一个纲领，「明明德」嘛。

<span id="p-44-040" class="reading-anchor"></span>

从第一纲领到最后一个条目，不就是一句话嘛，明明德于天下。明明德就是本心复起，明德就是本心。到天下，不就是本心仁体嘛？我们总觉得很奇怪，我们的心如何可以跟天一样大呢？养心要养得和天一样大？它本是和天一样大。养心就是去除私欲的障碍，心和天一样大，在我们的生命实践中。

## 百亿集团和清洁工少拿的一百元

**回看 24:03—30:54**

<span id="p-44-041" class="reading-anchor"></span>

我喜欢虚构。假定你是一个百亿集团的董事长，你运作好几百亿资产。有一天你要参加一个重要的商业谈判。这个谈判的结果，将决定你这个集团下一步发展的战略目标、战略决策。你高度重视这个谈判。

<span id="p-44-042" class="reading-anchor"></span>

谈判将在上午九点半举行。此刻已经九点十分了，你还在你的董事长办公室里。你一看表，心里有点慌。你的司机和秘书都在楼底下等你。你夹着一个公文包，匆匆忙忙地从董事长办公室里走出来，心里还担心着路上不要被堵了。

<span id="p-44-043" class="reading-anchor"></span>

你走到走廊里，突然被一个人拦住了。你抬头一望，想起来他是谁，每天在楼道里打扫卫生的清洁工。此刻他拦住你了，假如你姓张，他跟你讲：「张董，我知道你是个大忙人。今天我终于候到你了，有一件事情想要问你。」你问，「什么事？你说。」

<span id="p-44-044" class="reading-anchor"></span>

他说了，「上个月我拿工资的时候少了一百块钱，我不知道为什么扣我这一百块钱。我到财务部门去问过了，财务部门查了一查账，没算错，是扣你一百块。至于为什么扣，我们不知道，你要到人事部门去问。」

<span id="p-44-045" class="reading-anchor"></span>

「于是我又到人事部门去了。人事部门的人翻了资料，说是扣你一百块。为什么扣，居然不告诉我。我想来想去，只能问你张董了，你能不能告诉我为什么扣我这一百块钱呢？」

<span id="p-44-046" class="reading-anchor"></span>

你听到这里，差不多恼怒起来。你心里想，这区区一百块钱算什么？我要去参加那个谈判，牵涉到好几十个亿呢。你在恼怒之中扔下一句话，「这事也不归我管」，然后扬长而去。你的心非常小。

<span id="p-44-047" class="reading-anchor"></span>

假如你不是这样，而是从公文包里掏出笔记本和笔，记下他的名字，记下这件事，很负责任地跟他说：「我一定要把这件事情调查清楚；如果不该扣，一定还给你，而且要向你道歉。」

你就给了他三分钟时间吧。假如这样做，你的心就和天一样大。

<span id="p-44-048" class="reading-anchor"></span>

天包容万物，不仅包容喜马拉雅山，而且还包容喜马拉雅山山脚下一棵无名的小草，也是天所包容的。虽然你运作好几百亿资产，你仍然知道，对一个打扫卫生的清洁工，你每个月最多给他两千多块钱吧。上个月他少了一百块钱，一定影响他的生活，你仍然明白这个道理。

<span id="p-44-049" class="reading-anchor"></span>

一百块钱和几十个亿，这个比较实在是什么？天壤之别。尽管是天壤之别，一百块钱是这个清洁工的柴米油盐。你集好几百亿的资产，说到底无非也是柴米油盐。天道之极致，无非柴米油盐。什么叫心和天一样大？这就是。那一节之知便是全体之知，阳明说得真对，「一节之知即全体之知，全体之知即一节之知，总是一个本体。」

<span id="p-44-050" class="reading-anchor"></span>

学阳明心学，不要进入蹈空之论。「蹈」就是舞蹈的蹈，「空」就是空洞的空。阳明心学不是蹈空之论，落在实处的。心和天一样，但是落在实处的，落在真实的事情中。这就是人生的境界。什么叫大事小事？只要它是事，这小事中便有天。

<span id="p-44-051" class="reading-anchor"></span>

说过来说过去，无非要说一件事：什么叫格物。刚才假想的例子中，那位百亿集团董事长，如果采取第二种态度，而不是扔下一句话扬长而去——很负责任地记下这件事，一定要处理好——这件事很小，一百块钱，但他就在格物，就在正事。格者正也，物者事也。

<span id="p-44-052" class="reading-anchor"></span>

我们这个民族有没有这点精神呢？毛主席说的，一个人的能力有大小，但只要有这一点精神，便是一个高尚的人，一个纯粹的人，一个脱离了低级趣味的人，一个有益于人民的人。我相信毛主席是受到阳明心学影响的，而且还蛮深的。

<span id="p-44-053" class="reading-anchor"></span>

毛主席总说人是要有一点精神的，听说过吧？为什么不讲讲这个精神呢？我们活在这世界上，要有人的尊严，要有灵魂的高贵，才不枉为人一世嘛。所以读这一节我们感慨万千。我们明白了阳明说的话，人心是天、渊，心之本体无所不该，无论大事小事都涵盖了。好，就到这里。

## 本讲总结｜整理附录

黄直从随时做一件件事出发，担心只能得到局部的知。阳明以天、渊和房屋墙壁回答，课堂再把这一回答接到个人经历、知县职责、民族脊梁及仁体感通万物。

清洁工的故事在课堂明确标为虚构。完整的铺陈与两种回应，是本讲把「心与天一样大」落到具体事上的关键：外部事务有大小，良知的实现不按金额或地位分出部分与全体。
