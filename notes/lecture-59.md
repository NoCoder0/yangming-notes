## 良知是造化的精灵

**回看 00:00—01:25**

<span id="p-59-001" class="reading-anchor"></span>

好，各位，我们继续课程的第四部分。我们现在来看第四十三条啊。我们进入《钱德洪录》。钱德洪是阳明的一个重要的弟子，这《钱德洪录》一共五十节。我们现在来看它的第二节，也是实录阳明的原话。「良知是造化的精灵」，这句话是阳明的原话。

<span id="p-59-002" class="reading-anchor"></span>

「这些精灵，生天生地，成鬼成帝，皆从此出，真是与物无对。人若复得他完完全全，无少亏欠」，无稍亏欠，「自不觉手舞足蹈，不知天地间更有何乐可代」。我们这一段先看啊，这第二节看了，然后我们参看《黄以方录》第二十四节。

## 人心与物同体

**回看 01:25—04:04**

<span id="p-59-003" class="reading-anchor"></span>

我们找到《黄以方录》，也就是《传习录》下卷的最后一录。黄以方问，「人心与物同体」，这话看来就是唯心主义。「如吾身原是血气流通的，所以谓之同体。」打个比方说吧，就像我们的身体。

<span id="p-59-004" class="reading-anchor"></span>

身体呢，你可以把它看成是各种器官构成的吧，就好像机器由各种部件构造而成。但有什么？血气流通。器官与器官之间固然有很大的差别。心脏是心脏，它不是肝脏。耳朵是耳朵，不是手。但是把它们贯通起来的，中国人的说法叫血气流通，所以谓之同体。

<span id="p-59-005" class="reading-anchor"></span>

「若于人便异体了，禽兽草木益远矣，而何谓之同体？」说人心与物同体，就自己的身体这件事，还能够理解。但与人不同的呢？比如禽兽怎么办？草木不是更远了吗？人与人也异体，你的身体是你的，我的身体是我的。「而何谓之同体？」

<span id="p-59-006" class="reading-anchor"></span>

阳明说，「你只在感应之几上看」。这个几就是微妙的、虚无的东西。状态。我们上次讨论过这个几。「在感应之几上看，岂但禽兽草木，虽天地也与我同体的，鬼神也与我同体的。」

<span id="p-59-007" class="reading-anchor"></span>

这话一说，黄以方自然要追问吧，「请问」。阳明说了，「你看这个天地中间，甚么是天地的心？」黄以方回答了，「尝闻」，听说过啊，「人是天地的心」。

## 灵明与天地鬼神

**回看 04:04—08:07**

<span id="p-59-008" class="reading-anchor"></span>

那么又问，阳明又问黄以方，「人又甚么教做心呢？」回答说，「只是一个灵明」。回答得都对的啊，黄以方回答都对。「可知充天塞地中间，只有这个灵明。人只为形体自间隔了」，这因为我们身体不同，叫间隔了。

<span id="p-59-009" class="reading-anchor"></span>

「我的灵明，便是天地鬼神的主宰。天没有我的灵明，谁去仰他高？地没有我的灵明，谁去俯他深？鬼神没有我的灵明，谁去辨他吉凶灾祥？天地鬼神万物离却我的灵明，便没有天地鬼神万物了。我的灵明离却天地鬼神万物，亦没有我的灵明。」

<span id="p-59-010" class="reading-anchor"></span>

「如此便是一气流通的，如何与他间隔得？」这又引起黄以方的追问：「天地鬼神万物，千古见在」，自古以来不都有吗？「何没了我的灵明，便俱无了？」唯物主义的反驳。

<span id="p-59-011" class="reading-anchor"></span>

阳明怎么回应？你就看死去的人，「今看死的人，他这些精灵游散了」。「他的天地鬼神万物尚在何处呢？」不也就没了嘛。能不能接受阳明这个回应？各位想一想。

<span id="p-59-012" class="reading-anchor"></span>

看来朴素的唯物主义信念啊，通常我们都有，只是不知道这叫唯物主义。中国人没有这个概念，唯心主义、唯物主义，没的。但是有一种基本信念。什么信念呢？天地万物没有人，它也在，这一点大家不怀疑。

<span id="p-59-013" class="reading-anchor"></span>

我们还追溯宇宙的历史、太阳系的起源。这时候哪有人？要知道，太阳系为什么会称为太阳系？哪有人？没人，什么叫太阳系、银河系、地球、月亮？没有。你说它还在，物质而已，等于什么都没说。

<span id="p-59-014" class="reading-anchor"></span>

你说宇宙万物，可以的。万物都因人心而有。「天没有我的灵明，谁去仰他高？」它的意义在哪里？我们区分了天和地吧。「没有我的灵明，谁去俯他深？」鬼神没有我的灵明，我们谈得上什么吉凶灾祥之类的事吗？

<span id="p-59-015" class="reading-anchor"></span>

因为有吉凶灾祥之类的事，我们说有鬼神了。因为这种吉和凶、灾和祥，无法说明原因的，不是用自然科学能说明的。自然科学的因果关系是直接的，手推杯子倒。现在这个事情来了，某人莫名其妙生病了，或者生活中莫名其妙那个灾来了，绝不是他犯了认识的错误。

怎么办？人就想到有鬼神了，全是人设的。

## 没有人的宇宙，也是人在说

**回看 08:07—12:36**

<span id="p-59-016" class="reading-anchor"></span>

两节参照着读来细细体会，人有时候就是这样的自相矛盾。人说有一个宇宙，然后说这个宇宙呢，还有它的历史。过去、现在，往前追溯啊，最后说宇宙大爆炸学说，那不就是霍金讲嘛？

<span id="p-59-017" class="reading-anchor"></span>

然后就是说那个大爆炸呢，我们也可以倒推的。但我们发现天体、星体都在离开这个地球远去，那么你把它倒过来，不是不断地接近吗？最后就是一点了，它是爆炸，黑洞理论全来了。

<span id="p-59-018" class="reading-anchor"></span>

全是人在玩这个东西，这点要想明白。我们当然可以讨论没有人的宇宙，偏偏是人在说这个宇宙。也可以不说西方人讲的宇宙，可以说中国人讲的天地造化，不同的讲法。

总而言之，要有人这个灵明在，才能谈得上没有人的自然界是怎么样的。

<span id="p-59-019" class="reading-anchor"></span>

关于没有人存在的自然界是怎么样的，还是人心去规定的。你把人心拿掉，哪有天和地，是吗？所以天地万物鬼神，都离不了人的那一点灵明。这一点灵明就是我们的心。人为天地立心。

<span id="p-59-020" class="reading-anchor"></span>

所以张载说了。什么叫论道的学问？为天地立心，为生民立命。立心立好了，天地的意义来了。天地万物的意义，在人的心灵中立起来，也在人的言说中表达了。不是那些词来了吗？鬼呀、神哪、天哪、地呀等等的都来。语言来自哪里？人心啊。

<span id="p-59-021" class="reading-anchor"></span>

于是所谓世界万物、天地万物，于是所谓天地有一个尚未有人的过去，也这么说了。否则都没办法说，这个世界就是无法言说的。一旦世界因言说而有，也就是因人心规定而有，把人心规定、把言说拿掉，哪有世界？

<span id="p-59-022" class="reading-anchor"></span>

所以动物是没有世界的。动物恰好是处在它所处的物质环境里了，它被绑在一个物质环境里了。这个环境是我们懂的，它不懂的，不是一个世界。人才有一个世界，动物只是恰好被绑在它所在的环境里。而人却有大地、山川、星辰、河流，向人呈现。

<span id="p-59-023" class="reading-anchor"></span>

我们在比喻的意义上说，动物也有世界，所以那个片子叫《动物世界》。这个动物世界其实是人规定的，这个动物世界是人造的，人心所设定的，动物自己没世界的。蚂蚁终生在土地上走，爬来爬去，从这个蚂蚁穴爬出去找东西，然后回来了，就这样。

<span id="p-59-024" class="reading-anchor"></span>

企鹅在南极，就在南极。我们却有南极、北极。我们不是说区分了嘛，还有赤道。还有地球之外的太阳系的其他行星，太阳系之外还有银河系，全人心说出来的。那当然是西方天文学，那么我们中国人也有自己的天文学，中国的星宿学，全人心的。

## 复得良知，手舞足蹈

**回看 12:36—15:40**

<span id="p-59-025" class="reading-anchor"></span>

好，讲了这些，回过来看：良知是造化的精灵。这一点灵明之本体就是良知。所以，我们的心很了不得。心之本体，这个良知，生天生地，成鬼成帝，皆从此出，真是与物无对。

不是与物相对待，不是有一个主观世界叫良知，再有一个客观世界叫外物的世界。

<span id="p-59-026" class="reading-anchor"></span>

所以「人若复得他」，就能回到他自己本有的良知，而且要复得完完全全、无少亏欠。我们的欢乐是多么的大，不觉手之舞之、足之蹈之，手舞足蹈，「不知天地间更有何乐可代」，可以取代这种欢乐的。

<span id="p-59-027" class="reading-anchor"></span>

这真是什么？把我们的人心的生命情感看成就是世界的本体。请注意啊，良知是生命情感的本真。本真的生命情感，居然是生天生地、成鬼成帝的啊，所以人心是伟大，不是人的头脑之伟大。

<span id="p-59-028" class="reading-anchor"></span>

这一个真诚恻怛，就是良知。这一个真诚恻怛是什么？天地造化的精灵。如此看来，这良知简直就是基督教讲的上帝了。上帝是不是造物主啊？上帝创造世界、创造万物。我们中国人说什么？良知创造世界、良知创造万物。

<span id="p-59-029" class="reading-anchor"></span>

以此立信仰，就是我们一直讲，以本心立信仰。鬼神何足惧哉？有什么好害怕，是我生出来的，那有什么好怕？中国人的信仰，就是以这种方式展开了。一个宗教的，或基督教，或伊斯兰教等等的；一个是中国哲学的、心学的，你看简直叫并驾齐驱啊。

<span id="p-59-030" class="reading-anchor"></span>

各有各的信仰。我们中国人有中国人的信仰，欧洲人有欧洲人的信仰。所以西方的哲学不可能做成信仰的层面，西方人只能通过基督教。好，就到这里。
