## 磨镜，磨的是自家的私意

**回看 00:00—03:59**

<span id="p-23-001" class="reading-anchor"></span>

我们在这个课程的第四部分是讲养心的功夫。从第八条讲到第九条了。此心能明，就是把心比喻为明镜，就不怕事情在变化。那么保持心如明镜，就是要磨。如徐爱说的，在磨上用功。那么究竟怎么磨？我们看第九点。

<span id="p-23-002" class="reading-anchor"></span>

第四十一节，《陆澄录》的第四十一节，阳明的原话被记录下来。「喜、怒、哀、乐本体自是中和的，才自家着些意思，便过或者不及。」过、不及啊，这两种，一种过了，是吧，一种没达到。这便是什么？私。

<span id="p-23-003" class="reading-anchor"></span>

话说得非常简单，而且还特别希望我们普通的人都能听得懂，所以非常口语化吧。「才自家着些意思」，只要自家着些意思，把自己的私心放上去了，私意放上去了，那一定是什么？过，或者不及。这个情感过了，或者没达到。讲的过和不及，都不是认识偏差，是情感本身的偏差。

<span id="p-23-004" class="reading-anchor"></span>

我们讲心，千万别把它想到头脑上去。明镜，不是磨我们的头脑，认识保持清晰状态，不是这样的。我们很容易不知不觉又走到认识论立场上去了。心学是本体论立场，心之本体。这是最容易误解阳明的，或者难以进去的缘故。读着读着又想到认识论的问题了。

<span id="p-23-005" class="reading-anchor"></span>

刚才我们说磨镜、磨镜，就好像是什么认识要纠正错误似的，不是，是心。比方说我们不要去依赖以往的经验和知识，就能面对事情的变化，这好像头脑认识问题，其实还是心。我们的心如果抓住以往做成事情的手段和方法不放，是我们的心有问题。

<span id="p-23-006" class="reading-anchor"></span>

以往的成功我们老记在心里，老记在心里嘛，就是我们的自家意思在里边。这个成功你怎么判断的呢？被别人赞美了，或自己的目的实现了，叫成功，这些都是心不明。所以，总把以往的经验和知识当作得到一个好结果的重要手段和方法。

<span id="p-23-007" class="reading-anchor"></span>

这些表明，就是我们对以往自己所做的事情的评价，仍然是有自家意思在里边。所以明镜啊，要磨。这个镜啊，磨去的不是错误的认识。磨去的是什么？磨去的是私意。私意当然是份情感了，就从小我出发的情感。

<span id="p-23-008" class="reading-anchor"></span>

所以阳明先要说本体。看到本体二字了，一定记住，朱熹的立场是认识论立场，阳明的立场是本体论立场。这个本体是指什么？心，心之本体，或心体。

## 喜怒哀乐本是中和

**回看 03:59—06:40**

<span id="p-23-009" class="reading-anchor"></span>

就像阳明在别的地方说过这样一句话，「人心是天、渊。心之本体无所不该。」还记得吗？他讲的人心，人心很大很深，人心是天渊。底下说明为什么，「心之本体无所不该」，这「该」是什么？涵盖，一切都能涵盖。

<span id="p-23-010" class="reading-anchor"></span>

我们不可能拥有完备的知识，头脑里边的事情，知识永远不够，但我们的心足够涵盖一切。那是天渊，就我们的生命情感不得了。人是最高的有情物，情感之大，可以和天一样大。「喜怒哀乐之未发，谓之中」，「中也者，天下之大本」。人心的喜怒哀乐是天下的大本，这才是根本。

<span id="p-23-011" class="reading-anchor"></span>

人类社会的种种的变迁，社会的动荡，或者从动荡走向了和谐、和平，这一切无非是什么？人类的喜怒哀乐。所以就别把 ChatGPT 拿出来说了。ChatGPT 叫人工智能，它不是心，对吗？〔[听辨待核 1](#editorial-note-1)〕本是中和的，它发出来叫中节的话，就是《中庸》那句话。

<span id="p-23-012" class="reading-anchor"></span>

再回顾，「喜怒哀乐之未发，谓之中；发而皆中节」，就有节制吧，就既不过分，也不是没达到。这就是合适了。这个节拍的节嘛。发而皆中节就是恰当，发得恰当叫「和」吧。然后「致中和，天地位焉，万物育焉」。

<span id="p-23-013" class="reading-anchor"></span>

那么这个中和呢，阳明进一步说了，其实发或者不发，它本就是中且和。那么发出来为什么不中节呢？我们每每发得不中节，什么意思？因为自家着了意思，把一点私意放上去了嘛。看来这个不着任何自家意思是难的。

## 俱生我执和分别我执

**回看 06:40—10:42**

<span id="p-23-014" class="reading-anchor"></span>

难在哪里呢？我们总有一个小我。小我呢，叫我执。所谓我执呢，并不是一开始就错，每一个生命个体都有自保的本能。这种我执叫什么？俱生我执，与生俱来的，这没有任何问题。每一个动物的个体也一样，每一个植物的个体也一样。它没有自保的本能，它怎么生存呢？

<span id="p-23-015" class="reading-anchor"></span>

这个我执不用去，不用去。要去的是什么？因为人生活在社会中，也就是处在与他人的关系中，就有人我别了吧。这种人我别的我执要去掉的，这种我执叫分别我执。分别我执让我们每个人都很小了。本来心很大，结果自己弄小了，形成间隔。

<span id="p-23-016" class="reading-anchor"></span>

俱生我执是求生的欲望，这没什么错。但是人不是单个活在这世界上，他只要活在这世界上，一定处在与他人的关系中，他是在社会关系中的。在社会关系中，他这个求生的欲望就变成什么？小我的欲望，就人我别了嘛，这是一个问题了。

如果不去掉分别我执，这个社会呢，人类社会就很难维持。

<span id="p-23-017" class="reading-anchor"></span>

见死不救，让别人死、自己生，丛林法则不都来了吗？这是我们的生命情感的最根本的毛病。病源在此，分别我执。我们把分别我执去掉了，在禅宗里讲，那叫平等性智。转识成智嘛，把第七识转，第七识叫末那识，末那识就是小我。把末那识转为平等性智，人我别就去掉了。

<span id="p-23-018" class="reading-anchor"></span>

禅宗这么说，这是它一套修行的语言，修行就是要转识成智。什么叫转识成智？改变心的用法。从求如意的心变成了如如之心。那么如如之心所生的就是智慧，如意之心所生的叫业识。所以转此识为智。改变心的用法。

<span id="p-23-019" class="reading-anchor"></span>

那么在阳明心学看来呢，其实意思一样，回归我们本身的生命情感，本心。如果回归本心的话呢，也就是说我们的喜怒哀乐本就是在社会生活中的喜怒哀乐，它是中和的，在分别我执当中，它就偏了。

<span id="p-23-020" class="reading-anchor"></span>

中和的什么意思呢？「己欲立而立人，己欲达而达人」。别人生活中的美好的东西，我看到了也心生欢喜，是吗？中国人文化病症蛮多，有一种叫红眼病，看不得别人好了。这是不是分别我执？这样的生命情感是不中和的。

我们在社会交往中应该带来人性的光辉，它的价值，而这是倒过来了。

## 真诚恻怛的求生、求爱

**回看 10:42—12:20**

<span id="p-23-021" class="reading-anchor"></span>

所以阳明在别处讲，良知是什么？这是真诚恻怛。我们求生，俱生我执。人心真诚恻怛的求生，这生便是天理。一定是要真诚恻怛。若不真诚恻怛呢，恻怛就是恳切啊。若不真诚恻怛，意味着什么？每每自己求生，导致别人不能生。

<span id="p-23-022" class="reading-anchor"></span>

真诚恻怛地求生，自己生，别人也生，在别人的生当中也得到喜悦。人是社会存在物。人心真诚恻怛的求爱，这爱便是天理。但一切摧毁爱的都是恶，一切助长爱的都是善；一切摧毁生的都是恶，一切助长生的都是善。

<span id="p-23-023" class="reading-anchor"></span>

善恶之区分就在于真诚恻怛这个根本上。人人都求生，人人都求爱，只在一点上有了区别，是否真诚恻怛？换句话说，是否在良知中？再换句话说，是否在明德中？再换句话说，是否在本真的生命情感中？就是这样一件事，它绝不是头脑的事。

## 不逆诈，怎样又能先觉

**回看 12:20—16:57**

<span id="p-23-024" class="reading-anchor"></span>

「从小父母就教育我们，害人之心不可有，防人之心不可无。这里的心和老师你说的心有什么区别吗？」这个问题提得非常地好，我们提前讨论这个问题。也就是《答欧阳崇一》，这封书信在《传习录》中卷。《答欧阳崇一》这封王阳明写给欧阳崇一的信，一共分了四节。

<span id="p-23-025" class="reading-anchor"></span>

第四节，欧阳崇一写给阳明的信中有这样的话，「来书又有云：『人情机诈百出，御之以不疑，往往为所欺，觉则自入于逆、臆。』」假如我们觉察到别人可能什么？欺骗我，这叫欺诈。也可能是说话将来不会守信用。我这样觉察了，我就自然进入了什么？逆和臆了。

<span id="p-23-026" class="reading-anchor"></span>

「夫逆诈，即诈也；臆不信，即非信也；为人欺，又非觉也。不逆不臆而常先觉。」能否做到这一点？就我们不去揣度别人，不去怀疑别人，而我们能预先明白，若有欺诈会不会出现，我要先觉。是不是良知能做到这一点？「其惟良知莹彻乎？然而出入毫忽之间，背觉合诈者多矣。」

<span id="p-23-027" class="reading-anchor"></span>

我们看一看这个注释，就知道这话哪里来。出于《论语》。「子曰」，就孔子说，「不逆诈，不臆不信，抑亦先觉者，是贤乎！」什么叫逆诈？逆就是一个动词，表示预先怀疑。诈就是别人的欺诈。逆诈就是预先怀疑别人有诈。

这个臆就是揣度了，预先揣度别人说话不讲信用，这叫臆不信。

<span id="p-23-028" class="reading-anchor"></span>

而孔子主张什么？不要这样，不逆诈，也不臆不信。这叫什么？先觉者，这样叫贤人啊。这样呢，就是引起了一个讨论，引起谁呢？欧阳崇一不免在此有怀疑了。我们真应当不逆诈吗？我们真应当不臆不信吗？现在你看，人情机诈百出啊，这个社会我们都不去防备。

<span id="p-23-029" class="reading-anchor"></span>

「御之以不疑」，御就是对付他们，面对他们，我以不疑，结果是什么？「往往为所欺」，对不对？然后我们还是去怀疑他们的话。我要觉察出他们的欺诈的话呢，我又落于什么？孔子所反对的逆、臆中了吧？这该怎么办呢？

<span id="p-23-030" class="reading-anchor"></span>

孔子讲这个境界讲得很高，就当我们去逆别人诈，或臆别人不信的时候，我们自己已经什么？进去了，也进入了诈和不信。就我们自己也不干净了，就我们自己也不干净了。但是我怎么实践呢？明明我经常会被人欺嘛。这件事情怎么讲？

<span id="p-23-031" class="reading-anchor"></span>

我们从小父母教育我们，就是你刚才说的那句话，「害人之心不可有，防人之心不可无」。关键是，关于别人有欺诈、别人不诚信这件事情，你不要预先去防着他。就像别人跟你打交道，跟你说几句话，你要把它当真，别马上想到它背后是一种欺诈，你要把它当真。

## 小时候的事和烟杂店进货

**回看 16:57—20:42**

<span id="p-23-032" class="reading-anchor"></span>

我小时候呢就这样，然后我父母就觉得这家伙傻。明明这是一个进来要偷东西的人，他说，我是你爸爸的同事朋友啊。我就很热情了，给他倒杯水。结果他拿了块表要走，后来我妈回来了，正好逮住那个人。这件事情发生之后呢，家里开了个会，就提醒我啊，「防人之心不可无」。

<span id="p-23-033" class="reading-anchor"></span>

那么我从小就受到这教育了。长大以后我想一想，我当时也没错，我为什么一定要怀疑你是骗子呢？为什么？一个正常的、健康的社会，彼此应该信任的。说话之后，你别把人家的话当成不是真的，为什么先要把它当成不是真的呢？但是它真不真，你能发现吗？

能发现的，只要你真诚。

<span id="p-23-034" class="reading-anchor"></span>

你比方说在商业的舞台上，有的人不是行骗吗？比方说你开个小的烟杂店，假定。那么以前进货，你的烟杂店开出来就是为这个小区服务的，在小区就没这个店，你开了家店，为小区的居民服务。那么你进货，然后呢，卖给了小区的居民。

<span id="p-23-035" class="reading-anchor"></span>

那么本来是一个市场价，是这样一个价格。那么供应商呢，后来跟你提出来，我可以降价。可以降价，你进吧，你进我这货。你很高兴，为什么？你一算，这个价格差比原先更大，我中间得了更多的利润。那么在这样想的时候呢，你自然会不知道别人其中有诈。

<span id="p-23-036" class="reading-anchor"></span>

你不这样想，你也别怀疑他，而你总在想一件什么事呢？我为小区居民负责任。我卖给小区居民所有东西都应当什么？货真价实。你现在要降价了，那么我可以相信你是真想降价，打开更多的销路。

那么我还是要严格地检验你提供给我的货物，价格先不谈，货物要检验，保证货物的质量。

<span id="p-23-037" class="reading-anchor"></span>

在这种情况下，他如果愿意降价，就没什么欺诈。如果他降价是因为那个次等的货给你了，这其中就是诈。你不要预先猜他是诈，而是你保持你原来的真诚。你做这件事为谁？为小区居民负责任，你守住这一条。

<span id="p-23-038" class="reading-anchor"></span>

现在有许多骗子吧。现在公安部门不断提醒我们防止诈骗嘛。这防，你为什么要防呢？他为什么能诈骗成功呢？你心不正嘛，你有贪欲嘛，你会贪便宜嘛。骗子成功每每就是抓住我们这个弱点嘛。我所以就相信这一点，不管你这个电话打给我是真还是假，我不要，可以吧？

因为我没有这份贪心。我要买任何东西，我是正常地去买来，不要你给我一个诱饵。

## 用兵贵诚

**回看 20:42—25:00**

<span id="p-23-039" class="reading-anchor"></span>

我们都知道「兵不厌诈」这个成语吧。按照兵不厌诈这一条原则，孔子的那个说法就站不住脚了。打仗，我们都在防范对方诈了。那么孔子说「不逆诈，不臆不信」，怎么站得住脚呢？仗就没办法打了嘛。天下人都知道这四个字，兵不厌诈嘛，天下人的境界啊都低于孔子。

<span id="p-23-040" class="reading-anchor"></span>

我把兵不厌诈要改成另外四个字，「用兵贵诚」。人家一听就笑了，宋襄公，迂腐得很。真的迂腐吗？为什么用兵贵诚？打仗，交战双方，敌我双方，我自己的军事力量有多大，对方有多大？在打仗的这时候，我处于有利的地位还是不利的地位，这点要不要承认？

要承认，要实事求是。

<span id="p-23-041" class="reading-anchor"></span>

那么对方如果设一个陷阱呢，你会不会跳？你不会进去的，因为我就知道这场仗这样打的话是相当艰苦的。对方要占我的便宜，怎么占呢？就是说让我捡个便宜，设了个陷阱。哎呦，我这里很弱，佯攻之后马上逃。你开心了，哗，追啊。

追了嘛，他的包围圈已经设好了，埋伏全设好了，然后你就被他干掉了。

<span id="p-23-042" class="reading-anchor"></span>

你为什么去以为这里有便宜可得呢？你还是要知道，此刻的形势很严峻，我目前真打不过你，这是真的。你让我觉得好像很容易就可以得了某种好处，其实它就是陷阱。你不要预先想这是是不是陷阱，而是你总是诚。不是我能得的，我不干，所以你设的所有圈套我都不会进去的。

<span id="p-23-043" class="reading-anchor"></span>

因为我诚，我倒可以看到你不诚。一旦你不诚，我就设圈套，我就设陷阱。我所设的陷阱正好让不诚的人进去，就这样。但是你设陷阱我不会进去，因为我诚。所以打仗最后取决于什么？双方谁诚。诚者一定能看清楚什么？别人的不诚。

<span id="p-23-044" class="reading-anchor"></span>

因为你诚，这《中庸》讲的，「自诚明」，圣人的境界。因为我们诚，实际上就从诚到明，因为诚故明。明在哪里？第一，不会上当，不会落了别人的圈套。第二，会发现对方不诚。你明了，对方不诚，正是你可用的、你可设诈的地方了。

如果双方都诚，双方的诈都没用，该怎么打就怎么打。

<span id="p-23-045" class="reading-anchor"></span>

为什么总是兵不厌诈呢？就是说你要设计。你计很多。读《孙子兵法》，还有《三十六计》等等的种种的计。离间计，离间计为什么能成功？调虎离山计为什么能成功？围魏救赵，为什么能成功？用到你身上，为什么它成了呢？因为你不诚嘛，就这么解释。

<span id="p-23-046" class="reading-anchor"></span>

所以王阳明跟宁王朱宸濠打，王阳明设了很多诈，你们知道吧？设了很多狡计，结果宁王都上当了。原因是什么？因为宁王不诚。宁王不诚，阳明自然看见。宁王要设计诈阳明，不可能的，阳明诚着呢。所以我这四个字大概能站住脚了啊，用兵贵诚。

### 承认敌强我弱，争取局部优势

**回看 25:00—28:53**

<span id="p-23-047" class="reading-anchor"></span>

毛泽东也是这样一个伟大的军事家、战略家，他就是诚啊。重庆谈判后来一时成功，后来就结束了。然后国民党军队开始干起来了。大概是二十万大军，胡宗南直扑延安。当时整个共产党的军队和国民党军队力量悬殊吧，敌强我弱，敌多我寡。

<span id="p-23-048" class="reading-anchor"></span>

不光他们人数多，而且美式装备。我们这里叫小米加步枪。这种情况你得承认，毛就坦率地承认这一点，这一个诚字就在。不要想什么诡计可以干掉国民党军队。你来，我不跟你对抗，实事求是，你强我弱，让开可以吧？你这座延安城，你占领吧。

<span id="p-23-049" class="reading-anchor"></span>

然后国民党的报纸上欢呼他们的胜利，共产党的老巢被干掉了。他正得意呢。毛泽东跟他打运动战，你来我就让开。然后呢，我也不走，在边上兜圈子，那么你要跟着我走了。在打运动战的过程当中，可以造成什么？局部的优势。

<span id="p-23-050" class="reading-anchor"></span>

毛泽东的原则是那么的分明，不瞒天下任何人。集中优势兵力打歼灭战。全局你优势我劣势，是真的，但是我可以造成局部的优势呀。你三个、你五个旅来。我五个师上去了，可以吧？无论如何赢了呀，就这个道理。

<span id="p-23-051" class="reading-anchor"></span>

你在打运动战的过程中会造成这个局面嘛，造成局面嘛。你五个旅来，我五个师扑上去。这叫集中优势兵力打歼灭战，就这样兜啊兜啊，一直跟他打运动战的。不可以打阵地战，打阵地战弱方肯定结束了，你干不过他的，打阵地战是不行的。

<span id="p-23-052" class="reading-anchor"></span>

全局的优势在对方。在运动战打到一定阶段之后，因为一个一个的局部的优势，集中优势兵力打歼灭战，积小胜为大胜，整个战略改变了。局面的战略性转变，终于是共产党的军队占了全局的优势，国民党军队变成弱势。

<span id="p-23-053" class="reading-anchor"></span>

接下去是什么？横扫千军如卷席啊，打过长江去，解放全中国。解放战争的这个转折点，就这么被无数的小胜积累起来的。这没什么狡计的，没什么欺诈，没什么好诈的，就这么干。当然还有一个政治因素，人民支持了，支持了解放军了。这是民心嘛。

<span id="p-23-054" class="reading-anchor"></span>

这些例子都非常说明问题。不要一想到打仗，就想到这四个字，「兵不厌诈」。先要想到四个字，「用兵贵诚」，你得实事求是，否则你是自欺，然后欺人。这就孔子的境界，「不逆诈，不臆不信」，否则我自己陷进去了。那么双方用计。就这件事了，任何狡计只能在谁身上成功？

不诚之人身上成功。

## 自诚明

**回看 28:53—30:06**

<span id="p-23-055" class="reading-anchor"></span>

《中庸》当中的关键的一句话，「自诚明」。因为我们诚，我们便明。所以我们父母教导我们的话呢，还得注意啊，境界是不高的。就永远别害人，这是对的，但是永远要防人也不对的。你不用防，你诚着，别人的诈用不上来。

<span id="p-23-056" class="reading-anchor"></span>

如果他真是诈的，而你不是因为贪心的缘故，也相信了他，你还是对的。比如说有朋友向你借钱吧，你看到他真困难了，他能不能还呢？他说我一定还，两年或者一年之后一定还。结果他到时候他不理你了，不用难过，你也不是被欺骗了，你这个叫布施。有什么被骗的问题呢？

<span id="p-23-057" class="reading-anchor"></span>

人因此就坦荡啊，「君子坦荡荡，小人长戚戚」。这一条功夫，就先讲到这儿。
