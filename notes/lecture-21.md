# 第21讲 因病而药

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—14:36

**阅读导引｜整理附录**　本讲以「因病而药」承接培根功夫。先谈经典如何在生活中被体会，再读孟源好名自是的故事，说明病根未去，学习也可能反过来滋养病根。后半讲借几何、物理、金融与中医的课堂比喻，反复区分培根和去病。

## 一分钟速读｜整理附录

1. 纷扰时静坐、懒于看书时看书，方法须针对当下的病。
2. 哲学经典的意义往往要在生活经历中逐渐体会。
3. 成其为人是根本，与学习专业知识并不矛盾。
4. 孟源两次被指出「尔病又发」，使好名自是的病根显露。
5. 学习既要培根，也要查自己的病；老师的批评可以成为帮助。

## 因病而药

**回看 00:00—01:00**

<span id="p-21-001" class="reading-anchor"></span>

第七条，我把它概括为这样四个字，因病而药。这个「药」做动词用，针对自己的病去做治疗，药做动词用。对症下药。先看《陆澄录》第三节，这里没有对话，而是把阳明的一句话记录下来。

<span id="p-21-002" class="reading-anchor"></span>

「日间功夫」，我们平时下功夫。「觉纷扰，则静坐」，你如果觉得心很乱，静坐，先定下心来。「觉懒看书」，不想看书，偏要做什么？看书。「则且看书」。这叫什么？因病而药。

### 读书的意思，在生活中体会

**回看 01:00—03:40**

<span id="p-21-003" class="reading-anchor"></span>

我们读书，是为了运用到我们的生活中去。我一直讲，中国哲学就是中国人的生活，哲学就是生活啊。你读书就是进入哲学，进入哲学是为了让我们的生活提升它的属人的境界。那么这个就是读书的目的。

<span id="p-21-004" class="reading-anchor"></span>

那么读书呢，一时也不懂，特别是比方说你读先秦时候哲学的典籍，一时你真是不懂。不懂也没关系，年轻的时候或者年纪小的时候，先把它背出来。以后的生活道路展开了，遇到了那个状况了，或者挫折了，突然就明白，哦，这句话是这个意思。

<span id="p-21-005" class="reading-anchor"></span>

如果你不识字，得听。如惠能，惠能不识字，人家诵经，他就听，后来他就让弟子诵，诵了他就听。就是说，离不开经典。经典是必须的，人文经典最重要。

<span id="p-21-006" class="reading-anchor"></span>

那么你没有什么具体目的，就说你就是想要了解中国的思想和智慧。将来在生活中怎么运用，不到时候还不能体会。特别是我们遇到生活中的困境的时候，麻烦的时候，困扰的时候，那些我们先前读过的东西的意义就会领会。所以这叫什么？用心去体会。

中国人「体会」这个词好，从心体上去领会，而不是字面上去了解。

<span id="p-21-007" class="reading-anchor"></span>

中国人有一句话说得好，「半部《论语》治天下」。你总不会懂一部《论语》，就是要治两个天下的意思。再比方说，《道德经》五千言，八十一章，你全懂了？不可能的。各位慢慢来，这八十一章，五千言《道德经》，你懂个两句、三句，已经是终身受用的智慧了。

<span id="p-21-008" class="reading-anchor"></span>

这就是我们跟哲学典籍的阅读关系。它不像别的啊，你得按部就班，一步一步来。你读物理学那部教材，你不能从最后一章开始吧？你从第一章开始，循序渐进，这是知识的学习。

## 学专业也要有做人的根

**回看 03:40—05:41**

<span id="p-21-009" class="reading-anchor"></span>

不能理解了，还得停下来，在这一段下功夫，后面别去看。教材，科学的教材就这么编的嘛。而哲学不是这样的，你从最后一章开始也行啊，《道德经》。我们懂做人的道理，我们设立了我们人活在这世界上的生命实践的目标，也就我们知道要从小人变成君子。

<span id="p-21-010" class="reading-anchor"></span>

这件事情首先是作为人，成其为人。或在宗教中成其为人，或在中国哲学中成其为人，这是一件事情，很根本的。但成其为人不妨碍学习知识。为什么？成其为人你就要做事情呀，你要为文明的进步做贡献呀。这一定是会自觉地去学许多知识的。我说这里边不矛盾的。

<span id="p-21-011" class="reading-anchor"></span>

有的人专门研究哲学了，这是极少数的人。研究哲学、做哲学工作者的人，一定是整个民族当中的极少数的人。但我们大家都要学哲学，因为这是精神修养啊，这是作为人，成其为人。那么你肯定不是以哲学做专业的吧？你不是以哲学做专业的话，你肯定要学许多事情吧？

比如说你对物理学有兴趣，或者有天赋，那么你就去学。

<span id="p-21-012" class="reading-anchor"></span>

那么，你做物理学家的目的是什么呢？还是原来你那个根，做人的根，这是要先要培好的。现在为什么有许多高学历的人被称为野蛮的、有文凭的野蛮人？为什么成为精致的利己主义者？这就他没有哲学，只有科学。他是小人，又是博士。小人加博士，就这件事吧。

## 孟源和一生的大病根

**回看 05:41—09:13**

<span id="p-21-013" class="reading-anchor"></span>

我们讲因病而药。那么第五节，我们看《陆澄录》第五节，有一位阳明的学生叫孟源。这第五节开头就说，这位阳明的弟子有一个什么病呢？好名自是。好名，自以为是。好名就好自己的名声。「先生屡责之」，阳明经常要批，就这一点批评他。

<span id="p-21-014" class="reading-anchor"></span>

「一日，警责方已」，刚刚批评过孟源。当时好多人坐在一块，跟着王阳明讨论。有一位朋友当着大家的面，「自陈日来工夫」。我最近在下什么功夫，提出来请指正，请阳明指正。

<span id="p-21-015" class="reading-anchor"></span>

阳明还没有开口说话，孟源在边上就说了，哦呦，「此方是寻着源旧时家当」。源就他自己了，叫孟源。你现在下的功夫，我以前老早都下过了，已经不新鲜了嘛。这我以前下过的旧时家当的功夫嘛。

<span id="p-21-016" class="reading-anchor"></span>

阳明一看，「尔病又发！」你那个老毛病又来了。孟源不是脸色变了吗？「源色变，议拟欲有所辨」，他还想为自己争辩几句，这个愿望已经出来了。阳明立刻又制止他，「尔病又发！」又发。然后跟他讲，这是你一生的大病根。

<span id="p-21-017" class="reading-anchor"></span>

「譬如方丈地内」，那块土地很小的面积，一丈见方吧，叫方丈地内。要种一棵大的树。你在这么一块一丈见方的地里边种了你这棵大病根。「雨露之滋，土脉之力」，就土壤的肥力，只滋养得这个大根。

<span id="p-21-018" class="reading-anchor"></span>

在这大根边上，如果还想种些别的什么嘉谷啊，很好的谷物啊，粮食，还能种吗？上面被你这棵树，这棵病树的树叶遮覆了吧？下面又被此树根，此树根盘结在地底下啊。你这病根盘结着，如何生长得成？

<span id="p-21-019" class="reading-anchor"></span>

只有一个办法，「须用伐去此树，纤根勿留」。把这个病根彻底砍掉，这个病树砍掉，根不能留。「方可种植嘉种。不然，任汝耕耘培壅，只是滋养得此根。」我们了解到王阳明讲的培根的功夫。

## 任何一个领域都有它的根

**回看 09:13—11:51**

<span id="p-21-020" class="reading-anchor"></span>

任何一个领域都有它的根。我们复旦大学数学系，有一个几何学的大师，那么他后来成博士生导师，做教授、博导。那么有新来的博士生到他那里，这位教授给他一本什么书？就欧几里得的《几何原本》。

<span id="p-21-021" class="reading-anchor"></span>

这博士生觉得很惊讶，《几何原本》里的知识我在初中都完成了，学平面几何呀，对不对？你为什么还要叫我看？他说你去看了就知道为什么。《几何原本》跟今天的几何学教材还不一样的。它是欧几里得在这本书里边在探讨几何问题本身。

<span id="p-21-022" class="reading-anchor"></span>

他做了怎样的探讨和尝试，才树立起几何学的精神。所以叫他进去，叫这新来的博士生读原本。《几何原本》，不是叫你去学到你没有的几何知识，这些知识他都有。但你要读原本，这就是根，这就是根。

<span id="p-21-023" class="reading-anchor"></span>

我们现在看物理学，读近代以来的物理学，我们还不如先看牛顿的那本书，《自然哲学的数学原理》。就知道整个牛顿物理学是件什么事啊，是公理化的体系啊，把数学充分运用到力学的讨论，在力学的基础上繁衍出热学、光学等等。这是近代物理学的根，它不会动的。

<span id="p-21-024" class="reading-anchor"></span>

你比方说金融学，金融学这个新概念层出不穷，所谓金融工具太多了。你不知道它的根。就资本怎么会成为市场，资本本身成为一种商品，在一种市场上买卖，这件事是怎么回事？读《资本论》第三卷「生息资本」那一章。那叫培根的功夫。

<span id="p-21-025" class="reading-anchor"></span>

但是第七条呢，要讲我们恐怕已经有某种病根。病根不去，你的培根功夫就不行；我们要培的那棵树，就长不起来。所以去病很重要。

## 去病才能培根

**回看 11:51—14:36**

<span id="p-21-026" class="reading-anchor"></span>

就像中医的道理，你要吃补品。吃补品的前提是什么？先把病除掉，否则你补不进的。是不是中医原理？就像现在冬令进补，抓住冬令这个时节来进补。

<span id="p-21-027" class="reading-anchor"></span>

真正的中医该怎么跟你弄的？先把脉，望闻问切全来一遍，看到你身体的某种平衡，平衡已经被失去了，被打破了。虽然还没真正的病啊，中医不是治未病嘛，还未成病，但你已经需要调理了。调理完了以后，你再进补吧。那个病，纤根勿留，去除干净，一样的道理。

<span id="p-21-028" class="reading-anchor"></span>

但人都有病。毛主席那首词里边不是写了吗，「人有病，天知否」？那首词我们不大熟了，叫「人有病」。当然毛主席讲的是人类社会有病。天一定知道，我们也得知道。要把病除了。

那个人也一样，我们在这世界上生活过一段时间了，我们已不知不觉之间会染上这个社会传染给我们的病。

<span id="p-21-029" class="reading-anchor"></span>

我们自己还不知道，这些病就在身上积累，积累到后来这个病根还蛮深的，叫大病根，如孟源的病根。怎么办？先查一查自己的病。所以这时候的老师对我们的批评是非常重要的。王阳明对孟源的批评是非常重要的。王阳明在这里确实是表现出对孟源的关爱。

<span id="p-21-030" class="reading-anchor"></span>

我们大概在一个好的老师那里才获得这样的机会，因为他有洞察力，知道你的病是什么，帮助你把病根除了。我们没有这个机会，现在没有这个机会遇到王阳明。读《传习录》，查查自己的病，各有各的病。

<span id="p-21-031" class="reading-anchor"></span>

有的人并不是好名声的病啊，有别的病。有的人呢，或者执念，或者自卑，大事情都不敢做的，仿佛自己能力最差。这都是病。把病除了，才能成为一个堂堂正正的道德自觉的主体，在这世界上做该做好的事。前提还是要把病除了。

## 本讲总结｜整理附录

因病而药并不是给所有人一套固定动作。读书、静坐、接受批评，要针对自己的心究竟出了什么问题。经典学习也由此接回生活，不止停在字面理解。

孟源的故事把「培根」反过来照看：如果大病根占据了土地，雨露肥力也只滋养它。几何原本等例子继续说明根本的重要，结尾则返回对自己的病根作检查。
