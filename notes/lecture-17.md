## 顾东桥担心专求本心会遗落物理

**回看 00:00—03:39**

<span id="p-17-001" class="reading-anchor"></span>

第四节，顾东桥来信中还是有疑问。信中有这样的话：「真知即所以为行，不行不足谓之知。」这是阳明说的，顾东桥也表示同意。

「此为学者吃紧立教」，从关键处立教，教义的「教」，「俾务躬行则可」。这一点，他同意。

<span id="p-17-002" class="reading-anchor"></span>

但底下又问，若真的说行即是知的话，恐怕会有什么弊端？「恐其专求本心，遂遗物理。」把事物的道理给遗忘了，扔掉了，专求本心嘛。真知不就是本心嘛？那么本心起来就行动，这行便是知。那么我们还要知道事物自身的理吗？好像不要了。

<span id="p-17-003" class="reading-anchor"></span>

如果是这样，「必有暗而不达之处」。我们对事情本身的道理不明白，我们会在黑暗中行啊。这难道是「圣门知行并进之成法哉」？表达了一种深刻的怀疑。

<span id="p-17-004" class="reading-anchor"></span>

阳明针对这段话回答：

> 知之真切笃实处即是行，行之明觉精察处即是知。

知之真切笃实处即是行，离开行，哪有知的真切笃实？行之明觉精察处即是知。实践的时候，时时在明觉精察；实践中的明觉精察，便是知，如何能分开说？

<span id="p-17-005" class="reading-anchor"></span>

假如把知放在行之前，先知而后行，这个知是真切笃实的吗？不可能。你在行的过程中，不会糊里糊涂地做事情，每一步都在明觉精察，这不就是知在其中吗？

这叫知与行交养互发：行增进知，知增进行，互相促进。

<span id="p-17-006" class="reading-anchor"></span>

在这个过程中，哪有把事物的理都扔掉的事呢？这个事物的理在哪里？在心之外吗？若在心之外，就是心外有理了。心外无理。

## 从见花来讲心与物

**回看 03:39—06:23**

<span id="p-17-007" class="reading-anchor"></span>

再看阳明回答的第二段。顾东桥来信说：「专求本心，遂遗物理。」阳明说：「此盖失其本心者也。」

假如真如你所说，知行合一有这种弊端，只求本心，外面事物的道理都不管，其实本心也失去了。哪有本心呢？本心在哪里，在我们胸腔内部吗？

<span id="p-17-008" class="reading-anchor"></span>

「夫物理不外于吾心。」心无内外。有了内外之别，好像——作一个形象的比喻——在我的腔子里、胸腔里有一个心，外面有许多物。是这种情况吗？

<span id="p-17-009" class="reading-anchor"></span>

有友人问王阳明：「你说心外无物，我且问你，山间的花自开自落，与你的心何干？」阳明怎么回答？你未去见那花时，你心与花一时俱灭，其实都不存在了；你一去见那花时，你心与花一时都明了起来。〔[课堂转述与原典用字见整理注](#editorial-note-1)〕

<span id="p-17-010" class="reading-anchor"></span>

这在说明什么？说明一个「见」字最重要。当然，这里说的是看到花和没看到花，一个「见」字。其实这个原则要推而广之：一切做事情，都是「见」的意思。

<span id="p-17-011" class="reading-anchor"></span>

你在做事情中，那个心起来了吧？那个物也起来了。对，一头是心，一头是物，心与物关联。你说把物拿掉，这个心也不存在。你未去见那花时，这花不是物吗？未去见那花，你没有跟花打交道。你说专求本心，这个心有吗？没有啊，失其本心啊。

### 胡塞尔、马克思与主客体

**回看 06:23—09:28**

<span id="p-17-012" class="reading-anchor"></span>

哲学上的这一个思考，其实是一种很高的认识，对人自身一个很高的认识。这种认识的水平啊，就是相当于二十世纪开头由胡塞尔发动的现象学运动。现象学的原则就在其中了。当然现在无法展开。

<span id="p-17-013" class="reading-anchor"></span>

我喜欢这样虚构、假想。胡塞尔这位德国的哲学家，一九〇〇年，也就是二十世纪第一年，发表了他的著名的《逻辑研究》。这一年因此成了西方思想史上的重要的、划时代的一年。《逻辑研究》发表了，现象学运动起步。

<span id="p-17-014" class="reading-anchor"></span>

若胡塞尔在发表《逻辑研究》之前，先读到了《传习录》，又读到这一段，会怎么样？他会欢欣鼓舞：「我并不孤独，有一个中国古代的学问家叫王阳明，他已经说了一个『见』字。」

在此见中，一方面有认识主体，一方面有认识客体。胡塞尔的现象学就是这个意思。

<span id="p-17-015" class="reading-anchor"></span>

胡塞尔的现象学就是说：不是一个现成的认识主体先已在了，一个在主体外部的客体也先已在了，然后发生认识活动，让主体去跟客体一致起来。

不。胡先生说，认识的对象、那个客体，和认识的主体、那个人心，其实都是被做成的，被那个事情本身做出来的。一方面建构客体，一方面建构主体。

<span id="p-17-016" class="reading-anchor"></span>

王阳明其实就这层意思。离开物谈心，毫无意义。离开心谈物，也没有意义。现象学原则，马克思也在这个原则里边。

<span id="p-17-017" class="reading-anchor"></span>

《关于费尔巴哈的提纲》第一条，从前一切的唯物主义，包括费尔巴哈的唯物主义，共同的主要的缺点是什么？把事物、现实、感性，当成是客体或直观的对象。其实这些事物、现实、感性都是什么？应当被理解为人的感性的活动。是实践建构了两个方面，一个叫主体，一个叫客体。

### 花、鱼和「物质世界」

**回看 09:28—14:36**

<span id="p-17-018" class="reading-anchor"></span>

所以，这是在对顾东桥说：你误解了知行合一的学说。你把它看成只要专注本心，在行中知自然来，那么这个知就跟外物没有关系，遂遗物理了。

「物理不外于吾心。」把心拿掉，哪有外部的事物和它的理？把心拿掉，有那个花吗？

<span id="p-17-019" class="reading-anchor"></span>

但我们通常是唯物主义者，我们就觉得那个友人的提问，对阳明的提问，是对王阳明心外无物的一个唯物主义的反驳。这么想。我们想，这个花，不管人看还是没看它，它自己就存在，不是唯物主义吗？那么它如何存在？它不是被称为花了吗？

<span id="p-17-020" class="reading-anchor"></span>

谁称它为花的？人。为什么不称它为鱼？把鱼称为鱼，也是人。于是，花和鱼就被区分开来。这个区分谁做的？人，人心做了规定。

人心规定花，无非两个角度：一个是审美的角度，花是审美对象，所以看到花就喜悦，心花怒放。

<span id="p-17-021" class="reading-anchor"></span>

还有一个角度，就植物学规定，花是植物的生殖器官。那么来自植物学规定了。植物学是谁造的？植物学的理论是人建构的吧，也离不开人心啊。你把它作为审美的对象，也还是人心。牡丹花象征富贵，这不就是都离不开人心吗？

<span id="p-17-022" class="reading-anchor"></span>

把人心去掉，花不是作为花存在了，鱼也不是作为鱼存在了。没有鱼，只有一样东西，也不叫东西，叫物质，叫物质。物质不是东西，不是物呀。物质和物，是不是两个不同的概念？一切都是物质，OK，没问题。但是就是说，人心不能对它做任何规定。

<span id="p-17-023" class="reading-anchor"></span>

一切都是物质，等于没有世界。因为世界是万事万物构成的，等于世界没了。你说世界，就有大地、山川、星辰、河流，鱼、花、人，各种各样的东西。这些都是人心规定的。

把人心拿掉，哪有世界？所以，那个词语在哲学上是非法的联用，叫「物质世界」。

<span id="p-17-024" class="reading-anchor"></span>

这两个词是非法联用。讲物质就不能讲世界，讲世界就不是讲物质，讲物，诸物，种种的物。这一个道理想清楚，不要停留在朴素的唯物主义信念中。如果停留在朴素的唯物主义信念中，我们是不能想、也不能说的，一想一说就是唯心主义。

<span id="p-17-025" class="reading-anchor"></span>

那你吃饭千万别在想，我正吃饭呢。什么叫吃饭？两种含义了，要么是正在摄入卡路里，叫营养学概念；要么说我正在吃法国大菜，烹调学概念。千万别想啊，一想就是被你规定了，人心规定了它。

<span id="p-17-026" class="reading-anchor"></span>

不能想，不能说，不能把它放到语言中去的。一放到语言中去，又是人规定的，人心规定了。广东菜是人心规定的呀，摄入蛋白质、碳水化合物也是人心规定的。通通去掉，埋头吃，绝不想，绝不说，那就跟动物一样，这叫动物的果腹的行为，不是人类的饮食。

<span id="p-17-027" class="reading-anchor"></span>

这是一个有意思的讨论。说王阳明的心学是唯心主义，可以。但唯心主义不等于谬误，唯物主义不等于真理。

现在习惯了，说「你这观点是唯心主义的」，等于说它错误；说「你这观点是唯物主义的」，等于说它是真理。把唯物主义与真理划等号，把唯心主义与谬误划等号。

## 孝亲之理与孝亲之心

**回看 14:36—17:46**

<span id="p-17-028" class="reading-anchor"></span>

阳明的回答继续展开：「外吾心而求物理」，在人心之外求事物自身的理，其实就没有物理，「无物理矣」。「遗物理而求吾心」，把事物的理都扔掉，专求本心。「吾心又何物邪？」那我这个心是什么东西呢？

<span id="p-17-029" class="reading-anchor"></span>

然后，阳明说自己的意思：「心之体，性也；性即理也。」心之体就是人性。离开人性，也别讲理，别讲外面事事物物的理。把人去掉，就没有事物，更何言物理？

「故有孝亲之心，即有孝之理；无孝亲之心，即无孝之理。」

<span id="p-17-030" class="reading-anchor"></span>

我们中国儒家的传统几千年，中国人因此都知道孝之理吧？我们对父母要孝。这个道德上的理要问一问，它来自哪里？来自我们有孝亲之心。那么我们又要问一问，孝亲之心来自哪里？来自从小我们跟父母打交道，我们在父母的关爱和抚养下长大。

<span id="p-17-031" class="reading-anchor"></span>

父母对我们的关爱、担忧，种种的生命的帮助，我们亲身感受了吧？我们亲身感受了父母给我们的恩典，我们自然就有一个回报的心。如果不回报，心不安。这回报的心就是孝亲之心呀。

<span id="p-17-032" class="reading-anchor"></span>

孝亲之心的来历不是来自头脑，来自生命感受，孝亲之心就这么来。然后有了孝亲之心，我们便讲什么？普天下都一样，只要是父母所生、父母所养的，必有一个回报父母的心在这里边，没有个体差异的，于是这叫孝之理。

<span id="p-17-033" class="reading-anchor"></span>

明白这意思吧？于是这叫孝之理。它不是一个普遍的法则颁布给我们的头脑，大家去认同。我们认同孝之理，是因为我们本有什么？孝亲之心。人类生活的其他方面都如此。

### 民族情感来自怎样的生活经历

**回看 17:46—20:08**

<span id="p-17-034" class="reading-anchor"></span>

我们热爱自己的民族，也不是向我们颁布一个普遍道理、普遍规则：「你必须爱国。」不是这个意思。

你出生在这个民族，在中国的文化世界中长大，你的生命感受、生命情感都来自这个民族。对民族共同体生活的所有情感、感受，都凝聚在汉语中。

<span id="p-17-035" class="reading-anchor"></span>

汉语又是你的母语。于是，无论走到天涯海角，都知道自己是中国人。这个知道，不是人种学上的知道，而是生命情感上的知道。

因为我们在中华民族的生活世界中长大，对这个民族的爱就是自然的情感。不是有个道理让头脑去确认：我们必须爱国。不用你说。

<span id="p-17-036" class="reading-anchor"></span>

为什么那么多人到了国外留学或在那里工作？历史上向来如此，中国近代史中不断有人出国留学，在国外参加工作，甚至加入外国国籍，成为科学家。他忘得了自己是中国人吗？忘不了。

这个忘不了，是情感在，深深的民族情感，极其深刻。因为我们在这个民族的文化世界中长大，这是我们的经历，情感的经历、情感的体验。生命实践都是情感的实践。

<span id="p-17-037" class="reading-anchor"></span>

于是你流落番邦了，你在番邦，在国外。「番邦」这词用得不好，有点贬低国外的意思，但我们习惯这么说了。那在国外听到两个外国人在谈中国怎么样怎么样，中国人怎么样怎么样，你仿佛听到自己的名字被呼唤到了。

## 「心与理」和「心即理」的一字之差

**回看 20:08—25:35**

<span id="p-17-038" class="reading-anchor"></span>

所以阳明底下说的就是这样，「理岂外于吾心邪？」理不在我们的心之外。然后引用了朱熹一段话。晦庵就是朱熹，「人之所以为学者，心与理而已」。

<span id="p-17-039" class="reading-anchor"></span>

这话先想一想，朱熹在说什么？人之所以为学，人为什么会有认识活动，前提是什么？一方面有心，一方面有理，叫心与理。

什么叫学？达到心与理的统一。换句话说，心是认识主体，理是被认识的客体。有主体，有客体，才有学这件事。听上去很对。

<span id="p-17-040" class="reading-anchor"></span>

再看底下：「心虽主乎一身。」这一点我们同意。人有身体和心两个方面，谁是主宰？心是主宰。

「心虽主乎一身，而实管乎天下之理；理虽散在万事，而实不外乎一人之心。」说得多好，看来跟心学没区别。

<span id="p-17-041" class="reading-anchor"></span>

粗看以为没啥问题，还有什么理学派、心学派的争论呢？朱熹都这么说话了嘛，心实管天下之理了。理虽然在万事万物都散在那里，其实又可以由我们的心去认识到，「实不外乎一人之心」。这句话的意思其实是在说什么？

<span id="p-17-042" class="reading-anchor"></span>

首先，什么叫学？什么叫认识？一有心，二有理，一有主体，二有客体。同时呢，主体与客体能否统一呢？能统一的。就后面一句了，心是能认识天下之理的。理虽然散在万事万物中，而心实际上可以认识到它，就这层意思。

<span id="p-17-043" class="reading-anchor"></span>

这层意思表达了朱熹的可知论。在认识论领域里边有两种，一种叫不可知论，一种叫可知论。可知论强调认识主体是可以跟认识客体一致的，可以达到一致，这叫可知论。

<span id="p-17-044" class="reading-anchor"></span>

朱熹这段话粗读觉得很对，细读呢？阳明说，这个表达有问题。什么问题？「是其一分一合之间」。先分，然后再合。

先分怎么分？用「与」字来分。「心与理」是不是分了？英语那个词叫 and。「与」就是分了。然后又说「不外乎一人之心」，合了。

<span id="p-17-045" class="reading-anchor"></span>

所以叫先分后合，「未免已启学者心、理为二之弊」。让学习的人先把心、理分作两件，这个弊端就来了。

这个弊端，正是后世为什么会担心「若专求本心必遂遗物理」。其实这种担心来自什么？不知道心即理。

<span id="p-17-046" class="reading-anchor"></span>

一字之差，「心与理」还是「心即理」，一字之差。所以学哲学有一个重要的好处，不断地检查我们的说话方式。当然，平时日常说话我们可以不那么严谨，不那么严谨大概听的人也懂，因为没讨论到思想层面嘛，日常交往。

<span id="p-17-047" class="reading-anchor"></span>

一旦讨论到思想层面，也就是进入哲学，说话一定要严谨。这里的例子告诉我们，一字之差意味着什么？两种不同立场。

「心与理」，然后承认心可以跟理统一，这是认识论立场。先把心、理分开，再说理是可认识的，心可以认识理，这叫认识论立场。

<span id="p-17-048" class="reading-anchor"></span>

心即理，把一个「与」字换成「即」，本体论立场。理就是心之本体，这就明确了。

### 盗贼为什么喊「给我留着吧」

**回看 25:35—29:05**

<span id="p-17-049" class="reading-anchor"></span>

我再举个例子，讲那个说话的严谨。哲学学习的进步，在于我们通过哲学的学习，纠正了说话方式。有时候说话方式的改变是一种关键性的进步。举个例子，王阳明带兵打仗、剿匪，有一次他底下的人抓到一个大盗贼，这个盗贼做过许多伤天害理的事情，终于被逮住了。

<span id="p-17-050" class="reading-anchor"></span>

这个盗贼被押到王阳明面前。王阳明知道这个人，便跟他讲：「你做如此这般伤天害理的事情，良知何在？」

这盗贼很有意思，跟阳明说：「王先生，久仰大名，我知道你天天说良知、良知，你能不能把良知拿出来给我看看？」

<span id="p-17-051" class="reading-anchor"></span>

阳明说：「好，我现在就拿出来给你看。我决定放了你，但是走之前，身上所有东西要留下。」盗贼身上还有什么？无非衣服。听说能放他，自然很高兴。

阳明手下开始剥他的衣服，剥到最后还剩一条裤衩，盗贼呼喊：「王先生，求求你，这裤衩就给我留着吧！」

<span id="p-17-052" class="reading-anchor"></span>

他刚说完这句话，阳明大喝一声：「良知当下呈现了。你不是要我拿出来给你看吗？就在你身上，就在你心里。」

<span id="p-17-053" class="reading-anchor"></span>

现在举这个例子，是说明什么？大思想家说话不随便。他用了什么词？「当下呈现」。他不会用另外的词，说「你现在知道良知了」。

什么意思？是通过头脑推理吗？「我推理了一下，还是裤衩给我留着吧。」不是，没有通过头脑的认知，他是情不自禁地呼唤出来的。

<span id="p-17-054" class="reading-anchor"></span>

在此情此景中，这个良知是情不自禁地呈现出来了，变成一句呼喊，不是通过头脑的思考。「良知当下呈现」，这表达得多么精准。所以用词要恰当，说话要严谨。这是哲学的训练，让我们在讨论思想的时候，我们的能力就提高了嘛。

<span id="p-17-055" class="reading-anchor"></span>

所以，不同学问家讨论同一件事，有时两个人说话看上去差不多，其中其实有差别。不注意，就会不知不觉陷入他的那条路。发现用词的差别，就是刚才说的「心与理」和「心即理」。

## 良知是天理昭明灵觉处

**回看 29:05—32:19**

<span id="p-17-056" class="reading-anchor"></span>

良知是什么？生命情感的本真嘛。情感是通过头脑思考表现的吗？不，叫情不自禁，不就是呈现吗？所以良知跟天理统一。「良知乃是天理昭明灵觉处。」良知在我们心里吧？它就是天理。因为在我们心里，它是不是昭明灵觉了？

<span id="p-17-057" class="reading-anchor"></span>

天理不是被我们推论出来的，天理就是我们的良知，也就是天理昭明灵觉。如果把天理跟良知分开呢？它不昭明了，不灵觉了，它叫僵死的教条。所以阳明的原话嘛，「良知乃是天理昭明灵觉处，故良知即是天理。」

<span id="p-17-058" class="reading-anchor"></span>

所以要下养心的功夫。怎么下呢？去除对我们本来昭明灵觉的良知的遮蔽。遮蔽来自小我的私欲。小我的私欲也不是认识的差错，是情感的毛病。小我的私欲，也就是每个人都会有的生命情感的毛病。

<span id="p-17-059" class="reading-anchor"></span>

那么用佛教的话说，贪嗔痴。这个贪、这个嗔、这个痴，绝不是头脑认知能力出问题，跟认知能力没关系的。有的人绝顶聪明嘛，认识上几乎没什么差错的嘛。但他什么？贪嗔痴这三个字都是情感，都是情感，就是有毛病的情感。

<span id="p-17-060" class="reading-anchor"></span>

下养心的功夫，禅宗也是养心的功夫嘛。禅宗就是佛教中的心学，禅宗是修心的法门，直指人心，指向的是情感的毛病。这些都明了了。

<span id="p-17-061" class="reading-anchor"></span>

所以我们把人生若比喻为行路，这个路没有现成地给予我们。路是走出来的，关键是我们有一个欲行之心，有一种生命的理想，我们心向往之，往前走。没有路，也会走出路来。不是先有路再去行走。一个了不起的、有创造性的民族，就是敢于走出一条新路的民族。
