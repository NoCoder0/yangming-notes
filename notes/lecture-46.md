# 第46讲 致知功夫，从身边事做起

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—06:00

**阅读导引｜整理附录**　本讲解释「各随分限所及」：今天所知扩充到底，明日有开悟再继续。碾米与灌溉树苗的比喻，分别说明精一功夫和教人与自养都不能超越实际程度。

## 一分钟速读｜整理附录

1. 养心有逐步展开的过程，个人所及的分限不同。
2. 今日所知要扩充到底，不停在口头知道。
3. 明日再有开悟，再从新的所知用功。
4. 教人如灌溉树苗，水量要随成长程度。
5. 从身边事扎实做起，区别于好高骛远与揠苗助长。

## 各随分限所及

**回看 00:00—01:59**

<span id="p-46-001" class="reading-anchor"></span>

好，各位，我们继续课程的第四部分，看三十条。我们看《黄直录》第四节，也是录了阳明的一段话，照样录下来。「我辈致知，只是各随分限所及。」每个人的情况不一样，这个养心的程度不等，这叫分限。养心的功夫是一个逐渐展开的、不断进步的过程。

<span id="p-46-002" class="reading-anchor"></span>

所以在这过程当中，有不同的分限，你达到什么程度。「今日良知见在如此，只随今日所知扩充到底；明日良知又有开悟，便从明日所知又扩充到底。如此方是精一功夫。」精一就是「惟精惟一」。

<span id="p-46-003" class="reading-anchor"></span>

「精」是什么？就是农民打谷。谷物收上来，要做碾磨的功夫，把外壳、杂质去掉，最后达到什么目标？洁白的米粒，那叫一。

「精」是功夫，不断碾磨，终于达到洁白的米粒，叫精一功夫。这不是一蹴而就的吧？要不断碾磨。

## 与人论学也看分限

**回看 01:59—03:30**

<span id="p-46-004" class="reading-anchor"></span>

「与人论学，亦须随人分限所及。」比方说你跟人讨论心学，你要注意，要根据那个人他所达到的程度。你要能发现这一点，这实际上就是孔子说的因材施教。

<span id="p-46-005" class="reading-anchor"></span>

阳明作了一个很好的比方：「如树有这些萌芽，只把这些水去灌溉，萌芽再长，便又加水。」要等它长了，再去添加水。「自拱把」，一开始那么小，一只手就握得住，乃至大到要合抱。

如何灌溉这棵树？「灌溉之功皆是随其分限所及。」若是那么小的萌芽，就把一桶水全倾倒上去，便浸坏它了。

## 从身边的事做起

**回看 03:30—06:00**

<span id="p-46-006" class="reading-anchor"></span>

这不是光在说我们怎么教别人长进，实际上自己也一样。我们心里边有一个目标，把心养得和天一样大。这目标我们刚才说过了。那么你怎么实现这个目标？你不可一开始对自己就有超出分限之上的要求。你就从身边的事做起，它自然慢慢就长，如一棵树一般，终于长到要合抱，合抱还不行，要多人合围。那么这是一个过程。

<span id="p-46-007" class="reading-anchor"></span>

所以我们就在日常生活中，我们也不管自己目前的分限如何。达到什么程度。我们只管什么？把身边的事做好。这就是个「养」字嘛。养就是这层意思嘛，养不是个过程吗？我们养育小孩不是一个过程吗？我们养自己的心也是个过程。

<span id="p-46-008" class="reading-anchor"></span>

终于养到什么？浩然之气。孟子说的，「吾养吾浩然之气」。一个养字。自己养自己，也要明白这个道理。就从身边的小事做的时候养了，脱离身边的事，那叫好高骛远，那叫揠苗助长。揠苗助长就是孟子讲的一个寓言故事嘛。

<span id="p-46-009" class="reading-anchor"></span>

人活在这世界上，每天遇到事情，扎扎实实地把这件事做好了，叫格物。这便是养，所以不要好高骛远。你真着实地去养了，于你不知不觉之间，他人看你就有圣人气象。

<span id="p-46-010" class="reading-anchor"></span>

圣人气象不在圣人，而在我。还记得讨论过这个问题吧？所以，阳明心学就是要让我们树立自己的自信。不是说在丰功伟业、伟大的工程和事业里，我才算大。不是的。好，这就是第三十条，讲到这里。

## 本讲总结｜整理附录

精一并非一下完成，碾磨去壳的比喻保留了反复用功的过程。与人论学也要看对方所及，不能用一桶水浸坏小萌芽。

这一比喻又转回自己：把心养大是目标，眼下功夫在身边事情中。正文结尾把圣人气象与自信接回此前的讨论。
