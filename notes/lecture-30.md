## 静坐能不能屏息念虑

**回看 00:00—04:41**

<span id="p-30-001" class="reading-anchor"></span>

我们一条一条来讲养心的功夫。第十五条，我们再来看《陈九川录》的第二节。这第二节要讨论动静关系了。在养心的功夫当中，不能不讨论动与静。九川问得也很真切的，「近年因厌」，这个厌恶的「厌」，「泛滥之学」。

讨厌那些泛滥之学，说那么多话不着边际，这样的学问呢，他也讨厌了。

<span id="p-30-002" class="reading-anchor"></span>

「每要静坐，求屏息念虑」，结果「非惟不能，愈觉扰扰。如何？」怎么办？这自然让我们想起禅宗的打坐了，打坐不是要屏息诸念嘛？九川的实践让他觉得太难了。本要求一个屏息念虑，却做不到，反而觉得什么？更加扰扰，就内心纷扰不定。怎么办？

<span id="p-30-003" class="reading-anchor"></span>

阳明的回答多么直截了当，「念如何可息，只是要正」。你怎么息念？只是要正啊。说得好。就像禅宗打坐，有的人误解了，什么叫坐禅？心不起念，什么念都没有，不叫空心静坐嘛？什么念都不能起的，那个心不死了吗？心如死灰，这是打坐想要达到的境界吗？

<span id="p-30-004" class="reading-anchor"></span>

所以阳明讲得清楚，干嘛要息啊？关键要正啊。底下还有提问。我们从中也可以看到禅宗对心学修养功夫的影响，很积极的影响。包括阳明本人就深受禅宗的启发，也实践，而且在龙场悟道。

<span id="p-30-005" class="reading-anchor"></span>

陈九川就接着问了，「当自有无念时否」？达到什么念头都没有的、不起的这种情况。「实无无念时」，念总有。《陈九川录》二。这就让我们想起惠能在《坛经》里讲什么？无念不是绝念，一念绝嘛，就死了，然后想要别处受身，那就是早死早投胎，别处受身。

<span id="p-30-006" class="reading-anchor"></span>

阳明回答得很明确，我们没有无念的时候，就是没有绝念的时候。「如此却如何言静？」一个静字，怎么谈得上呢？那个安静的静嘛。「静未尝不动，动未尝不静。」比方说「戒谨恐惧即是念」。这戒谨恐惧，是来自《中庸》第一章，首章里边谈。

<span id="p-30-007" class="reading-anchor"></span>

道不可须臾离之啊，可离非道也。哪怕你在独处的时候，别人看不到你在做什么事情，也听不到你在说什么话。比方说独处暗室，这时候最要当心。为什么？道在的，道无处不在，不可须臾离之。

<span id="p-30-008" class="reading-anchor"></span>

这时候你动的念头要当心了。你也不能欺于暗室，别人看不到的情况下，你为所欲为，小人嘛。所以这时候你要提醒自己，提醒自己叫什么？戒谨恐惧。《中庸》中的意思，也就是慎独。慎独也是念，提醒自己，不就是个念嘛？何分动静？

## 无欲故静，静亦定、动亦定

**回看 04:41—08:01**

<span id="p-30-009" class="reading-anchor"></span>

那么这时候陈九川还有疑问，要接着问。比方说周敦颐，周子就是周敦颐，北宋五大思想家之一吧。他的学问一个核心的观念就是主静，强调静，这叫主静之说，不是强调一个静字吗？「周子何以言『定之以中正仁义而主静』？」周敦颐为什么那么强调主静呢？

<span id="p-30-010" class="reading-anchor"></span>

阳明的回答，「无欲故静」，是「静亦定，动亦定」的「定」字。其实周敦颐讲的静，其实就是定，静亦定，动亦定。不要误解了，这个静就是心里什么念头都没有，身体也在那里不动。你做事情也定啊，你不做事情也定啊。「主，其本体也。」主静，就是本体是静的。

<span id="p-30-011" class="reading-anchor"></span>

「戒惧之念是活活泼泼地，此是天机不息处。」就是我们的念头一直在起来吧，起来的时候，我们戒惧之念就跟上去。这个念不好，不应该起这个念，这个念便偏离了天道。这叫戒惧之念。

<span id="p-30-012" class="reading-anchor"></span>

戒惧之念为什么是活泼泼的？因为我们心中总有许多私心杂念不断要起来嘛。那么戒惧之念就跟着它，随时提醒，这叫天机不息。「所谓『维天之命，於穆不已』。」

<span id="p-30-013" class="reading-anchor"></span>

这里这个字呢，不应该写成简体字的。那个字就这么写的，在印刷上的校对上有了问题，仍然应该这样写。我们通常把它看成是「于」的繁体字，它确实是「于」的繁体字。但是它另外还有一层意思的，念成「乌」，「於穆不已」。

当它念乌的时候呢，它就不能简化成「于」了，这不能成立了。

<span id="p-30-014" class="reading-anchor"></span>

「於穆」就是深远的样子，深远貌，深远的样子。「於穆不已」，「已」就是停下来了，深远而不停下、不停息。这叫天命，语出《诗经·周颂·维天之命》。天道什么？生生不息的，自然是深远、不停息，叫於穆不已，於穆不已。

## 本体之念和躯壳上的私念

**回看 08:01—11:34**

<span id="p-30-015" class="reading-anchor"></span>

「一息便是死。」念头没了，就好像天道也停下来似的，不就死了吗？你也不用怕，关键它是不是本体之念，还是非本体之念。心之本体，在阳明那里就是良知，或这个《大学》说的明德，心之本体。

<span id="p-30-016" class="reading-anchor"></span>

若这个念是非本体之念，即是什么？私念。这私念哪里来的？叫躯壳上起念。躯壳上起念，必是私念。躯壳就是 body，就是佛家讲的色身。从色身上起了念。心当然是明觉，这个明觉也能领会自己的身体的欲求。

然后从身体的欲求当中起那个念，这个念就是那份情感，不是观念啊，那份喜怒哀乐。从躯壳上起了喜怒哀乐，那就是私念。

<span id="p-30-017" class="reading-anchor"></span>

我们再度强调，我们因为受西方哲学影响很久了，念就变成 idea，不是 idea。idea 是观念，跟情感没关系的。观念有什么私和公的？没有。养心的功夫，不是指向头脑中错误的观念，把它去除掉，起正确的观念。这叫认识的功夫，不是养心的功夫。

<span id="p-30-018" class="reading-anchor"></span>

所以我们时时要检查的，不是我们的观念的正确或错误，是我们的念头。这个念头全是情感，我们的喜怒哀乐从哪里发出来？从躯壳的欲求中发出来，叫私念。从心体上发出来，叫本体之念。

<span id="p-30-019" class="reading-anchor"></span>

什么是非本体之念？躯壳上的躯壳之念，从肉身上、色身上发出的念，念都是喜怒哀乐。我们平时的喜怒哀乐，大体都从色身上发。所欲得之，所求得之，喜。所求未得，嗔恨，恨了，求而不得就恨啊，全是私念。从欲求上起念，这个心就很小了，它跟着躯壳走了。

<span id="p-30-020" class="reading-anchor"></span>

那个程颢讲「廓然而大公」，那个心叫本体的心啊，作为本体的心，心之本体。

## 课堂问答，向往更好的生活算私欲吗

**回看 11:34—14:18**

<span id="p-30-021" class="reading-anchor"></span>

「我向往更好的生活条件，这种欲望属于躯壳上起念吗？它属于私欲吗？」

<span id="p-30-022" class="reading-anchor"></span>

这个问题提得很好，也是很根本的啊。欲望本身没错，我肚子饿着的，没饭吃怎么行？这里这不叫私欲。就算不是我执〔[听辨待核](#editorial-note-1)〕，我们人也想提高自己的生活的幸福感，生命的幸福感。

<span id="p-30-023" class="reading-anchor"></span>

那么这个生命的幸福感有两类。一类是从小我出发的幸福感。这个躯壳，我刚才少说一句，每一个人自己的躯壳跟别人的躯壳分开了，叫形骸间隔。从与别人躯壳分开的自己的躯壳上起的念，那叫私念。

<span id="p-30-024" class="reading-anchor"></span>

就很简单啊。比如说大家都饿得要死，家里人在一起，终于找到一点食物了。这时候第一件事情是谁吃？不是人人都吃得到。在这种情况下有几种情况。一种情况，你和他人两个人，不是亲人。那么你是自己吃，还是他吃，成了问题。

<span id="p-30-025" class="reading-anchor"></span>

还有一种情况呢，有亲人，还有他人在。你的父亲或者母亲在，在这种情况下，你先把你拥有的食物给自己的父母亲吃，多下来，或者没多也没办法，多下来这个不是亲人的他人吃。就是大家都要活，大家都有一个躯壳的欲念、欲求要实现。

这种情况，马上是社会性存在就呈现了呀，是你吃还是他吃的，这不是个问题来了吗？

<span id="p-30-026" class="reading-anchor"></span>

改善生活，大家都想改善生活。光是你改善自己的生活，那么你父母的生活会怎么样？所以爱有差等是真的，这是儒家。爱无差等，变成墨家的兼爱了。墨家的兼爱固然境界好像蛮高啊，其实它没有根基。墨家的兼爱是观念，实现不了的。

那么儒家的这个仁是有根基的，首先是亲亲，然后再仁民的，所以爱有差等。

### 欲望如何在社会关系中实现

**回看 14:18—19:00**

<span id="p-30-027" class="reading-anchor"></span>

在这种情况下，我们一定会讨论一个问题，就是欲望本身没错，只是你去实现的时候，一定跟他人有关。因为没有一个人单个地活在这世界上。每个人要实现自己的欲求的时候，一定处在与他人的关系当中。这里必有一个作为人的考量。

<span id="p-30-028" class="reading-anchor"></span>

动物没什么要紧，大家抢吧。我们看到食物来了，几个猫都上去了。它们不会考虑先谁吃才是好的，人要想这件事。所以你问了一个好问题，欲望本身非善非恶，人没有欲望，身体就没了。但欲望在处在人与人的关系中去实现的时候，就有善有恶了。

<span id="p-30-029" class="reading-anchor"></span>

别人不是你的亲人，而你呢，食物有限，你肯定先给亲人吃。那么接下去呢？剩下一个情况，你跟你父亲就两个人，在这种情况下只有一份食物，给自己吃，不给父亲吃。当到这个时候的时候，爱有差等啊，差等到就是我比父亲更重要，到这个时候就完蛋了，就是是可忍，孰不可忍。

<span id="p-30-030" class="reading-anchor"></span>

我让父亲吃到东西，让不是父亲的人先吃不到，可忍，此处可忍，因为亲亲的缘故。到剩下就是你跟父亲两个人了，你说我自己吃，让父亲死了吧，这里你还能忍？是可忍，孰不可忍？

<span id="p-30-031" class="reading-anchor"></span>

我们也不想伤害动物，但是人要吃饭，没办法，就宰了这个鸟兽。那么这是能忍了吧？我们去杀猪、杀鸡，鸡在挣扎啊，这时能忍了没有啊？不忍，不行的〔[否定词见整理注](#editorial-note-2)〕。因为人要活嘛，只能把那个鸡宰了，或者把那个猪宰了，我们把它吃了，此刻能忍吗？

<span id="p-30-032" class="reading-anchor"></span>

那么食物是在人当中怎么分配呢？亲人是第一位的了，于是别人没吃到东西，这时你能忍吗？还能忍。剩下你跟你的亲人两个人了，你自己吃，不给他吃，此处你还能忍？是可忍，孰不可忍？你什么事情都可做，这个人就绝对是可以行恶的人了。这时候是能不能忍的。

<span id="p-30-033" class="reading-anchor"></span>

强盗也一样的。强盗在外面杀人越货。回到家里，他跟他父亲会以强盗的行径做事吗？不可能的。在外面犯了许多罪恶的事，遇到亲人了不会了，同意吧？因为他还是人。他可以去抢别人的东西、偷别人的东西，他不偷他父亲的东西。

他如果父亲口袋的钱他也去偷，这样的人也不是没有，很可怕了。

<span id="p-30-034" class="reading-anchor"></span>

有两个老人亟待拯救，其中一个老人是你的父亲，另一个老人是别人的父亲，你先救谁？当然这是毫无疑问的。这时候别人的父亲也在死亡的威胁中啊，你不得不忍一忍吧，救自己的父亲。别人的在死亡的威胁当中，这个状况你忍住了，为了救自己的父亲。

<span id="p-30-035" class="reading-anchor"></span>

两个人，你跟你父亲都面临死亡的威胁，你把生的机会留给自己，让父亲死了，此处可忍吗？此处若还能忍，孰不可忍？什么都可以忍了。这就是完全在自身的躯壳中了。

<span id="p-30-036" class="reading-anchor"></span>

所以讨论的，你的问题提出来是好，因为欲望是本有的，因为我们都是生命体。它没有善恶，没有错，就在实现欲望的时候，一定处在与他人的关系中。既然处在与他人的关系当中，就应当从心体上起念，而不是从躯壳上起念。

### 改善生活与父母的牺牲

**回看 19:00—21:32**

<span id="p-30-037" class="reading-anchor"></span>

我这份念还是要求改善生活的，但不是从自己的躯壳上起的，在社会关系中起这个念。这样的事情很多很多。尤其是在中国儒家的文化精神传统中，许多父母都是这么自我牺牲的。他要孩子过得好，过得好是人人共同的愿望，但是父母愿意什么？牺牲自己。

<span id="p-30-038" class="reading-anchor"></span>

追求的目标都是要生活更好，不是抽象地谈善恶，不是离开欲念谈的。我也想吃饱肚子，我也想穿得漂亮一点，我也想锦衣玉食，这有什么错呢？问题，如果你的锦衣玉食以人家的衣不蔽体为代价，那完了，那就躯壳上起念。

<span id="p-30-039" class="reading-anchor"></span>

所以这是自然会提出来的问题。只是我们这把年龄还讨论这问题，我觉得迟了。实际上我们小时候就应该懂这个道理。就是那个孔融让梨，听说过？梨都想吃的，但处在与人的关系中，弟弟让给哥哥，孔融让梨。这就本体的念。

<span id="p-30-040" class="reading-anchor"></span>

我们的喜怒哀乐，都跟我们的对幸福的追求有关。幸福达到了，我们喜了、乐了。幸福没达到，我们愤怒了、哀了、悲哀了、怒了。这些都是人的情感。问题是你因什么而喜，因什么而怒，因什么而哀，因什么而乐？这里就有一个区分。人心真诚恻怛地求生，这生便是天理。

人心真诚恻怛地求爱，这爱便是天理。

<span id="p-30-041" class="reading-anchor"></span>

关键是什么？真诚恻怛。真诚恻怛就不会在自己的躯壳上起念。我们中国人要讲这些，这些话不讲不行。因为人作为人存在了，否则我们就活在动物界。那么作为人存在了，人怎么作为人存在？

## 本讲总结｜整理附录

本讲首先纠正把养心理解为止息一切念头的做法。静、动与定须回到心体，关键是念从哪里发动，而不是把心弄成死灰。

改善生活的提问使这种区分落到社会关系里。欲求必须在与他人的关系中实现，课堂据此解释亲亲、爱有差等与真诚恻怛，同时保留具体例子和有争议的主张。
