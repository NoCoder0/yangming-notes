# 第53讲 以格物致良知，才是有根的学问

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—15:33

**阅读导引｜整理附录**　本讲以「致良知在格物上用功」为主线，详细讨论父母与孩子如何在交往中共同成长。给孩子尽责任的机会、纠正情感的偏差，最后都返回有根的学问。

## 一分钟速读｜整理附录

1. 良知不能只悬空谈论，要在做事情中呈现。
2. 审视喜怒忧惧，是格物功夫的实际过程。
3. 父母也在与孩子交往中学习怎样成为父母。
4. 包办一切可能剥夺孩子尽责任的机会。
5. 有根的学问与外表修饰的区别，最终要在事情中看。

## 良知在哪里致

**回看 00:00—05:03**

<span id="p-53-001" class="reading-anchor"></span>

好，各位，我们继续课程的第四部分，第三十七条，《黄修易录》的第三节。第三节不是对话，是实录阳明的原话。「吾教人致良知在格物上用功，却是有根本的学问」，就是有根有本的。「日长进一日，愈久愈觉精明。」

<span id="p-53-002" class="reading-anchor"></span>

这个「精明」，不是现在所说的聪明、精明能干。良知在哪里致？不是悬空讲良知，天天讲致良知没什么用。心里还记得：「我本有良知。」你怎么知道自己本有良知？「阳明告诉我的。」

我们要自己知道本有良知。什么时候知道？做事情中知道，你遇到事情了。

<span id="p-53-003" class="reading-anchor"></span>

陆九渊讲，「人情只在事变中」。一切事情都是心事，心外无事。这一点我们曾经多次讲。什么叫一切事情都是心事？就是引起你情感变化的事情才叫事情，不会引起你情感变化的，不是事。情感变化就是或喜或怒，或忧或惧，或哀或乐。这叫情感变化。

<span id="p-53-004" class="reading-anchor"></span>

事情来了，那么你要去对付这件事了吧。好事嘛，你拥抱它。你觉得让你难过乃至愤怒的事情，你怎么去拒绝它？这些都是心事来了。然后下功夫，怎么下功夫，如何做这件事？事情来了，就是心事来了。心事来了，你怎么做？

<span id="p-53-005" class="reading-anchor"></span>

在做的过程当中，你的情感也变化。人的生命实践都是情感的实践。自始至终，我们的情感一直在变。在变的时候，我们就得审视，我这个喜是否当喜，我这个怒是否当怒，我这个忧是否当忧，我这个惧，就惧怕的「惧」，是否当惧。谁来审视？

<span id="p-53-006" class="reading-anchor"></span>

因为在做事情的过程中，事情肯定在不断改变着、变化着，遇到各种意外的因素闯进来等等。阻挠、困难，或者顺利，都有。在这个整个过程当中，我们只有一个目的，让事情终于做成了天理的实现。那么在这个目的的指引下，良知不断到场。

<span id="p-53-007" class="reading-anchor"></span>

不断到场来审视我们的情感变化。于是我们就不会被情感的变化所干扰，这叫格物功夫。在格物上用功，我们的目标很清楚，至善。让我们做事情的整个过程，此心纯乎天理之极，这是我们的目标。不容易达到啊。

<span id="p-53-008" class="reading-anchor"></span>

我们在做事情的时候，时而顺利，时而困难，时而挫折，时而走投无路，都有，困境重重。在这种情况下，你的心纯乎天理之极，难不难？所谓天理之极，就是天理不是写在天空上的理，天理是我们生命情感本真的条理。很容易偏的，闲思杂虑全来了，私意安排也来了。

<span id="p-53-009" class="reading-anchor"></span>

格物是一个功夫，就是致良知的功夫。致良知在格物上用功，也就是在正事上用功。这个用功是一种不断的积累，积累我们的一种能力。

这不是具体做事情的本事，而是总能让良知到场。良知随感随应，能达到这一点，叫精明，做任何事都一样。

## 做父母也要在事情上用功

**回看 05:03—08:42**

<span id="p-53-010" class="reading-anchor"></span>

父母跟儿女打交道、交往，父母们又承担着养育孩子的责任。那么跟孩子的交往，不就是事情吗？孩子成长得好，你高兴。孩子的成长遇到挫折，你难过。不叫事情来了吗？一切事情都是心事。

<span id="p-53-011" class="reading-anchor"></span>

最好没孩子，就没这个心事。谁让你生了孩子呢？生了孩子，不就有心事了吗？那么，跟孩子打交道也是一件事，那叫心事。在这个过程中，不断提醒自己：我的爱爱恨恨，是否有闲思杂虑？父母养育孩子也是格物。

<span id="p-53-012" class="reading-anchor"></span>

现在我们的父母有一个偏差，普遍的偏差，只关注这个孩子身体健康，学习成绩优秀，以为就是在尽自己最大的责任。其实是什么？你要关注的是你跟孩子的情感关系。你跟你孩子的情感，人与人的关系本身都是情感。你跟你孩子之间的情感本身是否出了问题？

这才是我们要用的功。

<span id="p-53-013" class="reading-anchor"></span>

在这个过程中，孩子成了我们的老师，你信不信？哪有一个男人天生是父亲？儿子出生的那一天，也把他作为父亲生出来了。你是天生的父亲吗？不可能。

要成为一个好的、合格的父亲，是你自己的成长过程。谁在教你？孩子。不是他有什么真理颁布给你，而是在跟他打交道的过程中，你才发现自己有许多问题。

<span id="p-53-014" class="reading-anchor"></span>

今天的父母如果不能自觉到这一点的话，问题就严重了。我们看到这种严重，到什么程度啊？就父母与儿女之间的关系彻底僵掉了，都不能交流、不能说话。动不动孩子得了什么抑郁症、焦虑症，或者干脆跳楼了。这问题多严重啊。

<span id="p-53-015" class="reading-anchor"></span>

所以一个男人的第二次成长表现在什么？他成了父亲。各位同学们，你做了几年父亲，旁人真发现你成长了。在这个意义上，孩子在教你呢。所有的关系都是交互性的。

<span id="p-53-016" class="reading-anchor"></span>

大多数的父母，在他们作为父母的成长过程当中，一般来说失败的多。鄙人也一样，基本上失败。等到终于似乎精明了，已经为时晚矣，孩子长大了，有些毛病就在他身上了，是吗？那么也没办法了，再生一个了。那么第一个成了实验品。尽管就是这样的。

## 给孩子尽责任的机会

**回看 08:42—12:23**

<span id="p-53-017" class="reading-anchor"></span>

我再举个例子。许多父母对自己长大的孩子不满意，不满意的其中有一条，太没有责任心了，有吧？批评自己的孩子，你怎么一点责任心都没有？你批评了，你要问问自己，他为什么没有责任心？为什么？在他成长的过程中，你从来没给他尽责任的机会。

<span id="p-53-018" class="reading-anchor"></span>

你和儿女的关系，你是爱着他，这是真的。但这个爱里边就不合适了，你包办一切。当你生病的时候，发烧了，躺在床上。你不要挣扎着还到厨房里把晚饭给他做好，然后你再去睡觉。不用，你好好躺在床上，你发烧了嘛。

<span id="p-53-019" class="reading-anchor"></span>

这时候，让孩子来侍奉汤水。只要他的年龄到了可以做这件事的时候，在你床前端上一杯热水，可以吧？现在还可以点外卖，点一份晚餐，捧到床头，让你吃下去。他看了很开心。你给了他尽责任的机会，这真是爱了。

<span id="p-53-020" class="reading-anchor"></span>

所以我们的这个情感要检查的。有时候你千万不要拒绝孩子对你的帮助。他也要帮助你，是他的情感，他的心。你要成全他这份心，是不是要成全？

<span id="p-53-021" class="reading-anchor"></span>

父亲打我们有两种，一种是手伸出来，把那把尺往你手心里敲，敲得你痛。你要让他敲。他如果举起大棒向你砸过来，你赶快逃。为什么呢？你为了成全他。他把你一棒砸死了，或者砸了重伤，他难受了。这时候逃就是成全他。

<span id="p-53-022" class="reading-anchor"></span>

我们的良知就这样起作用了呀。它不是僵死的教条呀，它活活泼泼、随感随应呢，就在跟人打交道的过程中。做事，没有一个单个地做的，总是跟人打交道的。

<span id="p-53-023" class="reading-anchor"></span>

你写一篇文章，你总要发表吧。虽然你在一个房间里一个人写，你想着读者吧。我发表了，发表在杂志上，谁来读？同行来读，还有非同行也来读，他们能得到些什么？你写书、写文章的时候，你就想着读者，已经跟人打交道了。

<span id="p-53-024" class="reading-anchor"></span>

所以一切事情都在人与人的关系中进行的。在这关系当中，就有一份情感总在的。要让这份情感合适，符合这种关系的本来性质、本来的人性价值，那叫致良知的功夫。

<span id="p-53-025" class="reading-anchor"></span>

所以我们要重新学习做父母。年轻的朋友们，你们成了年轻的父母，要重新学习了。这个重新学习其实就是什么？排除当下时代这个社会的种种病症对我们的干扰，回归父母与儿女关系的本来价值。这在打交道的实践中进行的，那叫格物。

## 有根的学问

**回看 12:23—15:33**

<span id="p-53-026" class="reading-anchor"></span>

底下阳明又免不了批评朱熹。这个「世儒」，这里指的其实就是朱熹。「教人事事物物上去寻讨」，不就是朱熹的主张，于事事物物上求天理吗？「却是无根本的学问。」这个「根」就是树根。我们现在也说无根无本：却是无根本的学问。

<span id="p-53-027" class="reading-anchor"></span>

「方其壮时，虽暂能外面修饰，不见有过。」我也讲道德规则，我也讲道德的普遍原理，这些听上去不错的啊，这只是外面修饰。老了，「老则精神衰迈，终须放倒」，终于撑不住了。

<span id="p-53-028" class="reading-anchor"></span>

这又是比喻。「譬如无根之树，移栽水边，虽暂时鲜好」，因为在水边，它还获得营养之类的，「终久要憔悴」。

<span id="p-53-029" class="reading-anchor"></span>

当然，这里讲的学问，不是我们今天所说的理论学说，是精神修养。所谓学问就是精神修养，要有根，而不是无根。根在哪里？在格物上用功。这根就扎好了。根没扎好，年轻时候似乎还像个样子，正人君子的，恪守道德规则的，到后来他也撑不住了，老了不行了。

这个比喻。

<span id="p-53-030" class="reading-anchor"></span>

所以一开始就应该把格物看成是致良知的功夫。致良知不能悬空地讲。你天天说致良知的，你能不能把良知拿出来给我看看？阳明能拿出来看，你看我做的事，比方说，是不是良知呈现了？就拿出来给你看了。不要脱离事情，不要脱离格物谈良知，那是悬空地讲。

<span id="p-53-031" class="reading-anchor"></span>

良知是真真切切的，就是我们做事的基本的目标和原则，也就是真诚恻怛。因为我们能真诚恻怛的缘故，我们做事情的时候，才不怕千难万难，不会觉得精疲力尽、疲惫不堪。不会。因为有一个真诚恻怛，我们不怕做事情遇到种种的阻挠、意外的、不好的因素闯进来，都不用害怕。

此事正是用功处。对，这一段课就先讲到这里。

## 本讲总结｜整理附录

本讲的「精明」指良知能随感随应，不是世俗的精明能干。事情不断变化，良知不断到场审视情感，格物因此是一项持续的功夫。

家庭讨论保留了父亲的再次成长、包办、侍奉汤水及成全之心等具体过程。最后以无根之树作对比，说明不能离开格物另谈良知。
