# 第25讲 人要随才成就，才是其所能为

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—28:55

**阅读导引｜整理附录**　本讲从名物度数是否应先讲求，转入随才成就、成人与成才。莫扎特和贝多芬的故事、专业教学、儿童唱歌与神童教育等旁支，共同展开心体与才的关系；结尾又回到君子不器和随处境行事。

## 一分钟速读｜整理附录

1. 心体与知识有本末关系，并非把名物度数全然不理。
2. 随才成就承认人与人禀赋不同，又以心体纯乎天理为根本。
3. 成人与成才不应分开，也不是先上完品德课再学专业。
4. 音乐家、科学教育与儿童生活的例子，用来说明精神成长如何进入专业学习。
5. 君子不器既涉及专业局限，也涉及不被一种生活处境限制。

## 名物度数，亦须先讲求否

**回看 00:00—04:28**

<span id="p-25-001" class="reading-anchor"></span>

我们继续在阳明的《传习录》中讲养心功夫。我们再接着讲第十一条，也还是在《陆澄录》里，第五十节。先是陆澄提了这样一个问题，「名物度数，亦须先讲求否？」天下的事物、种种的事物，各有分别。这些事物都有了概念规定的，叫「名」。

<span id="p-25-002" class="reading-anchor"></span>

名物度数，比方说我们还计算事物的量，这些是不是都应当先讲求？就是我们对万事万物都要有知识、有了解。先问这样一个问题，阳明怎么回答？

<span id="p-25-003" class="reading-anchor"></span>

阳明说，「人只要成就自家心体」，又用「心体」这词了吧，也就是心之本体，也就是良知，「则用在其中」。前面讲心体，一个体字。后面就讲用。体用关系吧，体用不二，有此体便有此体之用。「如养得心体」，不就是未发之中嘛。

「喜怒哀乐之未发，谓之中」，《中庸》中的话。所以凡说未发之中，便说的是心。

<span id="p-25-004" class="reading-anchor"></span>

自然就有发而中节之和，发而中节之和就是用，未发之中就是体。「自然无施不可」，怎样做都是对的了。「苟无是心」，假如把自己的心体遮蔽了，「虽预先讲得世上许多名物度数，与己原不相干」。你去了解种种的事物，去认知，去认识种种的事物，那是太多了啊。

<span id="p-25-005" class="reading-anchor"></span>

我们需要知道那么多吗？把天下万事万物全了解清楚了，需要吗？若不从心体出发，干嘛要认识？推动我们对事物的认识的动力在我们的心。假如心体被遮蔽了，你要去了解那么多干嘛？原不与自己相干。

<span id="p-25-006" class="reading-anchor"></span>

「只是装缀临时」，就像许多人卖弄知识。「自行不去」。卖弄了这些知识，你做得了吗？还是做不了。做事是不是心推动的？心之行嘛。所以讲那么多知识，离开心体讲这些知识，讲了也不会去实践。因为实践的动力毕竟还是来自心。

<span id="p-25-007" class="reading-anchor"></span>

「亦不是将名物度数全然不理」，不要这么误解。只要「知所先后，则近道」。这是引用了《大学》里的话了，「知所先后，则近道」。知本末的关系啊，我们对世界上事物的种种的认知是末，不是本。

<span id="p-25-008" class="reading-anchor"></span>

底下又继续展开一个话题。比方说人的本事哪里来？我们是都说从学习中得来。我们从小就要到学校去学知识、学文化去了吧。进入小学，然后初中、高中，今天的教育体制吧，然后最后大学。

## 因材施教

**回看 04:28—08:33**

<span id="p-25-009" class="reading-anchor"></span>

那么就讨论到一个教育问题，我们学哪一科、哪一种专业。这是不是个问题啊？先前倒是基础教育，各科都得学，这是从小学到高中。然后必有一个专业的选择，就考大学了，考大学的大学生都有专业属性，是吗？那么就引起一个很重要的关于人如何成才的讨论。

<span id="p-25-010" class="reading-anchor"></span>

阳明说，「人要随才成就」。这个「才」就是这个「材」字，什么材料，就人的禀赋不同，千差万别。有的人适合研究玄妙的学问，做抽象思维，甚至可以研究数学当中最难的部分，叫数论。比方说陈景润，要解哥德巴赫猜想的，他那篇数学论文我们都看不懂的啊，极度抽象。

<span id="p-25-011" class="reading-anchor"></span>

有的人喜欢哲学，终于研究到黑格尔的哲学中去了，那也是极度抽象的范畴的演绎、概念的推论。有人能做这样的事，有的人做不了这样的事。有的人在形象的领域里边非常敏感，在感性世界当中，他极敏感，这是他的禀赋了。

还有的人心灵手巧，将来一定会成长为能工巧匠，这是他的禀赋。

<span id="p-25-012" class="reading-anchor"></span>

所以阳明就说人要随才成就，去发挥好自己的天赋。孔子教哲学，他还强调因材施教呢。虽然教的是论道的学问，还是人与人之间不一样的，所以叫因材施教。所有的人都应当得到教育，那叫有教无类。但教学的方法和领域要有所不同，那叫因材施教。

<span id="p-25-013" class="reading-anchor"></span>

所以我们读《论语》就会注意到，有些话孔子只可能跟颜回说的，跟子路就不说这样的话。因为颜回和子路材不一样，材质不同。现在阳明开始举例子了，你看历史上传说的人物，「如夔之乐，稷之种」。这个夔啊，也是传说中在舜做帝王的时候，他是掌管音乐的，所以叫夔之乐。

<span id="p-25-014" class="reading-anchor"></span>

那个叫稷的人，说是周人的先祖，在尧舜的时候专门主管稼穑的事情，就农事。种植谷物是他的专长，掌管音乐是夔的专长。「是他资性合下便如此」。什么叫资性？禀赋。

<span id="p-25-015" class="reading-anchor"></span>

「成就之者，亦只是要他心体纯乎天理」。如何成就呢？我们每个人的禀赋、天赋都在那里了，能不能成就要点在哪里？要点是心体纯乎天理。要教他这一点，最根本，然后他的禀赋才能合适地发挥。「其运用处皆从天理上发来」才好。

## 成人与成才

**回看 08:33—12:20**

<span id="p-25-016" class="reading-anchor"></span>

这就是我们现在要展开的一个非常重要的讨论。讨论什么？成人与成才两者的关系。其实也没有一个先后，等会儿我们就把这说明白。成人，就是让得到教育的学生作为人，成其为人，我们通常叫育人。

<span id="p-25-017" class="reading-anchor"></span>

那么什么叫成才呢？让我们的学生成为某种人。所谓某种人，就是专才，用英语来说叫 specialist。现在时下中国教育的一个大家看到的弊端是什么呢？就把成人忘了，只关注成才。从小学开始就这么干了。因为文化知识课的考试决定了你将来读初中的情况，还要择校。

<span id="p-25-018" class="reading-anchor"></span>

那么初中呢，也是文化知识课考试，数理化特别重要，还加上一个外语，都是某种能力的培养。这种能力的培养就是指向成才嘛。然后终于到了高中，考取重点高中，然后要敲开名牌大学的大门，然后在某一个专业当中毕业了，将来找一份收入丰厚的职业，就成才教育。

<span id="p-25-019" class="reading-anchor"></span>

大家觉得理所当然，没有任何疑问。大学要为社会服务，为社会提供专才，不都是这么想的吗？结果把成人这一面忘了。连哈佛大学也忘了。二〇〇六年那个哈佛大学哈佛学院的院长，从职位上下来之后，用了大概一年左右的时间写了一本书。

<span id="p-25-020" class="reading-anchor"></span>

后来这本书有中译本，书名是什么？《失去灵魂的卓越》。这哈佛大学很自豪，我们培养社会精英，专业领域里边将来的 leader，领导者、高级人才。然后他的书名说「失去灵魂的卓越」，副标题「哈佛大学是怎样背离教育的宗旨的」。有中译本。

<span id="p-25-021" class="reading-anchor"></span>

这表明哈佛大学保持了自我反思的能力，没忘了自我反思、自我批判。那么我们今天是不是也应该多做一点自我反思和自我批判呢？这里边虽然是阳明短短的几句话，实在对我们启发很大。就是什么呢？就成人与成才的关系。

<span id="p-25-022" class="reading-anchor"></span>

我们先把这段看完再讲。我们读到这样的话啊，因为我们每个人有天赋，这是对的，叫才。成就是什么意思呢？「亦只是要他心体纯乎天理。其运用处皆从天理上发来」，就是我们运用自己的天赋，这叫运用。要从哪里发出来用？要从天理上发来，然后才真能称为什么？人才。

换句话说，不能成人也成不了才，是吗？

## 君子不器

**回看 12:20—14:09**

<span id="p-25-023" class="reading-anchor"></span>

「到得纯乎天理处，亦能不器」。不器是谁说的话？孔子说「君子不器」。「器」就是专才的意思嘛。我们确实想让自己成长为专才，因为器才能用嘛。但是器是用来行道的，因为每个人发挥自己的天赋，都是从天理上发挥的。

<span id="p-25-024" class="reading-anchor"></span>

终于能到得纯乎天理处就纯了，这个境界终于是纯了。到达纯的境界的时候，也能做到什么？不被自己的专业所限制，那就不器了。好，他还假定，假如让夔和稷彼此交换啊，让夔去做掌管农事的工作，做那样一个官，让稷去做掌管音乐的官，这叫易艺吧。

<span id="p-25-025" class="reading-anchor"></span>

「使」，假定啊，「使夔、稷易艺而为，当亦能之」，也行。好，我们把这段话念完了。现在讨论，特别是讨论随才成就这四个字。「随」表示说按照每个人不同的天赋，让他得到教养。那么教养有成就了，成就为真正的才了，前提是什么？我们举一个例子便能说明。

## 莫扎特和贝多芬

**回看 14:09—20:12**

<span id="p-25-026" class="reading-anchor"></span>

我们都知道，在欧洲近代音乐的舞台上，音乐的历史中，有一个真正的天才，毫无疑问的天才，莫扎特。莫扎特是神童，没有人会怀疑。莫扎特才五岁的时候，就作了第一部曲子，才五岁的孩子。他的父亲看到自己儿子作的这个曲，看了，惊讶了，绝对是天才之作。

<span id="p-25-027" class="reading-anchor"></span>

莫扎特的父亲一辈子有个梦想，成为一个出名的作曲家。他创作了不少作品寄给出版商，出版商都退回，不要。所以莫扎特的父亲只能成为宫廷乐师。现在儿子来了，五岁就作出这么了不起的曲子来，他不仅是惊讶，甚至嫉妒起来。

<span id="p-25-028" class="reading-anchor"></span>

这在中国不可能的。父亲不会嫉妒儿子的，他们可以的。想想，你怎么比我厉害多了。心里不舒服了。莫扎特十岁的时候已经作了三部歌剧了。想一想，我想我自己王德峰十岁的时候在干嘛？他三部歌剧作好了。这是天才，毫无疑问了。

<span id="p-25-029" class="reading-anchor"></span>

问题是什么？问题是像莫扎特这样的罕见的天才，也不是只有他一个，其实有。但现在我们知道的就莫扎特了，在他那个时代啊，那个年代。当然后面还有贝多芬一连串的人物。像莫扎特、像贝多芬这样有音乐天赋极高的人，并不是仅仅他们这几个，你们信不信？

<span id="p-25-030" class="reading-anchor"></span>

也同样得到机会成长，家里有条件让他们从事音乐的学习。也可以呀。但是真的最终在欧洲音乐历史上留下来的，甚至为这个音乐发展成为一种里程碑式的人物，就这么几个。那么其他那些跟莫扎特一样有极高的天分的神童，又到哪里去了呢？

<span id="p-25-031" class="reading-anchor"></span>

这里边的差别是什么？莫扎特虽然是在音乐领域里的天才，但他关注哲学的，也关注文学，从中获得许多的滋养，他的心灵就大，悲天悯人。正如阳明所说的，从天理上发来。倘若莫扎特没有这种在音乐之外的精神修养，他如何能成为一个伟大的作曲家，维也纳古典乐派的集大成者？

<span id="p-25-032" class="reading-anchor"></span>

一个时代用他来标志，欧洲当时音乐的这个古典主义阶段，用他来标志的，维也纳乐派从海顿到莫扎特。后来来了个贝多芬，又开了浪漫主义先河。一个转折点上的人物也来了。贝多芬一定也是天才。

<span id="p-25-033" class="reading-anchor"></span>

贝多芬有天下关怀。他写第三交响曲，叫《英雄交响曲》，本来要题呈给谁？拿破仑啊。拿破仑是个骑在马背上的世界精神，要改变欧洲社会，让欧洲社会进入近代啊，一手拿着宝剑，是吧，一手拿着一部《拿破仑法典》，一个新时代的法典。

<span id="p-25-034" class="reading-anchor"></span>

那么黑格尔赞赏过拿破仑吧，「瞧，一个骑在马背上的世界精神」。贝多芬也赞赏了拿破仑啊。贝多芬仅仅在自己音乐的范围里边吗？他的天赋用来什么？为时代唱出歌曲来。他叫时代的歌手，贝多芬。他心中没有时代，他怎么成就？心中为什么有时代？这个心，天下关怀。

<span id="p-25-035" class="reading-anchor"></span>

莫扎特晚年穷愁潦倒，其生活的困窘，都写在他给他友人的一封信里了。这封信在的，如今我们读了也会潸然泪下。这么伟大的音乐家、作曲家，生活如此的困窘、贫寒。就在这种贫寒困窘的生活处境中，却写出了第四十一交响曲，又名《朱庇特交响曲》，写出了人间至高的欢乐。

<span id="p-25-036" class="reading-anchor"></span>

不要以为作曲家的作品，是当他写这部作品的时候的自己的生活处境的反映、表达。不，他处境很糟糕，但一定要写出人类至高的欢乐来。这是他的心。个人是如此的苦难，却为人类写出伟大的欢乐。莫扎特此心如何想？用阳明的话，「到得纯乎天理处」。

<span id="p-25-037" class="reading-anchor"></span>

到了这个境界了，他不仅是在音乐范围里边的一个器。他叫真君子了，君子不器。所以这就对我们启发非常大了。

## 成人是在成才的实践中成的

**回看 20:12—23:48**

<span id="p-25-038" class="reading-anchor"></span>

我们都知道人才培养，最后培养成真正的才了没有呢？成人方能成才，但不是先后。先后的教育就变成一件什么事。大家先在一个学校别的不管，思想品德课，天天讲思想品德课，这能成？这叫成人吗？

<span id="p-25-039" class="reading-anchor"></span>

成人是在成才的实践中成的。是吗？你在学物理，你也在学化学或者生物学，你在这个专才能力的成长中，同时领会这个领域中的人类的精神和对人类生活的真实意义在哪里，是吗？所以不要脱离我们的这个人才培养，光讲一个育人，那是空的，就是空的。

<span id="p-25-040" class="reading-anchor"></span>

就是专业的课该怎么讲，教师很重要。教师在专业知识的传授中，要时时把人的境界放进去。讲物理学的每一种知识，都是人类智力曾经做过的巨大的冒险而获得的成功。所以要结合，比如说自然科学史来学自然科学。在自然科学史当中，我们成人，同时也在成才。

<span id="p-25-041" class="reading-anchor"></span>

小时候教孩子唱歌，可以吧？他也唱得欢天喜地的。在幼儿园就上音乐课。或者绘画课。那么教他技能肯定教了，但是让他的心灵进入这艺术，那么这也是成人了。在很好的儿歌中体验了生活，憧憬着未来。

<span id="p-25-042" class="reading-anchor"></span>

小时候我们最喜欢唱的一首歌，是我们这一代人唱的儿歌，《让我们荡起双桨》。这既是声乐的训练，儿歌的童声的合唱，是不是训练了专才了吧，专才的最初培养吧。它同时在这个歌曲当中，让每一个孩子感受到当时毛泽东时代少年的心灵，他的精神展开了，蓬勃向上，是吗？

<span id="p-25-043" class="reading-anchor"></span>

现在的误区就是把成人压根忘了，这是专才的训练，这是误区一。第二个误区，说起成人呢，又把成才放到后面再去说，把两者脱离。误区二。其实不管让我们的孩子去学哪一种专业的能力，都要让他在这种学习中感到心灵的提高，君子的养成，天下关怀的胸襟。

<span id="p-25-044" class="reading-anchor"></span>

这种天下关怀不是空说的，要能够什么？领会民间的疾苦，以及我们的民族正在从事的奋斗，是吗？这是结合在一起的。于是他就有志向，将来在自己的专长范围内，就天赋的范围内，推动整个民族的进步，做出他自己的贡献来。他才能真成人才了，方能成才。

### 神童也需要社会生活

**回看 23:48—26:34**

<span id="p-25-045" class="reading-anchor"></span>

「才是其所能为」，成就就是这么理解的，否则没成就。我印象很深，在改革开放之后，有一个阶段，大家关注神童，少年科技班，听说过吗？有许多神童在报纸上报道了，我们非常惊讶。这些人现在多大年龄，不知道到哪里去了，是吗？真成了数学家的吗？没有啊，为什么没有呢？

<span id="p-25-046" class="reading-anchor"></span>

为什么他如此高的天赋，终于让他成就不了了？他们的教育缺失很大一块了。你把他当一个神童啊，培养了，专门一个班。实际上在人生的经历当中，他们还有许多缺失、没有感受的东西。他们没有那个心，对天下关怀的心没有养出来，这就让我们感到莫大遗憾了。

<span id="p-25-047" class="reading-anchor"></span>

所以虽然承认天才的存在，但是天才要真成才，他同时就是成人。不成人，他成不了才，只是一时有名声的神童罢了，是吗？需要在社会生活当中磨练的，需要跟人打交道，在打交道当中成长，精神成长。

<span id="p-25-048" class="reading-anchor"></span>

小孩子要打架，把孩子关起来，作为神童专门培养，就不打架了。男孩子跟男孩子之间就应该打架的。有时候就要上演英雄救美女，某男同学欺负女同学了，那个男同学上去干了。可以吧，两个人对峙着呢。双目对峙啊，我在你的眼神中看到了怯懦，你在我的眼神中看到了勇敢。

这就是男孩子的成长。现在都在网上生活。

<span id="p-25-049" class="reading-anchor"></span>

所以所谓某一个领域里边禀赋特异的天才，不能让他跟社会生活分开。他在社会生活中才是真正成长。那叫亲民，第二条纲领，参与体察人民生活。成人与成才统一起来。

## 两种读法

**回看 26:34—28:55**

<span id="p-25-050" class="reading-anchor"></span>

这就是我们看的这十一条，「人要随才成就，才是其所能为」。可以有两种读法。一种就是「才」就是材质，他的禀赋是他所能做的，因为底下的话说明这一点，举了例子，夔和稷。但是随才成就，成就不成就，这就是另外一件更重要的事，「只是要他心体纯乎天理」。

成就了这个才，才是他所能做的了。

<span id="p-25-051" class="reading-anchor"></span>

所以这个「才」可以两种理解，一种是什么，一个副词，「方是其所能为」；或直接把它理解成前面讲的材质的「材」，也都可以。问题关键是什么？成就。

<span id="p-25-052" class="reading-anchor"></span>

最后一段我们不妨把它看完啊。「又曰：『如素富贵，行乎富贵；素患难，行乎患难。』」引自《中庸》，「君子素其位而行」。这都是不器的意思。我们的生活处境经常会改变，不管怎么改变，我们都在我们所处的生活处境中，做好在此处境中的人该做的事。

<span id="p-25-053" class="reading-anchor"></span>

素富贵，就向来富贵，「素」就向来。那么就行乎富贵，做一个富贵之人该做的事。素患难，向来患难了。就做一个患难之人该做的事，叫行乎患难。也是不器的意思。就不把自己局限在某种特定的生活处境中，不能改变。如果不能改变，就是器局限了。

<span id="p-25-054" class="reading-anchor"></span>

能达到这种境界叫什么？「此惟养得心体正者能之」，才能做到。养心是根本，存养扩充我们的心体。我们的这一段课就先讲到这里。

## 本讲总结｜整理附录

阳明的回答先把名物度数放回体用、本末之中，再讨论怎样成就人的才。课堂的核心不在否定专才，而在追问专才凭怎样的心去运用才能。

成人发生在成才的实践中。讲专业时领会其人类意义、在社会生活中成长，才使才能有真正的成就。结尾的富贵、患难之辨将不器的意思进一步展开。
