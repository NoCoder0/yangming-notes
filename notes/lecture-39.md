# 第39讲 听讲不难，体味不易

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—08:04

**阅读导引｜整理附录**　本讲从陈九川对致知的体验讲起，区分听讲时觉得容易与下功夫后尝到滋味。亲口尝梨、黄岩蜜橘和信仰的故事依次展开，最后回到在事情中养心、以本心立信仰。

## 一分钟速读｜整理附录

1. 体验之后觉得不同，才能说明功夫与先前有了变化。
2. 听讲时觉得容易，可能仍未尝到滋味。
3. 日见不同没有穷尽，要在持续实践中体会。
4. 尝梨与蜜橘的比喻说明体验不能只由别人讲给自己。
5. 信仰及人生境遇的讨论按课堂说法保留，最后返回养心。

## 体来与听讲不同

**回看 00:00—03:48**

<span id="p-39-001" class="reading-anchor"></span>

继续在阳明的《传习录》中学养心功夫。现在看第二十三条：听讲不难，体味不易。《陈九川录》第十一节。

那一次阳明主动问：「九川于致知之说，体验如何？」你有什么体验了？

当然要陈九川下过功夫才行。

<span id="p-39-002" class="reading-anchor"></span>

陈九川回答了，「自觉不同。往时操持，常不得个恰好处，此乃是恰好处。」听了阳明讲解致知之说，就让良知到达这种功夫。以往也是做过努力的，总得不到一个恰到好处，此乃是恰好处。

我现在用功，和先前用功已经不同了。

<span id="p-39-003" class="reading-anchor"></span>

自己的体会不一样，自己觉得不同了。这个不同，总得说一说哪里不同呢？当初在用功的时候，总觉得并没有到个恰好处，现在总觉得是恰好处。阳明非常赞同了，「可知是体来与听讲不同」。

<span id="p-39-004" class="reading-anchor"></span>

「我初与讲时」，我最初跟你讲的时候，「知尔只是忽易，未有滋味」。没尝到滋味，总觉得哦，说来是这样，容易了。我们一起讲论阳明心学，讲着讲着大家就觉得容易了吧，很容易了。

<span id="p-39-005" class="reading-anchor"></span>

事情来了，第一件事，念头起来不要随念而走。处境变化了，不要在此境中停留。要知道，比方说禅宗讲的离二相，哦，对了，明白了。明白是明白了，只是最初的了解，未有滋味。

「只这个要妙，再体到深处，日见不同，是无穷尽的。」

<span id="p-39-006" class="reading-anchor"></span>

「又曰：『此致知二字，真是个千古圣传之秘。见到这里，百世以俟圣人而不惑。』」你见到这样的一个真功夫了，你就会知道，以后的千百世也会有圣人的。过去有圣人，将来百世中必也有圣人。

你让他来，未来的圣人在这件事情上也不惑了，也都同意。以往的圣人和未来百世后出现的圣人，在这一点上一样。

## 要知道梨子的滋味

**回看 03:48—04:39**

<span id="p-39-007" class="reading-anchor"></span>

这里强调了什么呢？讲论学问固然是重要，只是第一步。日常的下养心的功夫，日积月累地不要中断，那就是日见不同。这叫尝到各种滋味了。尝到各种滋味，也说不出来。我说了，你听了也没用。

要知道梨子的滋味，就得亲口吃一吃，毛主席说的。

<span id="p-39-008" class="reading-anchor"></span>

你说梨子好吃，怎么说，你那个听你说的人没吃过，也不知道好在哪里。只有亲口去尝一尝，也就亲自要去下功夫，下了功夫便自然知道。

## 黄岩的橘子和信仰

**回看 04:39—08:04**

<span id="p-39-009" class="reading-anchor"></span>

我有一个朋友曾经问一个老太太，这老太太是基督徒。那我这个朋友当年就到教堂里，怀着好奇心，看他们礼拜，礼拜日做礼拜，星期天做礼拜嘛。那么遇到老太太，就问老太太，你怎么会相信上帝的？

中国人喜欢问，上帝在哪里呢？你怎么会信的呢？

<span id="p-39-010" class="reading-anchor"></span>

朋友以为老太太会解释《圣经》的教义。老太太一句也没这样讲，只说：我们都听说黄岩的橘子好，黄岩出蜜橘。橘子很好吃，好吃成怎样？只有吃了才知道。

我信仰上帝对我的好处，没办法跟你讲，只有你自己信了才知道。

就是这个意思。

<span id="p-39-011" class="reading-anchor"></span>

我们中国人很少有真正的宗教信仰，比方说信仰基督教。我也没有基督教信仰，但是我至少能够领会到一点，有信仰和没信仰的区分。有真信仰的人是值得我们羡慕的。他面对人生各种境遇，也会面对疾病、痛苦、人生不能忍受的处境，也面对死亡。

有信仰的人就是坦然，泰然处之。

<span id="p-39-012" class="reading-anchor"></span>

我们做不到。我们遇到突然来的困难、挫折、打击，我们张皇失措。这是真的嘛。平时没事的时候觉得很好，everything is OK，然后突然那个灾祸来了，有信仰的和没信仰的区别，一眼望就知道了。

他那种镇定和从容，谁给他的？信仰给他的。

<span id="p-39-013" class="reading-anchor"></span>

人生总会遭遇种种的，多一点少一点，早一点晚一点，对吗？有信仰和没信仰的差别就来了。所以那老太太说得对的，你别问我怎么会信仰上帝的，我也讲不清楚。黄岩那个地方的橘子好吃，我怎么跟你讲都没用，你去亲口吃就是了嘛。

<span id="p-39-014" class="reading-anchor"></span>

这话对。口上说、耳朵听，讲来讲去终究跟什么？自己体会不一样。有这层意思。听讲不难，体味不易。但我们没有宗教，我们在哲学中以本心立信仰，以良知立信仰，中国人自己的信仰，要养心。

养心在事情中养，那叫下功夫。下了功夫，叫尝了滋味，便能坚定。好，就到这里。

## 本讲总结｜整理附录

阳明询问体验，陈九川以今昔用功的差别回答。课堂据此强调讲论只是第一步，听起来容易与实地用功后的滋味并不相同。

老太太以黄岩橘子回答信仰问题，使前面的滋味比喻进入人生处境的讨论。结尾没有把课程改作宗教劝信，而是回到中国人在哲学中以本心、良知立信仰的授课主张。
