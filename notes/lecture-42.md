# 第42讲 好恶只从良知

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—14:44

**阅读导引｜整理附录**　本讲从陈九川赠诗中的「好恶从之」追问：从的究竟是什么？随后转读《答聂文蔚（二）》，由家庭中的孝悌讲到同一个真诚恻怛如何贯通种种关系，最后比较如如之心与如意之心。

## 一分钟速读｜整理附录

1. 好恶从之，所从的是良知。
2. 从小我出发的爱恨，被本讲联系到佛家的我执。
3. 在事亲从兄中得力，不等于可以把这一支节定作全部功夫。
4. 良知只有一个，真诚恻怛贯通事亲、从兄、事君等关系。
5. 如如之心与求如意之心的区别，成为结尾省察好恶的线索。

## 好恶从之，从个甚么

**回看 00:00—03:14**

<span id="p-42-001" class="reading-anchor"></span>

我们继续说下来，在《传习录》中学养心功夫。第二十六条，好恶只从良知。第十七节，《陈九川录》第十七节。「虔州将归」，也就是说陈九川要告别了。「有诗别先生云」，他写了首诗给阳明。

<span id="p-42-002" class="reading-anchor"></span>

「良知何事系多闻？妙合当时已种根。好恶从之为圣学，将迎无处是乾元。」

<span id="p-42-003" class="reading-anchor"></span>

我们看注释一，讲乾元，乾坤的乾。乾元指万物产生的根源，语出《周易·乾卦》，「大哉乾元，万物资始」，万物从中出来。将迎就是待人接物，将就是送别人走，迎就是迎别人来，送往迎来。「无处是乾元」，就在具体的事情当中，我们看不到乾元。这样一首诗给了阳明了。

<span id="p-42-004" class="reading-anchor"></span>

阳明还要问他：「若未来讲此学，不知说『好恶从之』从个甚么。」你写这首诗给我，说「好恶从之为圣学」，阳明没有否定这句话，只是问：从，从个什么呢？

「敷英在座」，这是另外一个弟子。他说：「诚然。」正是如此。「尝读先生《大学古本序》，不知所说何事。」

<span id="p-42-005" class="reading-anchor"></span>

以前曾经读过阳明为《大学》的古本作了个序，其实也不知道所说的是什么事。「及来听讲许时，乃稍知大意」。那个稍知大意是什么？没说出来。他们来到阳明这里听讲学，阳明心学之根本，做最高最大的概括是什么？三个字，致良知。

<span id="p-42-006" class="reading-anchor"></span>

整个阳明心学三句话了，心即理、知行合一、致良知。致良知是阳明心学最后的结论。这一点我们都知道，所以我们自然就明白第十七节讲的「稍知大意」，也就是稍知致良知这件事。

## 好恶为什么会从小我出发

**回看 03:14—07:04**

<span id="p-42-007" class="reading-anchor"></span>

好恶从之，这个「之」是谁，是什么？良知。好恶从之，也就是好恶只从良知。这件事该怎么讲？为什么我们每每不能从良知？

好，就是喜欢了；恶，就是恨了。我们的爱爱恨恨，能否只从良知？就这样一件事。我们不能从良知的缘故是什么？

<span id="p-42-008" class="reading-anchor"></span>

用佛教的话说得最明白，我执，小我自身的执着。我们恨什么、爱什么，我们每每从小我出发，那叫我执。我们若能够不从小我出发，从良知，那个功夫就是去我执。去我执，特别是禅宗所说的事，那是佛家的语言。

<span id="p-42-009" class="reading-anchor"></span>

若以儒家的语言来说，以阳明心学的语言来说，我们可以看《传习录》，答聂文蔚的那封信，《答聂文蔚（二）》。答聂文蔚有两封信。第二封信叫《答聂文蔚（二）》。这封信的第五节，我们找到这个地方。

<span id="p-42-010" class="reading-anchor"></span>

聂文蔚的来信里边说，「致知之说，求之事亲、从兄之间」，跟父母打交道、跟兄弟打交道，「便觉有所持循」者。「此段最见近来真切笃实之功。但以此自为不妨，自有得力处。以此遂为定说教人，却未免又有因药发病之患，亦不可不一讲也。」

<span id="p-42-011" class="reading-anchor"></span>

这段话什么意思呢？王阳明认为聂文蔚说的那段话是很好，叫致知之说，阳明的致知说。「求之事亲、从兄之间」，就我在家里跟父母亲打交道、跟兄弟姐妹打交道，便觉得有所依循了。阳明先肯定他，你这段话可以见到你近来真切笃实的功夫下过了。

<span id="p-42-012" class="reading-anchor"></span>

但是，「但以此自为」，你自己这么要求自己，自然不妨，自有得力处。如果你仅仅把这一点当作一种确定的说法来教别人，未免有因药发病之患。致知之说，你现在把它作为药来治自己的病了，但你又守住这个药不放了呢，又要发新的病了。「亦不可不一讲也」，就说你太狭窄了。

<span id="p-42-013" class="reading-anchor"></span>

你只知道致知之说，用于在家庭内部的亲人关系之上，要始终遵循的。但是你以为这就是最后的定论，来教别人，恐怕有问题了。

## 真诚恻怛是同一个

**回看 07:04—11:21**

<span id="p-42-014" class="reading-anchor"></span>

底下阳明说自己的意思了：「盖良知只是一个天理自然明觉发见处。」这里的印刷有问题：「盖良知只是一个天理」，后面有个句号。这句号不应该有，要把它去掉。

「良知只是一个天理自然明觉发见处，只是一个真诚恻怛」，这里要加逗号，「便是他本体」，这就对了。

<span id="p-42-015" class="reading-anchor"></span>

「故致此良知之真诚恻怛以事亲，便是孝；致此良知之真诚恻怛以从兄，便是弟；致此良知之真诚恻怛以事君，便是忠。」这是一个良知，一个真诚恻怛。

<span id="p-42-016" class="reading-anchor"></span>

「若是从兄的良知不能致其真诚恻怛，即是事亲的良知不能致其真诚恻怛矣。」同一件事。当然好像我们应当尊重兄长，你只是把它当成一个你应当遵守的规则了。我们之所以要尊重兄长，是那个真诚恻怛在。

<span id="p-42-017" class="reading-anchor"></span>

如果你从兄做不到这一点，那么你对父母，跟父母打交道的良知，也同样什么？不能致其真诚恻怛矣。「事君的良知不能致其恻怛，即是从兄的良知不能致其真诚恻怛矣。」都是一回事。

<span id="p-42-018" class="reading-anchor"></span>

无论跟怎样的人打交道，是跟双亲打交道，还是跟兄弟打交道，还是在朝廷跟朝廷打交道，等等，其实只是一个真诚恻怛。「不是事君的良知不能致，却须又从事亲的良知上去扩充将来。」不是的。「如此又是脱却本原，著在支节上求了。」

<span id="p-42-019" class="reading-anchor"></span>

「良知只是一个，随他发见流行处，当下具足」，它本是具足。「当下具足，更无去来，不须假借。」这一大段话，说到后来越来越像禅宗说的话。当下具足，更无去来。就不管什么事情，此事与彼事不同，跟不同的人打交道，在不同的关系当中。比如兄弟是种关系，儿女与父母亲又是种关系。

<span id="p-42-020" class="reading-anchor"></span>

我们在朝廷为官，那么跟朝廷也是种关系。种种的关系，在外跟朋友打交道，这些关系似乎都不同。但是良知，什么？更无去来，贯通的。这用佛家的话叫什么？如如之心，无滞无碍。你这个真诚恻怛，用佛家的话就是如如之心。

<span id="p-42-021" class="reading-anchor"></span>

如如之心在不同的人与人的关系中都一样。跟父母亲的关系是一种，跟兄弟姐妹的关系是一种，跟朝廷的关系是一种。假如你在地方上任官，你跟你所治理的百姓的关系又是一种。种种不同的关系，如如之心贯穿其中，无滞无碍。

## 如如之心与如意之心

**回看 11:21—14:44**

<span id="p-42-022" class="reading-anchor"></span>

有滞有碍的是什么心？如意之心。如我的意了，叫如意之心，不就是我执吗？去掉我执。我们在这世界上自然要爱爱恨恨，这是情感。好恶只从良知，只从如如之心。一定要知道良知不是头脑中的知，是份什么情感？四个字，真诚恻怛。

<span id="p-42-023" class="reading-anchor"></span>

又问：真诚恻怛如何达到？去我执。只要有小我的执着，那份情感便来自如意之心的好恶。

我们再度看到这里儒家与佛家的相通处。宋明新儒学不是实现了儒、道、佛三家合流吗？儒家讲它的心学境界，其中必有禅宗思想贯通。说法不一样，用的词语不一样，精神一致。

<span id="p-42-024" class="reading-anchor"></span>

佛家讲，如如之心即是真实。谁说的？弘忍，禅宗的第五祖弘忍。「一真一切真，万境自如如」。如如之心即是真实，什么叫真实？真诚恻怛。世界上所有的东西都是假的呀，只要一真来了，其他事情也就真了，一真一切真。没有如如之心这份真，如如之心是心而不是头脑。

<span id="p-42-025" class="reading-anchor"></span>

用儒家的话叫真诚恻怛来了，这一个真诚恻怛起来便是一真。所以你做的所有的事情，跟不同的人打不同的交道，全真了，叫一真一切真。否则我们都在假象中，我们可能一辈子就活在假象中。如果不精神修养的话，人生不就是假象吗？

<span id="p-42-026" class="reading-anchor"></span>

这就是阳明讲的去我执了。怎么叫去了我执？就去掉从如意之心出发的爱恨好恶。去掉这一点，我执就是去了嘛。我们每天会有喜怒哀乐。我们查一查，我们的喜怒哀乐是从小我出发的话，那就是一个求如意的心。求而不得叫不如意，不如意嘛就烦恼，就恨。

<span id="p-42-027" class="reading-anchor"></span>

所以这就是阳明心学跟禅宗修行的一致，一致的地方。好，先讲到这里。

## 本讲总结｜整理附录

赠诗与问答使「从良知」不止停留在口号上。《答聂文蔚（二）》先肯定亲人关系中的真切功夫，再警惕把得力的方法固定为唯一说法，反而因药发病。

正文保留了逐句解释、版本标点讨论，以及与禅宗的比较。这里的相通是课堂实际提出的哲学判断：去我执，让好恶出于真诚恻怛，贯通不同的人伦关系。
