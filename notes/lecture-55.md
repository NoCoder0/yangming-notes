# 第55讲 用功为己，勿念毁誉

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—09:11

**阅读导引｜整理附录**　本讲讨论用功的进退与社会毁誉。跌倒不必假装未跌，是说明不可助长；忍耐做去则说明功夫不依赖旁人的肯定。最后借八风与风幡之辨推进这一问题。

## 一分钟速读｜整理附录

1. 功夫有起伏，不应强装无破绽。
2. 跌倒就起来走，不必掩饰。
3. 不被肯定仍继续用功，是主体性的体现。
4. 诽谤、欺慢也可成为进德的材料。
5. 不动不是硬顶住，而是继续致良知的主宰。

## 最不可助长

**回看 00:00—02:39**

<span id="p-55-001" class="reading-anchor"></span>

好，各位，我们继续课程的第四部分。第三十九条跟三十八条还有关联。《黄修易录》的第七节，这第七节是继续实录阳明的原话。「诸君功夫，最不可助长」，揠苗助长。「上智」，上智的人绝少，「学者无超入圣人之理」。

<span id="p-55-002" class="reading-anchor"></span>

你是初学者，要超入圣人之理，不可能。「一起一伏，一进一退」，本是正常的，叫「自是功夫节次。不可以我前日用得功夫了，今却不济」。前一天功夫用得好，今天又不如前天，「便要矫强做出一个没破绽的模样来」。不要装样子。

<span id="p-55-003" class="reading-anchor"></span>

「这便是助长」，若你是要勉强地说我还是在前进了，这叫助长。这一揠苗助长的话，「连前些子功夫都坏了。此非小过。」如果我们有这种情况，这不是个小过错。

<span id="p-55-004" class="reading-anchor"></span>

「譬如行路的人遭一跌」，这不是绊了一脚吗？跌下来了，「起来便走，不要欺人做那不曾跌倒的样子出来」。说得多口语化。人有时候要装的，明明已经摔倒了嘛，好，马上起来，好像没倒啊。跌倒了就跌倒了。

## 依此良知，忍耐做去

**回看 02:39—06:21**

<span id="p-55-005" class="reading-anchor"></span>

「诸君只要常常怀个遁世无闷、不见是而无闷」。遁世无闷，就是世人都认为你没什么好、没什么意思，你的话也不对，不要难过。「不见是而无闷」之心，「是」就是肯定的意思。

<span id="p-55-006" class="reading-anchor"></span>

不见是，就是不见到他人对你的肯定，不被他人肯定，仍然心里不难过。「依此良知，忍耐做去，不管人非笑，也不管人毁谤，也不管人荣辱，任他功夫有进有退，我只是这致良知的主宰」，不要停息。「久久自然有得力处，一切外事亦自能不动。」

<span id="p-55-007" class="reading-anchor"></span>

外面的事情的变化，或者我做事情的结果如何，都不能撼动我。接着又说了，「人若着实用功，随人毁谤，随人欺慢，处处得益，处处是进德之资。若不用功，只是魔也，终被累倒。」

<span id="p-55-008" class="reading-anchor"></span>

如果自己不着实用功，别人的诽谤就起作用，简直是魔，终于被累倒。这也是心学精神的体现。心学精神就是主体性精神。

用功是自己的精神修养，是让自己的人生充满意义，不是为了别人表扬，不在乎别人承认不承认、诋毁还是赞美。

<span id="p-55-009" class="reading-anchor"></span>

所以人不要掩饰自己。有时候我们就一下子弄错了，或者就如跌倒了。不要装作自己不断在前进的样子。一起一伏是正常的，一进一退也是正常的。有时候我们就退一步，后来才进三步呢。你不会老是退的，因为你在用功。

<span id="p-55-010" class="reading-anchor"></span>

用功并不能表示我们线性地前进，总是有起伏的。因为每每就是我们犯的过错，才给我们更大的教益，给我们的帮助更大。不要天真地想自己的用功要顺利得很，往前走一路畅通、一帆风顺。下精神修养的功夫更难。它本就会有进退，有起伏。

<span id="p-55-011" class="reading-anchor"></span>

「吾养吾浩然之气」，容易吗？不容易。养得浩然气，正气了，浩然之气了，方能什么？美、大、圣、神。第一充实了，「充实之谓美」。充实，进一步来了，「充实而有光辉之谓大」。所以这就是《黄修易录》第七节讲的意思，我们把它看成也是养心的功夫。

## 八风与仁者心动

**回看 06:21—09:11**

<span id="p-55-012" class="reading-anchor"></span>

这方面的养心功夫也很重要：不要管别人对我们是毁还是誉，这正是功夫体现的地方。人是社会性存在，所以最在意别人对自己的评价。大家给予一致的好评价，精神满足感很强；大家一致说你不行、诋毁你，难过也很正常，因为人是社会性存在物。

<span id="p-55-013" class="reading-anchor"></span>

但是既然面对社会上各种的风，要八风吹不动。那就是苏东坡那首诗最后两句，「八风吹不动，八风吹不动，端坐紫金莲」。这算是一个境界。别人表扬你是种风，别人诋毁你又是种风，别人诬陷了你又是种风，等等的风，据说有八种，这是佛教的说法。

要吹你不动。

<span id="p-55-014" class="reading-anchor"></span>

当然按照惠能所说，境界还没到。要后来发现什么？风都不是风。就你觉得是风，你还是有问题的。风吹幡动，究竟是风动还是幡动？都不是，仁者心动。人家表扬你了，是一种风吗？这风哪里来？你高兴了嘛，你得意了嘛，这个表扬就成为一种风了。

<span id="p-55-015" class="reading-anchor"></span>

你没有把它看成是表扬，别人诋毁你了，你也没把它看成是诋毁。因为你心没动，风也就没了，最高境界，禅宗讲的。那么阳明的意思是什么呢？也是最后要达到自己这个境界，「我只是这致良知的主宰不息」，就可以了。一切外事自然亦自能不动，不是硬顶住啊。

<span id="p-55-016" class="reading-anchor"></span>

硬顶住就是说，人家表扬你的时候，别得意、别得意，已经得意了。人家批评你了，别难过、别难过，已经难过了。别去念那个毁誉，毁誉也就自然不存在了，自然不存在。这一段课就先讲到这里。

## 本讲总结｜整理附录

阳明的连续告诫把修养从表演中区分出来：不因退步装样子，也不以他人评价决定是否用功。进退本是功夫节次，过错还可能带来教益。

八风、风动幡动的讨论进一步追问：所谓外界的风，如何因自己的心动而形成？正文保留课堂由儒家转向禅宗、再回到致良知的次序。
