# 第54讲 但良知真切，则举业无累

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—23:14

**阅读导引｜整理附录**　读书时被考试与前程牵引，应该怎么办？本讲保留书生的连续疑问、阳明的回答、少年阳明的故事，以及我在中学攻克两道数学题的经历，逐步区别考试与得失之累。

## 一分钟速读｜整理附录

1. 读书调摄此心，也可以参加考试。
2. 强记、欲速、夸多斗靡，都是须辨认的念头。
3. 把牵累全部归于父母，可能遮住自己的得失心。
4. 立人生之志，使读书考试回到事情本身。
5. 考试可检验学习，不该成为给孩子终身贴标签的依据。

## 举业是科举考试

**回看 00:00—03:12**

<span id="p-54-001" class="reading-anchor"></span>

课程的第四部分讲养心的功夫。好，我们再来看下面一条。什么叫举业？乃科举考试啊。我们看《黄修易录》第五节，黄修易提问，「读书所以调摄此心，不可缺的」。读书是不可缺的，我们都要读书，调摄此心。「但读之之时，一种科目意思牵引而来。不知何以免此？」

<span id="p-54-002" class="reading-anchor"></span>

科目，就是科举之目，目录的「目」。这倒是真的：读书时想起来，将来要考举人、中进士，那叫科举。科举是不是有考试科目？「科」就这么来了，叫科目，科举之目。

<span id="p-54-003" class="reading-anchor"></span>

我就想，日本人有意思。近代日本学者在汉字当中找了一个字叫「科」，一个字叫「学」，来翻译西方的 science。其实是中国以前教育的传统，因为你考试总是有不同的科目嘛，一个「科」，分科的「科」字就来了，然后再拿了个「学」字，合起来。

<span id="p-54-004" class="reading-anchor"></span>

所以中国许多汉语、现代汉语的单词，翻译西方那些原来的原文，首创者每每是日本啊。「哲学」也是日本人翻译的，翻译 philosophy。「社会」，society，也是日本人翻译，找了一个「社」、一个「会」来翻译英语当中的 society。

<span id="p-54-005" class="reading-anchor"></span>

所以在这一点上，似乎日本成了我们中国人向西方学习的中转站。他们做了很多的功夫，所以我们就有那么多词来了。「教育」倒不是他们翻的，是我们本有的。最初用这个词的是孟子，「得天下英才而教育之」。人的、君子三个快乐，其中一个快乐。

这是顺带说的。

<span id="p-54-006" class="reading-anchor"></span>

现在来看科目。今天考试是不是也有科目？高考是不是要考数理化，还什么三加一，加一个生物，或者其他什么？文科也有它的考试科目，叫科举之目。你读着读着，想起这个实用目标，是不是被牵引了？如何避免这一点？

## 良知真切，虽做举业不为心累

**回看 03:12—06:42**

<span id="p-54-007" class="reading-anchor"></span>

阳明回答得非常直截了当，「只要良知真切，虽做举业，不为心累」。心累，心不为它牵累。举业有什么不可以做？「纵有累亦易觉」，你被它牵累，你也能发现，「克之而已」。

<span id="p-54-008" class="reading-anchor"></span>

我们读书不是为了考试。虽然有考试这件事，我也去参加考试，也不妨，这叫举业。我可以参加，有什么不可以参加的？有时候还乐得这样呢。我读书读得究竟怎么样了？也没有人告诉我读到什么程度了，参加一次考试嘛。

<span id="p-54-009" class="reading-anchor"></span>

那么最严、最正式、最严厉的考试，不就是举业嘛？事关未来的前程。别想前程这件事，考试去看看自己学得怎么样。有阅卷老师，叫高人指点，在你的文章当中做了圈点，做了评价，你拿来看，不就会有进步嘛？除了那些以朱子学问为基础的考试不在里边。

<span id="p-54-010" class="reading-anchor"></span>

当然，举业当中有一些跟观点无关，只看知识掌握的程度，这些值得考，没问题。底下如何「克之」，说得很具体：「且如读书时，良知知得强记之心不是，即克去之。」良知知道，你勉强记住那些读过的书，这个想法不对。

<span id="p-54-011" class="reading-anchor"></span>

不是勉强去记，而是要理解，要领会，要有心得，那叫读书。所以把强记之心克去。「有欲速之心不是」，良知也知道的，「即克去」。想要在短时间里边迅速地掌握知识来应付考试，叫欲速。

<span id="p-54-012" class="reading-anchor"></span>

「有夸多斗靡之心不是」，我们要跟别人竞比吧，谁读得多，这也是克去。古之人学习是为自己，不是给别人看的嘛，为了自己精神上成长嘛，不是去炫耀的嘛，所以这也要克之。

<span id="p-54-013" class="reading-anchor"></span>

「如此亦只是终日与圣贤印对」。如果你这样读书，你每天在跟圣贤心心相印，这叫印对。「是个纯乎天理之心」。「任他读书，亦只是调摄此心而已」。不管读这个还是读那个，其实都是调摄此心，那叫精神修养。现在看来知道了，古人讲精神修养，具体内容是什么？

调摄此心。

## 书生既怕声利牵缠，又不能违亲命

**回看 06:42—09:37**

<span id="p-54-014" class="reading-anchor"></span>

底下又有疑问了：「虽蒙开示」，简直像在跟禅宗祖师说话，蒙你阳明祖师开示。「奈资质庸下」，我这个人天资不好；「实难免累」，实在难以避免你所说的牵累。「窃闻」，我私下也听说过——这些都是自谦的词。

<span id="p-54-015" class="reading-anchor"></span>

「窃闻穷通有命」。你能不能考中啊，科举及第，或者落第啊，命嘛。「上智之人恐不屑此」。这不就是禅宗的话嘛，「下下人有上上智」，上智之人恐怕不屑于干这种事情，搞什么举业。

<span id="p-54-016" class="reading-anchor"></span>

「不肯为声利牵缠」，不要为名声、利益去牵扯了。「甘心为此」，如果我们心甘情愿地被声利牵缠，「徒自苦耳」，不自己找麻烦嘛？自己在尘劳之中了嘛。「欲屏弃之」，所以我就想不要为科举读书了，但是没办法，「又制于亲」，父母亲要求的，我怎么办呢？

又不能舍去，父母之命不可违。

<span id="p-54-017" class="reading-anchor"></span>

现在孩子不也这样吗？恨读书恨得要死的，那没办法，父母规定的。你还不上学，你还不好好读书，你还不考个好成绩给我看看，这还了得。将来要敲开重点高中的大门，你敲不开还行吗？将来要考取大学，还要名牌大学。父母之命吧，你能违吗？

奈何？怎么办？

<span id="p-54-018" class="reading-anchor"></span>

在阳明回答之前，我们先想一想。我们不到学校读书，不按学校的规定认真读书，自有一种说法：现在的应试教育有多大弊端。小孩子听到大人批评，也接过这个话头。干嘛读书？有了一个很好的理由不读书。

这个理由成立不成立？等会儿看阳明怎么回答。

## 十二岁的阳明问第一等事

**回看 09:37—11:04**

<span id="p-54-019" class="reading-anchor"></span>

读书是为了及第，这是阳明十二岁就不同意的观点吧。十二岁的阳明不是到北京去了嘛，到学校里读书，就问老师一个问题。才十二岁啊，少年王阳明问他的老师，什么是人生第一等事？

<span id="p-54-020" class="reading-anchor"></span>

你看那个老师回答，「读书及第尔」，就好好读书，将来科举及第。阳明不同意，「恐非第一等事」。那么老师问，在你看来是什么？「读书学做圣贤耳。」老师笑了，小小年纪，就说这么大话、空话的啊。

<span id="p-54-021" class="reading-anchor"></span>

好，我们知道阳明心里的意思的，从小立的这个志，读书不是为了科举。那么阳明该怎么看待科举这件事呢？又怎么看待父母对他的要求呢？父母要求他参加科举嘛，你怎么看？我们自己拿自己的良知想一想，我们坚决拒绝读书考试吗？不用拒绝，没有必要拒绝。

## 人自累于得失

**回看 11:04—14:30**

<span id="p-54-022" class="reading-anchor"></span>

好，还是听阳明自己说得清楚，「此事归辞于亲者多矣」。不光今天啊，以往就这样。那些年轻的书生们都埋怨，父母亲逼着我去参加科举考试去了，所以「归辞于亲者多矣」。

<span id="p-54-023" class="reading-anchor"></span>

「其实只是无志。志立得时」，我们若把人生之志立好了，良知是什么？「千事万为，只是一事。」

良知能用到读书、应付考试上吗？也能，有什么不能？这也是格物，把应付考试这件事做对了。「读书作文，安能累人？人自累于得失耳。」

<span id="p-54-024" class="reading-anchor"></span>

讲透了。你说都是父母不好，逼我去读书、科举，其实是什么？自己在考虑考试结果，害怕失败。大学没考取，自己蒙受羞辱，别人都看不起我。我害怕这一点，却推给双亲，说我不去了。这算什么玩意儿？

「全是功利的事情，我就不做」，振振有词。

内心其实害怕什么？失败。

<span id="p-54-025" class="reading-anchor"></span>

我们若立了志，不是立志考上名牌大学，立了人生的志向，此心纯乎天理之极，止于至善，我们害怕失败吗？不用害怕失败嘛。这一点能不能跟我们今天中国的青少年讲讲？

<span id="p-54-026" class="reading-anchor"></span>

就是说现在的这个学校教育呢，确实有比较严重的状况。比如说题海战术，不断地刷题。你可以刷一些，也不必全刷。累了，马上睡觉。读书是为了长进知识，为了满足自己对世界的好奇心，你去读嘛。还有一个志向，将来为文明也做自己的贡献，这叫人生的志向。

<span id="p-54-027" class="reading-anchor"></span>

以这个志向做引导去读书，哪里害怕考试成败呢？我考试败了，不等于我不懂啊。考试成了的人，未必懂了，将来未必就对文明做贡献了。这个志立得好，便没有别的事，哪里要计较考试结果的得失呢？

## 我在中学留下来做两道数学题

**回看 14:30—17:33**

<span id="p-54-028" class="reading-anchor"></span>

所以在孩子最初读书的时候，就要跟他们讲清楚一个道理。考试要考，这是教育的一个必要环节。通过考试来检验我们学的情况，哪些还是要补上去的，哪些已经达到了，哪些甚至已经超过了，有一个自我认识。

<span id="p-54-029" class="reading-anchor"></span>

然后通过考试，即使失败了，我们不要失去自信。有些地方我补上去就是了。也不要同学彼此之间比较，谁厉害，谁学霸，谁学渣，不要讨论这些问题。人都有利钝之差别嘛，这要承认。那么钝就钝了。还有一个词来鼓舞你呢，叫笨鸟先飞呀，你怕笨啊？

<span id="p-54-030" class="reading-anchor"></span>

你看我在数学上向来笨，但中学阶段，数学考试成绩在班里基本上不是第一就是第二。为什么？我没有数学天赋，但知道这是短处。是短处，就好好补。人家用一倍功夫，我用十倍，自然学懂了，心满意足，多愉快！

<span id="p-54-031" class="reading-anchor"></span>

人家解这道题，解出来了嘛，就解出来了，没什么，他有天赋嘛。我解出来了，我满心的欢喜呀。我印象很深，有一次我们布置了课后作业，在中学阶段啊。这个题目发下来以后，我一看，哟，其中有两道题我做不出来的，我就不回家了，在教室里一个人做了。

<span id="p-54-032" class="reading-anchor"></span>

做到大概晚上七点钟左右。当时没有电话，有电话，我父母老早打电话给我了，他们也不知道我在哪里混着呢，放学没回家。两道题攻下来了。老师很好，把教室留给我，你一个人做题吧。两道难题攻下来之后，我狂喜而归啊。

<span id="p-54-033" class="reading-anchor"></span>

这就读书啊，笨鸟先飞呀，要有这种精神嘛。至于考试本身的结果，不要在意啊。给我带来的是好名声还是坏名声，这不用去管。只是读书这件事自身就有自己的意义，自身就是自身的价值。它叫满足我们的好奇心。作为人文的学问，那叫调摄此心，那叫精神的修养。

总说人要有一点精神，这就是一点精神。

## 考试结果耽搁了几多英雄汉

**回看 17:33—21:46**

<span id="p-54-034" class="reading-anchor"></span>

「读书作文，安能累人？人自累于得失耳。」于是阳明接着叹了一口气，「此学不明，不知此处耽搁了几多英雄汉！」本是英雄啊，但是就因为什么？害怕考试的结果的得失，那些英雄汉就没了。

<span id="p-54-035" class="reading-anchor"></span>

有些人本来就有很大的本事啊。应该说他如果参加以前的考试，其实就文科嘛，没有数学的。科举考试都是人文修养，都是书读得很多，然后能够领会，能够行文表达，表达得又非常好。这就读书作文嘛，读书作文多愉快的事嘛。

<span id="p-54-036" class="reading-anchor"></span>

偏偏被什么所累了？科举结果的得失，被科举结果的得失所累了。有的人就望而生畏，本来是很有本事的人啊，天赋还不错的人啊，自己退了。这叫什么？耽搁了几多英雄汉。

<span id="p-54-037" class="reading-anchor"></span>

现在我们当下不知道耽搁了多少英雄汉呢。当下的基础教育的状况嘛，有许多孩子一开始读书都满心欢喜的，读了一年两年就不行了，最后就恨得要死，也怕得要死。为什么？没有按照良知天理来引导我们的学生，怎么正确地看待读书。学校有责任，家长也有责任。

阳明心学的基本道理，在孩提时代就应该跟孩子讲明白。

<span id="p-54-038" class="reading-anchor"></span>

比方说，期末考试成绩很糟糕，班级倒数第一。你跟他说：现在是班里最后一名，不要难过，没什么好难过的。再去问一问、找一找，这学期读书的毛病在哪里，问题出在哪里。把它找出来，克服了，下学期再进步。

<span id="p-54-039" class="reading-anchor"></span>

一个班级考试必有一个最后一名的，是他还是你，这无所谓。这是你自己检查。你绝不要给他贴个标签，差生。这标签怎么能贴呢？有许多孩子按照现在的标准就是差生，殊不知他后来成了科学家，who knows？钱伟长当初考北大物理学成绩只有五分啊，满分一百分啊，他后来不就物理学家了吗？

<span id="p-54-040" class="reading-anchor"></span>

不要把一时考试的结果当成评判孩子的标准。家长千万不要这么想，学校老师千万不要这么做。总是要能够保持我们的学生对世界和文明的好奇心，以及立下对文明也做出自己贡献的志向，这是最伟大的力量。

<span id="p-54-041" class="reading-anchor"></span>

要多讲一些自然科学史，多讲一些文学史，多讲一些历史。拿历史上的那些做出贡献的人物，他们的精神世界展示给我们的学生看。这叫榜样的力量是无穷的。我们现在不用，只是一味地拿一个尺度来衡量，优等生、差生、尖子等等。背离心学的境界多么远呢？

## 科举落第与耻

**回看 21:46—23:14**

<span id="p-54-042" class="reading-anchor"></span>

所以阳明叹息道，「此学不明」，心学不了解，「不知此处耽搁了几多英雄汉」。科举落第不为耻，因科举落第而难过方为耻。

<span id="p-54-043" class="reading-anchor"></span>

有的人不就害怕科举落第吗？因为一旦科举落第，他觉得耻了，shame。这不会耻，你自己难过了，耻才来了。你好好地读书，有了长进，你就满心地高兴。结果考试失败了，没什么，下次再来，继续经受一下考验。

<span id="p-54-044" class="reading-anchor"></span>

阳明本人就这样，他曾经落第嘛，后来再考、再成的嘛。是不是这件事？王阳明够不够天资聪颖了？绝对谈得上吧，他也会失败的，这没什么好稀罕的。

<span id="p-54-045" class="reading-anchor"></span>

最可恨的是什么？一考定终身。就给这个学生贴了一个永远的标签，他一辈子耿耿于怀。「我当年就是大学没考取」，引为终身的遗憾。这是不正常的事情。好，就到这里。
