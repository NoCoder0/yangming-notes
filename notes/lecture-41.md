# 第41讲 日用常行间，皆是良知实学

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—11:09

**阅读导引｜整理附录**　本讲从属官「公务太忙，没空为学」的困惑开始，逐项说明判案时可能出现的怒、喜、偏袒与敷衍，再以面试说明日常工作本身就是格物之处。结尾把诚意与格物的关系接起来。

## 一分钟速读｜整理附录

1. 为学不能离开簿书讼狱等日常事务。
2. 对人的言辞、礼貌、请求和托请所起的好恶，都可能使判断偏倚。
3. 公务繁忙也不能成为随意处置的理由。
4. 面试取舍同样需要省察私情私意。
5. 先立诚意，再通过做事把诚立起来，才是良知实学。

## 簿书讼狱之间

**回看 00:00—02:10**

<span id="p-41-001" class="reading-anchor"></span>

我们在阳明的《传习录》中学养心的功夫，仍然看《陈九川录》第十六节。这一节记载了一件事：「有一属官」。这个人也做官，王阳明也在做官，他恰好是阳明的下级，所以是阳明的属官。

<span id="p-41-002" class="reading-anchor"></span>

「因久听讲先生之学」，他听阳明讲心学，已经听了蛮长时间。他说：「此学甚好，只是簿书讼狱繁难，不得为学。」我实在没空，我的公务繁忙。

他在衙门里，有簿书、公务要处理，又有讼狱：有人来诉讼，他要判案。这也忙得很，所以实在没工夫学。

<span id="p-41-003" class="reading-anchor"></span>

这话后来被阳明听到了，阳明就跟他说：「我何尝教尔」——「尔」就是你——我何曾教你「离了簿书讼狱，悬空去讲学」？把公务扔在边上，悬空去讲学，我何曾这样教你？

「尔既有官司之事，便从官司的事上为学，才是真格物。」

## 判案时怎样省察

**回看 02:10—05:58**

<span id="p-41-004" class="reading-anchor"></span>

然后底下就说明为什么。「如问一词讼」，有人案子递上来了，你不是面对词讼吗？你要升堂了，升堂让原告被告都一起来。在这种情况下，「不可因其应付无状，起个怒心」。

<span id="p-41-005" class="reading-anchor"></span>

有时候遇到被告或原告，他上来说话、应付，不像个样子，叫应付无状。一个说话说不清楚，一个样子猥琐，或者没有礼貌；也可能喧嚣，在堂内咆哮。

这种情况，你不是恨了嘛？他在那里发急、哇哇叫，都可能。这叫应付无状，你便起个怒心。不可以的。

<span id="p-41-006" class="reading-anchor"></span>

「不可因他言语圆转，便生个喜心」，也不行。有的人前来诉讼，说话言辞爽利，说得很圆转，待你们也恭恭敬敬的。这样的人你便喜欢了。「不可恶其嘱托」，他来诉讼之前呢，先托了人了，想要打通你这个关节。

<span id="p-41-007" class="reading-anchor"></span>

你因为是清正的官员嘛，你就恨这种做法。「加意治之」，你对他的惩罚过了。「不可因其请求」，他委婉地哀求你，你呢，好像同情他了。「屈意从之」。

<span id="p-41-008" class="reading-anchor"></span>

「不可因自己事务繁忙，随意苟且断之」，太忙了，这个事情就随便断一断吧。「不可因旁人谮毁罗织」，旁人对某原告或被告，就说了许多诋毁他的话，你就听从别人的意思了，「随人意思处之」。

<span id="p-41-009" class="reading-anchor"></span>

「这许多意思皆私。」这一点你本是知道的，「只尔自知」，你心里自己能明白。「须精细省察克治」：把自己的私意、私心，把由于别人表现不同而起的喜心、怒心，加以省察克治。

「惟恐此心有一毫偏倚，枉人是非。」

<span id="p-41-010" class="reading-anchor"></span>

阳明说得很好，一个判案的人会不会这样？完全可能这样。人与人打交道，就有情感在其中。你遇到一个人上来就跟你恭恭敬敬的，恭敬有礼、言语圆转，你很舒服，那么你就喜欢了。喜欢了，你的情感就向他那里偏了，随时可能。

## 面试的例子

**回看 05:58—09:04**

<span id="p-41-011" class="reading-anchor"></span>

不光是判案。就像某企业要招员工，要 interview，叫面试。你做过企业的面试官吗？若做过，回想一下，你是不是也会受影响？

毕业生前来恭恭敬敬地鞠个躬，把简历递上来，把自己说得这也行、那也行，你就相信了吗？

<span id="p-41-012" class="reading-anchor"></span>

就那两个名额，比方说能招两个人，许多人来面试，你如何做取舍？这个取舍当中难免有你的私情私意掺杂其中。这事就做错了。这正是格物的时候嘛，要省察、克治自己的私意。这便是格物、致知。

<span id="p-41-013" class="reading-anchor"></span>

「簿书讼狱之间，无非实学。若离了事物为学，却是着空。」还是强调了一点，不离日用常行内。我们在日用常行内，我们就要让天理在我们的日用常行内呈现。而妨碍我们让天理呈现的时候，我们遮蔽了我们的良知，受了那份情感、私情的影响。

<span id="p-41-014" class="reading-anchor"></span>

闲思杂虑一进来，事情就做坏了，不能成为天理的呈现。所以格物的功夫，不就是在日用常行内吗？

我们每天都遇到格物，但结果没格，只是把事情做了。做事情的时候，自己没有省察，实际上有多少自己不知道的私意掺杂其中！这就是要下功夫的时候。

<span id="p-41-015" class="reading-anchor"></span>

对我们做事情的整个过程，我们的情感的变化，要有一个省察。你判案为的是公正，这个当事人可能有不同的特点、不同的性格，那么你不能因此而影响你公正的判案。否则你不要做判案的事。这不就是你的日常工作吗？你就在你的日常工作里边学嘛。

## 先诚意，再在事情上把诚立起来

**回看 09:04—11:09**

<span id="p-41-016" class="reading-anchor"></span>

哪有离开日常工作、离开日常生活，专门去学的？那叫着空。所以读《传习录》的这个大的好处，就是对我们平日做事立了一个很好的标准、很重要的标准，就致知，致良知。在格物中，也就是让良知呈现，先要有一个诚意。

<span id="p-41-017" class="reading-anchor"></span>

比方说我是县衙门的知县，做知县的，这是个官职吧？这个官职你做了，第一件事情就是诚意。我在这块地方，我承担相当大的责任，这一方的老百姓的生活出了矛盾、出了纠纷，我这个官职必须要处理它的。别把这官职看成是自己的社会地位，看成是自己获得钱财的机会，做官然后发财。

<span id="p-41-018" class="reading-anchor"></span>

有了这诚意，然后去格物，去做事情，担任好知县的工作，诚意便通过这个功夫实现了，叫格物立其诚。

两者是什么关系？第一，要拿定主意，主意不能拿错，这叫诚意。然后通过格物，把这诚立起来，这就是良知实学。不是着空地讲论，不是另辟一段时间去学。学归学，做事情归做事情，分成两个领域，这就错了。好，就到这里。

## 本讲总结｜整理附录

属官把工作与学习分成两块，阳明则把学习放回官司之事。判案中的六类偏差，使省察克治有了具体的对象，而非只剩一句公正的要求。

面试与知县的例子将这层意思延伸到岗位职责：把事做完并不自动等于格物，还要检查做事过程中自己的心。诚意是拿定主意，格物是在事情中实现这份诚。
