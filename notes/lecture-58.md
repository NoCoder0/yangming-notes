# 第58讲 求问天理

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—12:49

**阅读导引｜整理附录**　本讲完整保留关于卜筮的讨论：由朱子与程传的分歧，进入求决狐疑、神明吾心，再从天不容伪讲到《周易》、筹划未来与思想的源头。

## 《易》的卜筮和义理

**回看 00:00—02:18**

<span id="p-58-001" class="reading-anchor"></span>

课程的第四部分讲养心的功夫。好，我们接着再来看下面一节，也就是我们要讨论的第四十二条。我们讨论一下卜筮的事啊，所谓起卦、占卦。解卦。《周易》嘛，首先是本卜筮之书嘛。

<span id="p-58-002" class="reading-anchor"></span>

黄修易问，「《易》」，就是《周易》的易，《易经》。「朱子」，就是朱熹，认为它主要的事情就是卜筮。这也没说错，我们向来知道《周易》本来就是卜筮之书。那个起卦，想要预知未来。

<span id="p-58-003" class="reading-anchor"></span>

「程」，指程颐。程颐说这个「传」——《易》不是分了经和传吗？——《易经》主卜筮，《易传》主理。儒家解释《周易》的路子，就是从理上讲。〔[程传用字见整理注](#editorial-note-1)〕

<span id="p-58-004" class="reading-anchor"></span>

我们知道对卦的解有三个角度，象、数、理。那么从理上讲呢，六十四卦也伟大得不得了，经天纬地啊。人类社会和人与自然界的关系的道理，都囊括在其中了，无出其外。如来佛的掌心啊，那六十四卦，哪有在它外面的。

<span id="p-58-005" class="reading-anchor"></span>

那么其中做人的道理，天道，也在六十四卦中非常形象和具体地展现了。所以六十四卦是非常伟大的，所以我们讲叫经天纬地啊。黄修易问什么？问的就是朱子认为经，《易经》是主卜筮的。程颐先前说，《易传》呢是专门讲理的。这个说法对不对？

「何如」？

## 卜筮是理，理亦是卜筮

**回看 02:18—04:34**

<span id="p-58-006" class="reading-anchor"></span>

阳明来了，「卜筮是理，理亦是卜筮」。当我们想到卜筮的时候，我们就在想到预测这件事。那么讲理的时候，就是我们领会天道，简直是哲学的功夫。这两者什么关系？阳明说是一回事。想想看，闻所未闻啊。

<span id="p-58-007" class="reading-anchor"></span>

我们好像对《周易》有两种用法呀，一种拿它真是来算卦的。一种是从中领会道理的。这两者好像是两回事。阳明偏说是一回事。看看他怎么说明这一点，「天下之理孰有大于卜筮者乎？」

<span id="p-58-008" class="reading-anchor"></span>

天下之理，天理，哪有在卜筮之外的？「孰有大于卜筮者」，就天理大于卜筮吗？在卜筮之外吗？还有一块吗？没有的。「只为后世将卜筮专主在占卦上看了，所以看得卜筮似小艺」，小艺而已，小技巧、小技，与天道无关。不就贬低了吗？

<span id="p-58-009" class="reading-anchor"></span>

「不知今之师友问答」，老师朋友之间问答，「博学、审问、慎思、明辨、笃行之类，皆是卜筮。」这一点我们有点想不通了啊。比如说我们在学，读圣贤的书，讲究那个圣人之学，居然也属于卜筮啊，怎么看这件事呢？

## 求决狐疑，神明吾心

**回看 04:34—09:34**

<span id="p-58-010" class="reading-anchor"></span>

「不过求决狐疑，神明吾心而已。《易》是问诸天。」去问天了吧，因为人自己是搞不清楚的，心里乱了，不知该怎么办。人有迷惑的时候，人就这样嘛，人又不是神。于是在自己的生活，或者整个社会在某种困境中，自然要问天了。

<span id="p-58-011" class="reading-anchor"></span>

什么叫问天？四个字，神明吾心。人有疑，人肯定有种种的疑，人还有病呢。毛主席说，「人有病，天知否」？人有疑便问天，正常吗？非常正常。「自信不及」，自己明白自己不等于天。「故以《易》问天」，这是什么意思呢？以《易经》教我们的方法来问天。

<span id="p-58-012" class="reading-anchor"></span>

这是什么意思？因为「人心尚有所涉，惟天不容伪耳」。涉，后面有个宾语。尚有所涉，人心会有这一面。就是说，你有所求；有所求，一定有一点偏私在里面，否则你求什么？

<span id="p-58-013" class="reading-anchor"></span>

人总是有所求的缘故，人必有所偏私在。那么问天是什么意思呢？天不容伪耳。天毫无偏私，毫无造作。这个就是什么呢？其实是道家思想。就是人因为有自己的确定的目标要去实现，这立刻就伪了，叫人为呀。人、为两个汉字合起来就是个伪嘛。

<span id="p-58-014" class="reading-anchor"></span>

人必有伪，这不是道德评价，不是虚伪、伪善的意思，而是人从自己的因素出发，有狐疑不能决，有疑惑不能决，这一定都是人为。人总有「人为」的一面。「人」「为」加起来是个「伪」字，天没有为，所以这时候要问天。这个境界说到了。

<span id="p-58-015" class="reading-anchor"></span>

所以儒家能够把道家思想的精华吸收进来，那叫宋明新儒学嘛，也把佛家的思想精华吸收进儒家嘛，所以叫新儒学了嘛，所以自然对道家有领会啊。天是什么？如道家所说的，无为的。而人有为啊，有为就伪了。

<span id="p-58-016" class="reading-anchor"></span>

那么这种情况下，我们自然要什么？问天。问天就是放弃人自己的主观性啊。你在自己的主观性里边，你问什么天呢？你就是天了。人不可能是天，这还是存了一份敬畏天的意思在，所以问天了，这完全是对的。怕就怕人自以为是啊。

<span id="p-58-017" class="reading-anchor"></span>

所以呢，因为人有所涉。这就是表明人终于有疑，终于狐疑，终于要问天。问天无非是什么？神明吾心，把我这个小的心呢扩大了，扩大到跟天一样大。这就是问题，不是什么具体的事情的预测，这些事也能做。

<span id="p-58-018" class="reading-anchor"></span>

但是我们讲求学问，也是卜筮，就是在问天的意思。我们借用六十四卦，它们的象、数、理，来具体预测某一件事，这是完全可以做的事。把它仅当成小艺看，不对。而是什么？凡学问，都是什么？问天理，求问天理。所以那个结论就来了，卜筮是理，理亦是卜筮。

## 履霜，坚冰至

**回看 09:34—12:49**

<span id="p-58-019" class="reading-anchor"></span>

人有疑便问天，还好有《周易》帮助我们如何问。这个如何问里边呢，尤其是理。程颐说得没错，就这个卦象它有理在里边。比方说，「履霜，坚冰至」，这不是天道吗？人要明白啊，你地上看到霜了吧，你就知道后面会什么？坚冰要来了嘛。

这不是天理吗？

<span id="p-58-020" class="reading-anchor"></span>

许多的卦象在启发我们领会天理。领会天理意味着什么？筹划未来。我们的狐疑来自我们未来会怎样不知道了，这就狐疑了。狐疑嘛，你就要讲究学问了。论道的学问，才是启发我们领悟命运、领会命运、感悟天理的。

<span id="p-58-021" class="reading-anchor"></span>

然后在此基础上，才能谈得上筹划未来。筹划不是预知，是在对命运的领会和对真理的感悟、对天理的感悟中，去筹划我们未来的路。这就是《周易》对我们的最重要的地方，就是中国精神的、中国思想的源头啊，中国思想的源头。

<span id="p-58-022" class="reading-anchor"></span>

在这之前有经验、有知识，但没思想的呀。有许多的书不是都有了吗？讲〔[听辨待核 2](#editorial-note-2)〕的、农艺的，都可以呀。但是《周易》来了，那是思想，思想放在卦象里讲呢。六十四卦，从中启发出儒家和道家。所以这就是《周易》跟我们的关系，到今天依然如此。

<span id="p-58-023" class="reading-anchor"></span>

所以中国人问什么？问天。哪里问？在《易经》中就可以开始问了。许多的这个我们讲过的系辞啊，比如说「修辞立其诚」啊，「蒙以养正，圣功也」，不全是卦嘛？那个叫蒙卦。

<span id="p-58-024" class="reading-anchor"></span>

这个《易经》的学习，应当是我们中国人的必修课。可惜长久以来被当成是迷信的书，被贬低了。而阳明又把它抬起来了。卜筮就是理嘛，理就是卜筮嘛。我们当然要走向未来，所以要卜筮嘛，要筹划未来嘛，不就这件事嘛？这一段课就先讲到这里。

履霜、坚冰与结尾的经典引句，把这层论述接到《周易》对生活和思想的意义。筹划未来与预知未来的区别，也按课堂原顺序保留。
