# 第32讲 人须在事上磨练，心无内外（上）

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—18:34

**阅读导引｜整理附录**　本讲从静坐时收敛、遇事却中断的困惑讲起，解释为何做事与养心不能分作内外。随后细看喜怒忧惧从哪里来，并借安贫安富、武训办义学和为下一代奋斗的讨论，辨明安与行的关系。

## 一分钟速读｜整理附录

1. 静坐时的心与听讲、做事时的心，是同一个心。
2. 事上磨练着重养心，不能理解成保证每件事成功的本领。
3. 省察喜怒忧惧，要看它们是否出于良知，还是牵于个人得失。
4. 本体原无内外，贫贱或富贵都能成为用功的处境。
5. 安贫安富仍然要行，并不等于停止实践和奋斗。

## 静坐和遇事时是不是同一个心

**回看 00:00—03:47**

<span id="p-32-001" class="reading-anchor"></span>

我们还在课程的第四部分，接着通过《传习录》来讲阳明的养心功夫：人须在事上磨练。现在看《陈九川录》第四节。

陈九川先说自己的用功状况：用功过程中有许多麻烦，看看自己，好像总是不行。

<span id="p-32-002" class="reading-anchor"></span>

他说自己静坐用功的时候，「颇觉此心收敛。遇事又断了，旋起个念头，去事上省察」，把事情要做好。这是件怎样的事，要了解清楚。事情过了，「又寻旧功」，又要回到原来的用功状态中去。

这样就有一个感觉，有内外之别，「打不作一片」。

<span id="p-32-003" class="reading-anchor"></span>

他当然知道阳明讲心无内外。阳明对这个困惑作了回答：困惑从哪里来？来自你对「格物之说」还没搞透，没彻底明白。

「心何尝有内外？」比方说你惟浚——惟浚是陈九川的字——「今在此讲论」，你不是正在我面前讲论吗？

「又岂有一心在内照管？」

<span id="p-32-004" class="reading-anchor"></span>

一方面在跟我讲论，一方面你的心又在你的内部自己照管着它。「这听讲说时专敬」，你听我说，你自己也讲，这个时候你专一个「敬」字，「即是那静坐时的心」。你不是全神贯注地跟我讨论吗？

那不就是你自己一个人静坐的时候的那个心？还是这个心吧。

<span id="p-32-005" class="reading-anchor"></span>

「功夫一贯，何须更起一个念头」？说遇到事了，我另外起个念头去处理事情，回过来我再用功。不是的，人须在事上磨练。

<span id="p-32-006" class="reading-anchor"></span>

至于这个「练」字是火字旁，还是绞丝旁？有人主张火字旁，这我认为不是很大的区别。我一般用绞丝旁，就是练习的「练」。那个火字旁是冶炼金属的「炼」。那么就绞丝旁吧。于事上磨练，人须在事上磨练，「做功夫乃有益」。

<span id="p-32-007" class="reading-anchor"></span>

「若只好静，遇事便乱，终无长进。那静时功夫亦差似收敛。」表面上看像是你在收敛，其实是什么？放溺。你最好什么事都不遇到，然后天天在那里静坐用功，你以为你收敛了，这叫放溺了自己。

遇到事情你就乱。遇到事情正是用功的时候，这叫于事上磨练。

## 事上磨练要看喜怒从哪里来

**回看 03:47—06:05**

<span id="p-32-008" class="reading-anchor"></span>

事上磨练，磨练什么？不是磨练做事情的本领。事上磨练，磨练的就是我们的心。这不就是养心的用功吗？在做事上用功，这个功也就是养心的功。

<span id="p-32-009" class="reading-anchor"></span>

陈九川说遇到事便去省察。在这里，他做事情只想到：这件事该怎么做？手段是什么？他考虑这些，好像是在练本领。

<span id="p-32-010" class="reading-anchor"></span>

按照心学的原则，我们做事情的本领永远不完备的。我们还不断遇到变化了的事情。你以前的本事、本领、做法，一定能用到新的事情上吗？不能的。所以不要把于事上磨练，理解为于事上磨练我们的本领、做事情的才能。

做事情的才能永远要跟着事情的变化走，不能因循守旧的吧，不能刻舟求剑的吧。

<span id="p-32-011" class="reading-anchor"></span>

这个道理我们都明白。所以于事上磨练，不是锻炼以后做任何事情、每次都能保证成功的能力。天下没这样的情况。百战百胜的将军有吗？没有的。打十仗，赢了六仗、七仗就是好，还有几仗就失败了。

所以不是去磨练本领，增长做事情的才能，不要误解了这「磨练」二字。

<span id="p-32-012" class="reading-anchor"></span>

磨练的是我们的心。磨练我们的心是一件什么事？心就在我们所做的事情上。这个心之本体便是良知，让良知在我们所做的事情上实现，这叫磨练。这第十七条要点就在心无内外上。

### 喜怒忧惧中的省察

**回看 06:05—08:43**

<span id="p-32-013" class="reading-anchor"></span>

不要把心放在自己的内部，把事情放在心之外。这就隔开了。做事情就是你的情感在推动，在琢磨，在喜怒哀乐。你做事情的时候，做到一半喜了，做到另一半又怒了，做着做着又忧虑了，做着做着又惧怕了。

不是心一直在变吗？

<span id="p-32-014" class="reading-anchor"></span>

这时候正是磨练时。我因何而喜，因何而怒，因何而忧，因何而惧？看看我们的情感为什么会有这种变化。一问就明白。倘若我们以良知来判断，良知自然能判断。一判断，就发现自己这个喜，是不当喜，或者是侥幸有所得的喜悦，偏离良知。

在做事情的过程中遇到这种状况，千万别喜。

<span id="p-32-015" class="reading-anchor"></span>

有时候我们怒，也是偏离良知了，遮蔽良知的那个怒。自己本来的目标受到挫折了，怒了，为什么要怒？假如你是为了让这件事情成为良知的呈现、天理的实现，你遇到挫折不需要怒，你遇到偶然的顺利不当喜。

这叫磨练。

<span id="p-32-016" class="reading-anchor"></span>

你发现天理正在一层一层地展现出来，理是心的功夫啊。天理不是现成地摆在那里的，在做事情中让它呈现了。你在做事的过程中，天理就这样一层层来了。当喜。这是你的喜悦，在心体上乐了。

乐是心之本体，不是一时的得意和一时的失意。

<span id="p-32-017" class="reading-anchor"></span>

所以于事上磨练这句话特别重要。阳明晚年特别强调这一点。磨练我们的心，也就是磨练我们的生命情感。久而久之，我们的心很大，我们可以从容不迫地面对天下的难事。

## 本体原无内外

**回看 08:43—11:43**

<span id="p-32-018" class="reading-anchor"></span>

我们把这两段看完。「后在洪都，复与于中、国裳论内外之说。」「渠皆云：物自有内外，但内外并作功夫，不可有间耳。」这个「渠」就是第三人称，指他们。

这是陈九川与另外几位阳明的学生讨论，得出的结论是：事情当然有内外，但内和外的功夫要一起下，叫「内外并作功夫，不可有间耳」。

事情要做好，内心的功夫也要同时下。

<span id="p-32-019" class="reading-anchor"></span>

阳明回答，「功夫不离本体，本体原无内外」。本体就是心之本体，或换一种说法叫本心仁体。本心仁体简称本体。它哪里只在内、不在外呢？

<span id="p-32-020" class="reading-anchor"></span>

孔子在《论语》中说，「不仁者不可以久处约，不可以长处乐」。不仁者就是心中没有本心仁体的人。「约」就是节约的「约」了，表示贫贱的生活处境。「乐」就是快乐的「乐」，表示富贵的生活处境。

这不是在外吗？你的处境，无论是贫贱还是富贵，本心仁体在的。

<span id="p-32-021" class="reading-anchor"></span>

在贫贱的生活处境中，让本心仁体得以体现。在富贵的处境中，也能让本心仁体得到体现。哪有内外呢？如果有了内外，那个所谓本心仁体差不多就不存在了。不存在的情况下，贫贱难耐凄凉，富贵不能乐业，是吗？

这叫不仁者。没那个本心仁体，叫不仁者。

<span id="p-32-022" class="reading-anchor"></span>

所以它无内外。它在不同的生活处境中，它都在，本心仁体总在。于是我们在不同的生活处境中，照样活出人性的光辉，人生本有的意义和它的精彩。

## 安贫安富也要行

**回看 11:43—15:12**

<span id="p-32-023" class="reading-anchor"></span>

所以《中庸》里边就讲，「君子素其位而行」。「素贫贱，行乎贫贱；素富贵，行乎富贵；素夷狄，行乎夷狄；素患难，行乎患难。」本心仁体在的，这叫功夫。这功夫很真实的很。

一般人都是贫贱难耐凄凉。这不是贫贱的处境，让你看看你的功夫如何了吗？富贵也要看我们功夫的，富贵我们未必能安。安贫安富，安富更难。这个我等会再说。

<span id="p-32-024" class="reading-anchor"></span>

所以孔子要赞美颜回来的。「贤哉，回也！一箪食，一瓢饮，在陋巷，人不堪其忧。」大多数人都受不了，这不就看功夫了嘛？「回也不改其乐。」又来一遍，「贤哉，回也」。

<span id="p-32-025" class="reading-anchor"></span>

那么我刚才想到了，顺带想到了许多人对儒家的批评，对中国思想的批评。比方说我们这个民族为什么没有积极进取的精神呢？因为总要讲安贫安富。这个民族就没有一种奋斗精神了。

这是对儒家的误解。一个「安」字，并不等于随遇而安这么简单。

<span id="p-32-026" class="reading-anchor"></span>

「素贫贱，行乎贫贱」，要行的。你在贫贱的生活处境中，就应当做好一个贫贱之人该做的事，叫「行乎贫贱」。不是不行，不是不实践的。「素富贵，行乎富贵」，你在富贵中，就做一个富贵之人本应当做好的事。

<span id="p-32-027" class="reading-anchor"></span>

现在我们在资本和技术的文明中了，我们每每认为中国人讲的安富安贫、随遇而安，是消极的人生观。我们似乎不想改变现状，安于现状，不很消极吗？又是一种严重的误解。能安是指什么？

能安是指我们并不去拒绝我们的处境，而是在此处境中继续从事生命的奋斗。

<span id="p-32-028" class="reading-anchor"></span>

在贫贱之中仍然从事生命的奋斗。比方说武训，乞丐，他创办义学。这叫贫贱之中吧，他是安然，安。他没有说我一定要摆脱乞丐的处境啊。我要做的事是什么？创办一座义学，让贫苦人家的孩子也能读书。

这不是伟大的奋斗吗？

### 从文化处境谈为下一代奋斗

**回看 15:12—18:34**

<span id="p-32-029" class="reading-anchor"></span>

所以有许多对中国思想的误解，很严重很严重。当然也是有来由的，就是西方文化来了。它是什么？带着两个力量，一个叫资本，一个叫技术，你无以阻挡。在这种情况下，中国人终于遇到比我们更强势的文化了。

<span id="p-32-030" class="reading-anchor"></span>

以前我们把自己的文化跟异族的文化一比较，我们有充分的文化自信。异族也可能统治我们，统治我们，然后就要进入中国文化了。否则他的统治就很短命，如元朝。所以这时候我们中国人，历史上是不是一种文化优越感、文化自信？

<span id="p-32-031" class="reading-anchor"></span>

那么其他的异族全叫化外之人，有待教化。你们不行，我也不跟你们搞，也不会去征服你们。但你们得自觉地提高自己。这是中国人有过的文化优越感、文化自信。现在没有了，没有的原因就是我们确实在资本和技术两个方面，我们还是不如人的。

不如人，应当奋斗。

<span id="p-32-032" class="reading-anchor"></span>

中国人的奋斗精神从来没减弱过。中国人的安富安贫的人生观不等于不奋斗。中国人叫勤劳勇敢，为什么？为下一代奋斗。我们对自己的贫贱或者富贵，已经不是很 care 了，不那么在乎，而是希望我们的下一代活得比我们更好。

可怜天下父母心，最可怜的就是中国父母，为下一代奋斗的民族。

<span id="p-32-033" class="reading-anchor"></span>

为下一代奋斗，就是为未来奋斗呀。下一代就是未来。在这一点上，我们这个民族从来没改变过这种精神。眼看这辈子自己富贵毫无希望，继续努力，为下一代开辟光明幸福的人生道路。

<span id="p-32-034" class="reading-anchor"></span>

我们能安，是因为我们不抱怨。我们不怨天尤人，这是儒家教导我们的。如果我们抱怨我们的处境，我们的心就很小。又有了佛家跟我们讲，无论遇到怎样的生活处境，于境离境，不改你修行的决心。

这是中国思想。

<span id="p-32-035" class="reading-anchor"></span>

今天在资本和技术的时代，我们反复讲儒家的人生观，是不是与这个时代形成一种很突兀的关系？是不是违背了资本和技术的文明所要求于我们、加给我们的进步强制？这是许多人的想法。

<span id="p-32-036" class="reading-anchor"></span>

我相信我们中国人是能够在现代化的进程中继续向前迈进，但是我们不改我们民族的文化精神。我们的这一段课就先讲到这里。

## 本讲总结｜整理附录

陈九川把静坐与应事分开，阳明以眼前讲论的情形说明功夫一贯。课堂进一步辨别磨练心与增长办事本领：事情不断变化，心的功夫则落在每次情感变化的省察中。

本心仁体既无内外，就不能只在某种理想处境中成立。安贫安富的讨论因此接到行、奋斗和文化精神；武训及中国父母的例子，都服务于澄清「安」并非消极不动。
