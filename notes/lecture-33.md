## 周道通的两个问题

**回看 00:00—05:58**

<span id="p-33-001" class="reading-anchor"></span>

我们还在课程的第四部分。在阳明的《传习录》中，《答周道通书》一共有八节，我们看其中的第五节。通过这第五节的讨论，我们继续讲人须在事上磨练，怎么磨练。

<span id="p-33-002" class="reading-anchor"></span>

「来书云」，就是周道通的来信中说：「事上磨练，一日之内，不管有事无事，只一意培养本原。」

再看这一节：「若遇事来感，或自己有感，心上既有觉」——明觉、感觉的「觉」——「安可谓无事？」心上既有觉，就是情感起变化，遇到事了，怎么能说无事？

<span id="p-33-003" class="reading-anchor"></span>

「但因事凝心一会，大段觉得事理当如此，只如无事处之，尽吾心而已。然仍有处得善与未善，何也？」

<span id="p-33-004" class="reading-anchor"></span>

我们看周道通学阳明心学，已经有很好的体会了。比方说遇到事，是因为心上有觉了吧。有觉了，当然有事了啦。然后凝心一会，便能明白事情、事理是怎样的。然后，就当没有事一样对付它，我们的情感不跟着事的变化而起伏。

只当无事处之，我只有一个愿望，尽吾心而已。这应该说是蛮高的境界。

<span id="p-33-005" class="reading-anchor"></span>

第一，事情来了，我们一定情感起变化。心外无事，一切事情都是心事啊。你或喜或怒了，或忧或惧了，你一定就是遇到事了嘛。

<span id="p-33-006" class="reading-anchor"></span>

遇到事了之后，周道通说，我是下这样的功夫，凝心一会，别的不去想，想一想这事情的事理在哪里。然后我就把那些喜怒哀乐都放下了，放下就叫只如无事处之了。只有一个愿望，尽吾心，这是孟子讲的尽心了。

<span id="p-33-007" class="reading-anchor"></span>

但还有一个疑问想问你阳明，「然仍有处得善与未善，何也？」事情不是只当无事处之吗？做了吧，做了以后还有一个善和未善的区分吧，做得好还是做得不好啊。叫处得善，就是做得好，处得未善就做得不好。

这是一个疑问。

<span id="p-33-008" class="reading-anchor"></span>

另外还有一个疑问：「又或事来得多，须要次第与处。」事情纷至沓来，怎么办？要先分个次序，先做什么、后做什么。

「每因才力不足，辄为所困」，对付不了了，精力有限，「虽极力扶起而精神已觉衰弱」。

<span id="p-33-009" class="reading-anchor"></span>

遇到这种情况，周道通说，自己「未免要十分退省」，先把事放下来，反思自己的心。宁可不了事，「宁不了事，不可不加培养」。要培养本原，就是培养自己的本心。

这样做对不对？

叫「如何」。他提了两个问题。

<span id="p-33-010" class="reading-anchor"></span>

若我们不下养心的功夫，这样的问题也就没有。做事就去应付吧，应付了一件，再去应付另一件，就没有周道通的疑问。因为周道通总没忘了，做事情同时就是下养心的功夫嘛。那么养心的功夫我已经能下了，因为遇到事情知道自己心起变化了，这叫心事嘛。

<span id="p-33-011" class="reading-anchor"></span>

然后我就把这个心凝聚起来，别的不想，什么闲思杂虑都不想，只看这事情本身的理在哪里。想到了这件事情的理在哪里，我就尽我的心把它做好。但是总有一个问题吧，终会做得好或者不好，这是一个疑问。

<span id="p-33-012" class="reading-anchor"></span>

第二个疑问，事情多了怎么办？眉毛胡子一把抓吧，于是要分个次第，一个先后。那么事情实在太多，终于精力支撑不住了，才华也不够了，退一退，把事放一放。「宁不了事」，宁愿不把事情做完了，也要回过来培养本原。

这个想法对不对？

## 终身只为这一事

**回看 05:58—07:51**

<span id="p-33-013" class="reading-anchor"></span>

阳明回答，「所说功夫，就道通分上，也只是如此用」。就你周道通已经达到一定的境界了，目前也就这么用了，用功夫就这么用了。「然未免有出入在。」

<span id="p-33-014" class="reading-anchor"></span>

「凡人为学，终身只为这一事，自少至老，自朝至暮」，从年轻的时候到年纪大的时候，从早晨到傍晚。「无论有事无事，只是做得这一件，所谓『必有事焉』」。「必有事焉」是谁说的？

孟子。千事万事，其实只是一件事。

<span id="p-33-015" class="reading-anchor"></span>

一件什么事？吾养吾浩然之气，把心养得和天一样大，那叫浩然之气呀。我们无论做什么事情，事情也实在多种多样。在阳明心学的境界说来，其实就一件事，专主一天理。你时而去读书，时而做老师，时而去经商都可以呀，时而还去打仗也行。

<span id="p-33-016" class="reading-anchor"></span>

此事彼事，种种的事，其实就一件事。让你所做的任何事情都成为天理的实现，这样你的气就养了。吾养吾浩然之气。这就是我们前面部分提到的什么叫主一。主一不能误解为专心致志地做事情。

### 专心做事与逐物

**回看 07:51—09:47**

<span id="p-33-017" class="reading-anchor"></span>

如好货，便一心在好货上。如好色，一心便在好色上。如接客，一心便在接客上。如读书，一心便在读书上。阳明回答了。这叫什么？这叫逐物。心向外驰求了，不就是逐物嘛？

<span id="p-33-018" class="reading-anchor"></span>

我现在在接待客人，一心只在接客上。我此刻又读书了，一心只在读书上。此刻我好色了，一心只在好色上。此刻我做生意了，要发财了，一心就在好货上。货就是财产了。这叫主一吗？

这叫把心放出去了，逐物了，在心外逐物啊。

<span id="p-33-019" class="reading-anchor"></span>

把主一误解为专心致志地做事，但不知道做事该做成什么样。就这件事而求它的目标。比如说我接客，接客为什么一心地接客呢？终于把这个客人接待好了，他很满意了，我成功了。

读书，好像我读懂了，也成功了。好色，我也得到了好色。好货，我便得到了财产。

<span id="p-33-020" class="reading-anchor"></span>

把不同的事，都按照这些事自身好像指向的目标去做，那么一生就很散，忙这个、忙那个。阳明说，这叫逐物。我们做种种不同的事，听上去顺理成章，人不就是这样生活的吗？

孟子偏说，无论做怎样的事情，必有一件事：让所做的事情成为天理的呈现，成为我们的养气，养浩然之气。

## 「宁不了事」是把做事和养心分开了

**回看 09:47—11:20**

<span id="p-33-021" class="reading-anchor"></span>

现在，周道通提的第二个问题是什么？那么多事情来了，忙不过来，精力也够不上，只能先不做了。

阳明指出问题：「若说『宁不了事，不可不加培养』，却是尚为两事也。」

<span id="p-33-022" class="reading-anchor"></span>

一件事情是什么？正在做的、要做的事。还有一件事情是什么？我们养心的功夫。两件事分开了。「必有事焉而勿忘勿助」，这是孟子的原话。我们人生做种种的事都不算事，只有一件事才是所有的事的所在。

那就是把这个事做对了，同时我们也就养了心。

<span id="p-33-023" class="reading-anchor"></span>

不能忘了这个宗旨，也不要揠苗助长。事情没来，你就想把自己的心养得那么大，不可能的，养不起来。既不要忘了这个目标，养心，养浩然之气，也不要什么，离开事，我就想自己能成功。

那个揠苗助长的成语就来自孟子嘛。所以自然地让事情来，来了就好，在做事中养心，养浩然之气。

### 忠恕与身忙心不忙

**回看 11:20—13:04**

<span id="p-33-024" class="reading-anchor"></span>

「事物之来，但尽吾心之良知以应之」，所谓「忠恕违道不远矣」。一个忠，一个恕。忠就是推己及人的正推，「己欲立而立人，己欲达而达人」。恕就是推己及人的反推，「己所不欲，勿施于人」。

孔子说仁，仁义道德的仁，就从两个方面说，一个是忠，一个是恕。所以忠恕违道不远矣。

<span id="p-33-025" class="reading-anchor"></span>

这是回答他第一个问题〔[问题次序见整理注](#editorial-note-1)〕。没有累不累的问题，也没有累了就不做、事情先放下不了的问题，这都是搞错了。

你做那么多事，忙得很，可以理解。

但做这些忙的事情，没有那么多闲思杂虑让你累。为什么？你做不同的事情，只有一个目标：养心。既然是养心的功夫，做很多事情也没关系。身忙，心不忙。

<span id="p-33-026" class="reading-anchor"></span>

所以，阳明发现周道通下功夫时有一种误解。于事上磨练，磨练的不是别的，而是我们的心。

「宁不了事，不可不加培养」，你搞错了，这不是两件事。

培养本原，就是在做事中实现的，不是两事。这是第一个问题的回答。

## 善与未善，毁誉得丧

**回看 13:04—15:11**

<span id="p-33-027" class="reading-anchor"></span>

对第二个问题，他这样回答：「凡处得有善有未善」，事情有做得好和做得不好；「及有困顿失次之患者」，累得要死，然后就乱了。

「次」就是次第，「失次」就是次序乱了。

为什么会发生这种情况？「皆是牵于毁誉得丧」。

<span id="p-33-028" class="reading-anchor"></span>

你为什么做事做得那么累呢？你做事的时候，你对自己的评价无非两个标准。这事做得好还是不好，无非两个标准。第一，别人是怎么评价的？否定的评价叫毁，诋毁的毁。肯定的评价叫誉，赞誉的誉。

这是一个标准。

<span id="p-33-029" class="reading-anchor"></span>

第二个标准，我们通常也用来评价自己所做的事，它的结果是有利于自己的，叫得，不利于自己的，叫丧。就是两个标准吧，毁誉得丧。结果，这件事情你在做的时候不是去致良知，「不能实致其良知耳」。

<span id="p-33-030" class="reading-anchor"></span>

其实我们做事情就是什么？致良知。让良知到达，不就致良知嘛？没有别的想法。不要担心别人怎么评价我们所做的事，也不要担心做出事情的结果有利还是不利于自己。这两种担心都没了，你累个什么呢？

你不累，你就把事情一份一份做好它。因为你心中只有一个目标，实致其良知耳，千事万事就一件事。

## 喝酒的例子，一天就是一生

**回看 15:11—17:53**

<span id="p-33-031" class="reading-anchor"></span>

所以这样我们来看看阳明说的有没有道理。我们在这世界上生活，有时候真忙得不得了。忙得不得了，我主要的做法，是白天忙，晚上要喝酒，聊以自慰。因为想到晚上有好酒好菜的，我觉得白天的一天的忙也没有白忙，否则也太累了，境界比较低。

<span id="p-33-032" class="reading-anchor"></span>

当然我在喝酒的时候，回顾我今天白天所做的事情，假如心安理得，这酒就是美的，就不是苦酒了。这也算境界。因为你喝着酒，就想白天那件事怎么做败了，你这个酒也就没啥意思了，苦酒了。

愁来了，借酒浇愁愁更愁。

<span id="p-33-033" class="reading-anchor"></span>

我觉得一天就是一生。早晨起来，因为睡了一觉，清醒了，心很平静的。这时候的心是特别清朗，除非你晚上做了个噩梦啊。若未做噩梦，一觉醒来，就像我们小时候一样，那个童心的感觉就来了。

<span id="p-33-034" class="reading-anchor"></span>

然后，上午做事情，无论是起居还是做事，都很顺畅，精力也充沛。中午吃了饭就昏昏欲睡，睡个午觉，恢复精力。下午继续做，就相当于中年。中年人慢慢到黄昏了，老年，已经感觉到疲惫了吧。

<span id="p-33-035" class="reading-anchor"></span>

但是一天做下来的事情让自己很惬意，很舒服的，这就老年人的幸福感。然后准备睡觉，就一天就是一生。那么老的时候，你也没有别的好想了吧？反正接下去就睡觉去了。那么你喝点酒了。

老年人喝酒，那个酒的味道才浓呢。少年人只会醉，老年人会什么？欣赏，enjoy。人一生大概就像一天一样。

## 用良知来作自我评价

**回看 17:53—18:53**

<span id="p-33-036" class="reading-anchor"></span>

好，我们继续把阳明的话看完。「若能实致其良知」，如果我们做事情是能够让良知到达的，「然后见得平日所谓善者，未必是善，所谓未善者，却恐正是牵于毁誉得丧」。

<span id="p-33-037" class="reading-anchor"></span>

我们把自己的事情做自我评价，有时候像是好，但未必是好。有时候说未善，做得不够好，不好，其实未必不好。因为我们只是牵挂着别人的评价，牵挂着自己的得失。由于这种牵挂的缘故，我们把自己的良知戕害了，「自贼其良知者也」。

这个「贼」作动词用，盗贼的贼字作动词用，表示戕害。

### 得意、自责与自我评价

**回看 18:53—21:57**

<span id="p-33-038" class="reading-anchor"></span>

所以阳明说得很分明了。我们做事情总会同时发生自我评价的。自我评价如果是肯定的，得意了。自我评价如果是否定的，后悔了，自责了。一个我在表扬另外一个我，叫得意。一个我在批评另外一个我，叫自责。

这是我们每个人都这样的。那么怎么办？

<span id="p-33-039" class="reading-anchor"></span>

别忘了，我们得意也罢，自责也罢，如果它来自毁誉得丧这两个标准，我们就不应该得意，或者不应该自责。有时候你做一件事，天下人都一致地否定你，不是错的，未必是错的，你自己心里明白。

这就是毛主席曾经说过的，要有反潮流的精神。

<span id="p-33-040" class="reading-anchor"></span>

心学让我们有勇气自我评价，不在乎别人的评价。心学让我们知道，事情的结果有利于自己还是不利于自己，不应当是我们考虑的。因为做事情不是达到有利于自己的目标的手段，事情本身不是手段，它自己就是自己的价值。

所以这件事情本应当做，不做是不应该的。

<span id="p-33-041" class="reading-anchor"></span>

所以做事情就是实致其良知耳。如果实现了，自己的评价就应该是肯定的。如果没实现，自己的评价、自我评价，就应该对自己所做的事给予否定。这叫于事上磨练，岂有它哉？

<span id="p-33-042" class="reading-anchor"></span>

我们中国人都能在阳明心学中下这养心的功夫，自然会成为道德自觉的主体，成为收拾精神、自作主张的大英雄。

这就是我们讲的第十七点：心无内外。

<span id="p-33-043" class="reading-anchor"></span>

不要空洞地守着一个内在的心，把外部的事情看成是与它可以分开的，不可分开。所以这是养心的功夫里边非常基本的一条原则。养心不是一个人在那里苦思冥想，然后静坐、不起念头，守护着这个所谓本原，搞错了。

培养本原就在做事中培养。

## 学问、诉讼和宇宙内事

**回看 21:57—23:33**

<span id="p-33-044" class="reading-anchor"></span>

这就是孟子讲的「必有事焉」。你必是一定是在做事中养浩然之气的，那叫必有事焉。千事万事只是一事。你认真做这件事情，但这件事情当中没有你这个小我。这件事情就是天理，也就是你的良知，不是你的小我。

<span id="p-33-045" class="reading-anchor"></span>

比方说我做学问，学问乃天下之公器，哪里是我的？假如我写一篇文章被人批评，我觉得很好，学术就应该争鸣。

不要以为建立起来的学问，就像放在自己口袋里的钱，拿来在社会中获得兑现价值。

不对，学问是天下之公器。我是为学问服务，不是让学问为我服务，其中就无我。

<span id="p-33-046" class="reading-anchor"></span>

这是佛教讲得最清楚的事，如何去我执？我们总以为自己所做的事情是属于自己的。不，它是天下的事。「宇宙内事即己分内事，己分内事即宇宙内事。」哪里是自己的？

### 律师和教师的事

**回看 23:33—25:57**

<span id="p-33-047" class="reading-anchor"></span>

比方说我做律师，假定，那么我要参与诉讼。参与诉讼，我就为某一方辩护。这件事情，现在的律师都看成是自己律师成长的一个关键的事情。然后官司打赢了，律师辩护成功了，律师每每把这看成是自己的成功，自己的律师的地位和声誉的提升。

<span id="p-33-048" class="reading-anchor"></span>

都想错了。打官司就是主持正义，这是天下的事，不是你个人的事。做别的行当，教师也是一样的。我作为教授了，牛起来了，比讲师高多了。其实我跟讲师一样，只有一件事，站在讲台上，不要误人子弟。

天下的事，宇宙内事。

<span id="p-33-049" class="reading-anchor"></span>

某某人在复旦任教，或者在北大任教，任教这件事是宇宙内事，那我们去做了而已。这种境界，禅宗有，阳明心学有，达到这个境界，所以人就不会有恐惧。我们牵于毁誉得丧，我们就恐惧，怕事情做坏了。

<span id="p-33-050" class="reading-anchor"></span>

什么叫做坏了？大家批评了，结果对自己严重不利了，这叫做坏了。真做坏了吗？未必。王阳明说，你自己判断，你有良知，自己判断。所谓做得好的，未必是好的。所谓做得不好，未必不好。

标准不在外界，也不在你躯壳上起的那个得失之念，都不在，只在你本有的良知那里。这很难做到的啊。

## 以良知立信仰

**回看 25:57—28:16**

<span id="p-33-051" class="reading-anchor"></span>

如果你有宗教信仰，你做到这一点，因为你把你的生活本身当成是上帝计划的一部分。你连结婚都是上帝的事业的一部分，那你做到了。但你偏不是基督徒，那你如何有信仰呢？这，阳明讲得清楚了。

我们以良知做准绳了，于是小我就去掉了。

<span id="p-33-052" class="reading-anchor"></span>

但所做的事都是宇宙内事。那么基督徒说，我们所做的事都是上帝的事业的一部分，其实境界是一样的。这里是宇宙，那里是上帝。基督教讲上帝，陆九渊讲宇宙，明白吧？

<span id="p-33-053" class="reading-anchor"></span>

一个基督徒认为他一生的生活都是什么？上帝事业的一部分。他的目标的实现，叫上帝计划的实现。比如说此人爱上那个人，两个人都是基督徒，后来结婚了。他们的结婚是什么？上帝计划的实现。

不是两个人个人的事。

<span id="p-33-054" class="reading-anchor"></span>

于是婚礼在教堂中举行，没有当事人什么事。什么新郎新娘怎么安排整个过程，没你们的事。牧师来了，神父来了，这哪里是你的事呢？他们就很认真地在教堂中举行了婚礼，在上帝面前做出庄严的承诺。

这就是婚礼在教堂中举行的缘故。

<span id="p-33-055" class="reading-anchor"></span>

我们中华民族不是宗教的民族，同意了吧？因为我们没有这种宗教精神的。我们除非把道教修行长生不老当宗教，我认为这不叫宗教。宗教关乎我们的灵魂和关乎我们对人生意义的确认，所以这就是宗教。

但我们没有宗教。我们在哲学中以本心立信仰，以良知立信仰，就这件事。

## 课堂问答，为什么良知会被遮蔽

**回看 28:16—30:59**

<span id="p-33-056" class="reading-anchor"></span>

有人问：「为什么有的人没被遮蔽，有的人良知被遮蔽呢？良知被遮蔽就是恶吗？」

<span id="p-33-057" class="reading-anchor"></span>

这件事只能这样说：如果从小没有得到必要的精神修养，长大以后每每会这样。但是他会得到提醒的。谁提醒他？良知。

怎么提醒？

心不安了。良知被彻底遮蔽的人，良知仍在，只是被遮蔽了。结果是什么？心不安。心不安才是根本的问题，是精神上最大的痛苦。

<span id="p-33-058" class="reading-anchor"></span>

有的人在这种比较艰难的岁月当中受到了不公正的待遇。比方说文革当中有些人被关到牛棚里去了，一关好多年，但他心没有不安。他就在那里站着，精神上站立着呢。但凡我们遇到了一种很艰难的处境的时候，若我们想起以前做过品节不端正的行为，曾经害过别人，我们就没那种精神上的勇气了。

<span id="p-33-059" class="reading-anchor"></span>

所以这就是孟子讲的养心，养浩然之气。在任何处境上，我们精神上是自立的，自己站在那里了。前提是什么？我们以前没做过那么多亏欠别人的事、伤害别人的事。这是一个非常重要的东西。

<span id="p-33-060" class="reading-anchor"></span>

所以良知，许多人都是被遮蔽的，他的良知被遮蔽了。没关系的。这叫迷了，妄念覆盖，良知在的，有一天他醒了，那叫觉悟了。这是禅宗的语言。「前念迷是凡夫，后念悟即是佛。」

<span id="p-33-061" class="reading-anchor"></span>

当然你刚才说的那些差别，儒家不做解释啊。为什么有的人良知总是能呈现了，有的人的良知总是遮蔽的，然后为非作歹。原因是什么？不说。只是说小时候没有好好地建构自己的精神家园。

### 慧根与孩童时代的滋养

**回看 30:59—32:54**

<span id="p-33-062" class="reading-anchor"></span>

但佛家说了，人不一样，就慧根有深浅。在找到弘忍法师之前，惠能也没有在人生的道路上什么大起大落吧。无非就是三岁丧父了，然后得不到读书的机会。普通的劳动者，砍柴火、卖柴火为生，奉养老母，就这些事。

<span id="p-33-063" class="reading-anchor"></span>

但是他一听到那八个字，「应无所住，而生其心」，心即开悟。《坛经》里写着，那就是上根之人。佛教有了说明。确实孩子有差别。我们会发现，有的孩童很小的就有大悲悯，不是小悲悯。

<span id="p-33-064" class="reading-anchor"></span>

小悲悯就是什么意思呢？他跟这个人认识的，这个人也曾经帮助过他，然后那个人遭难了，他同情了，小悲悯。天下的路人，素昧平生的路人的苦难，让这个小孩难过了，一定是慧根，毋庸置疑的。

这就是佛家说了，人有区分的缘故。

<span id="p-33-065" class="reading-anchor"></span>

惠能自己说，我为什么有机会闻如上顿教？从弘忍那里来的，弘忍就主张顿悟的。他说我也是前世种了善根，宿昔有缘，才走到今天的。这是佛家的解释。

<span id="p-33-066" class="reading-anchor"></span>

你问的问题，其实是许多人都想问的。人为什么差别那么大？在善恶这件事情上，佛教有佛教的说明。那么儒家的意思就是，我们不能错过孩童时代，应当及时得到心灵的滋养。这是儒家的说明，就到这里。

## 本讲总结｜整理附录

本讲反复辨明做事与养心的关系：专心追求不同事情的外在目标，仍可能逐物；在事情中实致良知，才贯通为同一功夫。事情做得善或未善，也不能仅以他人评价与自己的得失来定。

喝酒与一天一生的个人体会、学术争鸣、律师与教师、基督教婚礼等讨论，都是课堂实际展开的旁支。结尾回应良知为何被遮蔽，保留慧根、顿悟、前世善根等具体说法，不把它们缩成一般心理解释。
