## 理是心之功夫

**回看 00:00—04:04**

<span id="p-13-001" class="reading-anchor"></span>

我们总想知道天理本身是什么，那么就是要认识它了。但在心学那里，我们不讨论天理是什么，我们把天理看成什么？人心之功夫。

《传习录》中有许多对话都涉及这层意思、这个思想，比较集中的是《徐爱录》。所以，课程第四部分的第一节，叫「理乃心之功夫」。

<span id="p-13-002" class="reading-anchor"></span>

换句话说，它不是头脑认识的对象。了解这一点，真是进入阳明心学的关键一步。因为心即理，心是生命情感的居所，生命情感的本真便是天理。所以这个理呢，是情之理吧，不能脱离情来讲理吧。

<span id="p-13-003" class="reading-anchor"></span>

所以，这个理是我们生命情感的条理。汉语中有一个普通词语，叫「情理」，情与理并举，不能分开。又有这样的词语，叫「合情合理」。

<span id="p-13-004" class="reading-anchor"></span>

你把情撇开，只说一个合理，不是中国思想，或者是中国哲学思想当中走偏了的那一路。合情合理，如果你做事情合情合理，效果是什么？又是个成语，心安理得。心是不是情感？头脑当中得了个理，心还没安呢。

<span id="p-13-005" class="reading-anchor"></span>

有时候，我们遵循了头脑确认的某些规则，认为合乎理性，然后去做这件事。做完之后回顾这件事，突然心不安起来。这是我们得注意的。

比如说，企业家管理企业有一套规则：企业制度、企业规则、管理规则。这些都是大家用头脑确认的理。

<span id="p-13-006" class="reading-anchor"></span>

那你去管理的时候，遇到的是人吧，是人的事情吧？在做人的事情的时候呢，你只知道那个规则，事情做了啊，这影响到员工的生活了。也许你认为按照这个规则，我这么做是对的，但员工的生活如果因为这些规则的运用而受到伤害呢？若发生这种情况，这个企业管理者一定会什么？心不安了。

<span id="p-13-007" class="reading-anchor"></span>

法律有它的理，叫法理。但在法理之上是什么？天理。所以，人在日常生活中做事情，总要记得做到什么？心安理得。这叫情理，不合情理不行。

我们不是个宗教的民族。基督教的民族，有上帝管人心，上帝最高，肯定高于法理。我们没有上帝，但我们有天理。

## 徐爱的启蒙

**回看 04:04—06:24**

<span id="p-13-008" class="reading-anchor"></span>

我们等于再度说明了在当代学阳明心学的根本重要性。我们如何理解这个理？我们看徐爱向阳明先生所提的问题。《传习录》上卷第一篇、第一个对话录，就是《徐爱录》。

<span id="p-13-009" class="reading-anchor"></span>

那么徐爱是谁呢？阳明的一个高足弟子啊。他后来境界很高的，据说还被称为什么？王门颜回。孔子七十二个弟子当中最了不起的是不是颜回啊？孔子赞美颜回，「贤哉，回也！」王门中也有一个颜回，那叫徐爱。

<span id="p-13-010" class="reading-anchor"></span>

徐爱在接触阳明心学之前，他深受朱熹理学的影响。朱熹理学对他的影响非常非常深，他一时还调转不过来，所以就有种种的疑问要问王阳明的。看来我们进入任何学问，第一步、第一阶段接触怎样的学问，这是很关键的啊。

<span id="p-13-011" class="reading-anchor"></span>

就像你学钢琴，启蒙老师多么重要。第一个教你弹钢琴的人，教你一整套技法：弹成什么样算好，怎样是错误的。他成了你的启蒙老师。

<span id="p-13-012" class="reading-anchor"></span>

假如这个启蒙老师不太合格，会怎么样？后来的老师要教他教出来的学生，难不难？实在太难，要纠正，还不如从一张白纸开始。先要去掉先前所学的不对的东西，这让老师很难。

现在阳明面对徐爱也一样。徐爱曾经浸染于朱熹的理学，于是提出这样的问题。

## 至善只求诸心吗

**回看 07:38—10:51**

<span id="p-13-015" class="reading-anchor"></span>

现在看《徐爱录》第三节。徐爱问阳明：「至善只求诸心……」「至善」不就是《大学》三纲领的第三条，「止于至善」吗？「至」就是最高，至善就是最高的善。

「至善只求诸心」，这个「诸」实际上是「之」「于」两个字合起来。至善只求之于心，就是这个意思。

<span id="p-13-016" class="reading-anchor"></span>

从哪里求至善？从心里求至善。「至善只求诸心，恐于天下事理有不能尽。」我们只要求自己的心就可以了？天下万事万物各有道理吧，那些事理总得了解吧。你光求之于心啊，那个天下万事万物的理，你如何能懂呢？如何能了解呢？

<span id="p-13-017" class="reading-anchor"></span>

这个事理，就像我们今人所说的知识。做任何事，都有与这件事相应的知识。你说「至善只求诸理」〔[此处用字见整理注](#editorial-note-1)〕，当然好，是蛮好的话。徐爱的意思是：好是蛮好，但是我们不是光求诸心吧？做这件事或者另外一件事，做每一件不同的事，都要就不同的事，了解与它相关的道理，叫事理。

<span id="p-13-018" class="reading-anchor"></span>

这个疑问不就来了吗？徐爱这个疑问，显然来自朱熹对他的影响：于一事一物上求天理。面对这个疑问，阳明回答得非常简要：

> 心即理也。天下又有心外之事、心外之理乎？

<span id="p-13-019" class="reading-anchor"></span>

回答得非常干脆。你徐爱说天下的事理呀，你说理了吧，阳明说心即理，在心之外哪有理啊？在心之外哪有事情啊？一切事情都是心事，心外无事。你说天下万事万物还各有它的理。心外无理，哪有心外之理，哪有心外之事啊。

### 孝、忠、信、仁的疑问

**回看 10:51—15:24**

<span id="p-13-020" class="reading-anchor"></span>

这样一回答，若我们是徐爱，难免仍然疑惑。徐爱的疑惑不就来了吗？他这么问：「如事父之孝……」我们跟父亲打交道，叫事父。事父，是不是要讲一个「孝」字？

<span id="p-13-021" class="reading-anchor"></span>

如果我们跟朝廷、国家打交道，朝廷、国家在这里称为君。那么要事君吧，事君是不是讲一个字，忠诚的忠？还有交友，我们交朋友，不是要讲一个信字嘛，交友之信。如果我们是官员，去治理社会，不就是民嘛，老百姓、人民的民，那么治民要讲一个字吧，那个仁义道德的仁。

<span id="p-13-022" class="reading-anchor"></span>

徐爱问：

> 如事父之孝，事君之忠，交友之信，治民之仁，其间有许多理在，恐亦不可不察。

事父要实现孝，有一种理，这种理跟事君不一样。事君要实现忠，又有它的理，你要了解。交朋友要实现信，如何实现这个信字，也有它的理。

<span id="p-13-023" class="reading-anchor"></span>

治民，为父母官者啊，如何治理一方百姓的生活？不要讲一个仁字吗？要实现这个仁，也有它的理在。恐不可不察，恐怕都要一一地了解。这话说来，大家觉得自然是对的了。

<span id="p-13-024" class="reading-anchor"></span>

那徐爱这么说有道理啊。比方说你要治民吧，做官、为官者治民，治理老百姓的意思啊，治民。是不是有一番讲究啊，有一番理啊，今天这个理叫政治学。那么你怎么好做官呢？如果你不到大学里边学那个政治学，怎么行呢？

<span id="p-13-025" class="reading-anchor"></span>

据说现在复旦好像也有这样的课，是国际政治系开的吧，叫 MPA。MBA 是管理科学，MPA，P 就是行政的意思啊。所以为官的啊、政府机关的干部啊，要到大学学这个课程的，叫 MPA，行政管理硕士。就治民有治民的理。要学。

<span id="p-13-026" class="reading-anchor"></span>

我怎么孝我的父亲呢？也要学，恐怕应该另立一门学科。我怎么交朋友呢？也要学，也有一门学科，比方说心理学，那就这个意思了。徐爱无非如此的意思，我听来呢，只有四个字，岂有此理。

<span id="p-13-027" class="reading-anchor"></span>

当然，也有一些口号在说干部知识化，要有文凭。现代社会，为官的、做干部的，要年轻化、知识化，口袋里文凭越多越好，最好拿好了博士学位再去做官。

这叫什么？用阳明的话说：「此说之蔽久矣。」这种说法造成的遮蔽，已经很久了。

## 都只在此心

**回看 15:24—19:25**

<span id="p-13-028" class="reading-anchor"></span>

你徐爱说的这个道理啊，其实是一种遮蔽啊，很长久了。「此说之蔽久矣，岂一语所能悟！」我刚才跟你说的就一句话嘛，心即理，天下又有心外之事、心外之理乎？一句话说给你听了。你不能明白。岂一语所能悟，岂是一语所能悟的？

<span id="p-13-029" class="reading-anchor"></span>

「今姑就所问者言之。」你刚才不是问我了吗？如事父，跟父亲打交道，该怎么办？「不成去父上求个孝的理」，去研究父亲，通过研究得一个孝的理？

事君，「不成去君上求个忠的理」，去研究君、研究国家、研究政治？

<span id="p-13-030" class="reading-anchor"></span>

「交友、治民，不成去友上」，在朋友身上，或者在老百姓身上，「求个信与仁的理」，都不可能。底下说：「都只在此心，心即理也。」

什么叫「此心」？「此心无私欲之蔽」，小我的欲望叫私欲。如果去除私欲之蔽呢？「即是天理」。

<span id="p-13-031" class="reading-anchor"></span>

心即理。在什么情况下，我们的心不是理了？被私欲遮蔽的时候。把这个遮蔽去掉，心即理。「不须外面添一分」，不必从外面添加。

「以此纯乎天理之心，发之事父便是孝」，用到跟父亲打交道上，便是孝。

<span id="p-13-032" class="reading-anchor"></span>

用到跟国家打交道，当时叫跟朝廷打交道，叫「发之事君便是忠」了嘛。以这个纯乎天理之心，用到交朋友上去，用到治理百姓上去，便是信与仁。「只在此心去人欲、存天理上用功便是。」

<span id="p-13-033" class="reading-anchor"></span>

心还是这一个心吧，只要它没有私欲之遮蔽，用到不同的事情上，便得了不同事情的理。用到跟父亲打交道上，便得了孝之理了，不是另外去学。用来跟朋友打交道，便是个信，讲信用的信字。朋友有信，这个信的理是什么？还是你那个心用到跟朋友的关系上去了。

<span id="p-13-034" class="reading-anchor"></span>

还是这一个心，用来治理人民生活，便是个仁，仁义道德的这个理就得了嘛。还是那一个心，一用，用到不同的事情上，便都得了不同事情本应该有的那个天理。心即理。

### 温清定省，如何不讲求

**回看 19:25—24:01**

<span id="p-13-035" class="reading-anchor"></span>

徐爱还是要追问。旧说在他心中——这个旧说就是朱熹的学说——纠缠已久，所以接着说：

> 闻先生如此说，爱已觉有省悟处。但旧说缠于胸中，尚有未脱然者。

「爱」就是徐爱，他有所醒悟了。他也说得很坦率：朱熹的影响实在太深，还有没摆脱的地方，所以还得进一步问。

<span id="p-13-036" class="reading-anchor"></span>

「如事父一事」，事父就是跟父亲打交道。在这件事情上，「其间温清定省之类，有许多节目，不亦须讲求否？」不也应当要讲求一番吗？

<span id="p-13-037" class="reading-anchor"></span>

什么叫温、清、定、省？父亲年纪大了，我们作为他的孩子，自然关心他。「温」是什么意思？寒冷的冬天，要想着父亲如何得到温暖。「清」呢？夏日炎炎，总要想着父亲得到一份清凉。

<span id="p-13-038" class="reading-anchor"></span>

什么叫定？就是你晚上睡觉之前，你总得去关心一下，看一看父亲能否睡得安稳。早晨起来，你第一件事情要去问问老父亲，昨天晚上睡得好吗？叫省吧，早晨的问候。四个字吧，温清定省。这温清定省，其间有好多节目呢，就怎么做法，有这讲究吧？

<span id="p-13-039" class="reading-anchor"></span>

听来还是有道理。徐爱的意思是：光有我这颗心，总还得研究一些事情，如何让父亲温，如何让父亲清，如何让父亲定，如何问候、帮助他，其中有许多节目。

阳明回答：「如何不讲求？」当然讲求。「只是有个头脑。」

<span id="p-13-040" class="reading-anchor"></span>

要有个头脑，头脑在这里说的是有个主宰。要有个主宰，什么主宰？「只是就此心去人欲、存天理上讲求」。具体说吧，「就如讲求冬温」，寒冷的冬天，父亲能不能得温暖，这叫讲求冬温吧，「也只是要尽此心之孝，恐怕有一毫人欲间杂」，不要有私欲间杂其中。

<span id="p-13-041" class="reading-anchor"></span>

夏天要讲求夏清吧，清凉的清，「也只是要尽此心之孝，恐怕有一毫人欲间杂，只是讲求得此心。此心若无人欲，纯是天理，是个诚于孝亲的心」。冬时，在冬天的时候，「自然思量父母的寒，便自要去求个温的道理」，就找一个让他温暖的方法。

<span id="p-13-042" class="reading-anchor"></span>

「夏时自然思量父母的热，便自要去求个清的道理」，要找到让父母得到清凉的方法。「这都是那诚孝的心」，那个诚就是真诚的诚，「这都是那诚孝的心发出来的条件。」

## 诚孝之心是根

**回看 24:01—28:12**

<span id="p-13-043" class="reading-anchor"></span>

这里的「条件」不是今天逻辑学讨论的条件，指的是树干上生发的枝条。

「却是须有这诚孝的心，然后有这条件发出来。譬之树木」，就是好比树木，「这诚孝的心便是根，许多的条件便是枝叶。须先有根，然后有枝叶，不是先寻了枝叶，然后去种根」。

<span id="p-13-044" class="reading-anchor"></span>

先寻枝叶，然后去种根，叫本末倒置。「本」是树根，「末」就是枝条。所以《礼记》中有这样的话：「孝子之有深爱者，必有和气；有和气者，必有愉色。」

什么叫孝子？对父母存孝的孩子，他有深爱。

<span id="p-13-045" class="reading-anchor"></span>

他的面色就好。面对需要他帮助的老父、老母，他的脸色总是愉悦的。「有愉色者，必有婉容。」要做到这一点，跟父母打交道，跟年老的父母打交道，他们有许多事情都不会做了，人就笨拙了。就像我们小时候需要父母帮助一样，我们是孩子，父母老了就需要我们帮助了。

<span id="p-13-046" class="reading-anchor"></span>

在帮助的时候是怎样的？要有一个深爱做根的，自然什么？和颜悦色嘛，不会板着脸去帮助的吧？现在有些孩子就板着脸的，他知道这是责任啊，对父母有责任感，这是好的，但他没有深爱做个根。于是他在承担责任的时候，他有私欲掺杂其间，于是心里就不高兴。事情还在做，脸板着，说话是教训父母的口气，这样的人不少。

<span id="p-13-047" class="reading-anchor"></span>

所以，对徐爱这个问题，不能只讨论怎么孝顺父母、怎么温清定省，有许多节目要一一学来。只要有一份诚孝之心，有对父母的深爱做根，自然会想尽一切办法：冬天让他们温暖，夏天让他们清凉，每天让他们睡得安稳、吃得好。

<span id="p-13-048" class="reading-anchor"></span>

你想各种办法，不同的时代还有不同的办法。今天我们是装空调吧，古代也没空调。那么你就去研究一下空调，总是对的吧？这有什么难的呢？现在据说还有地暖，好像比空调更好，你也会想办法弄地暖，如果你有能力的话。你没能力，没有经济能力，那么你至少在家里烧个火炉吧。

<span id="p-13-049" class="reading-anchor"></span>

总而言之，要想各种办法。哪里是需要先去学各种办法，然后才对父母有深爱？阳明说：「须是有个深爱做根，便自然如此。」

### 从恋人之间的愉色婉容，回到孝亲之心

**回看 28:12—31:06**

<span id="p-13-050" class="reading-anchor"></span>

你谈恋爱的时候怎么谈的？你爱着你的恋人了吧，是不是深爱啊？所以你跟他打交道了吧，你怎么打交道的？怎么谈恋爱的？和颜悦色，必有愉色，必有婉容啊。你好几天没见到他，今天终于见到了，脸上的喜悦溢于言表。

<span id="p-13-051" class="reading-anchor"></span>

你的内心的喜悦溢于言表呢。你会板着脸谈恋爱吗？怎么样？不可能的。你是情不自禁的，愉色婉容嘛。我们能对父母这样吗？这就是阳明要问的。哪有在父母身上研究出一个孝的理的？孝之理是天理，在心里。心啊，是情感、深爱。

<span id="p-13-052" class="reading-anchor"></span>

我不是再度强调情理吗？这是情的条理，情之理。这样就把心即理三个字讲得很清楚了。所以我这里设了一个标题嘛，理是什么？心之功夫啊。你从本心出发、从心体出发，做事情了。这一做，理就来了。不同的事，不同的理。其实都来自心。

<span id="p-13-053" class="reading-anchor"></span>

所以理不是认识的对象，是心的功夫。心的功夫就是在实践中的功夫来了嘛，然后这件事做好了，不就理的呈现了吗？理不就是通过心之功夫出来了吗？哪有预先等待我们去认识的？

<span id="p-13-054" class="reading-anchor"></span>

你要治民，要担当起对一方人民生活的责任。前提是什么？前提是你深爱着百姓。

如邓小平说他自己：「我是中国人民的儿子。」听说过吧？既然是儿子，就孝养父母，有那份深爱做根。我倒想问一问：邓小平是不是到大学学过政治学？得了博士学位没有？这样就明白了。

## 本讲总结｜整理附录

徐爱的两次追问，使讨论从「天下是否另有许多理」推进到「是否仍要学习具体做法」。阳明的回答并未取消做事的讲究，而是反复追问：讲求这些做法的根本在哪里？

正文从诚孝之心讲到温清定省，再以树根与枝叶、深爱与愉色婉容说明先后关系。结尾回到治民：本讲把心即理理解为本心在事情中的展开，而非先获得一套独立于心的道理。
