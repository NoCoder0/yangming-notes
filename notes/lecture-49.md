# 第49讲 勿在容貌上用功，勿在做事上轻忽

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—07:59

**阅读导引｜整理附录**　本讲以两类弟子作对照：一类过分矜持，一类全不检束。阳明对两边都作提醒，课堂再由长者交往、酒店礼仪和艺术家形象，说明外在举止与真诚之心不能分作两件事。

## 一分钟速读｜整理附录

1. 专在容貌上用功，可能无暇照管心。
2. 全不检束则把心与事割裂。
3. 语言与举止都在传达情感。
4. 合适的标准是心的真诚，不是僵硬形式或放任散漫。
5. 课堂保留酒店和艺术家的例子，以及对个性的最后限定。

## 容貌与中心的照管

**回看 00:00—01:50**

<span id="p-49-001" class="reading-anchor"></span>

好，我们接着讲养心的功夫。勿在容貌上用功，勿在做事上轻忽。我们看《黄直录》第十一节。这一段对话蛮有意思。那一天，在阳明先生周围，「门人在座」，就他的弟子。有的弟子的样子是怎样的呢？「有动止甚矜持者」，有这样的人，他一动、言行举止什么，矜持得很。

<span id="p-49-002" class="reading-anchor"></span>

阳明说：「人若矜持太过，终是有弊。」有弊端、有毛病。弟子不免要问：「矜持太过，如何有弊？」

阳明回答：「人只有许多精神。」人哪里有那么多精神？「若专在容貌上用功，则于中心照管不及者多矣。」

<span id="p-49-003" class="reading-anchor"></span>

就是我们把精力用到什么？自己的外貌上了。我们的言谈举止的那个样子要矜持，要怎么样，可以矜持，但不能太过。太过的毛病是什么？你就没心思照料自己的心了，照管我们的心所起的念，这才是重要的事。

## 又分心与事为二矣

**回看 01:50—06:01**

<span id="p-49-004" class="reading-anchor"></span>

那么倒过来的情况也有，在容貌上毫不在意，那叫直率。「有太直率者」，阳明也批评。对太直率者，就是什么样子、举止的仪态都不管的人，阳明说什么？比方说「如今讲此学」，我们在讲心学。既然是讲心学，有人认为只是照管我们的心嘛，我们的外貌、举止言行的样子，不要在乎，不就是心学吗？

<span id="p-49-005" class="reading-anchor"></span>

只管好这个心才是最根本的嘛。阳明说，如果是这样想，我们在讲心学，「却外面全不检束」，对自己的样子、形象毫不检束，检查、束缚，要有所束缚，全没有。这其实是什么？把心与事分为两件了。

<span id="p-49-006" class="reading-anchor"></span>

既然我们照管我们的心。养的是心，养的是心。然后我们待人接物、打交道，是不是也有个样子嘛？这个样子如果是跟心分开来的，又错了呀。为什么有时候我们待人要恭恭敬敬呢？这不是外在的礼仪呀，它是我们心之所在嘛。

<span id="p-49-007" class="reading-anchor"></span>

你说我的样子可以随便，放荡不羁，不修边幅。有时候边幅还得修一修，表示对别人的尊重，发自内心真诚的尊重，不希望人家看得不舒服。

所以不能把待人接物的样子与心分成两件事。心上去了，自然合适。

<span id="p-49-008" class="reading-anchor"></span>

而不是不管外在形象，不是不管的。但外在形象为什么要合适呢？是我们的心到了，心到这件事上了，我们该怎么打交道，跟别人。你遇到一个长者，年轻的人要恭敬，因为你内心是尊重他的。长者坐在面前跟你聊天，你翘着二郎腿，在晃着，不好吧。

<span id="p-49-009" class="reading-anchor"></span>

人与人交往，不光是语言，还有举止，都在传达情感，都在传达情感。所以怎么拿捏？太过矜持不对，全不检束也不对。

如何拿捏？心与事一致。待人接物是事情，心上去了，事情就做得合适，包括形象、言谈举止的样子，都合适。

<span id="p-49-010" class="reading-anchor"></span>

这也是我们得关注的。按阳明的意思，它分散了我们的精力。我们本要全心全意把这事做好的，然后心不去照料，照料自己的外貌，那叫矜持太过。要合适，这个讨论也不是多余的。我觉得生活中你会遇到各色人等。有的人西服革履，那是一本正经的那个样子，你跟他打交道呢，也觉得不得不有所疏离，因为不够亲切了。有这种人吗？有。

## 酒店的例子

**回看 06:01—07:59**

<span id="p-49-011" class="reading-anchor"></span>

当然现在有些商业需要，某些岗位上的人就必须这样弄着。你看他也是商业上的需要，这种商业需要就是一种表面的效应而已，效应而已。当然也没办法了，你到酒店里去了，有礼仪小姐来了，这全是形式。这是一个我们这个文明的一种虚假处。

<span id="p-49-012" class="reading-anchor"></span>

在阳明看来嘛，这个酒店用心要用在什么地方？把酒店办好，不是光摆个样子。现在一进去，「欢迎光临」，一起叫，我就很讨厌。这也没办法。但是呢，你也有一些基本的礼节要有，不能散漫，放荡不羁，那也不行。合适与否的标准，就在我们的心的真诚这件事情上。

<span id="p-49-013" class="reading-anchor"></span>

那么艺术家例外，披着长发。不修边幅。我们看，哦，艺术家来了，然后我们倒起了敬重之心，这是例外。王阳明有时候也很赞赏狂者。狂狷之人，「狂者有进取，狷者有所不为」。总而言之，他对过分拘谨是不喜欢的，过分矜持是他很讨厌的。

<span id="p-49-014" class="reading-anchor"></span>

阳明本人有这方面的心性，一辈子都没有扔掉过，就是张扬个性，但也不要有意张扬。好，就到这里。

## 本讲总结｜整理附录

先批评矜持太过，再批评过于直率，目的不是取一个表面折中，而是回到心与事的一致。长者面前的姿态，是课堂说明真诚如何体现在举止中的具体例子。

酒店的形式礼仪与艺术家不修边幅的讨论，使这一问题不被简化成统一的外貌要求。结尾仍保留张扬个性、但不要有意张扬的双重提醒。
