## 四句教概括了什么

**回看 00:00—00:44**

<span id="p-11-001" class="reading-anchor"></span>

按冯友兰先生的说法，《大学问》是阳明整个体系的全貌，而四句教是这全貌的概括。概括为四句话，又是对致良知的说明，而致良知是阳明心学的结论。好，我们把四句写在黑板上，然后一句一句来看。先来看第一句。

## 无善无恶心之体

**回看 00:44—03:50**

<span id="p-11-002" class="reading-anchor"></span>

「无善无恶心之体。」阳明在另一处有这样的话：「人心本体原是明莹无滞的。」这个「心之体」，就是人心的本体。它本是光明的，明莹无滞。这就很像什么？禅宗所言：「自性本自清净。」

<span id="p-11-003" class="reading-anchor"></span>

「人心本体原是明莹无滞的，原是个未发之中。」未发之中，就是心体，就是心之本体。

「未发之中」，这句话来自哪里？《中庸》。《中庸》第一段有这样的话：「喜怒哀乐之未发，谓之中。」就是没发出来的时候。接着说「发而皆中节」，「节」就是节拍的「节」。

<span id="p-11-004" class="reading-anchor"></span>

喜怒哀乐发出来了，情感发出来了。在什么情况下发出来？遇到事情了，跟人打交道了，自然发出来。如果发得合适呢？叫「发而皆中节，谓之和」，和谐的「和」。

「中也者，天下之大本」，这个「中」，就是未发之中。天地本无心，人为天地立心，叫天下之大本。

<span id="p-11-005" class="reading-anchor"></span>

「和也者」，就发而皆中节的话，那叫和。「和也者，天下之达道」，整个社会生活成了天道的体现。然后，「致中和」，如果我们达到了中和，「天地位焉，万物育焉」。这个位就是地位的位字，位置的位。天在上，地在下，乾坤没有颠倒。

<span id="p-11-006" class="reading-anchor"></span>

那叫「天地位焉」。「万物育焉」，这个育就是养育的育，也就是万事万物都生机勃勃。这是儒家理想中的人类社会，就是中和。中，人的仁心之本体。所以阳明说，仁心本体原是明莹无碍，原是个未发之中。

<span id="p-11-007" class="reading-anchor"></span>

这就是在说「无善无恶心之体」。它本来就是非常明净的，本就是明莹。

## 有善有恶意之动

**回看 03:50—04:31**

<span id="p-11-008" class="reading-anchor"></span>

第二句来了：「有善有恶意之动。」意怎么会动？刚才说了，遇到事情了。遇事，意之所在便是那个物。这个「物」就是事，格物的「物」就是事。于是意念起来了，这意念发动了，有善恶的区分。这善恶的区分，谁来发现？良知。

## 知善知恶是良知

**回看 04:31—07:01**

<span id="p-11-009" class="reading-anchor"></span>

第三句来了：「知善知恶是良知。」为什么良知能知善恶呢？真诚恻怛地求生，真诚恻怛地求爱。这就是良知与天理的统一。

「良知自有不容于自昧者也。」良知是无法自己欺瞒的。你一时欺瞒它，它总在。

<span id="p-11-010" class="reading-anchor"></span>

欺瞒良知的结果是什么？自欺其良知的结果是什么？心不安。注意这一点。这叫良知的呼声。这个说法好，良知是有声音的。良知的呼声起来了。它不是理论，不是概念，不是逻辑，它就起来了。良知的呼声你压不住的，各位，每个人都一样。

<span id="p-11-011" class="reading-anchor"></span>

就像我们先前举过例子，儿女把父母告到法庭上去了。为了那个财产的争夺，或者分配的不公，儿女可能胜诉吧？儿女是胜诉方，父母是败诉方。胜诉方会有幸福感吗？从此绝了父母养育之恩情了，他会不安，一定不安。不安就是欺瞒良知的结果嘛，谁也帮不了他了。

<span id="p-11-012" class="reading-anchor"></span>

兄弟姐妹诉讼于法庭，无论谁胜诉，谁都没有幸福感。从此断了手足之情，自己对自己终于交代不过去，这叫不安。良知就是这么起作用的。它「自有不容自昧者也」，其实不容我们欺瞒它。

<span id="p-11-013" class="reading-anchor"></span>

这叫知善知恶是良知。这个知不是逻辑的知、概念的知，不是逻辑判断，它是生命情感的本真的判断。这就是第三句话吧，知善知恶是良知。

## 为善去恶是格物

**回看 07:01—08:26**

<span id="p-11-014" class="reading-anchor"></span>

然后做事情了。因为遇到了事，才会有意之动。那么你去做事，这做事就是为善去恶，这叫把事情做对了。格物就是正事，把事情做对了。

把事情做对了，叫什么？良知在你做的事情中呈现了。这就是致良知。

<span id="p-11-015" class="reading-anchor"></span>

所以冯友兰先生说对了。这四句教是什么？是《大学问》所展现的心学体系全貌的概括。概括为四句话，又是对致良知的说明。

良知本有，何须致也？为什么要致？因为「有善有恶意之动」，要让良知到达。致良知是阳明心学最后的结论。

<span id="p-11-016" class="reading-anchor"></span>

明明德不是在家里明，一个人关起来，苦思冥想地明。不，明明德就在亲民的实践中，参与体察人民生活，要做多少事，遇到多少事。所以阳明晚年特别强调一句话，「于事上磨练」。

## 在事上磨练什么

**回看 08:26—11:03**

<span id="p-11-017" class="reading-anchor"></span>

磨练什么？中国人比较能同意「于事上磨练」这样的话。中国人主张实践：在实践中才长本事。这叫于事上磨练，容易这么理解，就是在做事情当中出真知、长本事。

中国人愿意接受，我们这个民族是重实干的：空谈误国，实干兴邦。所以，在做事情中磨练自己的本事、才能。

<span id="p-11-018" class="reading-anchor"></span>

理解错了。这个于事上磨练，不是磨练我们做事的能力。磨练什么？磨练我们的心。我们人生在世做事，本事永远不够，经验永远不够丰富，知识永远不完备，本事总有欠缺。各位同意吗？

<span id="p-11-019" class="reading-anchor"></span>

我们先主席毛泽东也说，一个成功的将领，一般来说，打五次仗，赢三次，输两次，也是成功。百战百胜的将军没有的，林彪也输过。哪有本事完备了的人啊？不可能的。所以不要误解了这句话，不是磨练本事，本事永远不够。你只要做事，本事总会来。

<span id="p-11-020" class="reading-anchor"></span>

这叫闻见之知，总会有。但是人心有另外一个方面，叫德性之知。磨练的是我们的心。我们在做任何事情的时候，能否让良知呈现？这是要磨练的。这个磨练是难之又难的事情，所以叫磨练。

我们做事情的时候，心起了念，这念每每就有偏离处，偏离心之本体。你能发现它，把它去掉。这件事情怎么才叫做成功呢？做一件事情的时候，有多少周遭干扰的因素，来引起你念头的变化。

### 社区小店与进货的差价

**回看 11:03—13:25**

<span id="p-11-021" class="reading-anchor"></span>

比方说，我们说件很小的事。假如你居住在某一个社区，这个社区开发、建成以后，周围缺少买生活日常用品的店。你发现了，开个烟杂店或者小超市。这个初衷倒是蛮好：为居民服务，你也借此谋生，有什么不可以呢？

<span id="p-11-022" class="reading-anchor"></span>

事情开始做了。做着做着，你就越来越了解市场，了解价格的变动。你又想到这是投资，要取得更大的利润，这种念头都来了。

假如你的供应商跟你讲：「我现在供应你同样的商品，在你的店里卖，现在我把它价格降低了。」你很高兴。商业的利润就来自价格差：进货的价格和出货的价格有一个差，这个差越大越好。

<span id="p-11-023" class="reading-anchor"></span>

这叫干扰因素来了，于是你动了心。不能动心。不要忘记，你这家店就是为社区居民服务的。你在此担当一份责任，要让社区的居民买到货真价实的东西。

所以，对你来说，进货的降价绝不能成为一种诱惑。你仍然要严格地做什么？控制质量。要搞清楚；没有搞清楚的情况下，你不能进他的货。这就是致良知，在磨练你的心。

<span id="p-11-024" class="reading-anchor"></span>

因为利益，利润的诱惑，更高的利润的诱惑，就可能让你的良知被遮蔽。始终不能被遮蔽，这是一种考验、磨练。不要担心自己做事情本事不够大，能力不够强，永远不够大，永远不够强。

### 宁王举兵与良知的力量

**回看 13:25—15:32**

<span id="p-11-025" class="reading-anchor"></span>

宁王朱宸濠举兵叛乱，十万大军攻城破池，直指京城。王阳明知道这件事了。他当时手下有哪些兵？区区一万乌合之众，本是去剿匪的。中途听到这个消息，扭转头来，跟宁王干起来了。以区区一万乌合之众，跟宁王十万大军战斗。

<span id="p-11-026" class="reading-anchor"></span>

这种勇气从何而来？他把自己准备充分了吗？他用各种军事学理论把自己武装好了，十拿九稳地干掉宁王吗？没这个条件。必须干。

这叫于事上磨练，良知告诉他必须干。因为这时候的皇帝还没有成为一个应当被推翻的皇帝，还没到天命转移的时候。如此发动叛乱，置人民于水火之中，所以阳明一定要干。胜利了！

<span id="p-11-027" class="reading-anchor"></span>

在中国军事的历史上，又创造了一例以小胜多的辉煌战例。我们不用害怕自己知识不够，本事不够，经验不够，都不够，永远不够。该干嘛干嘛。于事上磨练，磨练我们心灵的力量。这心灵的力量就是良知的力量，良知的力量，这是真正的力量，没有别的算力量的。这就是四句教。

## 进入良知实学

**回看 15:32—16:51**

<span id="p-11-028" class="reading-anchor"></span>

我们了解了《大学问》的思想内容，了解了四句教是《大学问》思想内容的概括，是对致良知的说明。我们就终于明白，进入阳明心学是什么？进入良知实学。

实学，换句话说，不是空论，而是在你的生命情感的实践中。这叫于事上磨练。

<span id="p-11-029" class="reading-anchor"></span>

阳明心学是一个养心的功夫体系。存养、扩充我们的心，让我们的心灵有力量。

头脑和心有什么区别？头脑里活动的是概念、判断、推理，心里活动的是生命情感。这生命情感才是我们的力量。当人生遇到挫折和困境的时候，被考验的绝不是我们头脑的知识、智力的水平。被考验的是什么？心灵的力量。

## 本讲总结｜整理附录

本讲先从《中庸》的中和解释心体，再沿「遇事—意动—知善恶—为善去恶」展开四句教。良知并非等到事情结束才作评价，而在做事中面临遮蔽与考验。

后半讲把这个功夫放到具体处境：商店经营者不能因进货降价而忘记质量责任，阳明面对叛乱则不能等知识、本领全部完备才行动。结尾由此落到良知实学和养心功夫。
