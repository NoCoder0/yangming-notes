# 第31讲 用功不离闻见

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—05:31

**阅读导引｜整理附录**　本讲围绕陈九川「用功收心时，是否应当不闻不见」的疑问展开。先分清闻见与被闻见牵走，再讨论静坐者不问儿子读书的掌故，最后回到心无内外、用功就在日常事情中。

## 一分钟速读｜整理附录

1. 收心不等于把自己变成槁木死灰、耳聋目盲。
2. 声色与处境仍在，功夫在于虽闻见而不随之流去。
3. 课堂借于相离相、于境离境说明不为外境所染。
4. 不问隔壁儿子的勤惰，被用来讨论静坐是否离开了生活责任。
5. 心无内外，养心的功夫要在所做的事情上用。

## 用功不离闻见

**回看 00:00—03:05**

<span id="p-31-001" class="reading-anchor"></span>

现在来看养心的功夫。我们说到第十六条，也就是《陈九川录》第三节。这里的用功，指的是下养心的功夫。

九川又问：「用功收心时，有声、色在前。」有事物的样子，我们也听到了声音。

「如常闻见」，闻声见色，「恐不是专一」了。

<span id="p-31-002" class="reading-anchor"></span>

是不是这么理解：当我们用功，把心收敛起来，周遭的一切都应当不闻不见才好；若还是有闻见，就没有达到专一？这是陈九川的疑问。

阳明回答：「如何欲不闻见呢？除是槁木死灰。」除非把自己弄成槁木死灰，身如槁木，心如死灰，或者耳聋目盲。

<span id="p-31-003" class="reading-anchor"></span>

我们活在这世界上，身如木，心如死灰，耳朵聋了，眼睛看不到东西，除非是这样了。这不是用功啊。所以用功是要有闻见的，「只是虽闻见而不流去便是」。不跟着闻到的、见到的走，这也就是禅宗所说的不为外境所染。

<span id="p-31-004" class="reading-anchor"></span>

外境一直在变化，叫迁流。不跟着外境迁流，叫不迁。「不迁名常」，这是《涅槃经》中的话。或者用禅宗的语言，那叫于相离相、于境离境。相总有，境总有。于相，就是承认相，但是心不跟相走；于境，就是承认境，心不跟境走，叫离境。

<span id="p-31-005" class="reading-anchor"></span>

什么叫用功？这才叫功夫。不是耳聋目盲，周遭的一切都不闻不见，这叫用功？不。

## 儿子隔壁读书的掌故

**回看 03:05—05:31**

<span id="p-31-006" class="reading-anchor"></span>

陈九川就提起一个掌故了。说以前有人静坐，下静坐的功夫，「其子隔壁读书」，他的儿子在隔壁正读书，「不知其勤惰」。也不知道自己这个儿子，读书是勤奋的，还是懒惰的。有人静坐就不管，不管儿子怎么读书，我自己静坐。

<span id="p-31-007" class="reading-anchor"></span>

「程子称其甚敬。」这里的程子指程颐。程颐说此人甚敬，似乎是在表扬他。

陈九川问：「何如？」

阳明说：「伊川恐亦是讥他。」程颐说这个人静坐甚敬，恐怕是在讥讽他、嘲笑他。

<span id="p-31-008" class="reading-anchor"></span>

因为他想，程颐总不会这么看待用功吧？我们用功就与世隔绝吗？与世隔绝了才叫真用功了吗？错了。用功就在日常生活中用。你主静固然是主静了，静固然是静了，但这个静不是指什么都不看、什么都不闻，而是指不跟着闻见走，不被闻见所牵累。

闻见当然还在闻见。

<span id="p-31-009" class="reading-anchor"></span>

如果儿子在隔壁读书懒惰了，你得去提醒他。你说一概不闻不问，这不是用功。这一条很简单，概括为用功不离闻见。我们下养心的功夫，并不是下一种与世隔绝的功夫，把这个心孤立起来，这搞错了。

<span id="p-31-010" class="reading-anchor"></span>

心无内外。心不是在你的腔内，我们的心都在我们所做的事情上。好，今天就讲到这里。

## 本讲总结｜整理附录

陈九川把专一与不闻不见联系起来，阳明则把问题转向心会不会被闻见牵走。外境一直变化，不意味着必须取消外境或取消知觉。

后半的掌故把这一区别放到父子生活中。静坐与过问儿子读书并非必然冲突，收心也不是把心孤立起来；结尾因此再次强调心无内外。
