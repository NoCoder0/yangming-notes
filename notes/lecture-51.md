# 第51讲 真情非相

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—07:56

**阅读导引｜整理附录**　本讲从与自己父母相处的难处，转入阳明对儒家、佛家「着相」的不同判断。父子、君臣、夫妇关系中的仁、义、别，最后接回青春期的争执和父慈子孝。

## 一分钟速读｜整理附录

1. 父母有各自的特点与缺点，不必先设想理想父母。
2. 真情与相要分清，关系中的麻烦不是关系的全部。
3. 阳明以逃避父子、君臣、夫妇关系解释他所批评的着相。
4. 仁、义、别分别说明三种关系的价值。
5. 结尾以青春期冲突再次说明父子关系的根本。

## 和自己的父母打交道

**回看 00:00—01:28**

<span id="p-51-001" class="reading-anchor"></span>

好，各位，我们继续课程的第四部分，第35条。比如你跟父母打交道，你的父母跟别人家的父母就不一样。有他们的特点，有他们不同的社会地位、性格和文化修养。

<span id="p-51-002" class="reading-anchor"></span>

不要想着，应该有一个理想的父母才好：有钱，有地位，有知识，有能力，对你还特别慈爱。这一切就是你心中期待的理想父母，但是你找不到，天下没有这个事。就像人各有所长一样，为人父母，有时候也是做不到父母该做的事。

<span id="p-51-003" class="reading-anchor"></span>

那么你难过，在跟父母打交道的时候，也要记住，他们的个性、他们的特点、他们的缺点，都绝不妨碍你跟父母之间的那份父子之情、母子之情、父女之情、母女之情。不要着相，那就这个意思，用禅宗的话。

## 真情非相

**回看 01:28—06:36**

<span id="p-51-004" class="reading-anchor"></span>

王阳明曾经在另外一个地方批评那些出家人：你们出家人自以为不着相，说我们儒家着了相，搞错了。我们找到这一部分来念一下。这里有一个关于佛家修行与儒家天下关怀，这两种人生目标的差别的讨论。找到下卷《黄直录》第十五节。

<span id="p-51-005" class="reading-anchor"></span>

「先生尝言」，这先生指的就是阳明，曾经说过，「佛氏不着相，其实着了相」。佛氏是指什么？那些要出家的人啊。那么他们出了家，他们认为自己不着相，阳明说其实着了相的。「吾儒着相」，是天下人经常讲的。你看儒家多么入世啊，不出世的，入世，所以最着相，有种种的关怀。

牵挂，放心不下，不都着了相吗？说我们儒家着相，「其实不着相」。

<span id="p-51-006" class="reading-anchor"></span>

好，这黄直就拿阳明说过的这段话，又来请教阳明了。你这些话的意思究竟是什么？请问。阳明做了说明，「佛怕父子累」。要出家修行的人害怕什么？怕的是父子关系，也是很麻烦的吧，在父子关系当中我们很累的啊。

<span id="p-51-007" class="reading-anchor"></span>

于是什么？「逃了父子」。你不是出家了吗？你出家了，遁入空门了，然后就不再承担对家族的责任吧，叫逃了父子吧。「怕君臣累，却逃了君臣」。你既然是出家人，你就不再关心国家的政治了吧，国家的事跟你没关，你出家了，这叫什么？

怕君臣累，逃了君臣。

<span id="p-51-008" class="reading-anchor"></span>

遁入空门的人是不是不结婚了？怕的是夫妇关系，也很累的，多麻烦，婚姻是很苦恼的事，所以逃吧。「怕夫妇累，却逃了夫妇」。都是为个君臣、父子、夫妇着了相，便须逃避。归根到底，出家遁入空门是着相的。

<span id="p-51-009" class="reading-anchor"></span>

至于我们儒家，按照儒家的原则，「如吾儒，有个父子，还他以仁」——仁义道德的「仁」字。「有个君臣」，有君臣关系，「还他以义」，天下大义。「有个夫妇，还他以别」。

<span id="p-51-010" class="reading-anchor"></span>

夫妇有别，丈夫与妻子的关系是什么？各自做好自己能做好的、但对方做不了的事。女人能做的事，男人做不了。女人怀孕生个孩子，男人试试看你行吗？不行。男人有比较强大的体魄啊，可以在外面干，为家庭觅食啊，在这方面男人每每比女人强啊，能够遮风挡雨的。

这就是夫妇的区分吧。

<span id="p-51-011" class="reading-anchor"></span>

这种区分不是相互歧视。各自发挥自己作为丈夫或妻子能做的事情，互相帮助，共命运，这叫夫妻关系的一份价值。儒家用一个字来表达：别。

<span id="p-51-012" class="reading-anchor"></span>

父子关系的真实的价值是仁，君臣关系真实的价值是义，夫妇关系真实的价值是别，所以我们不逃避。我们在父子关系当中还他一个仁字嘛，在君臣关系当中还他一个义字嘛，在夫妇关系当中还他一个别字嘛，「何曾着了父子、君臣、夫妇的相」？

## 青春期的争执

**回看 06:36—07:56**

<span id="p-51-013" class="reading-anchor"></span>

这话有道理。人与人的关系，其实都是情感的关系。每一种关系里边有本真的情感，叫真情。真情非相。人跟人打交道总有麻烦，那么你害怕这麻烦，你就逃，这叫着了相。父子关系会有麻烦。这个很自然。

<span id="p-51-014" class="reading-anchor"></span>

父亲对儿子有期待，儿子长到一定的青春期了，对父亲的这个权威要挑战，叫叛逆期。不都是麻烦吗？麻烦归麻烦，专主一天理，还他一个什么？仁。在父子关系当中会有许多的对抗或烦恼，总不能忘了父子关系的根本是一个仁字。父亲在根本上对孩子是慈爱的，父慈，子就应当孝吧。

叫父慈子孝，这是最根本的。好，就到这里。
