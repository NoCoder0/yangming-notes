# 第18讲 主一之功

王德峰课程｜阳明心学与当代人生｜第一人称口述整理稿｜原视频 00:00—09:53

**阅读导引｜整理附录**　本讲开始读《陆澄录》，讨论主一之功。陆澄把主一理解为专心读书或接客，阳明用好色、好货反问。接着从家庭、社会及企业关系说明「专主一个天理」，结尾谈企业与员工之间的守信。

## 一分钟速读｜整理附录

1. 主一不是把注意力全部放在某一件事上。
2. 专心好色、好货也可以很集中，却仍可能是逐物。
3. 主一所专主的是天理；千事万事都要成为天理的呈现。
4. 在人生不同阶段和不同关系中，这个功夫始终贯通。
5. 企业与员工的例子讨论正当谋生、贡献、薪酬和信任；06:42附近一句否定词仍待核。

## 《陆澄录》里的主一之功

**回看 00:00—02:59**

<span id="p-18-001" class="reading-anchor"></span>

现在接着讲第四点：主一之功。这是《传习录》上卷第二录《陆澄录》一开头就讲的。《陆澄录》也分了节，共七十四节，我们找到第一节。陆澄是阳明的弟子，字原静。

<span id="p-18-002" class="reading-anchor"></span>

《传习录》中卷收录的八封书信，其中有两封是王阳明回复陆原静，也就是陆澄的来信。他跟随阳明下心学功夫，非常认真，记下许多阳明的话，所以我们有了《陆澄录》。

<span id="p-18-003" class="reading-anchor"></span>

看第一节，他就问阳明主一之功。心学讲主一，该怎么理解？陆澄问：

> 主一之功，如读书，则一心在读书上；接客，则一心在接客上，可以为主一乎？

「接客」就是接待客人。如果我们能这样做，是不是就叫主一的功夫？

<span id="p-18-004" class="reading-anchor"></span>

阳明的回答非常有意思：照你这个说法，我来说下去。

「好色则一心在好色上；好货，则一心在好货上，可以为主一乎？」「好货」就是喜欢财产、财物。如果这也叫主一，其实就是逐物、向外驰求了。向外驰求、逐物，怎么叫主一呢？

<span id="p-18-005" class="reading-anchor"></span>

所以不能把主一之功误解了，误解为做事情专心致志。你好货，想要发财，一心在发财上。你接待客人，专心致志地接待客人。这都是搞错了。心学讲的主一之功不是专心致志做好一件事的意思，而是指什么？做任何事情，「主一是专主一个天理」。专主一天理，这才叫主一。

## 千事万事只是一件事

**回看 02:59—07:02**

<span id="p-18-006" class="reading-anchor"></span>

那么这究竟是什么意思？人生在世要做那么多不同的事情。读书是一件事情，接客是一件事情，好色也是事，好货也是事。种种的事，千事万事，在阳明心学主一之功来说，其实只是一件事。千事万事其实就一件事，让你所做的事情成为天理的呈现，这叫主一。

<span id="p-18-007" class="reading-anchor"></span>

活在世上，是不是有种种不同的事情？在家里跟父母、丈夫或妻子、孩子打交道，种种家务事；到单位工作，完成岗位职责，要跟同事打交道；在学校做老师，面对学生，做学生则面对老师。

是不是这些不同的事情，构成了日常生活？

<span id="p-18-008" class="reading-anchor"></span>

种种不同的事，都别忘了一条，让所有不同的事由你做来，成了天理的呈现。就永远不要忘了这一条，在任何不同的事情当中，都下主一的功夫，总是只有一个念头，让这件事情做成了。什么叫做成了？让它成为天理的呈现。

<span id="p-18-009" class="reading-anchor"></span>

在家庭中，遇到了种种事情。家庭成员之间的关系也是事。此事彼事，都专主一个天理。天理在哪里？天理就是情感的本真。这里讲的真情、真心，就是天理。

<span id="p-18-010" class="reading-anchor"></span>

在社会生活当中，种种的事情都是跟人打交道的。那么跟人打交道，就不要忘了专主一天理，去实现那件事情本有的价值。这事情本有的价值，就是这个事情本身的天理。这叫主一之功。所以千事万事只是一事，就一件事。让所有的事情都实现，都成为天理的呈现。这是心学的功夫，用一个词来表达，叫主一。

<span id="p-18-011" class="reading-anchor"></span>

人活在世界上，事情实在多，方方面面。不同人生阶段又有不同的事：小时候的事情，长大、毕业、工作，又是新阶段，新阶段面临新事情。

人生就这样一个阶段一个阶段地走。贯穿整个人生，在不同阶段的种种事情中，也还只是一个事情：专主一个天理。

<span id="p-18-012" class="reading-anchor"></span>

人就是这样在精神上成长。一开始要明白主一这个道理：此事彼事做得怎么样，成败得失别去想〔[听辨待核1](#editorial-note-1)〕。让所做的任何事情，都有天理的呈现，完成事情本来的价值。这个事情本来的价值，也就是人与人关系本来的价值。

## 到企业工作与守信

**回看 07:02—09:53**

<span id="p-18-013" class="reading-anchor"></span>

比方说你在企业中工作，你作为一个企业的员工，那么你是企业的工作者，现在叫打工人。打工人也是件事。第一，你谋生吧，你必须谋生。谋生当然要正当谋生，正当谋生不能欺蒙拐骗。

<span id="p-18-014" class="reading-anchor"></span>

在正当谋生中，你为企业作出贡献，企业保证你每个月的月薪，这就是天理。

如果觉得企业不合适，某种人生理想无法实现，可以跳槽。跳槽归跳槽，要找到更好、更能发挥特长的另一个单位，这也是对的。

<span id="p-18-015" class="reading-anchor"></span>

但始终要在企业与员工的关系中，实现它本有的那份天理。因为企业为社会而存在，是社会生活中的一个角色；社会生活需要它，企业才能存在。

社会需要企业干什么？你是其中一员，把这件事干好。不用一一展开，还是那件事、那个功夫：主一。所以做任何事情，因为主一的缘故，总是心安理得。

<span id="p-18-016" class="reading-anchor"></span>

儒家做了一些比较基本的概括，五种人与人的基本关系叫五伦。每一种关系都有一份价值被表达了。君臣有义，父子有仁，夫妇有别，长幼有序，朋友有信，信用的「信」。

<span id="p-18-017" class="reading-anchor"></span>

比如在我看来，到单位工作是谋生，企业与作为员工的我们，其实是朋友关系，就是一个「信」字。到企业工作一段时间，叫朋友一场。企业跟我就是朋友，大家守一个信字，便是对的，便是天理。

<span id="p-18-018" class="reading-anchor"></span>

现在中国企业管理有毛病。互不信任。员工与企业之间互不信任的情况蛮多的，然后又设置种种规则来防范员工，有吗？有，这就很不好。

## 本讲总结｜整理附录

陆澄从专心做事提问，阳明的反问让「专心」与「专主天理」分开。之后列举不同生活场景，并不是另立许多功夫，而是说明同一个主一之功怎样贯穿种种事情。

结尾把问题放到企业与员工之间：正当谋生、为企业作贡献、按约取得薪酬以及双方守信，都是本讲说明这种关系价值的具体内容。
