**阅读导引｜整理附录**　两首偈不是孤立的名句。本节保留弘忍出题、神秀的犹疑、惠能作偈以及弘忍擦偈的全过程，再逐步辨析心、尘与空的关系。

## 一分钟速读｜整理附录

1. 弘忍的考问以出离生死为目标，不能只理解为寺院接班人的竞争。
2. 神秀的偈有修行价值，却被指出未见本性；公开劝诵与私下开示有不同对象。
3. 下下人和上上人的讨论，聚焦能否不住社会身份之相，并连到乔布斯的演讲。
4. 烦恼由心而生，因此把心与尘当作两个现成对象，再问谁来擦灰，会遇到问题。
5. 惠能的偈破了心、尘二相；弘忍仍说“亦未见性”，引出不应停在空上的下一步。

## 两首偈与弘忍的考问

**回看 02:20:01—02:34:37**

<span id="p-tan-01-243" class="reading-anchor"></span>

就是两个偈句的对比。我们大概都听说过，弘忍法师有一天把他的弟子叫到边上来，因为真觉得自己年龄大了。弘忍法师也知道自己什么时候走嘛，要解决衣钵传承的问题，把众弟子叫到身边，跟他们讲话。

<span id="p-tan-01-244" class="reading-anchor"></span>

第一句话就说，“世人生死事大”。这话我们能够同意的，对世界上每一个人来说，没有什么事情比生死的事情更大的。“世人生死事大。”汝等跟我学佛，终日只求福田。种福田，求福报。“终日只求福田，不求出离生死之苦海。”

<span id="p-tan-01-245" class="reading-anchor"></span>

“自性若迷”，就自己的本性看不到，每个人自己的本性就是佛性。“自性若迷，福何可救？”你得了福报也救不了你。福报救得了你吗？这什么意思？要救什么？什么叫得了救？就消了罪业。消了罪业，我们才能什么？出离生死苦海，摆脱了生死轮回。

<span id="p-tan-01-246" class="reading-anchor"></span>

你得了福报，罪业还在。罪业还在的证明是什么？我们不是又被抛到这娑婆世界来了嘛。消了罪业，就出离生死了。这是佛教修行的根本目标，就是达于涅槃境界，不生不死了。可信与否？我们后面再说。这个课程一定要提到这个问题，如何是涅槃，是吧？就如何是不生不死。

<span id="p-tan-01-247" class="reading-anchor"></span>

看来弘忍法师对他的弟子们都不满意，是吧？这话是说得很清楚，非常直截了当的批评了，是吧？你们就是来求福报的，对吧？遗忘了佛教修行的根本目标。“汝等各作一偈”，拿来给我看。什么叫偈？一般都是四句话构成的，可以算作是佛教中的一种诗歌的题材，叫偈。大多数偈都是四句，就四句话，短短的。你们都作偈给我看。谁作得好，谁得衣钵。那不就是考试来了吗？

<span id="p-tan-01-248" class="reading-anchor"></span>

众弟子领受了这个任务，各自回到寮房里。大家都在想，作还是不作？结果得出共同的结论，不用作。为什么？眼看我们的师父最喜欢的那个弟子，叫神秀，让他做了首座弟子了，那叫教授师。就等于我们今天讲的助教，弘忍法师的助教。神秀当时叫教授师，还没达到我们今天讲的教授的地位，实际上就相当于什么？助教。

<span id="p-tan-01-249" class="reading-anchor"></span>

众弟子想：“弘忍法师最喜欢神秀，我们也去作偈句，等于跟神秀竞争。将来他得了衣钵，没我们好果子吃。”所以大家想好了，不作。神秀也回到寮房里，他也得想，作还是不作？如果不作的话，衣钵肯定得不到。如果作了，师父见到了说作得不好，还不光得不到衣钵，还在众弟子面前失去了威望，还做什么首座呢？所以他睡在床上辗转反侧，不能入眠，进退两难嘛。

<span id="p-tan-01-250" class="reading-anchor"></span>

后来他终于想出一个妙计，好主意，作一定要作，但不要署名。所以他在半夜三更的时分，在南廊的墙上写了他的偈句了。不署名地写在墙上。这个偈句很出名，这样四句话，“身是菩提树，心如明镜台。时时勤拂拭，勿使惹尘埃。”

<span id="p-tan-01-251" class="reading-anchor"></span>

我们不要把我们的身体仅仅看成是色身、肉身，其实它还是法身，就像菩提树一般。因为释迦牟尼在菩提树下悟道嘛，所以菩提树就成了觉悟的象征。第二句，“心如明镜台”。我们的心本来很干净，如明镜一般，但是来到这世界上，就难免沾染上灰尘。

<span id="p-tan-01-252" class="reading-anchor"></span>

所以怎么办呢？要不断地擦，不断地擦灰。“时时勤拂拭，勿使惹尘埃。”神秀用这四句话表达了他对佛教修行的理解。什么叫修行呢？就是不断地保持我们的心与外尘的隔绝状态。内心与外尘，外面的尘，要隔绝。不断擦就是隔绝嘛。

<span id="p-tan-01-253" class="reading-anchor"></span>

写在墙上了，后来弘忍也看到了。弘忍法师见到墙上有神秀的偈句了。本来这个墙上是要画画的，请来一个画匠，要把这个禅宗传承的血脉图，如何从初祖达摩一直传到五祖弘忍，这个要画出来。那个画家也来了。弘忍法师见到这个偈句就跟画家讲了，不用画了，不必画了。“凡所有相，皆是虚妄”，还不如留着这个偈句。

<span id="p-tan-01-254" class="reading-anchor"></span>

好，众弟子都在边上，弘忍法师就跟众弟子们讲，你们从今天起，每天都要念诵这个偈句。念诵这个偈句，对大家有大利益，就对你们修行有很大的好处。那么弟子们每天都诵这个神秀的偈句了。

<span id="p-tan-01-255" class="reading-anchor"></span>

弘忍法师一见到这首偈句，虽然他没署名，已经知道一定是神秀作的。师父对自己的弟子所达到的境界了然于胸，所以私下里就把神秀召到方丈室来了。跟他讲，这偈句是不是你作的？神秀说，是我作的。弘忍法师底下就不客气了，“汝作此偈，未见本性，只在门外，未入门内。”对他的偈句不满意。

<span id="p-tan-01-256" class="reading-anchor"></span>

这样看来，是不是弘忍法师有一点表里不一了？弘忍对弟子们讲：“每天要诵这个偈句，对你们修行有很大的帮助，有大利益。”私下里又这么严厉地批评了神秀，这怎么理解？神秀的偈句的境界一定比其他弟子要高。他没认为修行是求福报的，不是种福田求福报的事。

<span id="p-tan-01-257" class="reading-anchor"></span>

修行是很认真的一件事，解决我们心的问题。心沾染了灰尘，心就有问题，所以要擦干净。这个尘，就妄念来说，确实要去掉。我们本来干净的心，蒙上了种种的妄念，拿尘来比喻妄念，没错的。

<span id="p-tan-01-258" class="reading-anchor"></span>

所以神秀境界要比其他弟子高，至少提醒其他弟子们，你们别把修行搞错了。要像神秀那样嘛，如神秀的偈句所表达的境界，解决的是心的问题嘛。禅宗不就是直指人心嘛。这一点，弘忍法师说的是大实话，佛家不打妄语。但是就传承衣钵而言，以后能够传心法这件事情而言，你还没到。所以私下里就把他找来跟他讲了。

<span id="p-tan-01-259" class="reading-anchor"></span>

底下的话我们一起看。“汝作此偈，未见本性，只到门外，未入门内。”“如此见解”，按照你这个偈句所表达的见解，“觅无上菩提，了不可得”，达到真正的觉悟不可能。“无上菩提，须得言下识自本心，见自本性。不生不灭，于一切时中，念念自见。”

<span id="p-tan-01-260" class="reading-anchor"></span>

你种种的念起来，你要从自己的念中看到自己起念的那个本心。念是不是从心中起来的？我们通常讲的叫起心动念。你通过你的念来回看自己的心。“万法无滞”，这样才能够畅通无阻了。“一真一切真，万境自如如。”

<span id="p-tan-01-261" class="reading-anchor"></span>

这一真是什么真？把这一真拿掉，一切都假。换句话说，一假一切假。这是佛家对世界的认识，世间万物其实都是假象。在什么情况它们不假了呢？你的心真了，那么一切都真了。这个一真就是后面讲，“如如之心，即是真实”。世界上唯有一样东西是真的，就是我们的如如之心。

<span id="p-tan-01-262" class="reading-anchor"></span>

如如之心相对于如意之心而言。我们平时的心就是求如意。我们要趋利避害，趋得避失，趋贵避贱，趋富避贫，趋乐避苦，趋顺避逆，种种的趋避。若趋而得之，避而免之，如意。若趋而不得，避而未免，不如意。

<span id="p-tan-01-263" class="reading-anchor"></span>

这就是平时我们的这个心。这个心是在外面的，不断地趋避。其实它是假的，不是本心。假如我们改变了呢？变如意之心为如如之心呢？那叫一真来了。然后我们还在这世界上吧，遇到万事万物吧。因为你的心是如如之心，万事万物的真实的意义才向你呈现。否则都是假的。

<span id="p-tan-01-264" class="reading-anchor"></span>

什么叫好事？什么叫坏事？完全从你的如意之心出发的。这不是事情本来的意义，不是事情本来的存在。所以这番话说得非常清晰，非常的清楚。那叫谆谆教导。

<span id="p-tan-01-265" class="reading-anchor"></span>

如果你有这样的见解，“若如是见，即是无上菩提之自性也”。你觉悟到自己的佛性了。“汝且去一两日思惟”，你再去想，“更作一偈，将来吾看。汝偈若入得门，付汝衣法。”你现在还在门外呢，你再去作一首，再作一首。如果我一看，入门了，那衣钵就能传给你了嘛。

<span id="p-tan-01-266" class="reading-anchor"></span>

后来神秀作不成，再作一次再也作不出来了。《坛经》这么描述的，“又经数日，作偈不成，心中恍惚，神思不安，犹如梦中，行坐不乐”。

## “下下人有上上智”

**回看 02:34:37—02:42:01**

<span id="p-tan-01-267" class="reading-anchor"></span>

现在要提到惠能了。有一个小沙弥童子经过那个舂米房，叫碓坊。经过的时候，他口中念念有词，唱诵的就是神秀的偈。惠能听了，一听便知道“此偈未见本性”。《行由品》里，虽然惠能没有得到弘忍法师的指点吧，叫“未蒙教授，早识大意”。因为他已经开悟了，虽然没了悟。

<span id="p-tan-01-268" class="reading-anchor"></span>

所以惠能就跟童子讲：“你在诵什么偈呢？”童子回答：“尔这獦獠不知。”你看，又贬低地称他獦獠。你是不懂的。大师也就是弘忍法师，我们的师父讲“世人生死事大”，他为了传衣法，叫弟子都作偈。等于考试，是吧？谁能悟大意的话，就作第六祖了。

<span id="p-tan-01-269" class="reading-anchor"></span>

童子的意思是：“我们念诵的偈，就是神秀上座，也就是首座，在南廊壁上书写的无相偈。”看来大家都已经知道这个偈是神秀作的了，因为弘忍法师把它说清楚了，一定是你作的嘛。

<span id="p-tan-01-270" class="reading-anchor"></span>

惠能就讲，在这里一直舂米吧，踏碓舂米八个多月，从来未到方丈室那里去，你能不能带我到偈前礼拜？好，来到了神秀的偈句这个墙面前，惠能说，我不识字，能不能请你为我念一下，完整地念一遍。

<span id="p-tan-01-271" class="reading-anchor"></span>

当时有一个江州别驾在场，他叫张日用，便高声朗读。惠能听完了，说：“我也作一首，希望你张日用帮我书在墙上。”别驾说了一句话，“汝亦作偈，其事希有。”你这獦獠还作什么偈呢？这也太奇怪了。瞧不起他吧？惠能马上来了。

<span id="p-tan-01-272" class="reading-anchor"></span>

惠能对张别驾说：“欲学无上菩提，不得轻于初学”。切不可轻视初学者。“下下人有上上智，上上人有没意智。若轻人，即有无量无边的罪。”上纲上线了。后来这句话就很出名了，“下下人有上上智，上上人有没意智”。我们就在这里略微停留一下，讨论一下。

<span id="p-tan-01-273" class="reading-anchor"></span>

什么叫下下人？生活在社会最底层的人。什么叫上上人？社会地位很高的人。惠能说，下下人有上上智，上上人却可能是没意智。这个“没意智”作何解？“没”实际上可以理解为沉陷，沉没在意欲之中。我们为了实现我们的意欲，我们会想许多办法，那叫机智，那叫机巧。所以这叫什么？没意智。没意智与上上智对比了。

<span id="p-tan-01-274" class="reading-anchor"></span>

我们恐怕会觉得奇怪，一个人有没有智慧，难道跟他的社会地位有关联吗？难道上上人就不能有上上智吗？这两者之间好像没有必然关系吧。社会地位高了，倒在没意智里了。社会地位很低，倒可能有上上智了。这两者之间怎么会有必然关联呢？我初时也想不明白，总觉得奇怪。后来才明白禅宗的原则，为什么修行的人一定要不住相？这是一种功夫啊。

<span id="p-tan-01-275" class="reading-anchor"></span>

下下人为什么可能有上上智？因为下下人没办法住相，是吧？他已经是社会最底层的人了，每天还把自己拿出来跟别人比，每一次比较，别人都比他高。他活还是不活？他只能不比了，每天投入于生活本身之中。上有老母需要奉养，下有孩子嗷嗷待哺，边上有妻子或丈夫需要互相帮助。每天都投入到生活的真谛中去了。他没办法住相。

<span id="p-tan-01-276" class="reading-anchor"></span>

想一想，假如我们自己是下下人，怎么跟别人比呢？别人高，自己低，永远这样。算了，不比。叫没办法住相。

<span id="p-tan-01-277" class="reading-anchor"></span>

至于上上人，叫他不住相，难了。你社会地位很高，市长、省长，以前比方说古代的官，封疆大吏，什么地方的巡抚。地位高啊，见到你的人一律地拍你马屁的，都围着你转，天天向你鞠躬。以前还不是鞠躬，要拜的。每天都在提醒你地位高。

<span id="p-tan-01-278" class="reading-anchor"></span>

昨天晚上你不是读过《金刚经》的吗？想好了，不住相的呀。你早晨起来，出了门，见到你的人一律向你鞠躬。你一出行，警车开道，前呼后拥，昨天的《金刚经》又白读了。所以上上人不住相太难。我终于才明白惠能这句话有道理。

## 乔布斯演讲里的话

**回看 02:42:01—02:46:34**

<span id="p-tan-01-279" class="reading-anchor"></span>

我又想起了乔布斯。我这个人向来孤陋寡闻，不看报，不听新闻。等乔布斯去世了，我才知道苹果是他开创的。当时上海电视台就播了一个节目，来追忆乔布斯，他生前的许多活动的镜头，做了一个专题。那一天我恰好看电视了。

<span id="p-tan-01-280" class="reading-anchor"></span>

正看到那样一个镜头，乔布斯在斯坦福大学毕业典礼上演讲。我们都知道斯坦福大学在美国是一流的大学。在斯坦福毕业的学生都志存高远，认为自己一旦进入美国社会，很快就应当成为社会精英。电视画面上面是演讲的镜头，下面打字幕，突然一句字幕打出来，“Stay foolish. Stay hungry.”

<span id="p-tan-01-281" class="reading-anchor"></span>

我看到这一句出现，第一反应就是：此人学过佛。什么叫 foolish？愚笨。什么叫 hungry？饥饿。它前面用了一个动词 stay，S-T-A-Y，stay，是吧？后面是形容词 foolish，还有一个形容词叫 hungry。那么这个动词就应当理解为连系动词了吧，跟后面的形容词构成了系表结构。那么这个 stay 该怎么翻译呢？保持。整个这句话译成汉语，就是保持愚笨，保持饥饿。

<span id="p-tan-01-282" class="reading-anchor"></span>

我看到这句话的第一反应是：此人学过佛。为什么有这个反应？一个既笨又饿的人，就下下人吧？乔布斯在告诫斯坦福大学的毕业生们，你们将来进入美国社会，有可能真成为社会精英。即使你们成了社会精英，你们也永远不要忘记自己是下下人。你们永远记得自己是下下人，不要自以为是。

<span id="p-tan-01-283" class="reading-anchor"></span>

自以为是，你就把自己看成上上人，远离智慧了。不管你们将来有多大的财富，也不管将来你们做出怎样了不起的功绩出来，成为某个领域里的 leader，别忘了，自己始终是愚笨的，始终是饥饿的。这不就是禅宗的思想吗？

<span id="p-tan-01-284" class="reading-anchor"></span>

后来有人告诉我，他是学过佛，是吧？只有学过佛的人才会说出这样的话嘛。所以《坛经》里边这句话，惠能这句话，非常重要。我一直认为我们中国年轻人应该早一点读《坛经》，最好在中学时代就读过。它是一个基本的人生态度，在社会上跟人打交道。

<span id="p-tan-01-285" class="reading-anchor"></span>

后来这个禅宗的思想就演化为后来有过的那句话，“卑贱者最聪明，高贵者最愚蠢”。这样的话有来历，就禅宗思想呀。现在我们还听说过这样的话吗？没有了。我们从小学到初中到高中，一直在攀比呀，是吧？比家庭出身，家里的富贵程度，身上穿的衣服、鞋子，是不是顶级的品牌，都在比。最好自己是上上人的家里出来的，民工子弟学校就不能去了，要到贵族学校呢。这问题很大。

## 弘忍为什么擦掉惠能的偈

**回看 02:46:34—02:49:56**

<span id="p-tan-01-286" class="reading-anchor"></span>

好，我们看下去。因为他说了这些上纲上线的话，所以张别驾肯定心里慌的，你知道吧？张别驾说：“这样，你先别说让我帮你书写，你先念出来。”好，惠能就念了他的偈句了，也是四句。我们看，每一句都是对原来神秀的偈句的针锋相对。

<span id="p-tan-01-287" class="reading-anchor"></span>

神秀的偈句说“身是菩提树”，惠能偏来一句“菩提本无树”。神秀的偈句说“心如明镜台”，惠能偏来一句“明镜亦非台”。神秀说“时时勤拂拭，勿使惹尘埃”，惠能偏来一句“本来无一物，何处惹尘埃”。这念出来之后，他们觉得真是了不起了，果然境界高了。

<span id="p-tan-01-288" class="reading-anchor"></span>

但是还不愿意帮他写呢。张日用和惠能讲：“你要我帮你把它也写在墙上，有条件。”什么条件？“万一你将来得了衣钵，必须先来度我啊。”这应该没问题的，这是自然没问题的。张日用帮助惠能，把惠能的偈句也写在了墙上。

<span id="p-tan-01-289" class="reading-anchor"></span>

后来弘忍法师来了，见到了惠能的偈句了。惠能这首偈句是公开的嘛，就是我惠能念的，然后他们写的。弘忍法师脱下自己一只鞋子，把墙上惠能的偈句给擦了。然后说了一句话，“亦未见性”。也还没有见到自己的本性。

<span id="p-tan-01-290" class="reading-anchor"></span>

这句话等于否定了惠能的偈句了。有原因，当然是继续要保护惠能的意思，是吧？众弟子们一听，原来我们的师父也并不欣赏惠能的偈句，惠能就是继续安全的。有这层意思在。但是弘忍法师毕竟是说了那句话，“亦未见性”。这不光是保护惠能，也是说了实话。佛家不打妄语，弘忍法师不会说妄语的。这句话是真话。为什么呢？

<span id="p-tan-01-291" class="reading-anchor"></span>

惠能的偈句境界要比神秀的偈句高，各位都感受到了。那么不免要追问一下，高在哪里呢？换一句话说，既然这个偈句是针锋相对，针对神秀的，等于这个问题在问什么呢？问的是神秀偈句的毛病在哪里，是不是这件事啊？因为他都是针对性的嘛。所以说惠能的偈境界高，就要先指出神秀偈句的毛病。那么神秀的偈句的毛病在哪里？要直截了当地说。

## 尘是从哪里来的

**回看 02:49:56—02:56:36**

<span id="p-tan-01-292" class="reading-anchor"></span>

佛家讲的尘是指什么？烦恼。对，不是客观的外部世界自身存在的尘，尘就是烦恼的意思嘛。这个世界到处都是烦恼，这个世界叫尘世。我们做事情叫劳，劳动的劳，是吧？人活着就得做事，很正常，这叫劳。但如果我们是带着烦恼做事，这叫尘劳。世界叫尘世，做事情每每带着烦恼，那叫尘劳。

<span id="p-tan-01-293" class="reading-anchor"></span>

人与人的关系叫缘，是吧？如果在这种关系中我们在烦恼，换言之，这个关系是带给我们烦恼的，那叫什么？尘缘。尘就是烦恼。在烦恼中的人与人的关系就叫尘缘。你实在受不了了嘛，斩断尘缘。斩断尘缘嘛，出家了呀，遁入空门了呀。所以佛家讲的尘就这个意思，就是烦恼的意思。

<span id="p-tan-01-294" class="reading-anchor"></span>

请问烦恼从哪里来的？不是这个世界把烦恼降临到你头上了，烦恼本从心里生出来。为什么烦恼？烦恼就是不如意，对吧？烦恼是不是就是不如意呀？人才会生烦恼呢，因为人有求如意的心嘛。动物就没烦恼。动物有时候会焦虑的，肚子饿了，找不到食物，急了。但这不叫烦恼。

<span id="p-tan-01-295" class="reading-anchor"></span>

动物也会生病。如果病得比较严重，它感受到肉体的痛苦，我们听到了鸟兽的哀鸣，但这不是烦恼。人在正常情况下，三样东西都具备的。第一，食物。大多数人在大多数正常情况下有食物吧，我们没饿着吧。大多数人在大多数正常情况下，安全没有受到威胁。大多数人在大多数正常情况下，尚未生病，是吧？

<span id="p-tan-01-296" class="reading-anchor"></span>

那么我们在大多数情况下同时拥有三样东西，一，食物。二，安全。三，健康。但我们烦恼不断。若动物呢？它只要有这三样东西，每天都很开心的。你们家里若养一条狗，就是你们的宠物了。你们每天都保证了它三样东西吧，一样都不缺。食物、安全、健康。生病了，送到宠物医院解决问题。

<span id="p-tan-01-297" class="reading-anchor"></span>

那么你家里那个狗，每天尾巴就摇得很欢，是不是啊？No problem，没问题。人会这样吗？不会的。如果会就好了。如果我会，就希望大家豢养我，每天保证我三样东西，我天天开心得很。我知道我做不到。食物、安全、健康样样都有，三样都有，烦恼不断。

<span id="p-tan-01-298" class="reading-anchor"></span>

这烦恼就是人心生出来的嘛。人心能生烦恼，可就表明这个心很伟大的。为什么呢？什么叫不如意啊？因为你筹划了未来，结果落空了，不就不如意了嘛？人心能筹划未来呢。这不就是人心的伟大吗？说得再好听一点，叫提出生命理想，足够伟大了。了不起，人心之所以了不起，因为它生烦恼。

<span id="p-tan-01-299" class="reading-anchor"></span>

动物不筹划未来。当然有人说也筹划，比方说蚂蚁会把过冬的粮食准备好，是吧？这个就是本能，它没有更多的想法。世世代代的工蜂只制造同样的蜂房。人类创造东西，不断地在演进，要更好，再更好。今天是高楼大厦，以前是洞穴，是吧？一步步来，草木屋到城堡，到洋房，样样来。这就是人，了不起，因为筹划更好的未来。人心有无限的一面，人心的伟大。

<span id="p-tan-01-300" class="reading-anchor"></span>

所以惠能后来讲的话真是有意思得很。他说什么叫烦恼？烦恼就是菩提，烦恼即菩提。因为你烦恼了，你才会有觉悟，菩提就是觉悟的意思。我们的人心能觉悟，伟大。前提就是有烦恼，伟大。人心了不起，叫提出生命理想，并为实现生命理想而从事生命奋斗，结果落空了。落空不就烦恼呀？

<span id="p-tan-01-301" class="reading-anchor"></span>

一个个人，一个民族，在一定的时候都会烦恼。不用拒绝烦恼，从你心里生出来。你把这个生烦恼的心变一变嘛，它就生出智慧了。那就是心的觉悟。这就是禅宗修行指向的根本目标，转识成智。这个识什么意思呢？业识，由业力造成的心识叫业识，这是佛教用语。我们在业识中嘛，烦恼不断的嘛，能不能转一转呢？转业识为智慧。这一个转，就是觉悟的意思。

## 谁来擦灰

**回看 02:56:36—03:02:02**

<span id="p-tan-01-302" class="reading-anchor"></span>

看到了惠能这个偈句，他这个偈句本身在说什么？在指出神秀偈句的毛病。烦恼本从你心里生出来，你如何隔开它们？然后惠能说，第一，不要说我们本来干净的心是现成存在的，要把这个相无掉。你也不能说这个世界本来就有客观的尘，客观的烦恼，也无掉它。两面都无了，那叫什么？“本来无一物，何处惹尘埃。”

<span id="p-tan-01-303" class="reading-anchor"></span>

心与尘，就是心与烦恼，是吧？叫心与尘二元对立。尘本从心中生，如何擦？这是一个问题。假如真能擦，擦者是谁？又是一个问题。心生出烦恼了，然后去擦吧。这个擦者是谁呢？很有意思，不免要想一想这问题。

<span id="p-tan-01-304" class="reading-anchor"></span>

擦者有两种情况。一种是高于心和尘之上的，这恰如基督教了。这高于心与尘之上的、能把心与尘分割开来的，上帝。在基督教里那个尘就是罪，心就是灵魂。灵魂有罪，是吧？这个有罪的灵魂自己没办法解决问题的，只有通过对上帝的信仰、对基督教教义的尊奉，才能赎这个罪。显然，擦灰者就是上帝了。基督教就是救赎宗教。

<span id="p-tan-01-305" class="reading-anchor"></span>

我们这个民族没有神，没有宗教意义上的神，除非你把道教也看成宗教。当然现在都说道教是宗教，其实不是。道教是把活人变成不死的活人，那叫神仙，长生不老。而真正的宗教是说，世界万物有一个最高的主宰。这个最高的主宰者是一种人格的存在，当然他叫神了。中国没有这样的宗教的。

<span id="p-tan-01-306" class="reading-anchor"></span>

世界万物的最高的主宰，中国人确认有，那叫天道，但它不是人格神。这一点要加以说明。当然现在用词都混乱，把道教以为成宗教了，因为一个“教”字在。佛教也以为是宗教了，一个“教”字在。其实都不是宗教，因为是无神论的。若把道教所说的仙也当成是西方宗教的神，那就搞错了。用语的混乱，导致思想的混乱。

<span id="p-tan-01-307" class="reading-anchor"></span>

当然，神秀不可能推出一个高于心、尘之上的上帝来擦灰。他不可能，因为他是中国人，他不会这么想。如果神秀这样继续想下去，他可能在中国成为宗教创立者。

<span id="p-tan-01-308" class="reading-anchor"></span>

所以神秀偈句的毛病两条。第一，心与尘二元对立。第二，擦灰，他没说明谁来擦灰。因为在二元对立当中，他说修行就是保持这双方的隔绝状态。对立双方要隔开。那么惠能怎么来指出他的毛病呢？用了“无”的观念。

<span id="p-tan-01-309" class="reading-anchor"></span>

你说“身是菩提树”，“菩提本无树”嘛。树这是种相，因为释迦牟尼在菩提树下悟道了嘛，菩提树就成为一种象征了，也就是佛家讲的相了。要把这相无掉，“菩提本无树”，不就相无掉了嘛？“明镜亦非台”，我们干净的心说成像明镜一般，也是相了，也把它无掉。结果都没有吧，“本来无一物”。既把觉悟的那个相，菩提相，无掉，也把心这个相，心也成了相，也把它无了。“本来无一物，何处惹尘埃。”无的境界来了，无相。

## 从非相到非非相

**回看 03:02:02—03:06:30**

<span id="p-tan-01-310" class="reading-anchor"></span>

但无相只是第一步，或者用《金刚经》的话来说，叫非相。非相第一步，第二步叫非非相。那么惠能先达到非相，但没有非非相。非非相叫想入非非，他终于没想入非非。当然现在“想入非非”成了成语了，另外一层意思，你想多了，想得过分了。这本来的意思是佛家的《金刚经》的意思。想入非非，想入非非可了不起了，了不得。惠能尚未达到。

<span id="p-tan-01-311" class="reading-anchor"></span>

所以整个偈句就是无相的意思。他只是达到了第一步，领会空，然后又停留在空里。所以弘忍法师用鞋子把墙上惠能的偈句擦掉，这个动作就是禅意。何必擦呢？照常理而言，大家都知道这是惠能的偈句吧，这是一。其二，已经写在墙上，就这么四句，大家都记住了吧，一望而知嘛。你擦掉等于没意思嘛，大家不都读到了吗？都看到了吗？你擦它干嘛呢？

<span id="p-tan-01-312" class="reading-anchor"></span>

他还是擦了。这个动作的禅意，周围的人谁领会了，不知道。但我领会了。什么意思呢？你停留在空了，我对你这空再空一次，叫空空。对空再空一次，那叫空空。

<span id="p-tan-01-313" class="reading-anchor"></span>

你知道“应无所住”，惠能不是当初听到“应无所住而生其心”，心即开悟嘛？他实际上只悟了什么？前面四个字，“应无所住”。“而生其心”，他还不明白呢。无所住就是，一，不要住心。二，不要住尘，是吧？这都无掉了嘛。无了之后不是没东西来，有东西来了，“而生其心”，那叫如如之心起来。这后面四个字，他尚不明白。

<span id="p-tan-01-314" class="reading-anchor"></span>

弘忍法师一眼就看到了。好是很好了，亦未见性。惠能的偈比神秀的偈前进了一步。如果说神秀的偈句只到门外，未入门内，惠能的偈句是已经站在门槛上了，他只要再跨一步就进去了。这就是惠能偈句跟神秀偈句的高低，一个只在门外，一个在门槛上。

<span id="p-tan-01-315" class="reading-anchor"></span>

弘忍法师立刻明白，时机成熟了。这个东山寺里一定会有人悟的，这个人呢，一定是惠能，就差一步嘛。对此要预做准备。怎么预做准备的？后面就知道了。对于弘忍法师来说，时机成熟了，这件事情是弘忍法师满心欢喜的事。

<span id="p-tan-01-316" class="reading-anchor"></span>

为什么一个禅宗祖师还继续活在这世界上？只有一个原因，要有传承的人。用我们今天的话来说，要有接班人。现在看来找到了。找到了，弘忍法师就能放心了。这对于弘忍法师的使命来说，多么重大的事啊。你看那么多弟子，几百个人啊，这个东禅寺大得很，几百个弟子没有一个行。总算有一个神秀了，又差一口气。然后叫他再作一首，又作不出来了。看到惠能的了，门槛上。

## 本节总结｜整理附录

课程先完整讲述作偈的情境：众弟子的退让、神秀的顾虑、题偈、弘忍公开与私下的回应，以及惠能怎样借人读写。这些细节使“下下人有上上智”不只是口号，而进入社会地位与住相的实际关系。

论证随后追问尘从哪里来、擦者又是谁，指出心尘二元对立的困难。惠能以“无”破相，却还要越过停留在空的一步。因此擦掉偈句既有保护惠能的作用，也被课堂解释为对空再空；这一解释保留原有的推论口吻。
