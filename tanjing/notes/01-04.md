## 惠能是怎样走上学佛道路的

**回看 01:54:01—01:59:21**

<span id="p-tan-01-196" class="reading-anchor"></span>

惠能怎么会走上学佛修行的道路？《坛经》第一品讲得非常清楚。《六祖坛经》一共十品，第一品叫《行由品》。所谓行由，就是说明惠能如何学佛修行，如何得到了弘忍法师传给他的衣钵，成为第六祖。这件事的来龙去脉，都在《坛经》第一品当中做了说明。故事非常精彩。

<span id="p-tan-01-197" class="reading-anchor"></span>

说惠能有一天把他砍到的柴火卖到一个客店里，然后从客店里走出来，走到街上，就听到有人在街边上念经。有八个字飘到惠能耳朵边上，“应无所住而生其心”。惠能一听到这八个字，心即开悟。这是《坛经》中的原话。

<span id="p-tan-01-198" class="reading-anchor"></span>

当然，开悟不是了悟。不是说他彻底悟了，而是开了能够悟的那扇门，那叫开悟。惠能上前去问那个念经的人：“你在念什么经？”那个人说：“《金刚经》。”惠能又问：“谁让你念？”那个人就告诉惠能，当时叫蕲州，有一个县，黄梅县。黄梅县里有一座庙，东禅寺。东禅寺的方丈弘忍法师，这个人其实就是禅宗的第五祖。

<span id="p-tan-01-199" class="reading-anchor"></span>

那位客人说：“弘忍法师跟我讲过，佛经浩如烟海，读不胜读。其实我们只要读其中一部就够了，终身受用。这部经就是《金刚经》。我听了弘忍法师的话，所以我每天都要念诵《金刚经》。”

<span id="p-tan-01-200" class="reading-anchor"></span>

惠能听到这样的话，心下大喜，发了一个宏愿：“一定要找到弘忍法师，求他度我。”这就是立了一份学佛修佛的志向。后来在一个朋友的帮助下，这个朋友给了惠能十两银子。十两银子在当时是一笔巨款。惠能用这十两银子安顿好老母的生活，他就上路了。他在广东生活，所谓广东新州百姓。

<span id="p-tan-01-201" class="reading-anchor"></span>

从广东赶往湖北，一路上要寄宿在别人家里。有一次他寄宿在一个叫刘志略的家里。这刘志略家里有一个在家修行的姑妈，每天在家里念一部经，叫《涅槃经》。有一天就跟惠能聊天。她跟惠能讲：“这部《涅槃经》我不知道念过多少遍，大部分段落的含义我都能理解，只是其中有这么一段，直到今天我不知道它在说什么。你能不能给我讲解讲解？”

<span id="p-tan-01-202" class="reading-anchor"></span>

说着就把这部《涅槃经》交到惠能的手上。惠能立刻还给她，跟这位姑妈说，“字即不识，意即请问”。我字是不识的，但是你要问我经文的含义，可以问。

<span id="p-tan-01-203" class="reading-anchor"></span>

那姑妈大吃一惊。“字尚不识，何能会意？”她说了这句话，你字都不识，你怎么能领会经文的含义呢？惠能立刻回答她一句话，“诸佛妙理，非关文字”。佛教各种高妙的道理与文字无关。没想到他一说出这句话来，那姑妈言下大悟，非常激动。她跟惠能说：“你一句话点通了我，我现在明白这几年在干什么了。我是在《涅槃经》的文字中讨真理。如此讨法，真理是讨不到的。”

<span id="p-tan-01-204" class="reading-anchor"></span>

这时候的惠能尚未见到弘忍法师，但已经说得出这样的话了。这样的话的意思，其实我们今天都知道。其实就是禅宗的一条原则，破文字执。打破对文字概念的执着，真理不在文字概念中。

## 在东禅寺舂米

**回看 01:59:21—02:03:18**

<span id="p-tan-01-205" class="reading-anchor"></span>

惠能终于到了黄梅县东禅寺了，弘忍法师接见了他，劈头就是两个问题：“你从哪里来？你来求什么？”

<span id="p-tan-01-206" class="reading-anchor"></span>

惠能如实回答：“我从岭南那个地方来。”求什么呢？求作佛。弘忍法师就说了，“汝是獦獠人”。什么叫獦獠？中原一带的汉人瞧不起南方人，把他们看成是南蛮子，给他们一个贬低的称呼，叫獦獠。你是獦獠人，如何作得了佛？惠能当即回答：“人有南北之分，佛性本无南北。”

<span id="p-tan-01-207" class="reading-anchor"></span>

这句话一说出来，弘忍法师心里明白，此獦獠根性大利。根性也可以叫根器。佛教讲的根性或根器，我们现在基本不用这样的观念了。我们代之以智商。智商跟根性是两回事。一个人可能智商很高，根性暗钝。另有一个人智商可能并不高，却根性大利。

<span id="p-tan-01-208" class="reading-anchor"></span>

所谓根性、根器，就是慧根的意思，智慧的根。是拿树来比喻的。慧根深的人就像一棵树，它可以经得起各种气候、各种环境。冬天到来，它也枝叶凋零。春天一旦来了，它又枝叶繁盛起来。这是个比喻了。

<span id="p-tan-01-209" class="reading-anchor"></span>

弘忍法师心里明白了，此獦獠根性大利。这样的人，最适合把佛法传给他。但是弘忍法师没有流露出对惠能的喜爱。为什么？众弟子都在边上。当时黄梅县东禅寺有一个非常重要的问题，就是眼看弘忍法师年岁大了，将来他的衣钵会传给谁？谁会成为第六祖呢？

<span id="p-tan-01-210" class="reading-anchor"></span>

衣钵的传承是个继承权问题。当时是唐朝，朝廷支持佛教。一个寺院的方丈，同时一定是寺院地主，广有田产，所以衣钵的传承同时就是田产的继承。从此之后，丛林里就不清净了。

<span id="p-tan-01-211" class="reading-anchor"></span>

弘忍法师当然有很高的智慧。他这么跟惠能讲，我不收你作弟子，但我也不赶你走。你到舂米房里去舂米吧。叫他到舂米房去劳动，这其实是对惠能的保护。众弟子一看，我们的师父不怎么喜欢惠能，惠能就是安全的。

<span id="p-tan-01-212" class="reading-anchor"></span>

惠能也是心领神会，在舂米房里劳动了八个多月。弘忍法师也不去见他，他也不到弘忍法师的方丈室里去找弘忍。大家心领神会。

## 宿慧、知识与智慧

**回看 02:03:18—02:09:48**

<span id="p-tan-01-213" class="reading-anchor"></span>

我们讲到这里，不免就要想，一个文盲、不识字的惠能，怎么会说得出这样的话？比方说“诸佛妙理，非关文字”，比方说“人有南北之分，佛性本无南北”。惠能的智慧哪里来？肯定不是读书来吧。读书识字的人，知识会很多，但知识再多，也积累不出智慧的。

<span id="p-tan-01-214" class="reading-anchor"></span>

这一点让我们觉得奇怪、惊讶，但佛教自有说明。佛教认为，我们每个人活在这世界上，现实现在世，我们的智慧都来自前世。那叫宿慧。这个“宿”就是前世的意思，前世或者再前世。因为佛教有三世因果这个基本说法。

<span id="p-tan-01-215" class="reading-anchor"></span>

基本信念就是，我们并不是第一次来到这世界。我们先前来过多次，多次，甚至叫累世累劫。我们在前世、再前世都做过许多事。我们在前世做事也罢，我们在生活中也会长智慧。所以有两样东西是可以传到下一世的，这是佛教的说法。

<span id="p-tan-01-216" class="reading-anchor"></span>

第一个，我们所做的事情留下了业。事情早就结束，但是有东西留下来，这东西就是佛家的一个观念，叫业。业是流转的，它是种力量，叫业力。种种的业力合在一起，再度把我们抛到这世界上来，那叫现在世。我们在前世所长的智慧，也能传到下一世，所以这智慧叫宿慧。佛教的说法。

<span id="p-tan-01-217" class="reading-anchor"></span>

那么我们先且不管有没有三世因果，宿慧这个概念我认为仍然成立。就是什么？智慧在以往。这个“宿”未必一定要理解为前世、再前世，理解为以往、古代，这就对了。我们今天的人的智慧不是自己生出来，是对以往的智慧的传承。在这个意义上，宿慧这个概念就成立的。就像我们先前讲轴心时代，智慧在古代。

<span id="p-tan-01-218" class="reading-anchor"></span>

从《坛经·行由品》所说的惠能来历来看，很说明问题了。第一，惠能不会有多少知识，因为他不识字嘛。不识字的人当然不能读书，于是他拥有的恐怕只是狭隘的生活经验，并没有许多普遍性的知识。具有普遍性的知识，他没有，但这一点都不妨碍对人生真谛的领会。那叫智慧。所以智慧跟知识的区分，我们已经做了说明。

<span id="p-tan-01-219" class="reading-anchor"></span>

若一定要说智慧和知识的区分，可以这么说。知识是对周遭事物的认知，假如比较完整的、系统的，叫科学。但智慧是什么呀？智慧是人心对道的领会。人心对道的领会叫智慧。

<span id="p-tan-01-220" class="reading-anchor"></span>

哲学就是论道的学问。而古希腊有一个词，由两个词合起来做成了哲学这个词。一个希腊词叫 philo，还有一个希腊词叫 sophia。philo 加上 sophia，哲学这个词就来了。拉丁化之后，英语当中叫 philosophy，德语中是 Philosophie，都来源于希腊词。从这个词的构词法来看，什么叫哲学？爱智慧的学问，就很清楚了。

<span id="p-tan-01-221" class="reading-anchor"></span>

汉语中本没有“哲学”这个词，但向来有哲学，先秦时候就起步了。我们不称为哲学，称为什么？道学或道论，就是论道的学问。我们进入道学、道论，或用今天的话说，进入哲学，是什么？长智慧，因为去领会天道。

<span id="p-tan-01-222" class="reading-anchor"></span>

智慧是对天道的领会。知识是对事物的认知和事物之间因果关系的把握，所谓种种的规律。对规律的认识，那是知识。对天道的领会，那叫智慧。这就是做了一个非常重要的区分。不要把知识与智慧混为一谈。有知识未必有智慧，有智慧的人知识也未必多。惠能是典型的例子。

<span id="p-tan-01-223" class="reading-anchor"></span>

这样说来，智慧的神秘性来了，是吧？惠能能说出这样的话来，尚未见到弘忍法师，已经把禅宗的一条原则说了，叫破文字执。这是智慧。那么我们今天的人要长智慧，不可能自己生长，生长不出来，为什么？

## 为什么还要读古代的典籍

**回看 02:09:48—02:15:49**

<span id="p-tan-01-224" class="reading-anchor"></span>

想一想，在轴心时代，公元前五世纪，这四个民族，一个中华民族，一个古印度，一个古希腊，还有一个古代以色列，为什么出现那些哲人呢？其中有一个非常重要的原因，他们身处其中的那个文明还非常朴素。在朴素的文明中的人，才可能俯仰天地，领会天人之际。用一句简单的说法来说，叫开天眼了。

<span id="p-tan-01-225" class="reading-anchor"></span>

我们开不了天眼了。因为我们身处其中的这个当代文明，已经高度地复杂和精致化，充满种种知识和机巧。在如此复杂和精致的文明中生活的人，离开智慧最为遥远。所以我们若要有智慧的话，就只能是对古代智慧的传承。这一点就不用怀疑。

<span id="p-tan-01-226" class="reading-anchor"></span>

就像我们今天的中国人，又开始重返古代的哲学典籍了。许多人又去读儒家的《大学》《中庸》《论语》《孟子》，有的人去研究《易经》，有的人去读道家的经典，老子的《道德经》，还有《庄子》。也有人去读从印度传来的佛学的经典，比方说《金刚经》《心经》《楞严经》等等。

<span id="p-tan-01-227" class="reading-anchor"></span>

为什么在二十一世纪的中国人会这样做呢？道理很简单，智慧在古代。我们今天的人恐怕还能写一点哲学的文章或哲学的著作。写哲学文章，写哲学的专著，其实是为了传承。这叫“为往圣继绝学”，张载说的。勿令断绝。所以我们都是在做传承的工作。

<span id="p-tan-01-228" class="reading-anchor"></span>

一个民族如果有哲学，它的哲学史并不是一个思想进步的历史。其实都是在每一个时代，面对这个时代的挑战，重返古代的智慧。表现出似乎哲学在进步，其实只是在展开。

<span id="p-tan-01-229" class="reading-anchor"></span>

所以英国哲学家怀特海说那句话是对的。他说，什么是欧洲哲学史？整部欧洲哲学史无非是对柏拉图思想的一连串的脚注，所谓 footnote，脚注。你比方说到黑格尔那里了，德国古典哲学集大成者黑格尔。黑格尔的哲学著作，在他的基本思想的境界方面，没有超出柏拉图。柏拉图学说的近代形式就是黑格尔。

<span id="p-tan-01-230" class="reading-anchor"></span>

所以思想从来都是旧的。智慧在古代，在思想和智慧的领域当中，我们只能重返古代。所以我们今天会去读中国先秦时候的哲学典籍，就是这个缘故。

<span id="p-tan-01-231" class="reading-anchor"></span>

中央电视台首播《百家讲坛》，好多年、好多年前首播《百家讲坛》，来了于丹，讲中国先秦的哲学了。从《论语》一直讲到《庄子》。收视率如此之高，出乎我们意料。我们万万想不到，一个讲先秦哲学的学者也会成为明星啊。

<span id="p-tan-01-232" class="reading-anchor"></span>

这现象发人深省。它说明什么？说明我们这个民族终于认识到，科学不能解决一切问题，必须重返古代的思想和智慧。《百家讲坛》收视率如此之高，社会各个阶层都在收看这样的节目，这说明问题。

<span id="p-tan-01-233" class="reading-anchor"></span>

我们在改革开放最初阶段重视的全是科学。一开始重视自然科学，学好数理化，走遍天下都不怕。后来改革深入了，引发中国社会的转型。从计划经济体制转变为市场经济体制，引发整个中国社会的巨大的社会转型。

<span id="p-tan-01-234" class="reading-anchor"></span>

于是社会科学开始受到关注。社会科学当中的一门，叫经济学，成了当代的显学。社会科学还是科学。走到今天，我们终于认识到，无论是自然科学也好，社会科学也好，不可能解决我们中华民族对未来的选择这样一个命运般的抉择。科学帮不了我们。我们不能不重返轴心时代。今天我们再读《坛经》，也是这层意思。

## “教是先圣所传”

**回看 02:15:49—02:20:01**

<span id="p-tan-01-235" class="reading-anchor"></span>

惠能在《行由品》最后部分，《行由品》是他说的第一次法会，把自己的来龙去脉都讲一遍之后，他说了。我们把这个书打开来看，这是中华书局的版本。我们把这个本子翻到《行由品》的最后一段。说惠能开东山法会了。

<span id="p-tan-01-236" class="reading-anchor"></span>

他自己这么说，“惠能于东山得法”。东山是在黄梅县。现在他到了广东韶关开东山法会。他的法会仍然命名为东山法会，这是因为表达了他的传承，他从五祖那里传承。

<span id="p-tan-01-237" class="reading-anchor"></span>

“惠能于东山得法”，他自己说自己，“辛苦受尽，命似悬丝”，性命交关。“今日得与使君、官僚、僧尼、道俗同此一会，莫非累劫之缘。”我们都有缘，而且还是累世累劫的缘。

<span id="p-tan-01-238" class="reading-anchor"></span>

“亦是过去生中供养诸佛，同种善根。”前世、再前世种了善根的，“方始得闻如上顿教”。惠能从弘忍法师那里得了心法，主张的是顿悟，所以叫顿教。“方始得闻如上顿教、得法之因。”

<span id="p-tan-01-239" class="reading-anchor"></span>

底下一句话很重要，“教是先圣所传”，先前的贤圣所传的，“不是惠能自智”，就是惠能说：“不是我自己的智慧。”说得分明。“愿闻先圣教者”，你们在座的，如果想要闻这个先圣的教，“各令净心，闻了各自除疑”。如果真能进入智慧的境界，我们就和先代圣人没有差别。这叫智慧的传承。这就讲得清楚。

<span id="p-tan-01-240" class="reading-anchor"></span>

我们今天读《坛经》，就好像是跟着惠能一起去传什么？先圣的智慧。《坛经》固然是唐代的作品，是吧？但它的内容，它的智慧的境界，来自古代。就禅宗而言，要从灵山法会过来，一直到达摩，然后一代一代传。

<span id="p-tan-01-241" class="reading-anchor"></span>

在这一点上，惠能最后这段话也给我们信心了。我们虽然不是先圣、先前的贤圣，但我们若得了智慧，便跟先圣没有差别。

<span id="p-tan-01-242" class="reading-anchor"></span>

我们已经说明了惠能的来历。惠能就是个普通的体力劳动者，砍柴火、卖柴火为生。后来到了东禅寺，继续是普通劳动者，在舂米坊里舂米。弘忍法师没收他作弟子，所以他尚未剃度出家。当然，弘忍法师保护他，要等待时机。这时机后来就来了。

## 本节总结｜整理附录

这一节保留惠能求法的具体道路：闻经之后追问经名与来处，得到资助后安顿母亲，再进入黄梅的问答和劳作。课堂讲到不识字而能解经，以及弘忍为何让惠能舂米，重点都在辨别根器，而不是把知识多少当作智慧高低。

对宿慧的讨论先进入前世智慧与业力流转的宗教语境，然后转向如何在今天理解古代智慧。知识回答事实和因果，智慧则关乎人生与道的领会。现代知识增长之后为何仍需读古典，就在这一条思路中展开。
