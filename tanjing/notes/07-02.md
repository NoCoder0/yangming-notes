# 第7集 · 第2节 法海问即心即佛，定慧如何双修

王德峰课程｜《六祖坛经》与禅宗修行｜第一人称口述整理稿｜原视频 00:47:54—01:02:53

**阅读导引｜整理附录**　法海问“即心即佛”，回答没有先给名词下定义，而是指出前念、后念、成相与离相的功夫。手电筒和三问三反问，使问题回到自己的心。

## 一分钟速读｜整理附录

1. 法海的贡献包括记录《坛经》，所问“即心即佛”也直接关系禅宗根本。
2. “前念不生即心，后念不灭即佛”指向不追随过去的念，以及真如自性起念。
3. “成一切相即心，离一切相即佛”：心既成相，也能离相。
4. 贪生怕死被联系到对前念的留恋；歌名与刑罚的例子都服务于这个解释。
5. “即心名慧，即佛乃定”，定慧双修不是先后两件互相分离的事。

## 法海为什么列在第一

**回看 00:47:54—00:50:14**

<span id="p-tan-07-077" class="reading-anchor"></span>

第一个提到的，就是法海。这个《坛经》后来被整理、编撰。在编撰的时候，我相信编撰者是考虑过的，十二个机缘的前后顺序有它的道理。为什么把法海列为第一则机缘呢？我们知道法海的重要性。若无法海，我们读得到《坛经》吗？读不到。

<span id="p-tan-07-078" class="reading-anchor"></span>

法海自从追随惠能左右，惠能每一次说佛法，法海都作了记录。所以惠能在圆寂之前就跟法海讲，你要把你记录下来的、所有我说佛法的言论汇编成册，让它流布于世。法海做到了，所以要感谢法海。所以他的重要性，让他放在第一位。

<span id="p-tan-07-079" class="reading-anchor"></span>

还有一点，他问的内容也应当放在第一位。他问惠能什么问题？即心即佛。是不是也应该放在第一位？禅宗修行就是修心啊，禅宗又叫佛心宗，这个名称基本不用了。法海其实也是广东人，韶州曲江人。最初来参见祖师，便要提问，“即心即佛，愿垂指谕”。

<span id="p-tan-07-080" class="reading-anchor"></span>

修禅宗的人一定知道这四个字，也表明了这个法门是修心的法门。直指人心，见性成佛，不就即心即佛吗？如何理解，就这个意思了。如何理解，就变成问学问了。但惠能不是跟他讲学问的人吧。把即心即佛作为修行的功课来说，不是说心是什么、佛是什么，不这么说，那叫学术上的解释了。

## 前念不生即心，后念不灭即佛

**回看 00:50:14—00:57:01**

<span id="p-tan-07-081" class="reading-anchor"></span>

修行吧。“前念不生即心，后念不灭即佛。成一切相即心，离一切相即佛。”说得多清楚啊，你这么修吧。我们的心不断生念吧，生出来的念，让它过去，别跟着念走。换句话说，不要执念。你一旦不执念，你就在你本心中。然后后面再起的念，便是佛的念，真如自性起的念。

<span id="p-tan-07-082" class="reading-anchor"></span>

佛起念吗？佛一定起念，佛不起念怎么了得啊。但是他后念还能起，本心在，后念起的念就是佛，后念不灭即佛。禅是不是要离相啊，离相的境界吧。先要告诉你相哪里来的，“成一切相即心”。你明白啊，你不是修禅宗嘛，你法海，我告诉你，你要离开相，现在知道相就是你心造出来的。

<span id="p-tan-07-083" class="reading-anchor"></span>

成一切相，就是心。你能成相，也一定能离相，这是你的功夫。你成了相之后再离，那就是佛。惠能认为两句话够了。这两句话，特别是第一句话，第一句话前半段“前念不生即心”，后半段“后念不灭即佛”，是吧？非常巧妙，我心里想亏他怎么想得出来。

<span id="p-tan-07-084" class="reading-anchor"></span>

为什么？他把两个词语拆开了。“即心即佛”拆开了吧，“不生不灭”拆开了吧，明白这意思吧？拆开来重新组合。我们修佛是要达到不生不灭吧。达到不生不灭，是通过即心即佛来达到的吧，这是禅宗的路子嘛。那么不生不灭跟即心即佛关联一下，关联了吧。

<span id="p-tan-07-085" class="reading-anchor"></span>

什么不生了？前念不生了。什么不灭了？后念不灭了。前念只要不生，就是心，本心。后念只要不灭，你就是佛。大道理、根本道理，关系到一切佛教修行的目标，就是达到不生不灭的涅槃境界吧。

<span id="p-tan-07-086" class="reading-anchor"></span>

请问，我们为什么贪生怕死？我们贪的生是什么？我们活过了吧，在这世界上活过一段时间吧。我们贪的生就是什么？前念，种种的前念，明白这意思吧？你未生过，贪什么生啊？你生过了，生了，生了是不是有种种念？你经历了从孩提时代、童年、少年、青年、中年，你有那么多前念吧，这些前念就让你留恋这世界了吧。太深了。

<span id="p-tan-07-087" class="reading-anchor"></span>

为什么怕死啊？种种前念给你带来的快乐，就永远没了，怕了。所以在这句话里边，又表明了什么？禅宗的生死观。我们所贪的生，其实都是前念，而且因相而生，在二相中生的嘛。我们害怕没有这一切，没有二相和二相中起的念。害怕人世间不再有富贵和贫贱的区分。我在其中奋斗，多好。都没了，那么我干嘛呢？什么都没了，不行啊。

<span id="p-tan-07-088" class="reading-anchor"></span>

虽然生活够折腾的，但咱们有可能趋而得之，避而免之，我们还是可能的。前二十年不行，后二十年再来，说不定东山再起，诸如此类。你知道人就不肯走的。一个罪犯被判死刑好呢，还是被判无期徒刑好？估计还是判无期徒刑好，因为无期徒刑还有一种机会，叫减刑，对吧？是不是这样？

<span id="p-tan-07-089" class="reading-anchor"></span>

跟着前念走啊，执了念。前念不生，所有的生都是前念。不生，后念不灭，佛。所以佛叫不生不死，超脱生死二相。讲了禅宗的根本道理。我们真害怕那个死啊，害怕那个死，就是留恋那个前念嘛。可是往昔不能再来，这就是人生，“诸行无常，是生灭法”。

<span id="p-tan-07-090" class="reading-anchor"></span>

那首歌唱得好，《Yesterday Once More》，可能吗？痴心妄想。佛家一看这个歌名，还昨日再来？〔[听辨待核](#editorial-note-1)〕怎么 once more？前念过去了就过去了，不思向前，是吧？就前面有句话。否则是要系缚，束缚了我们。说两句就行了，这两句就是修行的功夫。

## 成相与离相都是心的事

**回看 00:57:01—00:59:11**

<span id="p-tan-07-091" class="reading-anchor"></span>

你看后面一句，“成一切相即心”。心放出光来了，是吧？我们的心，就像太阳，或者一盏灯，或者一个手电筒的小电珠。它放出光来，这个屋子的事物都呈现给我们。这小电珠，就是比喻我们的心。成一切相了吧，但小电珠不知道自己嘛。那它知道自己，可以的，“离一切相即佛”。

<span id="p-tan-07-092" class="reading-anchor"></span>

手电筒的小电珠无法回光返照。离了相，它发现自己了。解铃还须系铃人嘛。相本就是你成的相嘛，你离一离，不就回到心了嘛？心自己发现自己，那叫本心自悟。然后你还在相中折腾吗？不，于是叫佛。解铃还须系铃人。

<span id="p-tan-07-093" class="reading-anchor"></span>

那个僧人与禅宗祖师的三问、三反问，就是这个意思。

僧人问：“如何是解脱？”祖师反问：“谁缚汝？”谁束缚住你了？

第二问：“如何是净土？”反问：“谁垢汝？”

第三问：“如何是涅槃？”反问：“谁将生与死与汝？”谁把生与死的区分给了你？

你要解这个铃，谁系的这个铃？不就你自己的心吗？这就是禅宗的真精神。

<span id="p-tan-07-094" class="reading-anchor"></span>

所以这里也是啊，成一切相，是不是你的心啊？离一切相，是不是还是你的心啊？你的心能离相的。各位信不信自己？能离相的。虽然难，难嘛要修呀，不难也不用修。

## 法海的偈与定慧双修

**回看 00:59:11—01:02:53**

<span id="p-tan-07-095" class="reading-anchor"></span>

说了这两句够了。他说，“吾若具说，穷劫不尽”。还是给你个偈吧。“即心名慧，即佛乃定。”你离相了，是不是定了？这叫即佛乃定。“定慧等持，意中清净。”修定慧就是同一件事情，不是修定，然后修慧。等持，这就是第四品《定慧品》讲的。

<span id="p-tan-07-096" class="reading-anchor"></span>

“悟此法门，由汝习性。”这也是实事求是的话。你要悟入禅宗这个法门，个人的习性还不一样。“一切贤圣皆以无为法而有差别”，那就对了嘛。“用本无生，双修是正。”体用本来是一致的，没有什么生出来、不生出来。双修，就是既修定也在修慧。定慧双修，这是正。

<span id="p-tan-07-097" class="reading-anchor"></span>

“法海言下大悟，以偈赞曰：即心元是佛，不悟而自屈。我知定慧因，双修离诸物。”这是法海悟了，通过对话。即心即佛他不明白。其实即心即佛这个表达，已经表明定慧等持了。心是不是灵性、妙性吧？慧从中来。佛是不是定啊？即心即佛，不是即慧即定嘛？终于入了什么？禅宗的法门了。

<span id="p-tan-07-098" class="reading-anchor"></span>

佛由心中作的，心见到佛嘛。每个人因此要相信自己。没有悟到即心即佛，我们就没有自信。我们自己把自己看小了，这叫自屈了。现在知道定慧因了，所以就知道双修，定慧双修。修心就是修佛。放到《机缘品》的第一则机缘，对的，应该放在第一位。

<span id="p-tan-07-099" class="reading-anchor"></span>

除了法海的贡献这一点之外，更重要的是他问的内容，事关禅宗修行的根本，即心即佛。即心即佛，就即本解脱。原理是什么？解铃还须系铃人。就这个原则，天下人都是作茧自缚的，天下人都是作茧自缚的。禅宗把这一点点透了嘛。我们每个人自己把自己束缚住了，我们每个人自己把自己弄脏了，我们每个人自己贪生怕死，对吧？我们都当由此悟入禅宗法门。这是第一则机缘，来问即心即佛。

## 本节总结｜整理附录

法海的提问，把“即心即佛”从一句教理转成可下手的功夫。课堂先展开前念与后念，再说明相由心成、亦由心离，并把贪生怕死与对过去经验的执着联系起来。

手电筒只能照外物，而心能够离开自己所成的相。三问三反问进一步把束缚、污染和生死的分别追溯到自己的心；最后用定慧等持的偈和法海悟后的赞偈收束。
