## 摩诃是大，心量广大

**回看 01:09:32—01:16:27**

<span id="p-tan-03-118" class="reading-anchor"></span>

底下是要对“摩诃般若波罗蜜”作具体的说明，一共三个词，一个是摩诃，一个是般若，一个是波罗蜜多，分别讲这三个词。先说摩诃，再说般若，然后再说波罗蜜，这就构成了《般若品》的前半部分。先解释摩诃，摩诃就是大的意思。

<span id="p-tan-03-119" class="reading-anchor"></span>

我们看原文。惠能说，“摩诃是大”。这个大是指什么？“心量广大”。就是心要大，大到什么程度呢？“犹如虚空”，我们说宇宙啊。“虚空无有边畔”，就是没有边际。“亦无方圆大小，亦非青黄赤白，亦无上下长短，亦无嗔无喜，无是无非，无善无恶，无有头尾。诸佛刹土，尽同虚空。”

<span id="p-tan-03-120" class="reading-anchor"></span>

这是对虚空的描述。虚空只能这样来描述，它不是个什么样子的东西，是吧？而是用否定的方式来描述，所以连说好几个无或者非。无有边畔，无方圆大小，非青黄赤白，无上下长短，无嗔无喜，无是无非，无善无恶，无有头尾。这也是否定地说，而不是正面说虚空怎样，虚空没有形象。

<span id="p-tan-03-121" class="reading-anchor"></span>

拿虚空来说什么？说人心。“世人妙性本空，无有一法可得。”这句话特别重要。摩诃指的是我们的心量广大，广大到和虚空一样。这个心在这里被怎样称呼？妙性。关于人心有种种说法，或称其为灵觉，或称其为知识。

<span id="p-tan-03-122" class="reading-anchor"></span>

这个知识不是我们今人所说的 knowledge，什么科学知识，是吧？在佛经里边，在佛学里边讲的知识，就是我们的灵觉。我们都是有知识的，就是我们都是有心的，有灵觉的。或灵敏，或这里讲的妙性，都是指心，心要大。

<span id="p-tan-03-123" class="reading-anchor"></span>

我们要再度地说明，就是《坛经》讲佛法，不是讲理论，不是讲概念规定。比方说摩诃，不要把它当概念来看待，而是什么？修行的功夫。这叫般若行嘛，“此须心行”。底下说“口念心行，心口相应”。我们念了摩诃。实践都是情感的实践，就心的实践，所以叫心行。所以摩诃首先要讲的，修心的功夫。

<span id="p-tan-03-124" class="reading-anchor"></span>

禅宗讲修行，就是讲修心，修心。当然，你守戒也是修行，但禅宗的重点不在守戒，而在于生命情感的实践，那叫心行。所以摩诃是心行的功夫。如何下这个功夫？你看，“世人妙性本空，无有一法可得”。我们都有所得。我们在这世界上积累了许多东西。

<span id="p-tan-03-125" class="reading-anchor"></span>

生活过一段时间之后，我们积累了经验，积累了知识，积累了财富，甚至还积累了社会地位，如此等等。我们似乎拥有很多。我们拥有的越多，我们的心就越来越小。这些东西我们自以为都拥有了，所以人就慢慢地心越来越小，因为它被许多东西占据了。

<span id="p-tan-03-126" class="reading-anchor"></span>

我们获得了权力，我们获得了财富，我们都抓住不能放的。我们拥有了许多经验和知识，我们也就开始自以为是。这些都把它清空了，这叫摩诃的功夫。别以为自己拥有什么，“世人妙性本空，无有一法可得”。

<span id="p-tan-03-127" class="reading-anchor"></span>

我们习惯于积累、占有，拥有越多越好，终于这个心不妙了。不再妙了，有什么妙可言？什么创造性都不具备了，因为我们依赖我们拥有的东西了。要把这种依赖去掉。那句话说对了，“无有一法可得”，把它去掉。

<span id="p-tan-03-128" class="reading-anchor"></span>

我们每一次都是从零出发。不管你拥有怎样丰富的经验和知识，不管你在所谓的人生积累中拥有了多少东西，都把它看成是什么？其实我们并不拥有，对吧？无有一法可得。于是我们才始终是什么？妙性。妙性本空，若不空便不能妙。

## 童心为什么了不起

**回看 01:16:27—01:22:07**

<span id="p-tan-03-129" class="reading-anchor"></span>

如何心要大？心量广大的第一前提是空，不空如何大？这也是蛮难下的功夫。我们似乎把我们的信心、做事情的信心，都建立在我们的积累上。我们积累了本事，就自以为能成什么了。一切事情都是从零出发。

<span id="p-tan-03-130" class="reading-anchor"></span>

这就让我想起一种比喻。你看这个黑猩猩，幼年的黑猩猩跟人最像。为什么？好奇，善于模仿。它终于长大了，变成了成年的黑猩猩，它再也没有学习的能力了，也丧失了好奇心，而且自以为是。那叫老于世故的成年黑猩猩。

<span id="p-tan-03-131" class="reading-anchor"></span>

我们现在都主张孩子赶快成熟一点。什么叫成熟呢？我心里想，中国老百姓说这个孩子不够成熟，就什么意思啊？人情世故不大懂，就不够成熟。要很快成熟起来才好。我认为这完全是错的。童心为什么了不起？它空啊，空而后它就大。

<span id="p-tan-03-132" class="reading-anchor"></span>

童心不是傻。一个人要一辈子童心不泯才好。他始终能学习，他始终对这个世界有好奇心，他能真正地热爱生活。所以这要下摩诃的功夫的。中国儒家也向来认为，什么叫圣人啊？童心不泯的人。什么叫生而知之？就是因为童心在，他就生而知之。童心遮蔽了嘛，做贤人吧，学而知之，还得学了。

<span id="p-tan-03-133" class="reading-anchor"></span>

圣人了不起的地方，就是一辈子童心在。一切伟大的人物，我们讲在人类文明的历史上做出重大贡献的伟大人物，无论是艺术家还是科学家，他们有共同的特点。包括伟大的政治家。政治家总算老于世故嘛，但那倒是政客啊，真正的政治家一定童心在的。

<span id="p-tan-03-134" class="reading-anchor"></span>

比方说毛泽东，到老了，童心还在，这是了不起的。真正的成熟是包含着童稚的，才是成熟。不包含童稚的成熟，那就是老于世故罢了。老于世故，终于为人圆滑。修行者不能这样的。

<span id="p-tan-03-135" class="reading-anchor"></span>

所以摩诃的第一层意思就是空。我们似乎确实拥有了许多经验、知识、做事情的本事，还有地位，那个名片上印着你的社会地位。也许我们在银行里有很多的存款，诸如此类的。它们都不是我们生活的真正依靠的东西，无有一法可得。

<span id="p-tan-03-136" class="reading-anchor"></span>

破除小我的执着。我们周遭所有所谓我们拥有的东西，我们其实并没有拥有过。我们自以为拥有了。这个房子是我买下来的，它不是我的。其实要无我，在这里边没有我的。

<span id="p-tan-03-137" class="reading-anchor"></span>

再比方说，我们中国人吃饭很有意思的，圆桌，圆桌上面还有个转盘呢。这转盘在缓缓地转。这道菜没转到你面前之前，你别急，不要急啊。转到你面前，你优雅地夹一块，那么它又给下一个人了，是吗？那么转到你面前你来不及夹，它过去了，就让它过去吧。Gentleman，人生要有绅士态度，未到的不急，已去的不难过。就这样。

<span id="p-tan-03-138" class="reading-anchor"></span>

所以佛学讲透了，那么人总是颠倒。涅槃境界叫常、乐、我、净。我们一定会把常执为无常，那么就把涅槃境界搞错了。那么我们生活呢，都是无常吧？无常、无乐、无我、无净。但我们倒过来的。明明无常，我们认为常，就以为我们能在这个世界永远待下去。就说常得了吗？常不了。

<span id="p-tan-03-139" class="reading-anchor"></span>

乐，明明是苦，把它当乐。明明无乐，执为乐。明明无我，执为我。明明无净，执为净。要明白，没有东西，所有的东西里面没有你，你偏说是我的。世人凡夫的颠倒，便在此。所以摩诃的修行功夫，修般若行，第一就是摩诃。摩诃的第一就是空，空而后能大，不空不能大。

## 空而后大，能含万法

**回看 01:22:07—01:29:14**

<span id="p-tan-03-140" class="reading-anchor"></span>

那么第二层意思就是大。惠能讲得很清楚，我说了空，不要执着于空，还要讲后面一层，叫大。惠能这么讲的，“莫闻吾说空，便即著空。第一莫著空。若空心静坐，即著无记空。”什么念头都没有，是吧？什么事情也不想，那么这叫坐禅的功夫吗？坐禅的功夫不能被误解为空心静坐。

<span id="p-tan-03-141" class="reading-anchor"></span>

空固然是第一层意思，但心是在的吧？因为空，心就大。大什么意思？能含万法，能包容万物。惠能继续用形象的比喻来说了，“世界虚空，能含万物色像，日月星宿，山河大地，泉源溪涧，草木丛林，恶人善人，恶法善法，天堂地狱，一切大海，须弥诸山，总在空中。世人性空，亦复如是。”

<span id="p-tan-03-142" class="reading-anchor"></span>

底下说了，“自性能含万法是大，万法在诸人性中”。真正的人性就是佛性。“若见一切人恶之与善，尽皆不取不舍。”我们会遇到有人做坏事，也会遇到有人做好事，你不要在这里做一个取舍。即使做坏事的人，他佛性还是在。

<span id="p-tan-03-143" class="reading-anchor"></span>

所以采取的态度就是，你跟人打交道，不要区分善人、恶人两大阵营。不应该有……有好事和坏事，善事和恶事，这是真的，但是不要给人贴上善人恶人的标签。所以这是一种叫空而后大，能包容所有的人。如果你爱爱恨恨，那就是染著。

<span id="p-tan-03-144" class="reading-anchor"></span>

通常我们讲一个人爱憎分明，是对的，那是道德境界了。但是比道德境界更高的，叫天地境界。比方说假如你是个领导者，假如你是个企业家，你做企业的第一把手，你在你的员工当中，不应该做这种区分。一部分员工道德品节端正，你把他引为自己的朋友。有一部分员工为了个人的私利，曾经伤害过企业的利益，你把他当成敌人。区分敌友两大阵营，是吧？

<span id="p-tan-03-145" class="reading-anchor"></span>

你能做企业家吗？你只是跟员工一样，在道德境界上，你没有往上升啊，天地境界。所以我们可以指出某些错事，不应当做，那要明确得很，这叫是非分明的。但是别把人放到是非阵营中去，这是我们道家本有的境界。

<span id="p-tan-03-146" class="reading-anchor"></span>

就是老子《道德经》里说过的话，“天地不仁，以万物为刍狗。圣人不仁，以百姓为刍狗”。不仁不是指不讲道德，而是不偏爱。这个境界，道家本就说了。现在让佛学进入中国思想，这层意思自然也就被中国人领会了，摩诃。

<span id="p-tan-03-147" class="reading-anchor"></span>

所以最后一段，“心如虚空，名之为大，故曰摩诃”。摩诃就这层意思了。也就是我们修般若行的第一个功夫要下，下的就是摩诃的功夫。我们要在是是非非、善善恶恶当中，心不染著，很难。我们通常说爱憎分明是好的，但是在这种爱憎分明当中，如果把人当成恨或者爱的对象，我们的心就已经染著了。

<span id="p-tan-03-148" class="reading-anchor"></span>

这讲修心的第一个功夫，摩诃，讲得非常真切。我们不要自以为拥有什么。也许从客观上讲，某人是一个很大的集团企业的董事长，他拥有的可多了。他甚至被称为商界精英或商界领袖。但若他自己本人有修佛的境界，他一定会把自己先空掉。

<span id="p-tan-03-149" class="reading-anchor"></span>

就像乔布斯在斯坦福大学毕业典礼上的讲话，有一句话就这么说的。你们斯坦福大学的毕业生进入美国社会，都希望自己很快成为社会精英，是吧？也许你们有朝一日真成了社会精英，美国社会的精英，你们不要忘了，stay foolish，stay hungry。保持愚笨，保持饥饿。把自己作为斯坦福名牌大学的毕业生这个身份空掉。你们成了社会精英，也把这个身份空掉。

<span id="p-tan-03-150" class="reading-anchor"></span>

乔布斯是修过佛的，所以才说得出这样的话。这就是摩诃啊。摩诃的功夫啊，难，尤其是在这个市场经济的时代，人与人之间不断地竞比，竞比。到现在嘛，叫内卷，是吧？空掉，没什么好卷的，那该干嘛干嘛。世人妙性本空，无有一法可得。然后我们就大，心就大。自性能含万法为大，这就是摩诃。

## 空心静坐有什么问题

**回看 01:29:14—01:34:37**

<span id="p-tan-03-151" class="reading-anchor"></span>

讲了摩诃之后，要讲般若。在讲般若之前，他又重复了，反复申说了这样的意思。第一是实践。摩诃般若波罗蜜，这一句话都是修行的功夫。摩诃是功夫，“迷人口说，智者心行。又有迷人，空心静坐，百无所思，自称为大。此一辈人，不可与语，为邪见故。”跟这样的人，你就不用讨论了。

<span id="p-tan-03-152" class="reading-anchor"></span>

他认为他修行坐禅呢，空心静坐，他认为自己就大了。大不是这层意思，大是自性能含万法的，在生活中能包容万物，对吧？空心静坐，那么石头一定坐得比他好啊，对吧？你坐得过石头吗？人本就有心，这个心如果彻底没了，把空理解为心没了，心如死灰了，这还了得？

<span id="p-tan-03-153" class="reading-anchor"></span>

我们在这个世界上都有种种欲求嘛。美味佳肴在你面前，你都没有欲望了，你说你心空掉了，这有意思吗？出毛病了嘛，你的食欲都没有了。一位美女在你男性面前走过，你心不动，你能审美了吗？审美的能力都没了。这叫空心静坐，还不要这样修啊，这样修没意思的。“为邪见故”，此一辈人不可与语，把修行搞错了。

<span id="p-tan-03-154" class="reading-anchor"></span>

美女在你面前，你欣赏她，这真好。但不要起了占有的欲念。区分就在这里。你当然能爱，但不要迷了，迷了就开始执着。修行的功夫。美味佳肴在你面前，你情不自禁地就想吃它，这很好的。但是你不要说非要吃到美味佳肴不可，否则不能算吃饭，那错了。

<span id="p-tan-03-155" class="reading-anchor"></span>

欲望本身没错，任何一个生命体都有欲望。由欲望而执着为占有，那就着了相，住了法，执了自我，这是要去掉的。所以禅宗祖师那些话说得真很妙的。那位禅宗祖师说，“我终日吃饭，未曾咬着一粒米。我终日穿衣，未曾着了一缕棉絮。”未曾着了一缕棉絮，不就对了嘛？

<span id="p-tan-03-156" class="reading-anchor"></span>

什么叫着了一缕棉絮呢？非得穿名牌服装不可，否则等于没穿衣服。这叫着了棉絮了。名牌衣服也可以穿，普通的衣服也照样穿，很好。你也不要拒绝名牌衣服，没有必要，这又是着了相了。但是你穿上名牌衣服以后，就不要以为自己了不起了。

<span id="p-tan-03-157" class="reading-anchor"></span>

现在这个高消费，就是引导当代人嘛，对吧？这是贵族身份的颁布，颁布你是贵族身份。提着那个包，穿着那个衣服、鞋子、皮鞋，全是品牌，世界顶级的品牌。然后你走出去，觉得自己高人一等，这还了得。可以穿，可以戴，你喜欢，没错。

<span id="p-tan-03-158" class="reading-anchor"></span>

那个爱马仕很不错的，那个 LV 包也很好的，质量真好的。我看了也喜欢的。假如我拎了个 LV 包就自以为是了，那就错了。你背了一个 LV 包，然后我看了，哎哟，还了得，我这个包简直不是包。其实它还是包，我背的也照样开开心心的。有喜悦就可以了。用到质量好的东西，确实有喜悦，这也没错。但它绝不是你身份的标志。

<span id="p-tan-03-159" class="reading-anchor"></span>

这里边不要发生人我别，是吧？那么我有两个 LV 包，你看了都喜欢，我说这个就给你吧，也很好。这就是生活，生活就是修行啊。你在生活之外还修什么呢？生活每天都会考验我们，考验修行者。

## 心体无滞和八万四千智慧

**回看 01:34:37—01:41:45**

<span id="p-tan-03-160" class="reading-anchor"></span>

然后他继续讲那个摩诃，反复申说，“心量广大，遍周法界。用即了了分明，应用便知一切。一切即一，一即一切，去来自由，心体无滞，即是般若。”开始讲般若了。我们注意到他用了个词叫心体。心体是没有障碍的，来去自由的，我们的色身才是有障碍的。

<span id="p-tan-03-161" class="reading-anchor"></span>

心体就是什么？法身啊，佛学的用语。法身其实就是心体，色身就是我们的肉体，body。我们这一具肉体，让我们在生活当中不可能自由来去的，一定有种种的障碍了。那心体呢，法身呢，去来自由啊，它本来就没有障碍。

<span id="p-tan-03-162" class="reading-anchor"></span>

达到这一层，就是我们的心领会空、领会虚无，这叫什么？包容。心若跟着肉体走，这个心就不是心之本体了。其实就是种种妄念之心，对外住相，对内执我。住相、执我，就不在心体中了。不住相，去掉我执，便在心体中，它是去来自由的。

<span id="p-tan-03-163" class="reading-anchor"></span>

你背着 LV 包，我背着我这个包，我也很开心，很自由的。这些话都不是空话。人家开了一个连锁店，你现在还是一个小小的烟杂店，你也开得很开心。不要把自己跟人家比一比。人家在商业上成功了，我几十年开来开去还是这家小小的烟杂店，也很好啊，为人民服务啊，为小区居民服务啊。

<span id="p-tan-03-164" class="reading-anchor"></span>

你在心之本体中了，去来自由，能大能小，能高能低，而且还知道它们之间的相互关系。贵以贱为本，高以低为基，基础的基。这都是老子说的。所以回归心之本体，就是法身，我们自然是自由的。

<span id="p-tan-03-165" class="reading-anchor"></span>

然后底下说，般若智哪里来？“一切般若智，皆从自性而生，不从外入。”讲得分明。我们修行，修般若智，我们本有，在我们本有的佛性中就有。什么叫佛性？首先就是领会空的。“莫错用意，名为真性自用。”真性，就真如自性，简称真性。真就是不假，如就是不倒，叫真如自性。自性就人人都具备的佛性。

<span id="p-tan-03-166" class="reading-anchor"></span>

“一真一切真”，这话谁说的？弘忍，五祖。跟谁说？跟神秀。一真一切真，这一真是什么？真心，叫如如之心，而不是如意之心。“一真一切真，万境自如如。如如之心，即是真实。”五祖的原话，来讲给神秀听的，来启发神秀的。这样的话，一定也跟惠能讲过，是吧？所以惠能自然就随口就来了。

<span id="p-tan-03-167" class="reading-anchor"></span>

“心量大事，不行小道。”小道就是小机巧。有的人就是太过聪明了嘛，小机巧都很清楚的。那么你越是在小机巧中做事情，你的心就小了嘛，心就自然小了，久而久之，就是一个小人了。当然是聪明人。聪明人不值得追求，有智慧才是最重要的。人可以笨一点，就怕什么？人极其聪明，但远离智慧。

<span id="p-tan-03-168" class="reading-anchor"></span>

那么智慧从哪里出发？就从般若智出发，这是最根本的智慧。其他的智慧都从般若智里边生出来的。我们提前看看后面的，把它提前来先看一看。惠能说，“我此法门，从一般若生八万四千智慧”。为什么要用八万四千这个大数字呢？“何以故？为世人有八万四千尘劳。”劳就是做事情，尘就是烦恼，带着烦恼做事情叫尘劳。“若无尘劳，智慧常现，不离自性。”

<span id="p-tan-03-169" class="reading-anchor"></span>

所以我们说我们的智慧，它一定要从根本上从般若智出发。不是说最高的智慧嘛？你有那个领会空的智慧嘛。这个般若生出多少智慧来？这个八万四千种，这是佛教喜欢用大数字说话。虽然谁都没有去数过，是吧？如果数一下，写下来，写一本书，《八万四千种智慧大全》，没有这种事。言其多耳。有种种的智慧，在不同的事情当中，你的智慧，这个智慧、那个智慧都来了。其实都源出于什么？般若。

## 本节总结｜整理附录

对摩诃的解释分两层。先以无有一法可得破除对经验、知识、财富、身份的依赖，再以能含万法说明心量广大。童心、圆桌转盘和涅槃四德的讨论，都在帮助分清空与占有。

空不意味着没有心、没有感受与欲求。企业中的善恶判断、吃饭穿衣、LV包和烟杂店等具体例子，反复说明生活可以继续而不以相确定自我。由此进入心体无滞、般若不从外入，以及一般若生八万四千智慧的说明。
