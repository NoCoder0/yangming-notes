## 无念与不于境上生心

**回看 01:48:30—01:52:50**

<span id="p-tan-05-187" class="reading-anchor"></span>

然后我们再来看第三个。「善知识，于诸境上，心不染，曰无念。」什么叫无念？底下说得很清楚，「于自念上，常离诸境，不于境上生心」。这是很重要的。我们的人生处境一直在改变吧，一变我们就境上生心了。这是顺境，那是逆境，这是乐境，那是苦境，不是生心了吗？心是情感呀。

<span id="p-tan-05-188" class="reading-anchor"></span>

我以前看《动物世界》。这个《动物世界》里面，正好那个外国摄影师蛮厉害的，拍那个屎壳郎推粪球，很精彩。我正好看到了这个屎壳郎，沿着一个斜坡，把粪球往上推。推到一半，这个粪球被一个小木桩卡住了，它推不动了。

<span id="p-tan-05-189" class="reading-anchor"></span>

我在这里想，看你怎么办，看你这个屎壳郎怎么办？结果我就发现它往左面去，绕到左面，由左往右推，还是不动。它又绕到右面去，由右往左推，还是不动。我想你完了。结果它绕到上方去了，绕到这个粪球的上方，由上往下推，成功了呀！

<span id="p-tan-05-190" class="reading-anchor"></span>

这时候我禁不住为它欢呼，我想你成功了！但是我发现它很平静。它又下去了，又到斜坡底上了，然后继续把粪球推到坡顶了。看了整个过程，我心里想，人跟它不一样。假如我们人类做这样的事情，推到一半卡住了，推不动了，左推右推也不动，我们要沮丧，我们会难过，我们要跺脚，它没有啊。

<span id="p-tan-05-191" class="reading-anchor"></span>

然后终于推成功了，我们要举行隆重的庆典呢，欢呼伟大的胜利啊，它没有。一个结论来了，生活本无痛苦，向屎壳郎学习。它真做到了什么？不于境上生心。我本来以为这就是学佛嘛，问题在于它本来没心，人有心，这事情比较大。

<span id="p-tan-05-192" class="reading-anchor"></span>

境一改变，我们的心就变，这叫于境上生心。于境上生心，这也不是坏事，人就是有情感的，不是无情物。这是很正常的。问题是什么？不要停留，不住，能离，你这叫修行了。

<span id="p-tan-05-193" class="reading-anchor"></span>

后面的一种情况，就是屎壳郎的情况。「百物不思，念尽除却，一念绝即死，别处受生，是为大错。学道者思之！」如果我把屎壳郎看成我学习的榜样，那终于是什么？百物不思。这不可能。不要把坐禅修禅定的功夫，看成是百物不思的能力，这叫绝念了。

<span id="p-tan-05-194" class="reading-anchor"></span>

绝念就是心死了，心都不能起念了。一死，死了以后怎么办呢？再投胎，别处受生。受生之后还是一件事情，还是心要起念的嘛。「学道者思之！若不识法意，自错犹可，更误他人。自迷不见，又谤佛经。」千万不能这样。

## 无念的「无」与「念」

**回看 01:52:50—01:55:52**

<span id="p-tan-05-195" class="reading-anchor"></span>

「所以立无念为宗。」禅宗这个修行的法门，根本宗旨就是两个字，无念。禅宗修行，你可以说它是修般若行，也可以说它是修无念行。无念不能误解，误解为什么？念都没有了。这个「无」和「念」这两个字之间的关系，不是动宾关系。

把「无」看成是动词，把「念」看成是宾语，把念无掉，那叫绝念。

<span id="p-tan-05-196" class="reading-anchor"></span>

什么是无念？底下有说明。我们看下去，「云何立无念为宗？」云何，这种问法是不是《金刚经》里的？云何，云何应住，云何降伏其心？所以惠能一定是听《金刚经》听得蛮熟的，不知不觉就用起它的句型来了。

<span id="p-tan-05-197" class="reading-anchor"></span>

「云何立无念为宗？只缘口说见性」，其实没见性，这叫迷人。口说见性的迷人，「于境上有念，念上便起邪见。一切尘劳妄想，从此而生。自性本无一法可得。」前面说过吧，在《般若品》里。这里再说一次，「自性本无一法可得」。

万事万物，我们能得吗？佛性不是种占有万物的性，本无一法可得。

<span id="p-tan-05-198" class="reading-anchor"></span>

「若有所得，妄说祸福」，那就算命了。算命嘛，就这事情了，看看八字，妄说祸福。所以佛教就其本意来说，是不主张算命的。主张算命的是道教。儒家也信命，但算不算无所谓。道教是特别喜欢的。也有道理，我也算了。看看这个命理学，有道理的，中国的一门科学，可以跟中医学并列在一起，都是阴阳五行学说做基础的，这没啥问题的。

<span id="p-tan-05-199" class="reading-anchor"></span>

只是如果你境界更高一点呢，命就不算了，就这个意思。因为本无一法可得，你得什么呢？若有所得，便会什么？妄说祸福，就是尘劳邪见，「故此法门立无念为宗」。

## 尘劳和邪见从哪里来

**回看 01:55:52—01:59:13**

<span id="p-tan-05-200" class="reading-anchor"></span>

我们这里先要说明一下，这个邪见的「邪」字，不要把它当成一个道德评价词来说。因为邪和正通常被理解为道德上的评价，正的叫善的，邪的叫恶的，叫邪恶。在这里讨论的正见和邪见，跟道德评价没关系。什么叫正见？什么是邪见？不是善恶的问题。

凡二相中起念，必是妄念。哪怕在日常的道德标准评价起来，这个念还是善念，那它已经妄了。

<span id="p-tan-05-201" class="reading-anchor"></span>

要明白这个道理。我们有时候遵循了一条道德标准去做事，我们觉得在善念中，其实同时又在二相中。这善事终于成了恶事，各位信不信？中国历史上不是向来有礼教杀人吗？礼不是道德规则吗？我们遵循了礼教了吧，结果产生了害人的结果。

<span id="p-tan-05-202" class="reading-anchor"></span>

根源还在于那个妄，不是表面上区分善恶。所以叫无念为宗，这是非常非常根本的境界。人活在这世界上，我自然会受到时下的社会价值体系、价值标准的影响，这难免。要拿佛家的境界去审视一下，此善是正的，还是妄的呢？是不是？

<span id="p-tan-05-203" class="reading-anchor"></span>

还有一个尘劳，我们多次说明了，你做事情叫劳。人在世界上就得做事情，不做事情的人生不能算人生。做事情就做事情，带着烦恼做事情，烦恼就是尘啊，佛教讲的尘就是指烦恼。带着烦恼做事叫尘劳。那么怎么会带着烦恼做事呢？著相呀。

<span id="p-tan-05-204" class="reading-anchor"></span>

有高与低，贵与贱，得与失，利与害，乐与苦，福与祸，等等。你在这个相中了嘛，你做事情就求一个高、一个贵、一个富、一个乐、一个福，不是求了吗？一求嘛，你带着这个追求去做事，烦恼不断。这个尘就这么来的，尘从二相中来，二相就二元对列。

福与祸二元对列，得与失二元对列，利与害二元对列，所以相都是二相。

<span id="p-tan-05-205" class="reading-anchor"></span>

在二相中我们一定起了什么念？叫趋避。趋高避低、趋贵避贱，这个念就起来了。于是烦恼也就来了。趋而不得，避而未免，不如意。烦恼就是不如意，带着烦恼做事叫尘劳。

## 去尘，还是斩断缘

**回看 01:59:13—02:02:16**

<span id="p-tan-05-206" class="reading-anchor"></span>

在人与人的关系当中，带着烦恼跟他人相处，那叫尘缘。一个尘字也来了嘛。本来父母和儿女的关系，是多好的关系。结果带来烦恼了，终于成了尘缘。实在不行，斩断，跟父母说，我出家了，你别找我，这叫斩断尘缘。

<span id="p-tan-05-207" class="reading-anchor"></span>

李叔同还斩断尘缘，他妻子抱着孩子找他，他不干了。斩断，不就斩断尘缘吗？实际上不应该斩断这个缘，应该是去掉那个尘。所以王阳明说，那些一味想要遁入空门、逃避人世间的尘缘的人，他们著了相了。都说我们儒家著相，佛家不著相，其实他们才著了相。

<span id="p-tan-05-208" class="reading-anchor"></span>

还记得那个《传习录》里的对话吗？他们，那些出家人，不是指佛教错了，而是那些出家人，君臣关系对他来说也是累。因怕君臣累，故逃了君臣；怕父子累，逃了父子；怕夫妇累，逃了夫妇。都是因为著了君臣、父子、夫妇的相。

<span id="p-tan-05-209" class="reading-anchor"></span>

「吾儒不著相」，君臣还他一个义，父子还他一个仁，仁义道德的那个仁，夫妇还他一个别。夫妇有别是什么意思呢？男人能做的事女人做不了，女人能做的事男人做不了的，他们结合了，共命运了，叫合作了，共命运了，这叫别。

<span id="p-tan-05-210" class="reading-anchor"></span>

换句话说，君臣关系也罢，父子关系也罢，夫妇关系也罢，都还他一个本来的价值，那叫真情，真情非相。在人与人的关系中，我们始终在这份关系的真情中，它就没有尘，就没有烦恼。我们把尘去掉了，珍惜这个缘，而不是把缘本身也斩断了。

<span id="p-tan-05-211" class="reading-anchor"></span>

斩断尘缘是有些人的选择，我总认为王阳明说得对，这种选择不对，不应该斩断缘，应该去掉尘。君臣还他一个义，父子还他一个仁，夫妇还他一个别，尘就去掉了呀。

## 孩子的分数与父子真情

那么尘哪里来的呢？相呀。你生了个儿子，儿子出生的那一天，你欢天喜地。确实是人生的一件大喜事吧。中国人有句老话说什么？有子万事足。你看，很好了。你没想到，儿子慢慢长大了，你越看越不对了，怎么是这样一个儿子呢？来了，尘立刻来了，这个缘立刻是尘缘。为什么？你住了一个成龙成凤的儿女的相。

<span id="p-tan-05-213" class="reading-anchor"></span>

<span id="p-tan-05-214" class="reading-anchor"></span>

<span id="p-tan-05-215" class="reading-anchor"></span>

不要去住那个念，住着那个念。念就是在外境上生心，不于境上生心。境一直在改变，有时候那个境来了，你也大喜过望，怎么会这么好呢？其实跟你没啥关系。有的人就这样，我们以父母儿女的关系做例子，就是这样。孩子终于考上大学了，而且还牛，复旦大学医学院高材生，开心吧？后来给同学喝的水里下了毒了，你又该怎么看这件事呢？想来是个悲剧吧。

## 成人与成为专才

**回看 02:04:52—02:07:09**

<span id="p-tan-05-216" class="reading-anchor"></span>

不能住相的，不要于境上生心，孩子还走他自己的人生道路，你不断要提醒他的。第一，《大学》《中庸》读一读。第二，《六祖坛经》读一读。人生的教科书。做人是要被教的，不是天生会的。我这句话有根据的，《中庸》开头的第三句话，「修道之谓教」。

<span id="p-tan-05-217" class="reading-anchor"></span>

做猫不用教的。你把猫都找来上思想品德课，这不是开玩笑了？你们知道什么叫猫性吗？我告诉你们一共五点，记住，不要背离猫性。多余的。做人要教的。「天命之谓性，率性之谓道」，还偏要来第三句，「修道之谓教」，那叫教化。

<span id="p-tan-05-218" class="reading-anchor"></span>

教育的根本的任务，就是让被教育者作为人成其为人，其次才是成为某种人。某种人，就是某种专才，或厨师，或律师，或医师，总而言之，叫 specialist，专家。这是第二件事，第一件事先成人，作为人成其为人。

现在事情是倒过来的，专才不少，叫有文凭的野蛮人，是吗？第一件事情没做好，结果是很悲惨的。

<span id="p-tan-05-219" class="reading-anchor"></span>

早一点读《六祖坛经》嘛，像《行由品》应当编入中学语文课本嘛，不就对了吗？轻视他人有无量无边的罪，小孩子要记住，「下下人有上上智，上上人有没意智」。从小就要告诉他怎么与人相处。尤其在这样一个资本和技术的时代，住相住得最厉害的文明。

## 菜园的公案

**回看 02:07:09—02:09:27**

<span id="p-tan-05-220" class="reading-anchor"></span>

所以我们把尘去掉，劳还是要劳的。人活在这世界，就得做事情。所以我觉得那些比较好的寺庙是什么？自己种地的和尚，很少的，有的，让我很感动。佛法嘛，就在种地里边学了。

<span id="p-tan-05-221" class="reading-anchor"></span>

有一个禅宗公案就这么说的，这个禅宗祖师跟他的弟子们说，弟子们，你们要听我说佛法，可以，我先叫你们把后面那块菜园给我弄出来。那块荒地，把它开垦了，把菜园搞出来，然后我跟你们说佛法。那帮弟子卖力了，开始耕地了，把那个荒地耕成了一个可种蔬菜的菜园子。

<span id="p-tan-05-222" class="reading-anchor"></span>

全部做好了，叫师父，师父，你看我们做好了，你现在可以跟我们说佛法了。这个师父两只手一摊，我已经教给你们了嘛。证据在哪里？你们这菜园做得好。担水砍柴，无非妙道。可以了，好好劳，就是不要带着尘去劳。缘要珍惜，不要带着尘处于缘中。

<span id="p-tan-05-223" class="reading-anchor"></span>

这个世界干净不干净，取决于我们的心，心干净不干净。这世界到处都是尘，所以叫什么？尘世。随其心净，佛土净。所以禅宗的修行是向内求的，佛不责世，我上次讲了。不责世间的过错，而是要帮助这个世界改善，但不谴责这个世界。

因为佛不责世的缘故，所以不加入政治，佛教的原则是不加入政治的，不见世间过。

## 两种求，学英语与录取

**回看 02:09:27—02:12:47**

<span id="p-tan-05-224" class="reading-anchor"></span>

好，终于到了这里了，要解释无念了。惠能经常用这样的方式，来解释两个字构成的一个单词。比方说什么叫功德？先说功是什么，再说德是什么，然后连起来。这里也是，「无念」这个词，先说无是什么，再说念是什么。无者无二相，无二相。

<span id="p-tan-05-225" class="reading-anchor"></span>

他先说，「无者，无何事？念者，念何物？」底下来了，「无者，无二相」，无二相等于什么？「无诸尘劳之心」。说得多清楚。你的烦恼来自哪里？在二相中嘛，就来烦恼了呀。事情归事情做，不要在二相中。在二相中，你就有一个目标了，这个目标终于没达成，那么就烦恼。

<span id="p-tan-05-226" class="reading-anchor"></span>

你比方说，你去学外语是件好事情，你把英语学得更好一点，也不错。但是你学英语的目的，是为了被哈佛大学录取。你要参加托福、GRE 的考试。这件事情最后得还是不得，不取决于你啊。孟子讲得太清楚了，人生总是有所求吧，求分了两类。

<span id="p-tan-05-227" class="reading-anchor"></span>

一类是什么？「求则得之，舍则失之，是求有益于得也，求在我者也。」第二类求，「求之有道」，有方法的，「得之有命」。这样的求，无益于得也，跟得还是不得没关系的。这个求，因为这是「求在外者也」。Out of your control，你控制之外的东西，你求有什么用？得之有命。

<span id="p-tan-05-228" class="reading-anchor"></span>

虽然有人教你方法，教你怎么考托福、GRE，求之有道吧。得不得哈佛录取通知书，有命的。同样一件事情你做了，就学外语、学英语，第一种求，你终于实现了，英语水平真提高了。但是哈佛大学录取通知书给不给你，这是第二种求，得之有命。

<span id="p-tan-05-229" class="reading-anchor"></span>

你明白这一条，你就离了二相了吧。我是想被哈佛录取，所以我要把英语学得更好，以便经受托福、GRE 的考试。对的，没错，去吧。考试结果出来是有命的，不归你管的，所以你就省了那份心。结果没得到哈佛录取，你认为你这几年学英语浪费时间了吗？没有，你进步了嘛。

## 我参加恢复高考后的第二届考试

**回看 02:12:47—02:16:03**

<span id="p-tan-05-230" class="reading-anchor"></span>

我是最明白这个道理，因为我亲身体会的。恢复高考，我第二届参加高考了。我中学的时候学的，有一块没一块的知识，然后做了三年半工人。恢复高考，我居然去报名了。给我一个月的复习时间，这是当时的工厂。一个月我能补多少东西呢？补不了多少的。

## 真如自性起念

**回看 02:16:03—02:18:35**

<span id="p-tan-05-236" class="reading-anchor"></span>

所以惠能讲得多清楚啊，把二相无掉，然后你再起的念，不在二相中起的，那叫真如自性起念。「真如即是念之体」。什么叫真如？就是我们的本性，佛性。它不假，真就是不假，如就是不倒。「真如即是念之体，念即是真如之用。」所以这叫真如自性起念。

<span id="p-tan-05-237" class="reading-anchor"></span>

「非眼耳鼻舌能念。真如有性，所以起念。真如若无，眼耳色声当时即坏。」我们跟外部世界打交道，当然要靠眼、耳、鼻、舌、身、意，特别是眼、耳、鼻、舌、身。眼睛能看，耳朵能听，鼻子能闻，舌头能尝味道，我们的肌肤有触觉。

<span id="p-tan-05-238" class="reading-anchor"></span>

眼睛为什么能看？不是它想看，是心要看，它才看的。视听言动都是心要求的，心给予的推动，并不是眼耳鼻舌身自身能视听言动的。心让它视听言动，就看你这个心是怎样的心。这个心应当是什么？自见佛性的心。

<span id="p-tan-05-239" class="reading-anchor"></span>

于是它所起的念，让我们的眼耳鼻舌身，都符合人的存在。就属人的感觉，属人的视觉，属人的听觉，属人的味觉、嗅觉，都有道。香还有香道，烹调还有它的艺术，那叫味觉。眼睛看什么？伟大的美术作品，雕塑、建筑、绘画。耳朵听音乐，这叫属人的感觉，它都来自真如自性。

<span id="p-tan-05-240" class="reading-anchor"></span>

真如没了，我们的眼耳鼻舌身就坏掉了。虽然也能听，跟动物的听没啥差别，也能看，跟动物的看也没差别，叫坏了，就坏了。

## 以美术、文学和音乐说明怎样观照

**回看 02:18:35—02:20:34**

<span id="p-tan-05-241" class="reading-anchor"></span>

最简单的例子，比如说女性裸体画怎么样？有的以前不是说，这叫什么色情作品？究竟是不是色情作品，看谁画，画成怎样。那个画家是真如自性起念，他画出了女性的人体的美，这叫人体艺术。还有一个画家，不是真如自性起念，在二相中起念，他就有欲求，画出来终于是色情画，引起观看者也动了念。

<span id="p-tan-05-242" class="reading-anchor"></span>

真正的人体艺术，你观看她，只觉得她美，你不会起占有她的欲念，这就是人体艺术。真正的人体艺术，就看你的心。惠能这些话都有道理在里边。真如如果没了，眼耳色声当时就坏，我们终于跟动物差不多。

<span id="p-tan-05-243" class="reading-anchor"></span>

文学可以描写性爱吗？可以，文学没有禁区的，看你怎么描写。一种描写，就《查泰莱夫人的情人》，劳伦斯的，多好。还有一种描写，就《金瓶梅》，这完全不同的。所以把自然的东西变成人的东西，属人的东西，那叫美。把人性的东西、佛性的东西拿掉，它就是丑。

<span id="p-tan-05-244" class="reading-anchor"></span>

你看佛教的音乐多好，它不会激起你的欲望，它让你听的是什么？那么地宁静，那么地宏大而又宁静，听过吧？它把你卷进去了，来感受生活吧，以禅宗的境界感受生活，那叫观照世界。

## 在日常生活中修行

**回看 02:20:34—02:22:29**

<span id="p-tan-05-245" class="reading-anchor"></span>

禅宗主张在生活中修行的。不是说我们统统遁入空门，每天做几件事，一吃饭，二睡觉，三打坐，这叫修行。我们在家修行嘛，在家修禅宗。「行亦禅，坐亦禅，语默动静体安然。」禅宗对于中国人太重要了。不是少数修行者选择了这宗派，禅宗是中国思想智慧的一个方面，它进入中国哲学的。

<span id="p-tan-05-246" class="reading-anchor"></span>

我们在座的，有多少人说自己是个标准的佛教徒？受了戒没有？都没有吧，据我知道都没有。但没有，我们就承认我们还在修禅宗，在生活中修。这样我们读《六祖坛经》的意义就来了。不是说一部《六祖坛经》，只交给中国的佛教徒、修禅宗的佛教徒去读的。人民群众的佛经啊。

<span id="p-tan-05-247" class="reading-anchor"></span>

还是修行啊，就是实践禅宗的修行，在日常生活中的修行，跟我们儒家的人生价值目标不背离的。禅宗的修行者，以他自己的方式来实现天下关怀。因为大乘佛教嘛，普度众生嘛，它必有一个对众生的关怀嘛。否则你小乘就可以了，自了汉。

<span id="p-tan-05-248" class="reading-anchor"></span>

既然讲禅宗的境界，就是讲大乘佛教的境界。讲大乘佛教的境界，就是我们人生观的一部分。这人生观不是口上说，惠能教我们如何在实践中、在生活中修了。

## 能分别诸法相，于第一义而不动

**回看 02:22:29—02:24:47**

<span id="p-tan-05-249" class="reading-anchor"></span>

最后一段，「善知识，真如自性起念，六根虽有见闻觉知」。我们确实凭借六根，才能见闻觉知。但是最重要的是什么？「不染万境」。我们六根起用了吧，看到了、听到了、闻到了、摸到了，等等，有见闻觉知。

<span id="p-tan-05-250" class="reading-anchor"></span>

但是有了见闻觉知以后，就怕什么？染万境，染境啊。那消极的办法，是净土宗修行，收摄六根。你至少在念佛的时候，把这个门关起来。这是比较消极的做法。禅宗其实不主张这一点，硬要把它关掉干嘛？能够不为外境所染，靠的是什么？「真性常自在」。

<span id="p-tan-05-251" class="reading-anchor"></span>

「故经云，能善分别诸法相」，我们当然能分别诸法相。你那个是 LV 包，比我这个包名贵得多，质量也好得多，能分别吧？但是我「于第一义而不动」就好了。我的包还是包，这叫第一义。什么叫第一义？不染万境，真性常自在，这就是第一义。

<span id="p-tan-05-252" class="reading-anchor"></span>

这样我们算是把这个第五讲的主要内容讲了，关键是三个「无」，无念为宗，无相为体，无住为本。这三个「无」做到了，即能进入一行三昧。在一行三昧中，便就在定慧中了。好，就讲到这里。
