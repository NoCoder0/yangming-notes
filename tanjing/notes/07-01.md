## 参禅怎样与修行相接

**回看 00:00:00—00:06:56**

<span id="p-tan-07-001" class="reading-anchor"></span>

好，各位，我们这门课程讲禅宗的修行，根据《六祖坛经》来讲。讲修行，为什么还有一件事情叫参禅呢？参禅属于不属于修行呢？参禅不属于修行，但禅宗一个禅字，表明参禅是它必然的、本身包含的一种精神活动。这种精神活动跟修行的关系是什么？

<span id="p-tan-07-002" class="reading-anchor"></span>

禅宗的目标我们一开始就讲了，禅宗修行的根本目标就是觉悟。我们修行长久，那是实践。比方说般若行、无念行，是吧？这就是修行。修行能否达到觉悟，不能保证。有的人修行几十年，始终未能悟啊。所以悟是件根本的事。

<span id="p-tan-07-003" class="reading-anchor"></span>

当然惠能说了，有的人长久地修行不能悟，这涉及人的一种区分：根性是利还是钝。弘忍法师曾经赞扬惠能，是什么？根性大利。一个利字，表明弘忍法师发现惠能是上根之人。他能够不需要很漫长的修行，就能早早地开悟。

<span id="p-tan-07-004" class="reading-anchor"></span>

后来在弘忍法师的指点下，也就是跟他讲《金刚经》，讲到“应无所住而生其心”，惠能言下大悟。这是讲经说法，让惠能悟。这时候的惠能才二十四岁，他一定属于利。那么大多数人呢，是钝。迟钝的钝，不是智商低的意思啊，就慧根浅。

<span id="p-tan-07-005" class="reading-anchor"></span>

那么慧根为什么浅呢？业障太多。有的人业障深重，所以他一定钝，也就是小根之人。那么在禅宗修行的过程当中，总的目标当然是觉悟。但让一个长久修行的人能够觉悟的话，需要一种帮助。这种帮助的活动，就是参禅。

<span id="p-tan-07-006" class="reading-anchor"></span>

我们都听说过，在禅宗修行者当中经常发生的参禅的活动。有时候一个和尚跟你说了一句话，你一时听不懂，因为你把它当日常的语言来理解。不知这话里边藏着什么禅机，那么你听不懂，他那话也就白说了。

<span id="p-tan-07-007" class="reading-anchor"></span>

我们先看一个禅字。在汉字当中，这个字有两种读法。一种是 shàn，禅让，尧帝禅让帝位给舜，那叫禅让。但这个字的另一个读音 chán，实际上是音译，译的是梵文单词 Dhyana。所以一开始译成“禅那”，后来把那字省了。省了以后呢，也就是禅了，一个字。

<span id="p-tan-07-008" class="reading-anchor"></span>

梵文单词 Dhyana，它本意是什么？很难翻译嘛。当然你查佛学大词典，它还是作了一个词义的说明，叫思维修。当然，汉语当中本来也没思维这个词，因为翻译佛经才有。我们现在把思维看成是头脑的活动，不是心里的活动。其实思维本是心里的活动。这里有头脑和心的区分。

<span id="p-tan-07-009" class="reading-anchor"></span>

本心自悟，如何悟？要有机会，那叫缘、机缘。在机缘成熟的时候，通过禅宗祖师的帮助，这帮助就是让他参禅嘛。通过帮助，他可能就悟了。悟，就一下子悟，那叫顿悟，这叫顿悟。不是渐悟吧，不是渐渐地悟出来，没这件事。因为悟无所得，无法积累，所以惠能强调顿悟。要么没悟，要么就悟了，所以它一定是顿悟。

<span id="p-tan-07-010" class="reading-anchor"></span>

顿悟的发生，在大多数情况下，都是参禅带来的。一次参禅成功了，就顿悟。所以可见参禅跟顿悟的关联了。用我们现在的话说，当你的修行积累到一定的份上，你的境界已经不断地提高，是吧，但还没有悟。悟呢，就差一口气。用我们通俗的话说，就差一口气。这差一口气怎么办？禅宗祖师跟我们参禅了，提供了一种可能性。

<span id="p-tan-07-011" class="reading-anchor"></span>

参禅如果成功，顿悟。虽然我们不能说参禅是属于修行的一种方法，但它是一种契机。参禅提供了在修行、渐修的积累上，机缘成熟的时候的一个契机，让某人顿悟。那这点非常重要。假如说我们修禅宗，一开始就想到参禅，那么我们就要找许多参禅的例子，被记载下来。比方说《五灯会元》《景德传灯录》《古尊宿语录》。我们都把这些书打开来看了，看了那么多条参禅的例子，你能悟吗？你没有修行作基础的话，不可能悟。

## 从离相说到破文字执

**回看 00:06:56—00:12:58**

<span id="p-tan-07-012" class="reading-anchor"></span>

参禅的活动，就是抓住那个契机，在以往修行的积累上，抓住那个契机。这个契机是怎么抓住的呢？我们先要了解禅的本意。虽然词典里边解释为思维修，这只是词义的解释，仍然是个名相。意思是什么？惠能讲得清楚，“内见自性不动，名为禅”，“外离相即禅”。

<span id="p-tan-07-013" class="reading-anchor"></span>

至少有这两句话吧。内见自性不动，发现这一点了，外离相即禅。外离相和自性不动，实际上是一回事。你在相中了，在二相之中，你一定动啊。你住了那个相，一定开始趋避了吧。这样自性已经动了。禅的境界，自性不动，离相。问题是相怎么离呢？离相太难。

<span id="p-tan-07-014" class="reading-anchor"></span>

比方说我跟你讲一个道理。讲道理，我不就言说了吗？言说就有语言文字来了吧。语言文字其实也是相，那叫名相。一说“名相”，这个概念、文字概念又上去了。说话难呢。平时我们说话都在相中说嘛，叫相说。你学科学理论也一样，从自然科学到社会科学，每一门科学理论都是一个名相的体系吧。

<span id="p-tan-07-015" class="reading-anchor"></span>

物理学有一系列基本概念，哪一个概念不是名相？拿概念来把握世界、整理世界、言说世界。科学，或西方哲学，而不能算中国哲学啊。中国哲学的经典原著，我们都读过，多少读了一点，里边没有概念推演吧？有定义吗？概念的定义吗？没有。倒是有很高的文学价值呢，充满生动的形象、宏大的境界。

<span id="p-tan-07-016" class="reading-anchor"></span>

中国哲学不能列为用概念把握世界的学说，西方哲学是。从西方哲学中产生出来的西方自然科学和西方社会科学，都是用概念来把握世界。一句话，都在名相中。假如我要跟你讲佛理呢，讲生活的真谛呢，讲这方面的道理，尤其是佛教跟我们讲空理，是吧，你还能讲吗？你一下又落到名相中去了。

<span id="p-tan-07-017" class="reading-anchor"></span>

我们记住，这是一个根本，导致参禅的根本原因。参禅是为了帮助我们悟。妨碍我们悟的两个基本原因，一个是我们自然而然地在生活中趋避，在二相中趋避。还有一个原因是什么？我们趋避的时候，趋利避害、趋得避失的时候，我们还用知识来做这件事。那就是用概念的科学，帮助我们更好地趋利避害。科学就是概念系统。

<span id="p-tan-07-018" class="reading-anchor"></span>

有两大障碍，是吧？我们种种的烦恼障、业障，妨碍我们悟。所以平时要修啊，去除业障，去除烦恼障。但是还有一个障呢，文字障，也妨碍我们悟。因为我们总把我们要说的道理交付给语言，这个道理一旦交付给语言的话，它就在名相中了。而禅就是离相嘛。换句话说，离相，也要离名相吧。离名相，就是离语言文字呢。

<span id="p-tan-07-019" class="reading-anchor"></span>

这一离还能说话吗？但是我们还在说话嘛。道理总是用语言来言说的嘛，但是讲空理怎么办？我们看到了问题所在了，也就了解到为什么禅宗有参禅的活动。在语言文字中又要突破语言文字，用名相说话的同时要突破名相。这是一种多么有意思的事情呢！

<span id="p-tan-07-020" class="reading-anchor"></span>

这种事情就其本身来说，逻辑地看，就是自相矛盾。你用名相来突破名相，是不是这意思？因为你突破了名相，就离相，才能谈得上禅嘛。假定我是禅宗祖师，我跟你说一句话，我说你参。结果你参不了，你思量思量就不中用。思量就是逻辑中的事了，没用了，我等于白说，终于沉默。

## 无尽藏问字

**回看 00:12:58—00:17:30**

<span id="p-tan-07-021" class="reading-anchor"></span>

惠能的一个优势是什么？就不识字。一个不识字的人，他掌握的概念实在太少了。《机缘品》一开头讲了一段。当然这个事情其实发生在惠能找到弘忍法师之前，但现在把它移到了什么时候？移到悟了之后：惠能在弘忍法师那里得了衣钵，再遇到无尽藏。这不符合史实啊，但不管怎么样，《坛经》这么安排的，就安排了。

<span id="p-tan-07-022" class="reading-anchor"></span>

按照史实是什么？惠能从广东赶往湖北，一路上寄宿在别人家里。有一次寄宿在一个叫刘志略的家里。刘志略家里有一个在家修行的姑妈，法号无尽藏，两个人有个对话吧。后来我想，《坛经》把这一段故事放在《机缘品》一开头，真有道理。

<span id="p-tan-07-023" class="reading-anchor"></span>

我们先看这一段。师，也就是惠能。惠能这时候已经被称为师了，可见时间上有差错了。按照史实，这时候他还没有找到弘忍法师，但这里把他说成已得了黄梅的衣法了吧。“师自黄梅得法”，也就从弘忍法师那里得了法。“回至韶州”，已经到广东了，“韶州曹侯村，人无知者”。

<span id="p-tan-07-024" class="reading-anchor"></span>

有一位儒士叫刘志略，非常好地招待惠能，“礼遇甚厚”。刘志略有一个姑妈为尼，“名无尽藏，常诵《大涅槃经》”。无尽藏在那里诵，惠能就在边上听。“师暂听即知妙义，遂为解说。尼乃执卷问字。”惠能怎么回答？“字即不识，义即请问。”

<span id="p-tan-07-025" class="reading-anchor"></span>

这个无尽藏非常惊讶，“字尚不识，焉能会义？”惠能又来一句，“诸佛妙理，非关文字”。这句话一说出来，应该说是震动了无尽藏了。所以跟乡里的人说了，“遍告里中耆德”，年长的、有威望的人。告诉他们，你们知道吗？这里有一个得道的人啊，应该供养他。

<span id="p-tan-07-026" class="reading-anchor"></span>

这个故事就这么一段。按照史实，当初确实是想要供养他。但惠能想，我尚未找到弘忍法师，我还没悟，我还没得了佛法呢，怎么在这里能够停留呢？这一段放在《机缘品》开头，意味着什么？意味着《机缘品》讲参禅的事了。参禅的前提就是破文字执，所以放在开头作为一个 preface，作为一个序，非常好。

<span id="p-tan-07-027" class="reading-anchor"></span>

底下你读《机缘品》下面的十二条机缘，你都要记得破文字执，否则你读不懂。破名相，但又在文字中破，文字本就是名相。还是那句话，难。用名相破名相，这如何可能？妙就妙在这里。为什么要以名相破名相？因为要讲的那个道理是什么道理？空理。清楚了，禅宗为什么会参禅？参禅就是以名相破名相，为了讲那个简直无法讲的空理。

## 语言的澄明和遮蔽

**回看 00:17:30—00:23:37**

<span id="p-tan-07-028" class="reading-anchor"></span>

后来国外的人，包括欧洲人，也知道中国的禅宗了。参禅呢，参禅以后能悟，能与空契合，这是何等的智慧。所以上世纪六十年代，我们中国还是对外封闭的。但日本有禅宗大师，许多美国人、洋人，都到日本去了，围着日本的禅宗大和尚干嘛？参禅。多少年流连，基本上都失败了。以名相破名相。

<span id="p-tan-07-029" class="reading-anchor"></span>

后来也有人懂，二十世纪德国一位了不起的哲学家就是海德格尔。他就说语言了吧，语言是人存在的家，人以语言之家为家。但是他同时又说什么？语言是什么？存在的既澄明又遮蔽的到来。存在通过语言被保存了，被领会了。语言是存在的既澄明又遮蔽的到来。

<span id="p-tan-07-030" class="reading-anchor"></span>

海德格尔讲“思”，他正确地把握了思。这个思，不是我们今天在逻辑学和认识论里讲的、以范畴作单位的思维。我们现在讲思维，都是在逻辑中，是范畴思维、概念思维。其实思的本意是什么？铭记和感谢存在。思把对存在的领会托付给语言，语言成了思对存在的供奉。

<span id="p-tan-07-031" class="reading-anchor"></span>

这都是海德格尔说的话。我读到这些话，发现他懂禅宗了。我们能思存在者。对存在者的思，就是概念、范畴规定就来了。这是桌子，桌子是人工产品，物质的人工产品，然后物质又来了吧，范畴。对存在者的指认，全在范畴、概念里面。

<span id="p-tan-07-032" class="reading-anchor"></span>

存在本身呢，它不是范畴所能表达的、概念所能把握的。概念能把握一个存在者，或国家，或桌子。存在本身的领会，存在就是领会空，这是同一件事。因为人知道自己必有一死，人就领会了存在，死就是虚无啊。是不是同一件事？思就其原始的、本来的含义，就是思存在，而不是思存在者。

<span id="p-tan-07-033" class="reading-anchor"></span>

思如果变成理性的运用，就变成对存在者的思了，那叫概念来了。或者换句话说，名相来了。海德格尔后来非常感慨地说了一句话：“思想迄今为止最大的敌人是理性。”我们都听不懂，经过西方近代哲学修养熏陶的都听不懂。

<span id="p-tan-07-034" class="reading-anchor"></span>

我一开始也听不懂。我读康德、黑格尔的近代哲学，理性形而上学，范畴，把握世界，怎么听得懂？后来才明白，我们通过理性，这种逻辑的思、概念的思，把握住存在者，遗忘了存在本身。而禅宗让我们修，最终要悟。悟就是对虚无的领会吧，同时也就是对存在本身的领会。

<span id="p-tan-07-035" class="reading-anchor"></span>

所以怎么说话成了一个问题。我们日常的言说，都在稳定着、固定着、加固着对事物的概念把握，而每一次都在遗忘存在。那么你就不可能悟，你就在知识中了。禅境就是离相之境，离一切相，当然也包括离名相。我们的名相一直在巩固着二相，善与恶，好与坏，是不是二相？善恶是不是名相？

<span id="p-tan-07-036" class="reading-anchor"></span>

人类很尴尬。人类有语言是了不起的，是吧？因为有语言，才有个世界。基督教《圣经》讲得好啊，上帝造人，用泥土造的，造出来的是人的形体，还不是人。对这个形体吹一口气，人成功了。为什么？吹一口气，就是让他有了语言，于是人成功了。为什么？我们有语言便有了世界。动物是没世界的，动物只是被放置在一个狭窄的物质环境里了。

<span id="p-tan-07-037" class="reading-anchor"></span>

人却有一个世界，大地山川、星辰河流向人呈现了，这就是个世界向我们呈现。因为我们在语言中嘛，很伟大，了不起。然后呢，我们就把这世界固守为诸存在者之总和。然后《金刚经》怎么说？“如来说世界，即非世界”，然后才说“是名世界”。这就是《金刚经》中著名的三句义。

## 妻子、月亮与杯子

**回看 00:23:37—00:27:29**

<span id="p-tan-07-038" class="reading-anchor"></span>

为什么有三句义？以名相破名相。“如来说世界”，我们都承认有一个世界存在，然后马上要说它其实是相。“即非世界”，不是破了前面第一句话的世界吗？第一句话的世界，就作为名相的世界。但我们不知道，把它当真了，它是相啊。即非世界，它不是相，然后你再去领会什么叫世界吧，是名世界。

<span id="p-tan-07-039" class="reading-anchor"></span>

她是我妻子，即非我妻子，所以是我的妻子。想想看，有道理吧？有道理。你领会空吧，然后你才跟你妻子很好地相处了。你说第二句话，即非我的妻子，就准备离婚的意思了？只是把一个作为名相的妻子否定掉，破了。否则不破，不好。你希望她是个标准的妻子，没有，那是个名相。天下有标准的妻子吗？概念让事物标准化了，对不对？破。

<span id="p-tan-07-040" class="reading-anchor"></span>

然后还承认它存在。这个存在，在与你的关系中了，而不是一个你正好获得的存在者。妻子和丈夫是交互性关系。不是先有一个妻子在这，也有一个丈夫在这，然后他们结合为夫妻。有这种事吗？这种交互性关系叫啥？一个字，缘。我作为丈夫，你作为妻子，是这个缘生出来的，从这个缘里生出来的，哪是个现成的存在者？

<span id="p-tan-07-041" class="reading-anchor"></span>

月亮是个现成的存在者吗？从来不是。它以几种不同的方式处在与我们人类的关系中。一种叫什么？嫦娥居住的地方，是思念家乡的象征，神话中的一个东西。所以我们今天仍然过中秋节。它以另外一种关系跟人相关了，那叫地球的卫星，天文学。你把这些都拿掉，有月亮吗？没有月亮的。一切皆是缘起。佛学真有道理，不要在缘起之前，先讲那些东西自身存在着。

<span id="p-tan-07-042" class="reading-anchor"></span>

这是个杯子，喝水了。假如我此刻要抽烟呢，把烟灰一弹进去了，它叫 ashtray，烟缸。我跟它有不同的缘呢，不同的缘，让它成为不同的东西。此刻是杯子，等一会儿烟缸。所以名相会把事物的意义加以固定，于是空理我们不能发现，不能领会。我们就活在相中了。

## “甚么物，恁么来”

**回看 00:27:29—00:31:50**

<span id="p-tan-07-043" class="reading-anchor"></span>

那么打破名相对我们的束缚，需要参禅。参禅提供了我们顿悟的契机。你有那份幸运，可以跟禅宗祖师、大德高僧交流和对话，你得抓住这个契机。当然要有准备啊，这准备就是你先前修出来的。你当然先开悟了。开悟了嘛，就向往佛学了嘛。没有开悟，人家读佛经，你觉得莫名其妙嘛。你开悟了，你也去读佛经，这就是渐修。

<span id="p-tan-07-044" class="reading-anchor"></span>

修吧，修到差不多了，我王德峰就去找惠能。假定惠能尚未圆寂。那么他接见我了，一定跟我说话了。我是有备而去的啊。第一句话：“甚么物？”什么东西？第二句话：“恁么来？”你怎么来的？我是有备而来的，我知道他叫我参话头啊。那叫参禅来了。

<span id="p-tan-07-045" class="reading-anchor"></span>

假如我没有这个准备，我会怎么回答？“复旦教授，坐飞机来。”完了，完了。你去见谁啊？你为什么去见他？你要去抓住一个契机呀，他说不定就让你悟了嘛。那么他跟你说话，你能当一般的话来想吗？你准备过的，我怎么好说，甚么物，复旦教授，恁么来，坐飞机来？这不可以的。

<span id="p-tan-07-046" class="reading-anchor"></span>

我是有备而去的。他说“甚么物恁么来”，我应声回答，不是东西，没来，对了吗？参禅就开始了，底下还继续啊，《机缘品》里有。好，总而言之，我们知道何为禅境，离相之境。因为离相，我们领悟空。领悟空，进入实性，实性即佛性。不二之性，名为实性。

<span id="p-tan-07-047" class="reading-anchor"></span>

《机缘品》，一个机字，一个缘字，各有意思。机是什么呢？对话双方都抓住对方的特征，那叫机。所以中国人那句话说得好啊，话不投机半句多。我知道你的根本特征，你也知道我的根本特征，说话就对机了。你一句话来，我接了，叫接机。我一句话回给你，对准你的特征，准确而锋利，那叫机锋。

<span id="p-tan-07-048" class="reading-anchor"></span>

缘，就是条件、场合，形成某种事情的场合、跟这件事情有关的场合，这叫缘。禅宗祖师有本事的，他知道这个场合最能让你悟，因为你遇到这种事情了。悟缘成熟，所以我就抓住这个契机了。禅宗祖师在帮我们，很不容易。要让一个人悟，多难。要让一个人长知识，很容易的。

<span id="p-tan-07-049" class="reading-anchor"></span>

从第七品开始，不是法会，是什么？是惠能来接引前来参悟佛法的人。抓住了机，抓住了缘，让他人悟，所以叫《机缘品》。我们这些小根之人，当然也是善知识，只是不是大善知识。善知识总是要佛教的大德高僧的帮助，他们叫大善知识。

## 吹灭一盏灯

**回看 00:31:50—00:35:14**

<span id="p-tan-07-050" class="reading-anchor"></span>

其他宗派也有帮助。天台宗的祖师、大德高僧，净土宗也有大德高僧，都可以启发修净土宗的或修天台宗的人。他们启发人的方法，跟禅宗不一样。禅宗的特征是什么？跟你对话，对话为主。有时候不对话，不说话，一个动作，关键时候一个动作。

<span id="p-tan-07-051" class="reading-anchor"></span>

某僧人路途迢迢地到那个寺庙里拜访，参见那位禅宗祖师。已经傍晚了，禅宗祖师拒而不见，他破门而入。禅宗祖师说：“我这里没东西给你，你走吧。”连挂单都不让他挂，外面已经漆黑了，天黑下来了。这座庙在山上的，你怎么走啊，那个人怎么走啊？没办法，只能走了。

<span id="p-tan-07-052" class="reading-anchor"></span>

刚走出几步，又回过身来，跟这个禅宗祖师讲：“请求你给我一盏灯。”那个禅宗祖师也没说话，去拿了一盏灯，点燃的灯，交给他了，当然是煤油灯啊。刚交到他手里，马上这个禅宗祖师就把这灯吹灭了。没说话，就一个动作。你不是要灯吗？我给你了。全是动作嘛，吹灭它。

<span id="p-tan-07-053" class="reading-anchor"></span>

就因为吹灭这一刻，这僧人悟了。这也是种方法。因为大家都在这个场合里边，你禅宗祖师明明知道天黑了，我这个山路已经没办法走了，我向你求一盏灯总可以吧？对的，你是来求灯的，我给你。怎么给你啊？把这个物理意义上的灯吹灭了，灯就给你了，明白吧？我给了你灯，我把它吹灭了给你。

<span id="p-tan-07-054" class="reading-anchor"></span>

谁点燃这盏灯？你自己。你的心立刻悟。当然，这僧人本来也是有备而来的吧，他是修过的嘛，只是就差最后一口气嘛。你在生活中若遇到这样的高人，你的福气。你自己修了好多年了，没用，但也是种积累，就等那个契机。

<span id="p-tan-07-055" class="reading-anchor"></span>

我们需要帮助，经过帮助，我们自性自度。这盏灯就在我心里了。其实你帮我点燃了它，但你让我觉得是我自己点燃了它。你给我的灯，倒是要吹灭的。想想吧，这样的故事，《五灯会元》里记载着的。各位买来看，基本上看不懂啊，就这个意思。

## 棋里的禅机和山水画的留白

**回看 00:35:14—00:40:52**

<span id="p-tan-07-056" class="reading-anchor"></span>

所以参禅就是我们跟禅宗祖师的对话。禅宗祖师彼此也就很少说话了，说两句话也是闹着玩。为什么？他们都已经是悟了的人。如果高兴，也说两句。我一句话给你一个禅机给你，你呢立刻微笑，回了我一个。很开心，就像下棋一样玩玩，对吧？这他们的境界，我们可下不了这棋啊。他棋走了一步，后面有东西埋伏着呢，你知道吗？

<span id="p-tan-07-057" class="reading-anchor"></span>

当头炮，马来跳，你就会这个东西。下棋都下出禅机来，还有围棋。后来禅宗思想还影响了围棋高手呢，影响绘画。你画一幅山水画，山画出来了吧，水也画出来了。它是让你看山和水吗？它是让你看没画到的那地方。里边才意蕴丰富呢。写实为了写虚啊，这叫虚实相生。以实写实，那个景物就是死的。以实写虚，那景物是活的。活的地方在哪里？就没着笔的地方。

<span id="p-tan-07-058" class="reading-anchor"></span>

你们欣赏过这样的山水画吗？有的画画得很美，你永远走不进去的。它全是实，就是一张照片，精美的照片。中国流传下来的那些古代的文人画的山水画，石涛的，你去看看。你看着看着就进去了嘛。因为每一个对实景的描写，都是什么？存在的既澄明又遮蔽的到来。

<span id="p-tan-07-059" class="reading-anchor"></span>

然后你以实写虚，那真澄明了。你只看着景物本身，那叫遮蔽。你画了山，你遮蔽了山。你画出山之外的境界来，这山才是活的，你让它澄明了。这就是中国道家思想和佛家思想的结合。

<span id="p-tan-07-060" class="reading-anchor"></span>

中国美术，中国的水墨画，没有道家思想、道家的精神，没有那么多伟大的作品。若只靠儒家，我们基本上是以什么？寓教于乐，对？这个艺术作品起了道德教化的作用。但道家不是讲道德，讲天地境界的。然后又来了佛家，禅宗那个参禅，让空理呈现。你看跟道家多么契合。

<span id="p-tan-07-061" class="reading-anchor"></span>

什么叫以实写虚啊？化景物为情思，多少生命感受。在这些伟大的绘画作品当中，凡是没着笔处，全是你可以寄托处。画一个景物，也是寄兴写情，是把情思展现出来。这个情思，人类生命情感的体验、感受，其实是无法用语言表达的。若能表达，一定是首很好的诗。

<span id="p-tan-07-062" class="reading-anchor"></span>

再看绘画，中国绘画的成就很高。你欣赏一幅绘画作品，无论它是静物写生画，还是山水画，都是在写实中感受到虚的部分。而这虚的一面，就是情思洋溢的地方。这个艺术家本人就这样的，“登山则情满于山，观海则意溢于海”。于是你把山画出来吧，把海画出来吧，这一画就画出了情思，这是虚的，虚的才是存在的澄明。

<span id="p-tan-07-063" class="reading-anchor"></span>

修佛一样，当我们领会到空、领会到虚无的时候，我们不是头脑在理解空啊。头脑怎么可能理解空呢？头脑能理解的，全是实的东西啊。空不是头脑去理解的，头脑一旦起作用，概念、判断、推理、逻辑、范畴全来。空是心灵的领会，它是一种最深切的情感。这种情感之大，无与伦比。

<span id="p-tan-07-064" class="reading-anchor"></span>

所以当悟的时候，不免悲泣，流下泪来。法达就这样，那第二个机缘。这叫情思起来，这叫灵魂深处的革命。心灵是情感的居所，它革命了。所以我们不要学佛学到后来，读读佛经弄到最后，还变成理解的事情。所以禅宗讲破文字执嘛，这第一个序言就是破文字执。“诸佛妙理，非关文字。”

## 勃拉姆斯和孤独的心灵

**回看 00:40:52—00:46:07**

<span id="p-tan-07-065" class="reading-anchor"></span>

诸佛妙理在哪里？在生活中，在生活最根本的情感中。对空的领会、对虚无的体验，那是最深刻的情感。我们可曾体会过虚无啊？我们一无遮掩地、毫无依傍地，面对这个空吧。不要以为在人生的大海上，我们有什么救命稻草可依靠的。富也罢，贵也罢，我们仍然在这人生的海洋上沉沉浮浮。

<span id="p-tan-07-066" class="reading-anchor"></span>

你拉住你的富，拉住你的贵，它只是救命稻草，救得了命吗？救不了。经过了一番折腾之后，从内心深处发出了人生的浩叹。有时候它叹为一部了不起的交响曲，《勃拉姆斯第四交响曲》。勃拉姆斯的音乐，我认为要四十岁之后才听得懂。它并不那么优美动听，你感到周遭的一切都是寒冷的，在一片的寒冷之中透出丝丝的温暖来。这就是勃拉姆斯的交响曲。

<span id="p-tan-07-067" class="reading-anchor"></span>

一个人不到四十几岁，是听不懂的。我获得一个契机是什么呢？我正在读海德格尔的《存在与时间》，那段时间我又正在听《勃拉姆斯第四交响曲》，契合了。所以我回答年轻的朋友提问嘛，哲学和音乐的关系嘛，我就举了这个例子。《勃拉姆斯第四交响曲》第二乐章，慢板乐章的第二主题，你去听。

<span id="p-tan-07-068" class="reading-anchor"></span>

这是大悲悯，弥漫一切，你就在之中。不是“在其中”，“在其中”是在空间中；是“在之中”，在这个境界之中。勃拉姆斯会怎么说明，我们不知道，反正他说了也不算数。他创作出来的，属于我们大家。这作品有独立的生命。它有一种佛家般的悲天悯人。

<span id="p-tan-07-069" class="reading-anchor"></span>

就如王国维评价南唐后主李煜，做了亡国之君之后所作的词，不是道个人身世之悲戚。他说那些词是什么？仿佛耶稣、释迦担荷人类之罪恶。你去看《人间词话》，王国维的。所以参禅吧，透破存在者的遮蔽，换句话说，透过一切名相的遮蔽，去领会那空吧。空不是什么都没有，去领会这个人生、这个世界之本体。

<span id="p-tan-07-070" class="reading-anchor"></span>

我们都在相中生活，我们把这个心叫回来。在西方近代音乐，也就是我们通常说的古典音乐的伟大的宝库中，越是伟大的音乐作品，它越是属于什么？孤独的心灵。你不孤独，你听不懂。因为你在外面忙着呢，你怎么听得懂呢？觉得好听就可以了。

<span id="p-tan-07-071" class="reading-anchor"></span>

那么好听嘛？约翰·施特劳斯音乐够好听的了，能跟贝多芬比吗？能跟勃拉姆斯比吗？没办法比的。但是你不喜欢勃拉姆斯，因为你心在外面忙。什么情况下你孤独了？你被现实逼回来了。你在现实中走投无路、到处碰壁，于是你的心就是那颗孤独的心了。这时候你恰逢一部伟大的音乐作品，你在这部音乐作品中发现了自己。

<span id="p-tan-07-072" class="reading-anchor"></span>

在什么时候我们读佛经，产生重大的效果？就是你孤独了。这些年来，中国有许多人自觉地去学佛，这个队伍越来越大，居士越来越热闹，这个队伍正在壮大。寺庙里的和尚看到居士，还在恭恭敬敬的。有一个和尚跟我讲，他说，将来很快地，中国佛教成了居士佛教。

<span id="p-tan-07-073" class="reading-anchor"></span>

那我说肯定有道理的，因为你们老早遁入空门了，没啥事情。外面的人事情多了，终于逼回来了。逼回来嘛，找到佛教了呀，就这件事。他若有所思，肯定是这么回事。所以我们就大概把参禅这件事说了。当我们人生经历的积累，以及修行的努力，达到一定的境界，就差最后一个契机。

## 宝林寺和避难石

**回看 00:46:07—00:47:54**

<span id="p-tan-07-074" class="reading-anchor"></span>

由此我们才可以去读《机缘品》。前面有一部分，我称为序言，就是跟无尽藏的对话，是吧？说了那句话，“诸佛妙理，非关文字”。后面又有两段，是讲当时惠能得了衣钵，是吧？回广东了。

<span id="p-tan-07-075" class="reading-anchor"></span>
