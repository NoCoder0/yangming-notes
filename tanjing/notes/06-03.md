## 心灵的家与皈依

**回看 01:06:28—01:09:22**

<span id="p-tan-06-118" class="reading-anchor"></span>

我们讲第六品《忏悔品》，重点讲皈依。为什么重点是皈依呢？我们知道儒家在起步的时候，通过了孔子，抓住了人生问题的核心和根本，就是我们如何安心立命。孔子发现夏商周三代人民生活，到了东周末年，天下大乱。出了大问题的根源，在孔子看来是什么？中国人内心无家。

<span id="p-tan-06-119" class="reading-anchor"></span>

虽然周礼非常完备。孔子主张恢复周礼的。如此完备的道德规则和制度，为什么终于不被遵守了呢？为什么会礼崩乐坏呢？孔子发现的问题是，根本病症在于我们中国人心灵没有家。血缘关系的家向来有，血缘关系的家未必是心灵的家。

<span id="p-tan-06-120" class="reading-anchor"></span>

于是，孔子论道提出的第一个观念，也是整个儒家的核心观念，就是仁，一个仁字。仁不是头脑中的东西，是心里的东西，或者说就是本真的生命情感，就是个仁。如果我们背离了本真的生命情感，我们会心不安。

<span id="p-tan-06-121" class="reading-anchor"></span>

孔子还有一句话这么说，“不仁者不可以久处约，不可以长处乐”。所谓不仁者，就心没安顿好的人。人生无常，那么儒家、道家都发现，佛家更强调，“诸行无常，是生灭法”。但是我们的心要有常。在儒家看来，这个有常的心就是本心、仁体，叫仁之常体。这个常就是针对无常而言。

<span id="p-tan-06-122" class="reading-anchor"></span>

儒家如此，佛家也如此，尤其是禅宗，尤其强调心灵的家。心灵的家叫心舍，我们的心有家，这心灵的家叫心舍，要安住吧。安住心舍，也是安心立命的意思。那么心灵的家是怎样的家？禅宗有它的说明。所以《忏悔品》就讲这件事。换句话说，我们为什么会心不安呢？要问这个问题。

## 自性五分法身香

**回看 01:09:22—01:15:16**

<span id="p-tan-06-123" class="reading-anchor"></span>

这场法会一开始，说“时”，就当时了。“大师”，也就惠能，“见广韶洎四方士庶，骈集山中听法”，听法的人很多，“于是升座告众曰，来，诸善知识”。都来吧。“此事须从自性中起。”此事是件什么事？就修行。佛家的修行要从哪里起来？从自性中起，这是原则，不离自性。

<span id="p-tan-06-124" class="reading-anchor"></span>

“于一切时，念念自净其心，自修其行，见自己法身，见自心佛，自度自戒，始得不假到此。”还是把一个基本的原则说了一遍，就每个人本有佛性。关键是我们要明心见性。明心，就自净其心，把妄念去掉。见自己的心体，叫法身。见自心佛，自度自戒。

<span id="p-tan-06-125" class="reading-anchor"></span>

惠能在别的地方说，不是我能度你们，你们自性自度。确立这一条原则，你们才不是白白到这里来。我没有现成的真理颁布给你们，我也不是个救世主。你们先明白这个道理。来吧，你们每个人都要自修自行的，我是不能代你们修、代你们度，你们自度。

<span id="p-tan-06-126" class="reading-anchor"></span>

这个原则讲完之后，底下就说今天的法会的主题了。我们因为都有缘故，所以才聚集在这里了。各各胡跪。所谓胡跪，就是从印度那里形成的一个礼节，单膝跪地，偏袒右肩。这叫胡跪。“众胡跪”。底下惠能说，首先要传给你们的是五分香，五分香。这就传香了。

<span id="p-tan-06-127" class="reading-anchor"></span>

佛家各个宗派都要传香，无论你在哪一个宗派里边修行，这一点都一样。就像我们到寺庙里要上香。上香的真正含义是什么？我们现在把它看成是先表达了对佛和菩萨的敬重。我们上香、敬香，这是有求于佛、有求于菩萨的意思。我们带着这种求去了，天下那么多善男信女，总是如此吧。

<span id="p-tan-06-128" class="reading-anchor"></span>

每逢节日的时候，尤其是中国传统节日，许多大的寺庙里边，香火很旺。到年初一嘛，还要烧头香的，烧头香祈福啊。祈求佛和菩萨给我们保佑，给我们福气，最重要的福气是财多。当然另外到了年初五呢，另外求一求，求道教的，那叫财神。先求了佛和菩萨。年初五请财神来，财神是忙不过来的。

<span id="p-tan-06-129" class="reading-anchor"></span>

中国人很实际的。非常现实，是我们民族的一个优点。每每优点的另一面就是缺点，更关注世俗的幸福，遗忘了灵魂的问题。这确实要承认，有一个短处。因为我们没有上帝管人心，也不是穆斯林，有真主管人心。都没有的，心就先放在边上再说。咱需要现实的生活中的福气，这中国人。

<span id="p-tan-06-130" class="reading-anchor"></span>

然后惠能开始说了这个修行的功课，五个环节。第一个环节就是传香，第二个环节是忏悔，第三个环节是什么？发愿。第四个环节是皈依，第五个环节就是成佛。五个环节，传香、忏悔、发愿、皈依、成佛。惠能从禅宗的基本原则出发，这个基本原则，就是不离自性，不落两边。

说佛法的时候，两个原则，不离自性说佛法，也就是说，不是相说。

## 戒香、定香、慧香、解脱香

**回看 01:15:16—01:21:39**

<span id="p-tan-06-131" class="reading-anchor"></span>

比方说传香。传香是不是为了仅仅表达对佛和菩萨的敬重呢，和某种祈求呢？不，惠能说这个香叫自性五分法身香，不离自性吧。这五分香，通常我们都知道的是三分香。上香，三支香吧，三支香就戒定慧，戒香、定香、慧香。惠能在后面还加了两个，解脱香和解脱知见香。

<span id="p-tan-06-132" class="reading-anchor"></span>

惠能对五分香的说明，说得非常明了。第一分香，上去了是为了什么？戒。什么叫戒？就像我们在《疑问品》里知道了，这个戒就是戒轻视他人。那么轻视他人一定来自人我别，是不是人我别？每个人把自我看得十分重要，拿出来跟别人比，每每要轻视他人。

<span id="p-tan-06-133" class="reading-anchor"></span>

如果我们不轻视他人，是因为我们把人我别去掉了，把我执去掉了。把我执去掉，就是“自心中，无非、无恶、无嫉妒、无贪嗔、无劫害”。这就叫戒了，不是相说的戒。相说的戒，当然要戒酒、戒肉、戒偷盗、戒杀生、戒邪淫等等。这是相说。

<span id="p-tan-06-134" class="reading-anchor"></span>

一开始你跟着相说走，也是必要的修行吧，提醒自己。当然有些是做不到，比如说戒酒，许多人就做不到，我也做不到。这是相说。所以根本的戒，就是自心中无非无恶。非、恶、嫉妒、贪嗔、劫害，都来自人我别。把人我别去掉，这是第一分香。

<span id="p-tan-06-135" class="reading-anchor"></span>

第二分香，什么是定？见境心不乱。见境心不乱，为什么能作得到？不于境上生心。你看到的全是相，种种的境啊，善境也罢，恶境也罢，其实都是相。你明白这一点，自心不乱。你看到的是诸善恶境相，你要知道这是相，自心就不乱了吧。这叫定。

<span id="p-tan-06-136" class="reading-anchor"></span>

慧香。慧是定之用，在定中我们自然有慧。惠能对这个慧作了描述，是“自心无碍，常以智慧观照自性，不造诸恶”。看来慧是实践的。定是种精神状态，在这精神状态中，一定有慧之实践，智慧的实践。你在智慧的实践中，你自然不造恶。当然你会行善。众善奉行，但心不执着，我正在行善呢，那就住相了。

<span id="p-tan-06-137" class="reading-anchor"></span>

心不执着，自然而然地能做到什么？敬上念下，矜恤孤贫，这是很自然的。你恤孤贫，叫布施吧。无住相布施，那就是慧。这是戒定慧三分香。

<span id="p-tan-06-138" class="reading-anchor"></span>

第四分香，解脱，指出了修行的目标。解脱，就是从二相中得解脱。最根本的二相，是生死二相。如果生死二相你都能解脱，其他的二相全能解脱。生死二相的解脱达到了，便自然进入涅槃境界。那不就是佛吗？佛就是解脱的意思。我们如果能离二相，我们就是佛，佛也没那么神秘。佛的境界，不要想象得那么高妙。

<span id="p-tan-06-139" class="reading-anchor"></span>

我们在生活中时时地离二相，我们就时时地佛性呈现，就是解脱。我们随时解脱，这分香就要进来，上这分香了。“即自心无所攀缘”，我们不是攀缘，我们随缘。“不思善，不思恶”，就离了二相了吧。“自在无碍。”既然是解脱，当然自在无碍，不受束缚了嘛。

<span id="p-tan-06-140" class="reading-anchor"></span>

束缚我们的就是二相，利与害，高与低，贵与贱，富与贫，乐与苦，种种之二相。我们被这些二相始终束缚住了。我们得一个解脱吧。那个僧人问那个禅宗祖师，如何是解脱？禅宗祖师回答说，谁缚汝？谁把你束缚住了？你的心嘛。

<span id="p-tan-06-141" class="reading-anchor"></span>

你的心为什么束缚了你？因为你的心在二相中。离了二相，你就在自本心中吧。既然在自本心中，你会趋利避害吗？不断趋避吗？趋避就是攀缘。所以我们总不得自在啊，我们总被束缚住啊。所以第四分香要上的，提醒自己，不要被二相束缚了。

## 信解行证的第一步

**回看 01:21:39—01:27:27**

<span id="p-tan-06-142" class="reading-anchor"></span>

什么叫传香？树立修行的信心，就这个意思，起信念。传香、上香，就是起信念的意思。佛家修行，所有宗派都会说四个字的，“信解行证”。信解行证，第一步就是信。解就是解悟佛法，行就是实践、修行，最后要实证。信解行证，第一步就是信。别看这一步，不容易。

<span id="p-tan-06-143" class="reading-anchor"></span>

我们处在这样一个时代，就资本、科学、技术的时代，我们很难信佛学。佛学讲的许多道理，我们说你拿出证据来。比方说三世因果，拿出证据来。你向佛教要证据，你希望佛教成为科学，但它不是科学。尤其是知识多的人，最难起信心，他很难信。

<span id="p-tan-06-144" class="reading-anchor"></span>

我小时候读中学了，后来看我母亲天天还在那里诵经。我说：“你诵的经文，你知道什么意思吗？”她说：“我不知道。”我说：“你不知道，你诵什么诵呢？你总讲点道理给我听听吧。”

<span id="p-tan-06-145" class="reading-anchor"></span>

我父亲在边上，很认真、很严肃地跟我讲：你以为你母亲没多少知识文化，你就觉得她诵经是很莫名其妙的事。要懂了嘛，再去诵。你错了。我父亲跟我讲，你错了，你不如你母亲的地方，就是你没有信，她有信，那个信念在。

<span id="p-tan-06-146" class="reading-anchor"></span>

我当时不以为然，后来读哲学了，也了解了解佛学，才知道我父亲说对了。自己学了点科学，在中学里就自以为是。凡事都要论证一下。很有道理啊，看上去。这样要求论证、要求科学论证，要认为知识才是唯一的真理，别的都要通过知识来证明，错了。所以让一个科学学得很多的人去信佛学，很难。

<span id="p-tan-06-147" class="reading-anchor"></span>

佛学不是哲学，但可以把它融入哲学。因为它的思想层面、思想境界很高，中国哲学做了这件事。但是对于一个修行者来说，它不是一个学问，它是一个信念，或者说信仰。当然没有神，有神的信仰叫宗教信仰，它是无神论的。佛和菩萨都是真实的人，是觉悟了的。这一点，它不是神学，佛学不是神学。

<span id="p-tan-06-148" class="reading-anchor"></span>

但也不是哲学，但有哲学思想。对修行者来说，不是把它作为哲学来研究的，而是解决自己人生的根本问题，安心立命。安心立命是信仰的问题。我们无法在物理学当中，在经济学和金融学、法学中安心立命吧。各位同意吗？

<span id="p-tan-06-149" class="reading-anchor"></span>

你有那么多经济学知识，有那么多法学的知识，你那么多物理学的知识、化学的知识，你能在这些科学知识中找到安心立命的根本吗？科学能给我们精神家园吗？不能。我们建构自己的精神家园的第一步，就是信。它是超出科学知识范围之外的，我们心灵的需要。

<span id="p-tan-06-150" class="reading-anchor"></span>

那么坚持科学理性的人会质疑这一点，你们盲信，盲目的信仰，一切信仰都要用理性来审视一遍，看它站得住脚吗。通常我们这么想，这叫科学主义。我们绝不反对科学，科学对人类生活太重要了。

<span id="p-tan-06-151" class="reading-anchor"></span>

科学带来了人对自然界的极大的自由，这点同意，这是进步。但是不要采取科学主义的态度。采取科学主义的态度，你认为人世间的真理全在科学里边，把科学跟真理划等号了吧。殊不知什么叫真理，它不是知识。

<span id="p-tan-06-152" class="reading-anchor"></span>

真理是对命运的领会，和对未来的筹划和决断，那叫真理。我们凭借知识能筹划未来吗？我们在科学中能领会我们民族的命运吗？或者人类的命运，或者个人的命运。命运终于被我们领会了，那是经历过人生之后了。

## 弄堂里的孤老太怎样起信

**回看 01:27:27—01:29:46**

<span id="p-tan-06-153" class="reading-anchor"></span>

我后来才明白了，为什么我小时候生活的那个弄堂里，有许多没文化的，或者文化很少、知识很少的人，那么虔诚地信仰了佛教。我曾经举过例子，就我们弄堂里那个净土宗的修行者，孤老，一个孤老。她为什么信了佛教呢？

<span id="p-tan-06-154" class="reading-anchor"></span>

她的人生经历是最伟大的教育家。她遭逢过的一切，都无法用理性来说明的，没道理好讲。她就经历了这一切，她终于明白了，对世界采取另外一个态度。别以为我们所看到的世界，全是唯一真实的东西。我们在其中受苦受难，总要有个道理来说明。科学无法给我们说明这个道理。

<span id="p-tan-06-155" class="reading-anchor"></span>

于是她就相信了佛，相信了释迦牟尼佛，相信了阿弥陀佛。只有阿弥陀佛才能让我心安了。然后我有个最真诚的向往，到西方净土去。这个信起来了，生活让她起来的，不是灌输给她的，她也没去听课啊。

<span id="p-tan-06-156" class="reading-anchor"></span>

我们弄堂里这位孤老太，不识字的，几十年修净土宗的。她不是到学校里学了佛学的课，回来怎么做的。根本没有去过。她就听说了佛教，越听越有道理。因为当时佛教在中国民间也是蛮普及的嘛。

<span id="p-tan-06-157" class="reading-anchor"></span>

有人说，我们就应该念南无阿弥陀佛嘛，我们将来到西方净土嘛。这个世界，就暂时地待一待嘛，它实在很不好玩的。所以我们到西方净土去吧。那她信了呀。你问她，你凭什么信？她也是讲不出来的。所以这就是起信。

## 共业、别业和业力的木偶

**回看 01:29:46—01:38:40**

<span id="p-tan-06-158" class="reading-anchor"></span>

你信了佛教，你首先就信了三世因果。这个三世因果无法论证。佛教向来告诉我们，每一个人，你这辈子生活如此这般一个状况，或极富极贵，或极贫且极贱。跟他人有那么大的差别，有原因的。不是因为你不够努力，我看你也很努力的。也不是因为你不够聪明，你的智商实际上蛮高的。有的人不识字，不等于笨啊。

<span id="p-tan-06-159" class="reading-anchor"></span>

学什么都很快。你也努力了，你的智力水平，你也不是个傻子，智障者。那你为什么有这么多遭遇呢？佛学告诉你，你前世、再前世，你来到这世界上多次了，甚至叫累世累劫。你一直在生死轮回中的，叫无始以来。就没有开端，到现在了。

<span id="p-tan-06-160" class="reading-anchor"></span>

前世、再前世做了事情了，事情结束了，有东西留下来。这东西叫啥？业。你相信不相信业？没办法论证的。谁知道第一，我们以前活过啊？我们相信人在这世界上就一辈子，哪有几辈子的事啊？人生最宝贵的就是生命，这生命人只能得到一次。是不是这样想的？

<span id="p-tan-06-161" class="reading-anchor"></span>

我也不是一定要在这里宣扬以往说的佛教的迷信、三世因果，而是说我们自己去领会。这要悟的，而不是认知活动。要有体会，到一定年龄会有体会。中国人向来相信这一点的，儒家相信有命啊，道家也相信有命。那个诗人有一句话这么说的，一首诗，里边有这样两句。

时来，就时运到了，“时来天地皆助力，运去英雄不自由”。

<span id="p-tan-06-162" class="reading-anchor"></span>

这个时和运，是你创造的吗？你的理性、科学的理性，能造时造运吗？这个时和运有来历，佛家是一种来历的说法，叫业力。一个民族有它的业力，各位同意吗？我们中华民族的业，跟欧洲民族的业是不一样的，各位同意吗？你身为中国人，未经你同意，整个民族的业也就在你身上，你赖都赖不掉。

你又想拒绝，不可能的，你得承受，善业也罢，恶业也罢，都得承受。

<span id="p-tan-06-163" class="reading-anchor"></span>

这一点我们同意了。哲学里边讲，用西方哲学讲，叫历史的必然性。历史是有必然性在其中贯穿的，不是一大堆偶然事件的堆积。到这么一个阶段，这个民族发展到哪一个时代、哪一个阶段，必会产生怎样的人和怎样的事情。

<span id="p-tan-06-164" class="reading-anchor"></span>

黑格尔讲得很清楚。欧洲近代欧洲的政治局势，法国大革命起来。然后一下子天下就乱得一塌糊涂。欧洲政治的局势发展到一个事业形成起来的时候，必从茫茫人海中召唤到它所需要的英雄。这个英雄是谁？拿破仑。拿破仑哪里来的？欧洲近代历史进程的产儿。他不到这个时候，他就是个普通人，满身的缺点。

<span id="p-tan-06-165" class="reading-anchor"></span>

拿破仑的仆人一看拿破仑，因为他老是在他左右嘛，是他日常生活中的仆人嘛，看到别人那么尊重、崇拜拿破仑，他就觉得很奇怪。跟人家私下里说，你知道他有多少坏毛病？我告诉你，他怎么会变成英雄呢？后来黑格尔说了句话，“仆人眼中无英雄”。不是因为英雄不是英雄，而是因为仆人只是仆人。

他看不到这个世界历史的必然性的展开。对，这就是业。

<span id="p-tan-06-166" class="reading-anchor"></span>

欧洲民族的业力，到后来还两次世界大战。我们中华民族会发动世界大战吗？不可能。最爱好和平的民族，最不喜欢打仗的。而欧洲都打起来厉害了，而且很喜欢打仗。你看欧洲中世纪，还有十字军东征，三十年欧洲战争，还记得吗？那不得了的。我们中国人不喜欢打的。这是他们的业，不是我们中华民族的业。

<span id="p-tan-06-167" class="reading-anchor"></span>

那么我们有我们的业。我们也打仗的，打的时间长一点嘛，就结束了。跟少数民族打嘛，最后就和亲，劳民伤财，不打了。皇帝把女儿嫁给对方，不就好了嘛。我们有我们的业。讲到一个民族的业，我们大概都同意了，个人也一样。个人的业叫别业，民族的业叫共业。这就是共业和别业。

<span id="p-tan-06-168" class="reading-anchor"></span>

佛家就跟我们讲了这一套三世因果。这三世因果是什么东西？因果关系啊，业力的流转。久而久之，深入中国老百姓的内心了。我们中国人有因果报应这个说法吧？因果报应就来自佛教呀。在佛教来到中国之前，中国人有因果报应的什么？没这观念的。然后后来说，“不是不报，时辰未到”。

就到业力流转的这一刻，它已经报了。它不是自然科学讲的因果关系。

<span id="p-tan-06-169" class="reading-anchor"></span>

自然科学讲的因果关系，比如说桌子上一个杯子，我手推了吧，杯子倒了。手推是因，杯子倒是果。自然科学可以研究它，那叫力学。而佛家讲的因果是这种因果关系吗？不是，是受业和造业。我们每一个人的生命，实际上都是承受一份业的。在这种业中我们活动了，在活动的当中，又造出新的业了。

这叫业力的流转，它就是命运。命运就这么形成了，个人也一样的。

<span id="p-tan-06-170" class="reading-anchor"></span>

然后修行就摆脱，摆脱业力对我们的支配。我们其实都是业力的木偶。你们看过木偶剧吗？木偶在舞台上像模像样，在说话，在行动呢。其实都是绳子牵着呢。这个牵着木偶行动的绳子是什么？业力。我们自以为我们很自由，其实我们是被业力支配。那这一点要讲透的话，你就明白道理了嘛，然后有个信就起来了。

<span id="p-tan-06-171" class="reading-anchor"></span>

如何把业力消解掉？这辈子活着，活成这个样子，前世、再前世的业力规定的。我的前世、再前世的业，规定我这辈子不可能成为富豪排行榜上有名的人，你知道？因为这个发财跟我一点关系都没有。我的业就是吃开口饭、吃粉笔灰，做教书匠呀。

<span id="p-tan-06-172" class="reading-anchor"></span>

各有各的业。不要幻想，我也可以做总理嘛。这是他的业。跟我有什么关系呢？你到一定时候你就明白了嘛。做好你的事情，做教书匠，好好教书，不要误人子弟。你发什么财呢？马云是你做的吗？你没那个业，那个业是他的业。也未必是好的事情吧，好坏都在里边，一样的道理。

## 事实判断和价值判断

**回看 01:38:40—01:43:16**

<span id="p-tan-06-173" class="reading-anchor"></span>

有人说这样的看待人生是消极的。不，你去做跟你的业没关系的事情，才叫消极的人生。你做好你该做的事，积极的人生。佛教修行是精神活动，是事关心灵的，不关乎头脑。关乎心灵，就关乎人的生命的价值和人生的意义。

<span id="p-tan-06-174" class="reading-anchor"></span>

生命的价值和人生的意义，不是科学研究的对象。假如科学能向我们说明生命的价值、说明人生的意义，我们只要科学就够了。科学不解决人生观问题，各位同意吗？所以我们在佛家修行的这个领域里边说话，第一句话要说的是我们的信念是什么？我们如何确认生命的价值？我们如何领会人生的意义？

<span id="p-tan-06-175" class="reading-anchor"></span>

科学能告诉我们应当怎么做人吗？不可能告诉我们这一点。我该做什么事、不应该做什么事，科学能给我们一个区分标准吗？这些都是值得我们思考的问题。科学是对外部世界的、客观世界的正确的描述和规律的揭示。至于在这个世界中，该怎样作为人而生活，我们的成长，作为人而成其为人，而不仅仅是有某种专业能力的人。

<span id="p-tan-06-176" class="reading-anchor"></span>

第一个问题，作为人，成其为人，这件事跟科学没关系，跟哲学关联，跟宗教信仰关联。所以说有两种判断，一类是事实判断，事情本身是怎样的。科学给出一系列事实判断，无论是自然事实还是社会事实。自然事实，自然科学来描述。社会事实，社会科学来描述。这叫事实判断。

<span id="p-tan-06-177" class="reading-anchor"></span>

但还有一类判断，人总得做，叫价值判断。我应当做什么，不应当做什么，怎样的才是好的，怎样的才是不好的。这不是价值判断吗？在价值判断的领域里边，我们能否请科学到场的？没办法请它到场。那么进入了哲学或宗教了。

<span id="p-tan-06-178" class="reading-anchor"></span>

进入哲学和宗教，哲学又分两类呀，西方哲学和中国哲学。西方哲学确实要论证的，那叫理性的思辨。通过理性的思辨，客观地说明怎样做人才是对的。典型的例子，苏格拉底，他得出一个结论，“美德即是知识”。通过理性的运用，获得了关于人的自我认识，这种自我认识就是知识。

我们在这种关于人的自我认识中做人，那就是在美德中，就是在应当中，就是在善中，就是在好中。这是西方哲学。

<span id="p-tan-06-179" class="reading-anchor"></span>

但中国哲学呢，我们应当怎样做人，怎样作为人能成其为人？去领会天道。人和万事万物一样，都是天地造化的产物。“天命之谓性”，天命规定了人性的，所以要去领会天道。它可不是科学的工作，不是科学的研究吧。

<span id="p-tan-06-180" class="reading-anchor"></span>

那么来了佛学了，佛经进入中国，又有释迦牟尼的佛学的思想境界，来说明中国人讲的天道。在佛学那里，那叫佛道。成佛就是让我们的人生跟佛道一致。大家一起修行，彼此称呼对方为道友，我们都在佛道中。

## 本节总结｜整理附录

本节先说明为什么《忏悔品》关乎心灵的安顿，再按法会次序读五分法身香。前三香不是仅仅照物理上的三支香解释，而是回到戒、定、慧的修行；第四香则指向解除二相、尤其生死二相的束缚。

随后长篇讨论信从哪里来。母亲诵经、弄堂孤老太、民族与个人的业，以及拿破仑的例子，都是课堂论证的一部分。最后区分事实判断和价值判断，说明为什么科学知识与解决人生意义的问题不被当作同一类工作。
