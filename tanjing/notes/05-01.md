## 定慧品为什么从定慧一体讲起

**回看 00:00:00—00:04:12**

<span id="p-tan-05-001" class="reading-anchor"></span>

我们进入这个课程的第五讲。《疑问品》最重要的是提出了禅宗所认为的戒。既然把戒讲了，底下一定要讲定慧了。一定要讲定慧了，这是顺理成章的事。一切佛法都不脱离戒定慧的，所以讲了戒，自然讲定慧。所以第四品就是《定慧品》了。

<span id="p-tan-05-002" class="reading-anchor"></span>

从第一品到第十品的安排，有一个内在的逻辑。我们已经发现了，《行由品》讲的是惠能怎么会成为第六祖的；《般若品》讲的是禅宗是一种怎样的法门，般若法门；第三品讲禅宗的戒，禅宗所说的戒是什么？那么第四品自然讲定慧。

<span id="p-tan-05-003" class="reading-anchor"></span>

讲定慧这一品当中，我们认为最重要的是三无，无念、无相、无住。为什么最重要的是三无呢？离开三无，谈不上修定慧呀。或者说修定慧是怎么修的？就是以三无来修。无念为宗，无相为体，无住为本。这是《定慧品》当中的核心内容。

<span id="p-tan-05-004" class="reading-anchor"></span>

首先我们来看第一层意思，定慧一体。戒定慧三个字概括了佛教修行的法门，佛法。但这三个字容易引起的误解是什么？好像分三步走，第一步是守戒，第二步是入定，第三步是发慧。一、二、三，一个程序、一个次第。惠能在《定慧品》的一开头，就破除这种错误的想法。

既不能说是先定发慧，或者说先慧发定，这样一个先后的顺序就错了。

<span id="p-tan-05-005" class="reading-anchor"></span>

所以《定慧品》第一段就讲这层意思，「定慧一体，不是二」。有二了，就有一个先后了。「我此法门，以定慧为本。大众勿迷，言定慧别。」大家别搞错了，说什么定与慧之间有区分，其实没区分，定慧是一体，不是二。

<span id="p-tan-05-006" class="reading-anchor"></span>

这里就讲了体和用的关系，「定是慧体，慧是定用」。我们的智慧的本体就是定，而智慧呢，就是这个本体之用，这叫体用关系。「即慧之时定在慧。」这句话有意思。当我们智慧起来的时候，定就表现为我们的智慧了。当我们定的时候呢，智慧就表现为定。

「若识此义，即是定慧等学。」不是先学定或者先学慧，不是先修定或者先修慧。

## 天台宗的止与观

**回看 00:04:12—00:05:49**

<span id="p-tan-05-007" class="reading-anchor"></span>

这就让我们想起天台宗，天台宗修行的法门就是两扇门，止门和观门。那么就有一个问题要来了，先修止还是先修观？止是什么意思？止是指停止对事物的贪恋。观是指看到事物的虚妄不实。

<span id="p-tan-05-008" class="reading-anchor"></span>

那么就有一个讨论会发生。我们看到事物的虚妄不实，有前提，有人这么认为。什么前提？因为我们不贪恋事物了。我们对事物停止了贪恋，我们才有可能看到事物的虚妄不实。因为我们在贪恋之中的话，我们一定要把贪恋的对象当真吧，否则你不会去贪，不会去恋吧。

<span id="p-tan-05-009" class="reading-anchor"></span>

所以功夫下在哪里？下在停止贪恋上。因为你停止了贪恋，你才能观照事物，才能对事物有一个观照的态度。如果你对事物有贪恋，你对事物不是观照，而是认识。你要认识事物，因为你通过认识事物才能趋利避害，才能获得你想要的嘛。所以认识是为贪恋服务的。

## 叔本华、生存意志与科学

**回看 00:05:49—00:09:36**

<span id="p-tan-05-010" class="reading-anchor"></span>

这就是叔本华讲的嘛。我们知道，德国哲学家，跟黑格尔同时代的叔本华，也研究佛经的。他后来发现这个宇宙的本体是什么？意志，生存意志。因为生存意志驱使了我们把我们的器官变成认识器官，眼睛要看，耳朵要听，头脑要思考。人类的认识器官是意志造成的，生存意志是本体。

<span id="p-tan-05-011" class="reading-anchor"></span>

因为生存意志起来，要实现自己的目标，那么就需要理性的认识。科学是为意志服务的。他倒说出了真相了，至少说出了近代以来西方科学的目标是什么，跟古希腊的科学目标不一样。古希腊的科学研究，包括数学的研究和物理学的研究，如亚里士多德他们做的这些研究，跟今人的目标不一样。

<span id="p-tan-05-012" class="reading-anchor"></span>

今天的人研究科学，是为了利用科学，利用科学来更好地控制世界。古希腊人研究科学就是灵魂的需要。灵魂的最高部分就是理性。在对事物的认识当中，灵魂的最高部分，理性，得到了满足，这叫灵魂最高的福祉，是一种终极关怀的需要。

当我们认识了事物的真相的时候呢，我们就处在一个不朽的世界中了。

<span id="p-tan-05-013" class="reading-anchor"></span>

近代以来，由于资本主义的兴起，科学采取了近代的形态，就量化地描述自然界。为什么要把自然现象放到数学公式里去呢？就是为了 control，控制。所以叔本华指出了近代科学的动力来自意志，这件事他看得很清楚。

<span id="p-tan-05-014" class="reading-anchor"></span>

我们顺带讲到叔本华。那么佛教也是知道这个道理，就是说人认识世界的态度来自趋避的需要。因为我们把事物放到二相中了嘛，我们要趋利避害、趋得避失了嘛。那么这个趋避要有指导，认识起作用。所以对世界采取认知态度、认识态度，其实是一种什么？贪恋带来的。

<span id="p-tan-05-015" class="reading-anchor"></span>

停止贪恋，我们可以改变对世界的态度，变 knowledge 为 meditation，假如可以这么翻译的话，改变对世界的认知态度，而变成观照。所以止门是观门的前提，这是一种认识、一种理解。但倒过来似乎也通，你为什么能够停止贪恋事物呢？因为你看到事物的虚妄不实，全是虚幻的嘛，我干嘛要它呢？

<span id="p-tan-05-016" class="reading-anchor"></span>

因为我看到事物的虚妄不实，我就不贪恋事物了，这样观门又成了止门的前提。是不是这样？争论吧，先止后观，还是先观后止，真成了问题。与此同理，要讲定慧的话，定是慧的前提，还是慧是定的前提，这成了一个问题。

## 定和慧有先后吗

**回看 00:09:36—00:11:17**

<span id="p-tan-05-017" class="reading-anchor"></span>

慧是不在相中看事物。我们不在相中看事物和跟事物打交道。如果我们在相中认识事物、跟事物打交道，我们就远离智慧。我们离相，我们就进入实性。离相就是定。我们在相中定不了，我们要趋避，很忙。趋高避低、趋贵避贱、趋乐避苦、趋福避祸，最乱。

<span id="p-tan-05-018" class="reading-anchor"></span>

离了相就定。那么先定，然后有了慧，看到事物的实性本身，是不是先后分开了两件事？很容易被理解为先后两件不同的事。这样讨论来讨论去，是没有解决的可能的。对立的双方都有理由。

<span id="p-tan-05-019" class="reading-anchor"></span>

有的人说我慧了，我就看到事物的实性了嘛，我自然离相了，离相就是定嘛。就后面《坐禅品》里讲的，「外离相即禅，内不乱即定」。禅是定的原因。那么离相就在禅定中了嘛，因为禅定的缘故，我才能看到事物的实性，或者我因为看到事物的实性，我才禅定。

两件事情，真是两件吗？不是两件事情。若总看成两件事情，这个争论就没完没了。

## 徐爱问阳明，知道孝为什么做不到

**回看 00:11:17—00:14:44**

<span id="p-tan-05-020" class="reading-anchor"></span>

就好像王阳明讨论知行关系一样。知是行的前提，还是行是知的前提？各执一端，都有理由。行就是实践，知就是认识。先要把事物认识清楚，再去做事情，否则叫盲目的。好，这样就是先知后行。

<span id="p-tan-05-021" class="reading-anchor"></span>

还有对立的观点来说了，我们对事物的正确的认识来自哪里？来自实践，实践出真知嘛。结论又是先行后知。对立双方各执一端，每一端都有它的根据。你怎么办？一直争论下去，一直争论下去可以的，但是就没有真正的知和行，都没了。

<span id="p-tan-05-022" class="reading-anchor"></span>

在王阳明的《传习录》里边，就有这种讨论。比如说他的一个高足弟子，叫徐爱，就问他的老师阳明了，你说现在这个知和行是合为一体的吧？我看就是两样东西。为什么呢？何以见得呢？他说现在有许多人当然都知道孝父母的道理，都知道孝之理，但行不了，他去孝父母，孝不了。

<span id="p-tan-05-023" class="reading-anchor"></span>

这倒是今天我们也能看到的现象。一个中国人在中国文化世界长大，一定知道儒家讲的孝之理的。没用的。为了财产的争夺，居然把父母告到法庭上去了。知道孝之理，带来不了孝之行啊，分明是两件事啊。王阳明的回答是什么？若知道这个孝之理而行不了，此知非真知，其实是没知。

<span id="p-tan-05-024" class="reading-anchor"></span>

这话怎么说？王阳明拿《大学》中的话作例子，「如好好色，如恶恶臭」。你见到好色，你见到了吧，这叫知，便已经好起来了。见好色，自然好好色了。没有这种情况，先发现是好色，然后另立一个心去好它，这是不可能的。当我们见好色的时候，便已好了，便已喜欢上了嘛。

<span id="p-tan-05-025" class="reading-anchor"></span>

没有这种情况，见到了美好的东西，然后再想好还是不好呢，喜欢还是不喜欢呢？有这种事情吗？你既然见到好的，你就知道它不是丑的。这种见到跟向往是同一件事，哪有分开来的。王阳明这么解释知行合一，其实一定受禅宗的启发。

因为禅宗惠能就讨论定和慧的关系了嘛，哪有定了之后再生出慧来？你能离相不就定了吗？定的时候就是智慧起来，这本是同一件事。

## 事实判断、价值判断和情感

**回看 00:14:44—00:19:42**

<span id="p-tan-05-026" class="reading-anchor"></span>

我们注意到，王阳明讨论知和行的时候，他所说的知，不是哲学中认识论上讲的知。认识论上讲的知，仅仅是概念、判断、推理所达到的认知，它里边没有好与不好的问题。王阳明讲的知是什么？同时就是心向往之，同时就是对一份价值的认同。

<span id="p-tan-05-027" class="reading-anchor"></span>

这些问题都是很大的哲学问题。我们今天的科学给出事实判断，但给不出价值判断。于是事实判断是一个领域，价值判断是另一个领域，分开来了。分开来的结果是什么呢？我们可以在概念、判断、推理和范畴思维当中，达到正确的认识。

但这个认识跟价值好坏、善恶没关系，就跟情感没关系。这恐怕是当代文明的共同病症。

<span id="p-tan-05-028" class="reading-anchor"></span>

用西方人的讨论来讨论这个问题，他们的说法是什么呢？科学只是工具，叫工具理性。至于人该过怎样的生活，不应该过怎样的生活，这是个价值判断。在这个判断里边，在价值领域当中，理性无法起作用，就价值理性不能成立。

<span id="p-tan-05-029" class="reading-anchor"></span>

理性只能是正确地描述事物。至于我们把对事物的正确描述来做什么事，这个领域里边没普遍的真理了。好像谈起青菜萝卜，各人喜欢。谈起趣味无争辩，谈起喜好无争辩。所以在价值领域里边，我们陷入相对主义。

<span id="p-tan-05-030" class="reading-anchor"></span>

今天的人是不是这样？我们可以讨论事情是怎样的，但我们不能讨论应该怎样还是不应该怎样。若讨论到这个问题，就是价值问题的事，我们各持己见吧。你可以坚持你的价值观，我可以坚持我的价值观，不要争论，在这里没有真理。

<span id="p-tan-05-031" class="reading-anchor"></span>

当代文明的病症，看到了，把价值选择放逐到个人主观的领域中去了。真似乎可以讨论，善和美就不能讨论，是不是这样？相对主义的领域，价值主观主义、相对主义，乃至于虚无主义。不要讨论价值。但是中国思想一开始就抓住价值不放，这个价值的核心就是个「仁」字。

<span id="p-tan-05-032" class="reading-anchor"></span>

儒家讲的仁爱，仁与不仁是应当区分的，而且这种区分是客观的，不是主观的。佛教的修行也一样。什么叫定，什么叫慧？我们讲到智慧了吧，前面讲过的，大智慧就是大悲悯。那是份情感，非常深刻的、博大的情感，叫大悲悯。

<span id="p-tan-05-033" class="reading-anchor"></span>

在情感中难道没有价值选择吗？有非常明确的价值选择，否则就不要谈大乘佛教了嘛。大乘佛教叫度众生啊，这是一种价值选择。所以这个慧是指什么？不是聪明才智、机巧、手段，加上《三十六计》《孙子兵法》。是指这个吗？不是指这个。

<span id="p-tan-05-034" class="reading-anchor"></span>

就像王阳明讲的知，和惠能讲的慧，智慧的慧，其实都是生命情感的最高境界。如果停留在认识论领域里边，它就变成一个价值中立的、客观的、不偏不倚的东西。智慧是这样的吗？现在科学知识是这样的，它拒绝讨论价值问题。

<span id="p-tan-05-035" class="reading-anchor"></span>

我们修行的人是什么？变贪嗔痴为戒定慧。贪嗔痴是生命情感的毛病吧。把这毛病除掉，这个生命情感上升为戒定慧，它还是情感。请注意这一点。当代文明骨子里的、根子上的虚无主义，就来自这一点，远离了古代的智慧。它不谈智慧了，只谈正确地描述事物、有效地利用事物，这叫 knowledge。

<span id="p-tan-05-038" class="reading-anchor"></span>

<span id="p-tan-05-039" class="reading-anchor"></span>

好，这不展开，我们还是要回到《坛经》。展开一下的目的是什么？我们有一个参考系，我们知道讨论定慧关系，是件如何大的一件事。我们不要忘了什么叫悟。悟不在头脑中发生，悟是心的活动，就生命情感的升华，变贪嗔痴为戒定慧。

<span id="p-tan-05-040" class="reading-anchor"></span>

贪嗔痴是不是生命情感？就是有毛病的生命情感。它不是认识上的错误吧。王熙凤认识上准确得不得了的，智商极高的王熙凤，贪嗔痴不是她的认识错误吧，是她的情感的毛病嘛。禅宗修行不是直指头脑，而是直指人心。

## 从如意之心到如如之心

**回看 00:22:14—00:27:09**

<span id="p-tan-05-041" class="reading-anchor"></span>

那我们讲戒，也是一种情感，升华了的情感。永不轻视任何人，这是一种法喜，包括遇到伤害我的人，我也仍然知道他将来会成佛的，只要机缘成熟。佛与佛相见，是很开心的，那是一种喜悦。戒是一种法喜。如果你光戒肉，不是法喜。戒轻视他人，就是法喜。

<span id="p-tan-05-042" class="reading-anchor"></span>

有时候肉是无法戒的，这么简单，你要活下去啊。假如惠能当时在猎人队伍里边连蔬菜都没有，他得吃东西吧，能不吃吗？一定吃肉了喽，这要戒干嘛呢？所以禅宗讲的戒是对的，生命情感的升华，戒轻视他人。

<span id="p-tan-05-043" class="reading-anchor"></span>

那么定慧也是生命情感的升华，升华了的情感还是情感，不是头脑中的机巧。这样来讨论问题的时候，定和慧的关系就自然明了了。定是情感吧。我放下了，我改变了如意之心，变如意之心为如如之心，我不就定了吗？

<span id="p-tan-05-044" class="reading-anchor"></span>

<span id="p-tan-05-045" class="reading-anchor"></span>

<span id="p-tan-05-047" class="reading-anchor"></span>

<span id="p-tan-05-048" class="reading-anchor"></span>

## 有灯即光，灯与光无先后

<span id="p-tan-05-056" class="reading-anchor"></span>

<span id="p-tan-05-057" class="reading-anchor"></span>

<span id="p-tan-05-058" class="reading-anchor"></span>

<span id="p-tan-05-062" class="reading-anchor"></span>

所以禅宗很伟大的。千万别把修禅当成是一种处世艺术的学习，处世的机巧，然后情商变得更高了。情商是个很恶劣的概念。永不轻视他人，也不是提醒自己别得罪人，不是这件事。而是我永不轻视他人，我在跟人打交道的时候总是喜悦，那叫法喜，不是因为一件具体的事情而带来的喜悦。

<span id="p-tan-05-088" class="reading-anchor"></span>

某人帮了我一下，我高兴了，通常的喜悦。但是在守禅宗讲的戒的状态当中，那是什么？你帮我一下，我这个喜悦是什么？法喜。然后我帮了你一下，我也许比你这个被帮的人更喜悦，因为这是我的法喜。戒不是克制自己，它是生命情感的很高的境界。

<span id="p-tan-05-089" class="reading-anchor"></span>

因为我们每个人都知道自己是无限渺小的，我们也知道那个强者也是无限渺小的。他该帮助的时候，你能帮他就得帮他。虽然他向来叱咤风云，向来呼风唤雨，但他需要帮助的时候，你一个卑微的下人的地位，照样去帮了他。你能做到吗？你能做到就好。

<span id="p-tan-05-090" class="reading-anchor"></span>

我们习惯于帮助比我们弱的人，还有一种精神上的优越感相伴随。我们能不能去帮一个远远比我们强大的人，如果他需要帮助的话？这才叫学佛。我想我总算讲清楚了，这个定慧的境界。下面要追问的是如何修，如何定慧等学，就是定慧等修。底下自有答案，看下去，惠能这么说。

## 本节总结｜整理附录

“定是慧体，慧是定用”是全节主轴。课堂没有直接给出结论就结束，而是借止观与知行的两种先后说，展示把它们分作两事所遇到的困难，并进一步讨论事实判断、价值判断与情感。

灯光比喻之后，讨论又进入诚意、观照、大悲悯和日常生活。定慧是怎样的生命情感境界，与强迫自己镇定、用机巧取胜或依赖座右铭，并不是同一个问题；结尾复述定慧等学，为下一节如何修作准备。
