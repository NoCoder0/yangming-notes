# 第4集 · 第3节 《无相颂》中的在家修行

王德峰课程｜《六祖坛经》与禅宗修行｜第一人称口述整理稿｜原视频 01:25:11—01:42:59

**阅读导引｜整理附录**　由“在家亦得，不由在寺”引出第三问，逐句读《疑问品》的《无相颂》。日常伦理、改过、助人和向心觅菩提，构成这一节在家修行的具体展开。

## 一分钟速读｜整理附录

1. 在家或在寺不是修行成否的决定条件，关键仍是心是否清净、是否实际修行。
2. 心平行直之后，课堂依次讲孝养父母、兄弟姐妹相怜、尊卑和睦和对恶言的安忍。
3. 钻木出火、淤泥红莲说明在现实生活中用功；同桌吃饭的和尚一例强调不执着洁净的外相。
4. 苦口良药、逆耳忠言、改过生智慧、护短非贤，都指向从实际相处中改变自己。
5. 日用饶益不等于出钱便成道；菩提向心觅，开悟之后还要信受奉行，继续修行。

## 在家如何修行

**回看 01:25:11—01:26:59**

<span id="p-tan-04-141" class="reading-anchor"></span>

惠能继续说，「善知识，若欲修行，在家亦得，不由在寺。」并不一定要到寺庙里去，在家能修行的话，「如东方人心善。在寺不修」，有的人出家了，在寺庙里了，他其实没有修，这就好比是什么？「西方人心恶。但心清净，即是自性西方。」

<span id="p-tan-04-142" class="reading-anchor"></span>

惠能说了这段话，就引起韦刺史问第三个问题了。因为惠能这句话里面提到在家修行，那么韦刺史自然想问，我们不出家，我们在家如何修呢？「韦公又问：在家如何修行？愿为教授。」请你惠能指点我们。

<span id="p-tan-04-143" class="reading-anchor"></span>

惠能怎么指点？给他们一个《无相颂》。「但依此修」，按照这个《无相颂》来修，你们就仿佛跟我始终在一起，「常与吾同处无别」。若不依此修，即使剃发出家，于道何益？底下就是《无相颂》。我们读这《无相颂》发现，惠能其实提出了在家修行的十个要点。我们一句句来看，把这十个要点记下来。

## 心平、行直与孝养父母

**回看 01:26:59—01:28:46**

<span id="p-tan-04-144" class="reading-anchor"></span>

「心平何劳持戒？」就是我们讲的平等，永不轻视任何人，这就是真正的戒。有了这一条，别的戒就不用持了。「行直何用修禅？」直心是道场，直心是净土。心平行直是谁？阿弥陀佛。

<span id="p-tan-04-145" class="reading-anchor"></span>

第二个要点就是行直。第一个要点，守一个什么戒？戒轻视他人，这就是心平。行直的最高境界叫什么？一行三昧。

<span id="p-tan-04-146" class="reading-anchor"></span>

第三个要点，看，「恩则孝养父母」，要报父母之恩。因为你在家修行。你真的遁入空门了，出家了，你就解除了自己对家族的责任，对父母的责任你也解除了。但我们都在家修行嘛。你出家人还能天天在家里侍奉你父母汤水吗？不可能了嘛。既然没有出家，既然在家，佛教充分承认儒家的原则。

儒家讲的人生价值不能丢掉，所以报恩是儒家的原则，在家修行必须遵守的。

## 手足之情、礼让与安忍

**回看 01:28:46—01:31:14**

<span id="p-tan-04-147" class="reading-anchor"></span>

「义则上下相怜。」这个上下是指兄弟姐妹之间，兄姐与弟妹，一个上，一个下。要讲一个义字，讲个手足之情，这叫上下相怜。这是第四个要点。

<span id="p-tan-04-148" class="reading-anchor"></span>

第五个要点，让，「让则尊卑和睦」。尊卑就是上下级关系，从古代到今天的社会都是有上下级关系的。那么你怎么面对这个上下级关系呢？一个让字。就是上下级之间不能彼此争，尊也不向卑来争，卑也不向尊来争。

<span id="p-tan-04-149" class="reading-anchor"></span>

我想我们今天的企业如果能做到这点，该多好？企业的领导不要跟企业的员工争利吧，企业的员工也要体谅体谅企业的领导，他做出的努力。大家有一个让字，这个上下级关系就和睦了嘛。这是第五个要点。

<span id="p-tan-04-150" class="reading-anchor"></span>

第六个要点，一个忍字。我们在社会生活当中，自然会遇到跟别人关系不好的时候。有时候被人伤害，有时候被人诬陷，有时候被人诋毁。这时候你要忍。你不忍的话，叫以牙还牙，则恶恶相连。其实就是六种度当中的一种度，安忍波罗蜜。要做到这一点，这样众恶无喧。

<span id="p-tan-04-151" class="reading-anchor"></span>

你忍一忍。在家修行，你又没到庙里去出家，你还在单位里工作，你跟人打交道，各种社会关系嘛，所以要能忍。

## 俗中行真与闻诽自明

**回看 01:31:14—01:33:58**

<span id="p-tan-04-152" class="reading-anchor"></span>

第七个要点是两句话，「若能钻木出火，淤泥定生红莲」。这莲花是佛教的象征，它生长于淤泥中。我们把俗谛比喻为淤泥。真谛、俗谛，真谛和俗谛不能分开。我们就在日常的俗谛中，柴米油盐诸如此类，俗中行真。让生活的真谛实践在俗谛中，把佛法运用于世法，都是这个意思，一定能化腐朽为神奇。

<span id="p-tan-04-153" class="reading-anchor"></span>

我们把日常生活看成像淤泥一般，没有干净的地方呢。没关系的，一个在家修行的人，把对佛法的领会运用到世间法中去。有时候我们遇到有些寺庙里的和尚，真做到了这一点。他跟你和光同尘，然后他还跟你一起吃饭。我们没有守戒，不是要吃荤的吗？那么他也跟我们坐在一起，这怎么行呢？

<span id="p-tan-04-154" class="reading-anchor"></span>

他当然只是素菜。然后他坐上桌子第一句话，我们一国两制。虽然说开玩笑的话，蛮幽默的，他能够跟我们和光同尘。他不是那些刚刚开始修行的人，脸一板，我不能在荤菜边上，这是不行的。那叫着了净相。这是第七个要点。

<span id="p-tan-04-155" class="reading-anchor"></span>

第八个要点，其实也是我们日常的语言，中国人都会说的。「苦口的是良药」，叫良药苦口，「逆耳必是忠言」，忠言逆耳。惠能居然把这一点也列为在家修行的要点。我把它概括为「闻诽自明」。

<span id="p-tan-04-156" class="reading-anchor"></span>

有人批评你，有人诽谤你，你不要难过，要开心，因为他帮助了你。我们做事情需要对立面。有人批评你才好呢，因为批评你，才让你把事情做得更好。敌人是我们的老师，困难是我们的恩人。

## 改过生智慧，日用常行饶益

**回看 01:33:58—01:37:35**

<span id="p-tan-04-157" class="reading-anchor"></span>

第九个要点，「改过必生智慧，护短心内非贤」。护短是人之通病吧。每个人恐怕对自己的短处，或者做错的事情，都是心里本来明白的，但他要遮掩，要为自己辩解，那叫护短。你的内心就离开贤圣的境界很远了，「护短心内非贤」。

<span id="p-tan-04-158" class="reading-anchor"></span>

这个智慧哪里来？智慧不是读书读来的，在实践中来。实践当中最能够生智慧的就是改过。人都有过错，这没有什么要紧，关键是改正。人都有过错，人是会犯错误的动物，这是肯定的。发现了能改，所以智慧是实践中来的。最要紧的实践就是改正自己的错误。

<span id="p-tan-04-159" class="reading-anchor"></span>

第十个要点，「日用常行饶益」。饶就是丰富，益就是帮助别人。我们在生活当中跟他人相处，随时随地会发现别人需要帮助。你若发现别人需要帮助，而且你有能力帮助的时候，你不去帮助，在佛教看来，这是属于犯戒的，也是犯了戒的。

<span id="p-tan-04-160" class="reading-anchor"></span>

所以这个持戒波罗蜜当中有一条，就是常行饶益。你做不到这一点，你就犯了戒。这要求很清楚，蛮严格的。你明明知道人家需要帮助，你也明明知道这时候你是能帮的，居然不帮，那个戒没守好。所以常行饶益是个戒。在日用常行中，在日常生活中随时随地帮助别人，只要在你能力范围内。

<span id="p-tan-04-161" class="reading-anchor"></span>

「成道非由施钱」，不要以为帮助别人只是通过钱。布施是多种多样的，财布施只是其中一种。要把布施的种类讲清楚，讲不完，只要是帮助别人便是布施了。也许惠能所在的时代，人们已经有一种误解，布施就是要出钱，财布施是唯一的布施。

<span id="p-tan-04-162" class="reading-anchor"></span>

所以惠能强调了，我们要成佛道，不是通过财布施。当然财布施也是对的，并非仅仅通过施钱。这样十个要点就讲了。讲了之后最后四句话，「菩提只向心觅，何劳向外求玄。」觉悟在哪里？在我们心里发生，菩提就是觉悟。「听说依此修行，西方只在目前。」净土就在当下。

## 开悟之后才开始奉持

**回看 01:37:35—01:39:50**

<span id="p-tan-04-163" class="reading-anchor"></span>

「善知识，总须依偈修行，见取自性，直成佛道。时不相待」，大家要抓紧啊，「众人且散，吾归曹溪」。这三场法会都在哪里讲呢？在大梵寺讲的。现在他要回归，回到哪里去了？回到韶关那个宝林寺，现在叫南华寺。「众若有疑，却来相问。」他们很快就来问了，这是后面几品。

<span id="p-tan-04-164" class="reading-anchor"></span>

刺史、官僚、在这场法会上的善男信女，「各得开悟，信受奉行」。各得开悟是应当的，但开悟不等于了悟。第一步跨出来了，就是超出日常经验知识和这个趋利避害的如意之心，超出它，超出这种通常的如意之心。这一步跨出就叫开悟，就是开悟。

<span id="p-tan-04-165" class="reading-anchor"></span>

我们平时都忙碌于趋利避害、趋得避失，种种趋避之中，就忙碌于二相中。如果你能明白离二相之后的那个境界，这一个明白一旦发生，就是开悟。

<span id="p-tan-04-166" class="reading-anchor"></span>

我相信在座的不少人早就开悟了，就入了佛教修行的门了。否则你对修行都觉得这是件什么事，也许就是求福报、求菩萨保佑，这就没开悟。现在善男信女们在场的都开悟了。开悟之后，信受奉行，底下就奉持吧。奉持就修行开始了，真正的修行开始了。

## 回看《疑问品》的三个问题

**回看 01:39:50—01:42:59**

<span id="p-tan-04-167" class="reading-anchor"></span>

这《疑问品》三个疑问都是韦刺史向惠能提问。第一个疑问是最要紧的，如何理解修功德这件事。惠能在回答这个问题的时候，说出了禅宗所认为的戒。不是戒其他的，戒酒、戒肉的，而是戒轻视他人。这就讲出了禅宗修行的基本原理，心、佛、众生，三无差别。这是任何一个禅宗修行者首先应当达到的境界，就是众生平等。

众生为什么平等？众生之间千差万别，但佛性本无差别。

<span id="p-tan-04-168" class="reading-anchor"></span>

第二个疑问是讲西方净土如何到达。惠能通过他的回答，其实是把禅宗追求的觉悟，跟净土宗念佛往生西方，这两种修行的法门结合起来。这叫悟无生顿法。悟无生是净土宗应当达到的境界，但是要到净土才知道，花开见佛，这是在西方净土的地方，花开见佛悟无生。

惠能的意思就是我们念佛的时候，不是光口中念，我们要达到心灵的觉悟。这样一个结合，所以就有了后来我们常见到的现象，许多中国人禅净双修。

<span id="p-tan-04-169" class="reading-anchor"></span>

第三个疑问，在家修行。大多数人一定在家修行，全体社会成员都出家了，这个社会也就停下来了，是吗？在家修行，也有的人在寺庙不修，那就等于没出家。或者说组织上出家了，思想上没出家。所以在家修行是多数人的一个修行的路，在日常生活中。

<span id="p-tan-04-170" class="reading-anchor"></span>

所以这十个要点都是惠能在提醒我们，既然在家修行，就要把儒家的价值跟佛家修行的这个道路结合起来。所以就有了报恩、报父母之恩，就有了重视手足之情等等。这些儒家的价值都要接受。讲得是非常通俗的。好，就讲到这里。

## 本节总结｜整理附录

本节完整展开《无相颂》的各项内容：从心平、行直到恩、义、让、忍，再到在俗中用功、接受逆耳之言、改过和帮助他人。课堂把这些分别放进家庭、手足、上下级、饮食交往等情境中，因此不能只保留颂文或十个结论。

最后一段回到整场法会：前面问功德、问西方，现在问在家如何修行，三问贯通。听众“各得开悟”仍与以后继续用功的“了悟”有别；归曹溪、再来问法的交代也按原课程收束保留。
