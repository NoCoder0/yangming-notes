## 皈依是修行者的家

**回看 04:04:25—04:10:54**

<span id="p-tan-06-421" class="reading-anchor"></span>

你要建构自己的精神家园了吧。皈依是修行者的家。现在在现实生活当中，不少人在家修行，后来就选择了皈依。这皈依很具体的，找到一位和尚或者大和尚，作为自己的师父，皈依他了，并且常年交往，所谓供养自己的师父，这叫皈依僧。

<span id="p-tan-06-422" class="reading-anchor"></span>

有过这样的皈依的，或者实现了这种皈依的修行者，他心比较安定。这心的安定来自哪里呢？他觉得他自己从此有了精神上的父亲。他有疑难，向他所皈依的师父问。他有困惑，他有痛苦，可以向师父倾诉。

<span id="p-tan-06-423" class="reading-anchor"></span>

当然皈依这个概念，从大一点说呢，是精神上归于某一种宗教。比如说你归于基督教，或者皈依伊斯兰教。这是一般意义上的皈依这个概念，就精神上有一个寄托，精神上安一个家。那么在佛教来说，它严格意义上不是真正的宗教，因为它是无神论。所以我们归于谁呢？归于一个大德高僧，修行得道之人。

我们找到了现实中的老师，精神上的导师。

<span id="p-tan-06-424" class="reading-anchor"></span>

就像我们年轻的时候，总有这愿望。一开始把父亲当成自己的导师，后来慢慢长大了，觉得父亲本事没那么大，还经常有许多缺点和错误被自己发现了。那么他这个精神上的导师就消失了。有时候还自以为是，跟父亲抗衡。那是生身父亲。于是又要寻找一个精神上的父亲。

我年轻的时候也有一种幻想，哪一天我能找到我精神上的导师，来指点我。

<span id="p-tan-06-425" class="reading-anchor"></span>

这表明我们在精神上的成长是个过程。这种成长的过程，第一阶段是没有自信的。我们想领会这个人生，想走一条正确的人生道路，好的人生道路，这是每个人共同的愿望。这条人生道路，由谁来指点？有宗教信仰的人，他精神上皈依了。主与我同在，这是基督徒。真主与我同在，这是穆斯林。

<span id="p-tan-06-426" class="reading-anchor"></span>

我们中国许多在家修行的，很认真的、真实地修行的人，师父与我同在。这就是皈依。现实中达到这样一个境界的究竟有多少，我们不了解。但它实在就是佛教修行的一个重要的环节，皈依，是修行者的家。皈依佛、皈依法、皈依僧，这叫三皈依。一个佛教修行者的家，就是这三个方面建构起来。

佛法僧叫三宝，所以皈依又叫皈依三宝。

<span id="p-tan-06-427" class="reading-anchor"></span>

就儒家而言，我们的家在哪里？仁在哪里，家就在哪里。仁没了，家没了。中国人除了有儒家之外，还有佛家，还有道家。对道家而言，天道在哪里，家就在哪里。

<span id="p-tan-06-428" class="reading-anchor"></span>

道家学说的基本立场是什么？人类生活的幸福，都来自天。人类生活的麻烦和苦恼，都来自人自己。所以做减法，把来自人自己的因素都拿掉，做事情就和天道一致了。把来自人自己的因素拿掉做事情，这叫无为。无为不是不做事，不人为地做事。

<span id="p-tan-06-429" class="reading-anchor"></span>

所以对一个道家的修行者，不等于道教啊。道教是道家思想转变为术，求一个长生不老了。而道家是让我们全生避害。全上天给我们的生命，全上天给我们的一切，保全它。避害，害就是人为。全生里边，就包含着避害。

<span id="p-tan-06-430" class="reading-anchor"></span>

为什么呢？既然上天给我们生命，我们还需要保全它吗？要的，因为有人为的因素，这是害。从全生里边一定推出什么？避害来。害不是自然灾害，是人为。这就是道家的思想，我们这里不展开啊。

<span id="p-tan-06-431" class="reading-anchor"></span>

对儒家来说，仁心感通万物，“仁者与天地万物为一体者也”。这叫天下，就是我们的家。仁在，天下在。仁没，天下亡。天下兴亡，匹夫有责，不是仅仅讲国家兴亡。顾炎武改了这句话了吧？国家亡过好几次了，元朝、清朝吧，天下在的，因为仁在。仁心感通万物，不就是天下嘛？

## 无相三皈依

**回看 04:10:54—04:19:01**

<span id="p-tan-06-432" class="reading-anchor"></span>

好，讲佛家，佛性在哪里，家就在哪里。一个佛教修行者，就是皈依佛。但还说了，还要皈依法，还要皈依僧，三皈依。关于三皈依，就曾经有人很疑惑。有一个禅宗祖师，他的一个弟子，出家了，跟着这个禅宗祖师修，心中总有一个疑惑，一直没讲，后来终于有一天忍不住了。

<span id="p-tan-06-433" class="reading-anchor"></span>

跟他师父讲，师父啊，我们不是要三皈依吗？第一个就是皈依佛。师父，你能告诉我佛究竟在哪里？也就我到哪里去找到他呢？师父怎么回答的？在你面前听你说佛法的，就是佛。这句话一说出来，那个弟子言下大悟。

<span id="p-tan-06-434" class="reading-anchor"></span>

皈依佛，并不是说我们一定要找到释迦牟尼，才能言皈依。不，佛到处都在，众生是佛。这层意思惠能讲得非常好。为什么佛到处都在？人都可能觉悟，都可以见到自己本有的佛性。所以惠能就这么说，他说，“今发四弘愿了，更与善知识授无相三皈依戒”。

<span id="p-tan-06-435" class="reading-anchor"></span>

想一想，在三皈依前面加了两个字，无相。若我们皈依佛，就是每天拜佛。如果我们皈依法，就是每天诵佛经，然后去按照它来做。当然也不错。如果我们皈依僧，就是找到一个和尚，我们皈依他了，某一个和尚做了我们的师父了，我们皈依他了。这些皈依，其实都是有相，有相三皈依。

<span id="p-tan-06-436" class="reading-anchor"></span>

惠能按照禅宗的精神、禅宗的原则，一定讲无相。就像前面讨论忏悔，有相忏悔就事论事，无相忏悔不是就事论事，找到罪因。同样，皈依也一样。无相三皈依，该怎么说这三个皈依呢？皈依觉、皈依正、皈依净。

<span id="p-tan-06-437" class="reading-anchor"></span>

佛就是觉的意思，觉悟。佛法就是正的意思，那叫改邪归正。什么是真正的和尚？就是净，那个干净。然后他分别说明了，我们皈依觉，我们才能成为两足尊。我们皈依正，我们才能成为离欲尊。我们皈依净，才能成为众中尊。

<span id="p-tan-06-438" class="reading-anchor"></span>

惠能这样一个说明，是非常到位的。就像佛这个词，梵文就是 Buddha，本意就是什么？觉者。一个觉悟了的人，就是 Buddha，所以皈依佛，不就是皈依觉嘛。皈依佛法，我们有那么多邪知邪见，叫作众生知见吧。众生知见，其实都是邪知邪见。

<span id="p-tan-06-439" class="reading-anchor"></span>

当然我们这里需要说明一下，佛家讨论正和邪的时候，并不停留在道德层面上，正就是善，邪就是恶。不，有时候在世俗道德上看来是正的东西，善的东西，拿佛家的境界去看，它仍然是邪的。只要这个知见从二相中生，它一定是邪知邪见。这里超越道德。

<span id="p-tan-06-440" class="reading-anchor"></span>

我们有时候满脑子很好的道德观念，这是善的，这是要坚持的。用佛家的境界一看，镜子一照，邪见，行不行？因为标准这一条，此见解来自二相，它一定邪了。所谓皈依正，惠能说叫离欲尊，不是简单理解为自然欲望。我们作为生命体，都有自然欲望。有一个胃吧，那就有食欲。男女有别，就有性欲。

食欲、性欲本身都没错的。一个人食欲也没了，性欲也没了，出问题了，问题比较严重了。

<span id="p-tan-06-441" class="reading-anchor"></span>

欲本身没错。这个欲是指什么？从小我出发的私欲，要离了它，这叫离欲尊。又有两种，一种是我们的物质生活水平要提高，但是从小我出发的，这是一种欲。还有人与人之间的攀比，我要胜出别人。人我贡高，大家比，竞比。这是一种社会性的欲望，很强的，都要离了。这叫离欲尊。

<span id="p-tan-06-442" class="reading-anchor"></span>

然后讲皈依僧，其实就是皈依净。什么叫净？无我名净。把小我、我执去掉，你就干净了。你若是这样的人，你就是众人的榜样啊，众人的老师啊，你不自己就是僧吗？叫众中尊。僧人、和尚是我们的老师，是我们的榜样。我们自己也能成为他人的榜样。所以皈依僧，其实是皈依净。

<span id="p-tan-06-443" class="reading-anchor"></span>

我们再看下去，“从今日去”，从今天开始，“称觉为师，更不皈依邪魔外道，以自性三宝常自证明”。佛法僧三宝前面加了自性，其实就皈依你自己。“劝善知识，皈依自性三宝。佛者，觉也。法者，正也。僧者，净也。”底下就分别说明，我们的自本心起来，便皈依了觉。

## 由亚当夏娃说两种归属

**回看 04:19:01—04:26:37**

<span id="p-tan-06-444" class="reading-anchor"></span>

皈依觉意味着什么呢？“邪迷不生，少欲知足，能离财色，名两足尊。”我们前面也讨论过这一点。能离财色这件事情是根本。因为人活在这世界上，一要有财，二要有色。有色就是男女有性别，然后男女彼此什么？需要对方。

<span id="p-tan-06-445" class="reading-anchor"></span>

我们借用基督教的话说，上帝造人，如果光造一个倒也罢了，就叫亚当。他还造出一个，叫夏娃，这意味深长。假如只造一个，不管他叫亚当还是叫什么，没有另外一个，意味着每一个人类个体都是什么？Self-content 的，自足的。

<span id="p-tan-06-446" class="reading-anchor"></span>

他造两个，一男一女，男的叫亚当，女的叫夏娃，这意味着什么呢？在《圣经》的这种听上去很荒谬的上帝造人这种说法当中，我们体会到基督教的智慧。它是这种思想，一开始就表明了每一个人类个体，别以为自己是自足的。换句话说，每个人都有缺陷。我讲这是根本上的。

<span id="p-tan-06-447" class="reading-anchor"></span>

因为我们有缺陷的缘故，我们不是 self-content，我们不是自满自足的，我们总需要另一面。张贤亮有一部小说，《男人的一半是女人》。这不就从基督教里来的吗？上帝造了亚当，取了他一根肋骨，造了一个夏娃。然后我们一定彼此依赖了，男人和女人一定彼此依赖了。

假如我们每一个人都是自满自足的，我们没有任何归属的需要，没有归属感。I belong to you，没有这个必要。

<span id="p-tan-06-448" class="reading-anchor"></span>

我有时候想怪问题，上帝造人就造一个，也要繁殖，自行繁殖，不要两性繁殖啊，不就好了嘛？但是上帝没作这个选择，偏造一男一女。于是让每一个个体都不自足，都有所依赖。那么上帝造人，还把人造得什么呢？必有一死。你让人就永远活着，不也好了嘛？上帝不愿意。本来说可以的，后来不让他们这么做。

<span id="p-tan-06-449" class="reading-anchor"></span>

本来他们在伊甸园生活吧，违背了上帝的禁令，偷吃了知识之树的果实，有知识了，有理性了。赶出伊甸园。为什么？不让他们吃到另外一棵树上的果实。那棵树叫生命之树。若他们还吃到了生命之树的果实，他们没完没了地活下去了，那么就跟神一样了。于是上帝惩罚了他们，把亚当夏娃赶出了伊甸园。这就意味着什么？

意味着人必有一死。

<span id="p-tan-06-450" class="reading-anchor"></span>

别把它仅仅当神话看。这是人的一种自我认识，借助宗教的语言。我们想想，人是不是这样的？有两大缺陷。每一个人的个体有两大缺陷。第一，需要另一半，他不是自足的。第二，必有一死。这两大缺陷很根本的。对于第二个缺陷来说，只有一条路，对上帝的归属。上帝才是存在，我们都是非存在，就奥古斯丁说清楚了。

所以对上帝有一种绝对的依属感。

<span id="p-tan-06-451" class="reading-anchor"></span>

那么我们中国人没上帝，我们现在对佛性有一种绝对的依属感。因为我们在佛性中，我们才不朽了，叫不生不灭。那么还有一个缺陷，就是男人和女人的区分。所以我们对自己的另一半——当然，女人的一半也是男人，这说得通吧，说得通。我们对自己的另一半总是有什么？归属感。这不是利益的考虑，这是人的生存方式。

<span id="p-tan-06-452" class="reading-anchor"></span>

对上帝的绝对的依属感，是不是宗教、宗教信仰？对另一半的归属感，具有准宗教的性质。爱情具有准宗教的性质，于是它神圣了，你们信不信？所以今天的父母一定要懂这个道理。当你的孩子恋爱的时候，你不要跟他这么讲，你爱上这个人了，将来能跟他一起结婚吗？他那里的情况很有问题的。你开始担心了。

<span id="p-tan-06-453" class="reading-anchor"></span>

我们现在的父母就害怕自己的孩子谈恋爱了。因为一旦谈恋爱，第一，问清楚谁爱上谁，家庭出身如何，相貌如何，智商水平如何。马上就想到她将来跟他结婚。那是婚姻，跟 love 没关系的。婚姻也有解决的办法，有婚介所的嘛。婚介所嘛，大家称称分量了，那些指标都在的呀。

<span id="p-tan-06-454" class="reading-anchor"></span>

那现在有房有车，有一个好的职位，有个丰厚的年薪，那这几样就几条标准嘛。身体当然第一要健康，查一查有什么遗传病吗？那是 marriage 的事，跟 love 没关系。所以你的孩子恋爱了，你不要马上用婚姻的标准来要求他。按照你的婚姻的标准，阻止他们恋爱了，你们知道这意味着什么？

<span id="p-tan-06-455" class="reading-anchor"></span>

宗教要成全自己，必须被迫害。当耶稣被钉在十字架上的时候，基督教成功了。它需要苦难和最初的殉道者，因为它是宗教。爱情是准宗教，你越是去打击这份爱情，它越来越崇高。你在成全他。各位要懂这个道理，那是种归属感，很有意思的。

## 于财离财

**回看 04:26:37—04:33:55**

<span id="p-tan-06-456" class="reading-anchor"></span>

所以我们说到了爱情了，也就是这里惠能讲的色。一个财，一个色，都是人生根本的问题。什么叫觉悟了？这两个问题你解决了。如何面对钱财，如何面对男女之爱？两个根本问题。“能离财色，名两足尊”。这个离是不要吗？我们现在对佛教的说法了解了，离不是不要，不是否定。离财色是否定财和色吗？

于财离财，于色离色。

<span id="p-tan-06-457" class="reading-anchor"></span>

好，我们就来讲讲这个于财离财、于色离色。财能不要嘛？我们没到共产主义。所以那句话一定是对的，没有钱是万万不能的。但是有了财，还有多寡之分吧。有的人财少，被放到一个贫穷人群中去看了。有的人财很多，多到乃至是富豪。

<span id="p-tan-06-458" class="reading-anchor"></span>

我们问一个问题，第一，没财是不可以的，财是养身之资。财多、财寡才是一个讨论的问题。如果一个人彻底没钱，他只能做乞丐，挣扎在生死线上，这就不用讨论了。这叫自然界的状况了。就像动物也要求生一样，这个不去谈它。那么财多、财寡是一个问题，财多了一定给我们带来福气嘛？财少了我们一定没福气嘛？

所以这是一个基本讨论。

<span id="p-tan-06-459" class="reading-anchor"></span>

财少了叫贫，财多了叫富。没钱不叫贫，叫怎么活。这是另外一个问题。贫困是种社会感觉，各位，它不是自然的尺度。自然界让我们每天只要几杯水，几块面包，就活下去了。房子没有，到洞穴里去。冬天找一些东西保持温暖。这是自然界给所有的生物都规定了它的需要的自然限度。

实际上我们每天几杯水、几块面包或者几碗饭，就活下去了嘛。

<span id="p-tan-06-460" class="reading-anchor"></span>

贫困是社会感觉，不是自然的尺度，社会才会发生贫困的尺度。比如说据说是世界银行组织规定了，若一个人每天的消费支出不超过一美元，那在贫困线上。其实他一美元足以活下去了，但他被列为贫困线了。为什么？

<span id="p-tan-06-461" class="reading-anchor"></span>

举个简单例子，假定大家家里都有电视机，唯独你没有。没有电视机能不能活下去啊？当然能活下去了。但是你觉得你贫困了。道理很简单，人类文明的一切成就，你总是得不到，你的感觉就是被驱逐出人类共同体了。这就是贫困，不是自然的尺度。

<span id="p-tan-06-462" class="reading-anchor"></span>

我们没有手机，没有电视机，能活的呀。我们买不起车票，不能坐飞机，也不能坐高铁，我们也走过去了嘛。但是你如果连这种购买力都没有，你不是贫困吗？它不是自然规定的需要，是社会生活规定出来的需要。而这种需要你总是得不到满足，你就是贫困。贫困是社会感觉，记住这一条，它不是自然的规定性。

<span id="p-tan-06-463" class="reading-anchor"></span>

财是必须要有的。老百姓说得好，没有钱是万万不能的。当然前面一句话，钱不是万能的，两句话都对，都对。钱多了一定是福吗？钱少了一定不是福吗？没钱了是生存问题，先活着，别的再说，别的再想办法。这是另外一件事了啊。所以呢，什么叫于财离财呢？于财，是承认财的存在。能离，什么意思？安贫安富。

贫就是钱少，不是没钱啊，钱少。富就是钱多。

<span id="p-tan-06-464" class="reading-anchor"></span>

当我们拥有了钱财，这钱财能否给我们带来福气，取决于我们能否安。钱少能安吗？钱多能安吗？都要能安。我们通常把贫看成是不好的事情，那叫贫贱难耐凄凉。我们把富看成是好事情，但若我们不能安呢，那叫富贵不能乐业。不就孔子说的吗？关键是一个安字。

<span id="p-tan-06-465" class="reading-anchor"></span>

若能安富，财产才是你的福气，财多才是你的福气。否则财多不是你的福气，甚至可能是祸端。若能安贫，财少也是你的福气。若不能安，财少会变成祸端，终于去做强盗了。完全可能啊，去抢劫去了。因为不能安贫。无论是贫还是富，不论是钱少还是钱多，都要能安。这叫能离财色。先说离财，离财就是什么？安贫安富。

<span id="p-tan-06-466" class="reading-anchor"></span>

做强盗也蛮有意思的呀。《水浒传》读过？那是落草了吧，落草为寇。然后呢，最开心的是什么？大块吃肉，大碗喝酒，大秤分金，还有根秤很大的，抢来的金，大家分一分啊，多快活。那它属于非法暴力呢，于是变成剿匪的对象，终于打不过去了，然后宋江就受招安了，是不是这样？

## 于色离色，爱而不迷

**回看 04:33:55—04:40:32**

<span id="p-tan-06-467" class="reading-anchor"></span>

好，我们再来讲讲于色离色吧。男女互相的吸引，因为互相的需要，因为每一个人都是不自满自足的，都是对另一半有需求的、依赖的、归属的。这些都说明了，这叫承认什么？色，叫于色。那么能离，怎么叫离呢？我们刚才说爱情是伟大的，具有准宗教的性质。它可以是非常神圣的，或者它本来就神圣。

就像一个基督徒认为他信仰上帝是神圣的事情，一个在爱情中的人也同样这么感受的。

<span id="p-tan-06-468" class="reading-anchor"></span>

但是爱情可能变质，变为什么？强烈的占有欲。这叫迷了。第一，我们不能没有爱的能力，否则肯定出问题了。对一个男性来说，一个美女从他面前走过，他居然心不动，问题比较大。肯定问题比较大。心动了以后呢，看他怎么动的。心动了以后，就一定要拥有对方，那叫占有，那就是迷了。前念迷是凡夫啊。

<span id="p-tan-06-469" class="reading-anchor"></span>

就像一切宗教信仰是 devotion 一样的，就奉献，爱也是奉献的，那就在它爱情的本意中了嘛，而不是占有。爱是那么的真实，但是它如果转化为占有的欲望，那叫迷了。我们前面也讨论过，在爱情中，后来其中一方被抛弃了，那叫失恋。失恋是种痛苦，但这个痛苦让人升华，除非他从此认为爱是不存在的。

爱是存在的，它不朽。

<span id="p-tan-06-470" class="reading-anchor"></span>

我一直认为，特别是男孩子，到了年龄啊，第一，要谈恋爱的。第二，最好是失恋过的，失恋让男孩子强大。失恋，这是一种非常重要的体验，那是种伟大的痛苦。有些痛苦很卑贱，失恋的痛苦是伟大的。各位，在座的谁经历过这种伟大的痛苦？经历过了就好，让你精神强大。

<span id="p-tan-06-471" class="reading-anchor"></span>

我们今天的人是那么地软弱，那么地没有力量，都害怕失恋了。爱是真诚的，然后它是 devotion，把自己奉献出去了。在这种奉献中，我们得到了心灵最大的愉悦，那属于法喜的。它里边没有利害得失的，爱情是超功利的，各位同意吗？你不要说你付出得更多，然后你吃亏了，你怎么好这么想这件事呢？

<span id="p-tan-06-472" class="reading-anchor"></span>

就像友谊也是超功利的吧，叫 friendship。现在有真正的朋友吗？有真正的友谊吗？若有，它就是超功利的嘛。如果彼此互相利用的，它是 friendship 吗？不是啊。友谊是伟大的，如同爱情是伟大的一样。人世间很难得的。我们没有爱的能力，我们没有友谊的能力，这不是很糟糕的事吗？

这在考量我们的心灵。

<span id="p-tan-06-473" class="reading-anchor"></span>

爱情是座伟大的学校。我们每一个年轻人都要进入这个学校。当然也不管你愿意与否，这个校门总开着的，也没有录取通知书的。你会进去的，你一定会进去的。那个校门一直开着，早晚要进去的。进去以后能否在这个学校成功地毕业，这才是考验。能经受这个考验吗？对每个人来说都是重要的。

<span id="p-tan-06-474" class="reading-anchor"></span>

如果你经受住考验了，你真正地成长了。你不是成长为老于世故了啊，那是退化。当然，爱情需要缘分。这件事我们没把握，那叫情缘。但总有，什么时候发生，不知道。来到这世界上的每一个男人女人，都注定要爱一次的，这个缘分人人都有。有了这个缘分，不要把它变成孽缘，这才是修行。

<span id="p-tan-06-475" class="reading-anchor"></span>

情缘不能变成孽缘，孽债、造孽的孽，孽缘。有许多人终于成了孽缘，没修好，就在生活中修嘛。这是件很大的修行。一个面对钱财，一个面对男女之爱，这是多大的修行的功课啊。不要空说，我在修佛，你就在爱情中修佛呢。

<span id="p-tan-06-476" class="reading-anchor"></span>

于是我得出四个字，恰当与否，大家讨论。什么叫于色离色？爱而不迷。有人对我这四个字不同意的。因为你已经 fall in love 了，一定迷了，怎么还能够不迷呢？我说此言差矣。那你爱了，一定要天天跟他厮守在一起，这当然是自然的愿望。若不能厮守在一起呢，这爱在不在？在，在的。

## 《廊桥遗梦》里的两种真理

**回看 04:40:32—04:44:52**

<span id="p-tan-06-477" class="reading-anchor"></span>

看过那部电影吗？《廊桥遗梦》。这是真实的爱发生了。当然不幸是因为，女主人公已经结婚了，这是一场婚外恋吧。但婚外恋它也是很真实的 love 吧。于是到了命运抉择的关头了。看过这部电影的，一定记得这个情节吧？那个下雨的天，那个女主人公边上是她的丈夫，开着车。

<span id="p-tan-06-478" class="reading-anchor"></span>

前面不远处，她所爱的那个男子，正在那里等她，在雨中等她。这真是命运抉择的关口了。她好几次手要把车门打开，下去，去跟她的恋人在一起，然后走了。但边上是她的丈夫，很好的一个男人。终于她什么？没下去，没跟这位恋人走。但这爱在不在？在。

<span id="p-tan-06-479" class="reading-anchor"></span>

她不是后来，临死之前嘛，把这件事跟她丈夫说了，把我的骨灰撒到那个桥上。那个廊桥就在那里，他们分手的嘛。她没下车，love 是在的。人世间的悲剧就在这里，就两样东西都是真理啊。婚姻中的夫妻之爱，是份真理吧？婚外的那份 love，是不是也是真理啊？这两个真理冲突了，人世间的悲剧莫大于此啊。

这叫真正的悲剧。所以这部电影就写出了这个悲剧。

<span id="p-tan-06-480" class="reading-anchor"></span>

如果是一个是真理，一个是谬误，谬误终于要退场的。两个都是真理，也就是说都是人性的价值，都属于人性的价值。它们恰好冲突，你怎么办？这叫命运的抉择，这时候才叫命运的抉择。你大学毕业以后，是到政府作公务员呢，还是到集团企业作白领？这哪里是命运的抉择？

<span id="p-tan-06-481" class="reading-anchor"></span>

所以这些文学作品、这些艺术作品，让我们看到人生许多根本的东西。所以我想那位女主人公，我赞美她了，她爱了，爱而不迷。爱在的。当然那些浪漫主义的爱情故事被编过多少次了，那么比较深刻的，都是这种冲突。

<span id="p-tan-06-482" class="reading-anchor"></span>

那个《泰坦尼克号》，那份爱真实不真实？真实的，经过了生死考验。那男的放弃了，叫女的永远不要放弃。Never give up。女的后来是不是也嫁人了，也生出不少孩子。她老了，她那个蓝宝石，放到海里去了。那份永恒的爱嘛。佛教居然也讨论这问题了。

<span id="p-tan-06-483" class="reading-anchor"></span>

惠能居然说，“能离财色，名两足尊”。哪两足？一个福，一个慧。福来自对待钱财的正确态度，钱多钱少、贫和富，正确态度一个字，安。我们长智慧在哪里？最能长智慧，在爱情中。对待爱情的合适态度，生慧。所以于财离财是福，于色离色是慧。福慧俱全，那叫什么？两足尊。

## 皈依正，皈依净

**回看 04:44:52—04:50:23**

<span id="p-tan-06-484" class="reading-anchor"></span>

我们再看下去，如何是皈依正？皈依法，就是皈依正。惠能的表达，“念念无邪见，以无邪见故，即无人我贡高、贪爱执着”。皈依法就是皈依正，正意味着什么？正相对于邪而言。念念无邪见。无邪见意味着什么呢？邪见从哪里生？人我别。这叫从人我别中生了邪见，生了人我贡高，把它破了。

还有就是二相中起的贪恋、贪爱执着，都能去掉，称为离欲尊。

<span id="p-tan-06-485" class="reading-anchor"></span>

第三个，自心皈依净。皈依僧，就是皈依净，还是我们心灵自己的境界。“一切尘劳爱欲境界，自性皆不染著。”也就是不染境，不于境上生心。若于境上生心，我们做事情一定带着烦恼，那就是尘劳。我们有所求，我们趋避，这叫尘劳爱欲境界。

<span id="p-tan-06-486" class="reading-anchor"></span>

假如我们能自性不动呢？不于境上生心呢？那这就是众中尊，可以成为众人的榜样。原则都是讲自心、自性。这三宝叫自性三宝，皈依是自心皈依。自心皈依自性三宝，所谓无相三皈依。因为它从自心出发的，皈依的三宝就在我们的佛性中，那叫觉、正、净。

<span id="p-tan-06-487" class="reading-anchor"></span>

所以就是自心皈依，自性三宝。如此才能建构我们心灵的家园。所以皈依是修行者的家，也就是有家可归了。怕的是无家可归。这是《忏悔品》讲的修行的功课，第四个环节叫皈依。第五个就是成佛，成佛就是修行得了正果。所谓得了正果，我们的心灵达到了佛的境界。佛的境界并不是高不可攀，每个人都能成佛。

<span id="p-tan-06-488" class="reading-anchor"></span>

然后第五个环节，就是讲成佛的境界是怎样的。三身佛。哪三身呢？法身、报身、化身。不是说有三种佛，而是成佛的三种境界，三个方面的境界。我们看惠能先说明前面讲的自皈依。“凡夫不会，从日至夜，受三归戒。若言皈依佛，佛在何处？若不见佛，凭何所归？言却成妄。”终于把对佛的皈依变成了妄语。

佛并不在某处等着我们去皈依。

<span id="p-tan-06-489" class="reading-anchor"></span>

所以前面讲自性三皈依，底下又一段，“善知识，各自观察，莫错用心。经文分明言自皈依佛，不言皈依他佛。自佛不归，无所依处”。佛到哪里去求？莫向身外求。向身外求叫骑驴觅驴，骑着毛驴找毛驴呢。我们本有佛性，就这层意思，我们本该依自佛。自佛不归，无所依处。

<span id="p-tan-06-490" class="reading-anchor"></span>

所以三皈依讲的，还是每个人建构自己的精神家园。所以是无相。“今既自悟，各须皈依自心三宝。内调心性，外敬他人。”这就是自皈依，说得非常简明。
