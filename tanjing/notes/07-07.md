# 第7集 · 第7节 行思与怀让，不落阶级与悟后修证

王德峰课程｜《六祖坛经》与禅宗修行｜第一人称口述整理稿｜原视频 04:04:20—04:29:03

**阅读导引｜整理附录**　行思与怀让已经悟，来曹溪求印证。短问答涉及不落阶级，继而展开悟后还要不要修、磨砖成镜、衣钵传承，以及神会何以被称为知解宗徒。

## 一分钟速读｜整理附录

1. 不落阶级指不依修行阶梯、次第来求心法，课堂以教外别传说明。
2. 行思答“圣谛亦不为”，不是在问自己走到了哪个阶梯。
3. 怀让答“说似一物即不中”，拒绝用一个现成名相指认本来面目。
4. 悟后仍有修证：解悟至顿悟，随后以生命实践证悟、护念而不污染。
5. 传心法须有使别人觉悟的实际本领；只在概念中解说，仍可能是知解宗徒。

## 行思问「即不落阶级」

**回看 04:04:20—04:10:48**

<span id="p-tan-07-399" class="reading-anchor"></span>

我们现在接着说第六个机缘，禅宗修行不落阶级。其实不落阶级就是禅宗修行十六字大纲的最初四个字，“教外别传”。这个“教”是指修行的次第、程序、套路。禅宗修行把这些套路、次第都舍去了，别传就是另辟蹊径。

<span id="p-tan-07-400" class="reading-anchor"></span>

传什么？传心法。传心法最大的障碍是文字障碍，所以不立文字，打破文字障才能直指人心。这是传心法。直指人心若成功了，那叫本心自悟。本心自悟，即见自己本有的佛性，那叫见性成佛。

<span id="p-tan-07-401" class="reading-anchor"></span>

所以十六字大纲的最初四个字，就是禅宗修行不落阶级的意思。这个阶级不是阶级斗争那个阶级啊，是向上攀登的阶梯。是不是要一步步往上面攀登？通常我们会这么想修行的过程。

<span id="p-tan-07-402" class="reading-anchor"></span>

从第六个机缘开始，第六、第七、第八个机缘，前来参请佛法的，其实是已经悟了的禅师。所以他们到惠能那里干嘛？想要在惠能那里得到印证，印证自己是不是真悟了。若得到惠能的认可，他便是真正的禅宗祖师了。可见惠能在当时禅宗发展的这个关键时候所具有的关键地位。

<span id="p-tan-07-403" class="reading-anchor"></span>

第六则机缘来了行思，第七个机缘来了怀让。这两位禅师在中国禅宗的发展史上十分重要。不是说“一花开五叶”吗？这五叶是谁开出来的？行思、怀让。从行思开出三个宗，法眼宗、云门宗、曹洞宗。在怀让底下开出两个宗，沩仰宗、临济宗。所以惠能是通过了行思禅师和怀让禅师才一花开五叶，这就是这两位禅师的重大作用。

<span id="p-tan-07-404" class="reading-anchor"></span>

他们先要来到惠能这里，要得到认可。说行思听闻曹溪那里，广东韶关，“法席盛化，径来参礼”。直接就过来了，过来以后就跟惠能对话。他没有等惠能问，倒是先开口问。

<span id="p-tan-07-405" class="reading-anchor"></span>

行思问惠能：“当何所务，即不落阶级？”我们应当怎样修行，做怎样的功课，才不至于落入这个修行的通常的套路中去？落入这个所谓修行的渐进的次第中去，该怎么做？惠能没正面回答，倒是反问他了。

<span id="p-tan-07-406" class="reading-anchor"></span>

“汝曾作什么来？”你曾经怎么修的？行思回答：“圣谛亦不为。”我们知道，释迦牟尼在菩提树下悟道之后，初转法轮说的佛法是什么？苦、集、灭、道，四圣谛。所以行思回答得很直接，我四圣谛都不修的。

<span id="p-tan-07-407" class="reading-anchor"></span>

惠能还问一个傻问题，有意的。那么你在哪个阶级上呢？行思说：“圣谛尚不为，何阶级之有？”我第一个阶梯都没踏上去，哪有阶梯，何阶级之有？这样简短的对话就让惠能心里明白了，此人是悟了的。

<span id="p-tan-07-408" class="reading-anchor"></span>

所以《坛经》里这样讲，“师深器之”，十分地器重行思。先让他做什么？做首座弟子。惠能让行思做了自己的首座弟子，所以叫“令思首众”，率领其他弟子。

<span id="p-tan-07-409" class="reading-anchor"></span>

有一天，惠能就跟行思讲了，你不能老在这里，“汝当分化一方，无令断绝”。明确地告诉了行思的使命，你到别的地方去主化一方。后来行思就到吉州青原山，“弘法绍化”。他圆寂之后被谥号为弘济禅师。第六个机缘的内容就是这样，其实它是非常简单。通过惠能与行思的对话来说明教外别传。

## 怀让问答与悟后修证

**回看 04:10:48—04:18:09**

<span id="p-tan-07-410" class="reading-anchor"></span>

第七个机缘是怀让来了，也称他为禅师的。我们注意到这一点，前面几位都是尚未悟的，所以称为僧，僧人，出家人。到第六个机缘开始，被称为禅师，一共六、七、八三个机缘，都是悟了的人来惠能这里得一个印证。

<span id="p-tan-07-411" class="reading-anchor"></span>

怀让也是这样。他最初到嵩山安国师那里，安国师跟他讲，你到我这里来不行，你还是应该到惠能那里去。“安发之曹溪参扣。”怀让到了惠能那里，当然首先是拜，“让至礼拜”。

<span id="p-tan-07-412" class="reading-anchor"></span>

拜完之后，惠能就问他：“甚处来？”从哪里来？“嵩山。”“什么物，恁么来？”你什么东西那么来？怀让怎么回答？“说似一物即不中。”也就是说，我不是东西。这句话其实就够了。

<span id="p-tan-07-413" class="reading-anchor"></span>

“什么物，恁么来？”怀让若说自己是某某禅师，那完了。问的是本来面目嘛，所以他说“说似一物即不中”，说什么都错了。惠能心里已经明白了，问他一个问题：“还可修证否？”这个问题有一个前提，你已经悟了，所以才问他“还可修证否”。

<span id="p-tan-07-414" class="reading-anchor"></span>

这是一个比较重要的问题，向来有两种不同的见解。一种见解认为悟了就是悟了，不必再修了。还有一种见解认为，悟了之后还得修。我们看怀让是怎么回答，“修证即不无，污染即不得”。回答是肯定的，还得修。

<span id="p-tan-07-415" class="reading-anchor"></span>

悟了之后，他已经是真正的禅宗祖师了，他可以度别人了，也可以帮助别人悟。但他自己还得什么呀？还得修证。这个修证呢，就是悟了之后的修行。这悟了之后的修行是什么？证悟。

<span id="p-tan-07-416" class="reading-anchor"></span>

就禅宗而言，修行的第一阶段是解悟，那就是要去觉解佛法，借助佛经的诵读，借助大善知识的开示。这个阶段就是解悟。这个阶段在什么时候终止了呢？顿悟。达到顿悟这个环节，解悟这个阶段就终止了。还修，那叫证悟。

<span id="p-tan-07-417" class="reading-anchor"></span>

所以惠能问他“还可修证否”。这时候不需要佛经的经文，也不要听别人讲经说法，不需要。这个证悟就是用自己的生命实践来印证佛理，那是实证了。元音老人的一本书的书名叫《佛法修证心要》。就是元音老人悟了，悟了之后他的修行，叫修证。《佛法修证心要》，这个书我们可以找来看，就元音老人的。

<span id="p-tan-07-418" class="reading-anchor"></span>

这就是禅宗讲修行两个阶段，顿悟之前和顿悟之后。顿悟之后还要用文字吗？不用文字啊，就是生命实践来体现，体现佛理的。

<span id="p-tan-07-419" class="reading-anchor"></span>

所以丰子恺先生当年想念他的恩师李叔同。李叔同后来成了弘一法师的。想念自己的恩师，到了寺庙里，跟弘一法师相处了两个礼拜吧。出来之后，李叔同先前的其他弟子问丰子恺：“老师在庙里跟你说了些什么？”丰子恺回答：“一句话都没跟我讲，但是我的收获很大。”

<span id="p-tan-07-420" class="reading-anchor"></span>

换句话说，弘一法师用他的言行举止呈现佛理，让丰子恺得到领会，没有言语的交流。这是非常典型的。看来丰子恺也是有法眼，从这些日常相处，跟弘一法师朝夕相处那一段日子，自己受了极大的启发。不是语言文字的交流，弘一法师也没有给丰子恺讲经说法，没有。这就是证悟。

<span id="p-tan-07-421" class="reading-anchor"></span>

证悟是顿悟之后的修行，那叫护念。护念就是让自己不要再被外境所染。“污染即不得”，惠能立刻表示赞同，“只此不污染，诸佛之所护念”。成佛的人都这样。然后认可他了嘛，“汝既如是，吾亦如是”。等于向他宣布了，你可以真正地做禅宗祖师了。

## 磨砖与传心法的证据

**回看 04:18:09—04:24:56**

<span id="p-tan-07-422" class="reading-anchor"></span>

还给他一个谶语。“西天般若多罗”，谶就是种预言，将来在你手下，“汝足下出一马驹，踏杀天下人”。然后告诉他，你现在不能说。“应在汝心”，你只要等着，那天会到来。

<span id="p-tan-07-423" class="reading-anchor"></span>

这个马驹就是马祖道一。马祖道一后来修成了嘛，也是禅宗祖师了，非常厉害。在马祖道一下面悟出好几位了，马祖道一下面后来才开出沩仰宗和临济宗。所以马祖道一也是关键人物啊，大珠慧海就在马祖道一那里悟的。

<span id="p-tan-07-424" class="reading-anchor"></span>

怀让怎么让马祖道一悟的？这个故事。马祖道一坐禅功夫很深，名气也大。怀让听说马祖成天在那里坐，怎么办？如何启发他？在马祖道一所在的庙门口磨砖，终于被马祖道一发现了。

<span id="p-tan-07-425" class="reading-anchor"></span>

马祖道一问怀让：“你磨砖干嘛？”

“磨砖成镜，我要把这个砖磨成镜子。”

马祖道一笑了：“砖如何成镜？”

怀让跟马祖说：“坐如何成佛？”一句话点通了马祖道一。你以为拘束着这个身体不动，就终于成佛了？你想这样成佛，就像我要把砖磨成镜一样的荒谬。这是后话。

<span id="p-tan-07-426" class="reading-anchor"></span>

现在惠能跟他讲，你将来下面有一位非常了不起的禅宗祖师，你现在记住。听了惠能的这些话之后，“怀让豁然契会”。一下子就明白了，也知道将来的使命了。怀让知道了自己将来的使命，特别重要的是，将来要来一位马祖道一，在禅宗的领域里边起极大的作用，那叫“踏杀天下人”。

<span id="p-tan-07-427" class="reading-anchor"></span>

这样呢，就再追随惠能十五年，“执侍左右十五载”。他的境界越来越高，叫“日臻玄奥”。日臻玄奥表明什么？他帮助他人觉悟的方法越来越多。然后去南岳“大阐禅宗”，让禅宗发扬光大。

<span id="p-tan-07-428" class="reading-anchor"></span>

让禅宗发扬光大，要有真的本事，它体现为他能让许多人悟。中国近现代史上还有没有真正的禅宗祖师，这倒是个问题啊。要拿史实做依据。什么史实？有谁在某某大和尚那里悟了？这就是证据了。那么这位大和尚一定是什么？禅宗祖师。

<span id="p-tan-07-429" class="reading-anchor"></span>

虚云一定是的，因为在虚云那里悟的人很多，所以影响极大。虚云之后是谁，咱不知道，就没有史料做依据了。照理禅宗的传承，是谱系最清晰的一个宗派。

<span id="p-tan-07-430" class="reading-anchor"></span>

当初弘忍法师不是把一个画家找来吗？叫他在南廊的墙壁上画一个血脉图。什么叫血脉图？从达摩开始一路传过来，初祖、二祖、三祖、四祖，到他那里五祖，要画出来的。这是禅宗的一个重大的特点。

<span id="p-tan-07-431" class="reading-anchor"></span>

传心法很玄妙，究竟传成了没有呢？证据在哪里？得了心法的人要让别人也能悟啊，这才叫得了心法。当初达摩呢，是认为我们禅宗在中国的发挥要代代相承，但是没证据。衣钵的传承就是一个证据信物啊。

<span id="p-tan-07-432" class="reading-anchor"></span>

所以二祖慧可得了达摩的衣钵，三祖僧璨得了慧可的衣钵，四祖道信得了僧璨的衣钵，然后一直传到五祖弘忍。五祖弘忍把衣钵传给惠能，就是证据。后来不是到广州法性寺吗？印宗法师，也就是广州法性寺的方丈，说你把衣钵拿来看看嘛，就显示给大家，证据在啊。

<span id="p-tan-07-433" class="reading-anchor"></span>

但是弘忍法师跟惠能讲了，到你那里不能再传衣钵了，“止汝勿传”。因为这个佛教界已经出了很大的问题，传衣钵起争端，命若悬丝，变成一种利益的争斗，性命交关。所以惠能再传了没有呢？没传衣钵。所以就没有所谓第七祖、第八祖，都没了。但是开了五个支脉，这可是真的。各有传承，还传到日本去，比方说临济宗。这叫以史实做根据。第七个机缘的意思。

## 再看神会怎样回答

**回看 04:24:56—04:29:03**

<span id="p-tan-07-434" class="reading-anchor"></span>

关于本来面目不可说，后面《顿渐品》里也有一段，讲的是神会。我们看有一次，惠能把众弟子都叫在边上，跟他们说话。“一日，师告众曰”，跟众弟子们讲，“吾有一物，无头无尾，无名无字，无背无面”，既没有反面，也没有正面，“诸人还识否？”

<span id="p-tan-07-435" class="reading-anchor"></span>

神会站起来说了：“是诸佛之本源，神会之佛性。”听上去还说得不错啊，天下人都一样，都有佛性。你惠能说你有一个东西，问我们识还是不识。神会认为应当说识，不能说不识。是什么？你说的你的东西，也是我的东西，“诸佛之本源，神会之佛性”。这话听上去还不错，似乎蛮有境界的。

<span id="p-tan-07-436" class="reading-anchor"></span>

但是惠能怎么说？“向汝道”，先前我跟你们说的是什么？“无名无字，汝便唤作本源佛性。”你还是要给它一个名相。“汝向去有把茅盖头”，你将来可以做一个小草房、小草屋，你就待在里边。你修行终于只是一个“知解宗徒”，还在名相中讨真理呢，在佛经经文的概念中修行。这样的人被称为知解宗徒。

<span id="p-tan-07-437" class="reading-anchor"></span>

这个知解呢，就相当于英语当中那个单词叫 understanding。在理性的认识中来修佛，从经文中修没错的，至于把经文就当成概念，那就……佛经的文字是文字，但是它说话就是为了破名相的。而你就停留在概念中，停留在名相中修，这样的人就是知解宗徒。

<span id="p-tan-07-438" class="reading-anchor"></span>

“吾有一物”，那个怀让怎么说？“说似一物即不中”嘛。我惠能的本来面目，你们识还是不识？问这件事。结果神会说，我自己的本来面目跟你的本来面目是一回事。怎么可以这么说？一个真悟了的人，是知道自己本来面目的，但是说不出来的。一说出来，就不是本来面目。

<span id="p-tan-07-439" class="reading-anchor"></span>

惠能总不能说我是谁，我是禅宗六祖。禅宗六祖这一说，还不是他的本来面目吧。你达到了宿命通，知道你的前世了，说得出来吗？心里明白，你要把前世是怎样的，还是一个名相，还是那个末那识，还是那个小我。此生之小我已经不同于前世之小我，贯穿其中的是不可说的本来面目。

<span id="p-tan-07-440" class="reading-anchor"></span>

这里似乎神会被贬了一下，是吧？但是神会对禅宗的发展做出重要贡献。好，我们是把这一段跟前面的怀让禅师的对话联系起来，这就是第七个机缘。

## 本节总结｜整理附录

行思问怎样不落阶级，惠能反问其所修，行思以连圣谛也不为的回答得到认可。怀让机缘继续追问本来面目与悟后修证，课堂从解悟、顿悟、证悟的层次，讲到弘一法师以日常言行启发丰子恺。

之后保留马驹谶语、马祖磨砖故事、怀让十五年执侍及禅宗传承证据的讨论。最后借神会给无名无字之物命名为本源佛性，说明能解释概念与真正悟得本来面目之间仍有距离。
