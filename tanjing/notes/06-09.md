# 第6集 · 第9节 一体三身与《忏悔品》的无相颂

王德峰课程｜《六祖坛经》与禅宗修行｜第一人称口述整理稿｜原视频 04:50:23—05:14:48

**阅读导引｜整理附录**　《忏悔品》的最后一个环节是成佛。本节逐项说明法身、报身、化身，再回引《机缘品》智通问答，并完整读完本品《无相颂》及法会散场时的嘱咐。

## 一分钟速读｜整理附录

1. 一体三身是自性佛的三个方面，不是三位彼此分离、各有自性的佛。
2. 清净法身以本有佛性说明，日月浮云的比喻解释清净与遮蔽。
3. 圆满报身连到智慧与消除累世罪业，“莫思向前，常思于后”依课堂解释指向未来。
4. 千百亿化身通过师生、父子、店主顾客、上下级等关系展开，说明在不同处境中的生活实践。
5. 《无相颂》重申修福不等于修道、除罪缘须在心中，并催促抓住现在世修行；末尾区别开悟与以后的了悟。

## 一体三身自性佛

**回看 04:50:23—04:52:30**

<span id="p-tan-06-491" class="reading-anchor"></span>

底下要讲三身自性佛了。“善知识，既皈依自三宝竟”，把皈依这功课讲完了。“各各志心”，希望在座的每个人都专心致志。“吾与说”，我跟大家讲，“一体三身自性佛，令汝等见三身，了然自悟自性”。于是他要在场的人都念，“总随我道”。

<span id="p-tan-06-492" class="reading-anchor"></span>

“于自色身，皈依清净法身佛。于自色身，皈依圆满报身佛。于自色身，皈依千百亿化身佛。”色身就是肉体。“善知识，色身是舍宅，不可言归。”我们的身体，并不是我们的家。“向者三身佛，在自性中”，从来三身佛都在我们的自本性中的，“世人总有”。

<span id="p-tan-06-493" class="reading-anchor"></span>

因为迷了，“自心迷，不见内性”。心迷便不能见性。内调心性，前面讲了。因为自心迷的缘故，不见自己本有的佛性，向外寻找，这叫“外觅三身如来”。如来就是佛。“不见自身中有三身佛。汝等听说”，听我讲，“令汝等于自身中见自性有三身佛。此三身佛，从自性生，不从外得”。

就是我们心灵自己能达到的境界，三身佛的境界，佛性中本有啊。

## 清净法身佛

**回看 04:52:30—04:56:03**

<span id="p-tan-06-494" class="reading-anchor"></span>

那么我们下面就来看一看，惠能怎么说成佛的三个方面的境界。先说法身佛，前面两个字，清净。清净法身佛。“世人性本清净，万法从自性生。”万法就是万事万物。其实都从我们佛性中起来，才能发现万事万物，所以佛教是唯心论。看我们的心怎么样，如何思量。

<span id="p-tan-06-495" class="reading-anchor"></span>

“思量一切恶事，即生恶行。思量一切善事，即生善行。”就善和恶，不是世界上万事万物自己的属性，是我们思量出来的。就看我们的心怎么用嘛。用得不好了，恶事就被你思量出来了，便生恶行。用得好了，那叫“思量一切善事，即生善行”。

<span id="p-tan-06-496" class="reading-anchor"></span>

“如是诸法在自性中，如天常清。”天是不是包含万物啊？包含万法。如果常清的话呢，这叫“日月常明”。日和月两个字合起来，就是个明字嘛。因为“浮云盖覆”，结果是“上明下暗”。我们本有我们自己的明，但是被浮云盖覆了。这浮云就是小我之私欲，由我执产生的私欲，那就是浮云。结果是明还在的，下面倒是暗了。

<span id="p-tan-06-497" class="reading-anchor"></span>

“忽遇风吹云散，上下俱明，万象皆现。世人性常浮游”，浮游就是在二相中趋避，就好比是天上的云，它会遮蔽太阳，也遮蔽月亮。所以日和月又分开来说了，“善知识，智如日，慧如月，智慧常明”。如果于外著境呢，那就“被妄念浮云盖覆自性，不得明朗”。还是需要帮助。

<span id="p-tan-06-498" class="reading-anchor"></span>

“若遇善知识”，其实是大善知识，“闻真正法，自除迷妄，内外明彻，于自性中万法皆现，亦复如是”。这一段话我们念了，其实就想起惠能悟的时候，接着弘忍法师说下来，说了五个何期。“何期自性，本自清净”，不就是在说清净法身佛吗？

## 圆满报身佛

**回看 04:56:03—04:58:44**

<span id="p-tan-06-499" class="reading-anchor"></span>

然后我们再来看如何说报身佛。下一段：“何名圆满报身？如一灯能除千年暗，一智能灭万年愚。”这就让我们领会到了什么？这个报身是指什么报了？什么叫圆满报身佛？

<span id="p-tan-06-500" class="reading-anchor"></span>

我们布施，修福得福报。若我们是真修行，不是得福报，是什么？把累世累劫的罪业给它消了。这就是一灯能除千年暗，一智能灭万年愚。我们曾经是千年暗、万年愚的，种种之罪业，一起都消除了，这叫圆满报身。

<span id="p-tan-06-501" class="reading-anchor"></span>

过去的已经消除了，“莫思向前”，不要再想过去的事了。“已过不可得”，这个汉字它印刷错误啊，不是己，是已，已过不可得。“常思于后”，想着未来吧。“念念圆明，自见本性，善恶虽殊，本性无二。”善与恶是对立的。本性无二。“无二之性，名为实性，于实性中，不染善恶，此名圆满报身佛。”

<span id="p-tan-06-502" class="reading-anchor"></span>

看来圆满报身佛，是指向未来的。因为累世累劫的罪业已经消了嘛，不要再想过去了。“莫思向前”，就以往。“常思于后”，这就叫圆满报身佛。相当于惠能悟的时候说的，“何期自性，本自具足”，那叫圆满。“本无动摇”，这叫圆满报身。

## 千百亿化身佛

**回看 04:58:44—05:05:54**

<span id="p-tan-06-503" class="reading-anchor"></span>

再看如何说化身佛。“何名千百亿化身？若不思万法，性本如空。”我们活在这世界上，一定跟万事万物打交道。“一念思量，名为变化。”又想到前面讲的思量，就我们的心怎么用。

<span id="p-tan-06-504" class="reading-anchor"></span>

“思量恶事，化为地狱。思念善事，化为天堂。毒害化为龙蛇，慈悲化为菩萨。智慧化为上界，愚痴化为下方。”这讲到六道了。“自性变化甚多，迷人不能省觉。念念起恶，常行恶道。回一念善，智慧即生。”还是讲思量。但这思量为什么是化身呢？而且还说千百亿化身。

<span id="p-tan-06-505" class="reading-anchor"></span>

因为我们活在这世界上，活在这世界，要跟事事物物打交道。跟不同的人打交道，也就处在不同的关系之中。在每一种关系中，看你如何思量。当我们作学生的时候，我们有老师。在老师面前，我们是学生，那么作学生如何跟老师打交道，也看你如何思量。

<span id="p-tan-06-506" class="reading-anchor"></span>

但是我们随时会变化角色。后来自己也有了学生了，在自己的学生面前，我们成了老师了。在老师面前，我们是学生。同一个人，既是老师又是学生。我们为父母所生，在父亲面前，我们是儿子。后来自己也生了儿子了吧，在儿子面前，我们又是父亲。就是我们既当儿子，又当父亲。同一个人有种种变化的关系。

<span id="p-tan-06-507" class="reading-anchor"></span>

我们到别人开的店里买东西，我们叫顾客，面对了店主。别人到我们自己开的店里买东西，我们是店主，他成了顾客。同一个人，在一种情况下是顾客，在另一种情况下是店主。同一个人，是不是变化了？种种不同的关系吧。

<span id="p-tan-06-508" class="reading-anchor"></span>

上下级关系也一样。在上级面前，我们是下级，在自己的下级面前，又成了上级。你如何作下级，如何作好上级，这都是化身，只看你如何思量。人世间关系有种种，用大数字说话，叫千百亿化身。讲的就是我们在生活中如何实践的。讲的是应世，所以又叫应身。我们是不是要应世？

<span id="p-tan-06-509" class="reading-anchor"></span>

这样讲，成佛的三个方面，第一根本是什么？清净法身佛。清净法身佛达到了，意味着我们就是圆满报身。我们消了累世累劫的罪业。“自性起一念恶，灭万劫善因。”我们以前也做过善事嘛，结果一念恶，就把它灭了。“自性起一念善，得恒沙恶尽。”我们有种种的罪业，数量之大，如恒河沙数，都消解了，都消除了。

这叫报身嘛。

<span id="p-tan-06-510" class="reading-anchor"></span>

在圆满报身这个境界中，我们是向前看的，向着未来。在未来中，我们要跟世间万事万物和种种的人打交道，那叫应世，那便是化身佛了。关于这一点，在后面《机缘品》里边讲得更为简明。我们来看，就是三身佛，讲得非常简明的，就在《机缘品》里边，回答那个智通的提问。

<span id="p-tan-06-511" class="reading-anchor"></span>

智通不是问三身四智吗？他来问佛法，他诵那个《楞伽经》约千余遍，功夫也蛮深，但总是不能领会三身四智。所以到惠能这里来，惠能回答得非常简明。“三身者，清净法身，汝之性也。”你本有的佛性，你的自性、自本性，这就是清净法身了。

<span id="p-tan-06-512" class="reading-anchor"></span>

“圆满报身，汝之智也。”你的智慧。看来波罗蜜就是度啊，最高的度，是以智慧来度吧。因为以智慧来度的缘故，我们才消了累世累劫的罪业。六种波罗蜜，前面三种是什么？福德资粮，布施、持戒、安忍，这是积累了福德了。后面三种波罗蜜，智慧资粮。精进、禅定、般若，这叫智慧资粮。

因为起了智慧的缘故，我们得了圆满报身。

<span id="p-tan-06-513" class="reading-anchor"></span>

所以“圆满报身，汝之智也。千百亿化身，汝之行也。”千百亿化身，就是你的生活实践，就是你的实践。“若离本性，别说三身”，离开我们的自本性，去说那个三身，那叫什么？“有身无智”。“若悟三身无有自性”，那就是四智菩提。三身不是三种佛，分开来说的，法身佛、报身佛、化身佛，就是同一个佛三个方面。

不能说法身佛有它的自性，报身佛又另有自性，化身佛又有自性。所以这就是我们看《机缘品》对三身佛的说明，更为简明了。

## 无相颂与临别的话

**回看 05:05:54—05:14:48**

<span id="p-tan-06-514" class="reading-anchor"></span>

我们再回过来看，讲了三身佛，又回过来讲皈依了。什么叫皈依佛？“法身本具”，法身是心体吧，心之本体人人具备。色身是我们的肉体，法身是我们的心体。“念念自性自见，即是报身佛。从报身思量，即是化身佛。自悟自修，自性功德，是真皈依。皮肉是色身，色身是舍宅，不言皈依也。”

前面已经说过这层意思，这里重复了，再说一次。“但悟自性三身，即识自性佛。”

<span id="p-tan-06-515" class="reading-anchor"></span>

然后来了一个《无相颂》。这个《无相颂》讲了几点呢？我们先来看第一第二句，“迷人修福不修道，只言修福便是道”。就搞错了。其实就是《疑问品》里边说的，修福不是功德，会有福报，那叫福德。不要把修福当成就是修道了。

<span id="p-tan-06-516" class="reading-anchor"></span>

布施供养，要承认的，会有福报吧？有，叫福无边。但是心中三恶还在吧，元来造。哪三恶？贪、嗔、痴。我们布施、供养、做好事，却并没有把我们的贪嗔痴去掉。“拟将修福欲灭罪，后世得福罪还在。”《疑问品》里讲的意思，也是弘忍法师说的啊，“只求福田，不求出离生死之苦海。

自性若迷”，没见到自己本有的佛性，“福何可救”？你得了福报，还是救不了你的罪，赎不了你的罪业。

<span id="p-tan-06-517" class="reading-anchor"></span>

“但向心中除罪缘。”什么叫罪缘？就罪因啊。一共是三个，愚迷、骄诳、嫉妒，要把它除了。“名自性中真忏悔。”又总结了前面讲的忏悔这一个环节。“忽悟大乘真忏悔，除邪行正即无罪。学道常于自性观”，我们学佛，也就是要修佛道了，要从自性出发，“即与诸佛同一类”。

<span id="p-tan-06-518" class="reading-anchor"></span>

“吾祖惟传此顿法”，弘忍法师传的就是顿法，“普愿见性同一体”。我们都自见佛性，我们便没有人我别了。无我相，无人相，无众生相，无寿者相。“若欲当来觅法身，离诸法相心中洗。”我们要破除种种的名相。

<span id="p-tan-06-519" class="reading-anchor"></span>

最后四句，这是不断在提醒我们，要抓住现世，抓住现在世来修。“努力自见莫悠悠”，不要把岁月空添。“后念忽绝一世休”，如果我们没有抓住现在世好好修，突然有一天就走了，这一辈子就荒废了，叫一世休。后念忽绝，就死了。“若悟大乘得见性，虔恭合掌至心求。”总是从我们心出发。

<span id="p-tan-06-520" class="reading-anchor"></span>

我们看最后一段，很有意思。惠能要跟他们告别了。“善知识，总须诵取，依此修行。言下见性，虽去吾千里”，这个去，就离开，离开我有千里之遥，“如常在吾边”，仿佛还在我身边。要依此修行，就跟我在一起。汝既如是，吾亦如是。一定要修行，依照这个《无相颂》来修。

<span id="p-tan-06-521" class="reading-anchor"></span>

“于此言下不悟，即对面千里”，我们整天在一起也没用，我跟你面对面的，其实相隔着千里呢。“何勤远来？”如果我们总是对面千里的话，你远远地到我这里来干嘛呢？“珍重好去。”也就是说这个法会就说完了，结束了。各自好好去修。

<span id="p-tan-06-522" class="reading-anchor"></span>

这个效果是有的啊，叫“一众闻法，靡不开悟，欢喜奉行”。能开悟已经不错了，以后就有了悟的机会。所以开悟，惠能自己是一闻“应无所住而生其心”，心即开悟，那叫上根之人。我们没办法比呀，我们只能诵这个《无相颂》了，认认真真地去修。

<span id="p-tan-06-523" class="reading-anchor"></span>

这样就用一个《无相颂》总结了《忏悔品》讲的修行的五个环节，修行功课的五个环节。能否做到，看各位自己。惠能就这个意思，你们走吧，珍重好去。我们这个功课每天都做，就是惠能的意思。如果你在家修行，要传香，要忏悔，要发愿，要皈依，还有，目标坚定，一定要成正果。

<span id="p-tan-06-524" class="reading-anchor"></span>

这样我们就把我们的第六讲讲完了。从坐禅讲到皈依。后面还有两讲，第七讲是参禅与悟缘。我们要看禅宗修行者如何参禅的，这是非常精彩的事。为什么说惠能才是为中国禅宗真正奠基的人？在《机缘品》里边就能发现，禅宗在惠能之后，禅宗总是让人悟的种种方法，在《坛经》里边已经有了萌芽。

他们如何对话，如何棒喝，都有。这个我们后面再说。好，就讲到这里。

## 本节总结｜整理附录

三身的讲解始终遵循“不从外得”：清净法身是性，圆满报身是智，千百亿化身是行。课堂先随《忏悔品》展开云日、善恶、过去与未来等问题，再用不同社会关系解释化身，最后借智通问答作简明对照。

随后的《无相颂》重新连起福德与功德、罪因与真忏悔、见性与离法相，以及当下修行的紧迫性。法会最后的千里与对面千里说明听懂和实行的关系；全讲以传香、忏悔、发愿、皈依、成佛五个环节收束，并预告参禅与悟缘。
