## 即时豁然，还得本心

**回看 02:42:49—02:48:18**

<span id="p-tan-03-279" class="reading-anchor"></span>

好，我们接着来看。我们把《坛经》打开，看第二品《般若品》。“不悟即佛是众生，一念悟时，众生是佛。故知”，所以知道，“万法尽在自心”，在我们的自本心中。“何不从自心中顿见真如本性？”我们注意到惠能用了一个“顿”字的。

<span id="p-tan-03-280" class="reading-anchor"></span>

惠能主张顿悟的吧。禅宗在南宗是顿教，在北宗是渐教。惠能是南宗的领袖，他上承弘忍法师。弘忍法师就是讲顿悟的啊，上承五祖。《菩萨戒经》，有一部这样的经，讲戒律的，“我本元自性清净。若识自心见性，皆成佛道”。还有一部经，就是《维摩诘经》，也就是意译的话，就是《净名经》。“即时豁然，还得本心。”

<span id="p-tan-03-281" class="reading-anchor"></span>

什么叫豁然？顿悟。我们不是有个成语叫豁然开朗嘛？一下子明白了，豁然开朗。即时，当下，就当下豁然。豁然悟了是什么？本心自悟，叫还得本心。禅宗强调的就是本心自悟。大善知识、禅宗祖师、大德高僧帮助了我们，但他们不能代我们悟。这是启发，悟是每个人自己的事，是吧？

<span id="p-tan-03-282" class="reading-anchor"></span>

那么我们会不会悟呢？根据在哪里？根据在本心呢。悟和认知活动不一样。我们能理解科学，根据在哪里？头脑的智力，understanding，理解力。悟不是认知，那么悟的根据在哪里？不是 understanding 吧，不是你的智力，intelligence，不是。是什么？很难翻译成欧洲语言的，是本心。大概有一个词，德语的那个词叫 Gemüt。悟是心的事情，不是头脑的事情。

<span id="p-tan-03-283" class="reading-anchor"></span>

但许多人修行就走了头脑的路。什么叫走了头脑的路？就去解释经文。惠能称这些人叫知解宗徒。靠佛经的文字来修的，这叫知解宗徒。所以《维摩诘经》也是部了不起的经，在中国也普及，也相当普及。《坛经》很普及，《维摩诘经》也是许多中国历代修佛的人必读的经。

<span id="p-tan-03-284" class="reading-anchor"></span>

维摩诘就是什么？跟佛陀同时代的大居士。他说的话，“即时豁然，还得本心”，两层意思吧。一，悟是谁在悟？本心自悟。悟是怎样的？顿悟。我说了一句话，以前在讲课的时候也提到的。对顿悟的比较好的解释，我们今天中国人都听得懂的，叫灵魂深处爆发革命。这就是顿悟。

<span id="p-tan-03-285" class="reading-anchor"></span>

第一，它不是头脑的事，是吧？是灵魂的事。我们不会把头脑的事变成灵魂，把灵魂的事理解成头脑的事，不可能吧？这一点我们清楚的。第二，它是革命，什么叫革命？我们的心灵，也就是生命情感所在的地方。生命情感向上翻转，那叫升华，revolution，革命。

<span id="p-tan-03-286" class="reading-anchor"></span>

升华倒是借助于物理学的概念，从固态越过液态，直接气态，不叫升华吗？你们家里用樟脑丸，是吧？樟脑丸的特点嘛，就是升华呀。它越过了液态，从固态直接到气态，对吧？这叫升华。革命呀，revolution 呀。这革命是怎么发生的？爆发的，那叫顿。就我们的灵魂可曾爆发过革命？等于在问我们可曾悟过，是不是这件事？

## 渐修、顿悟与护念

**回看 02:48:18—02:52:01**

<span id="p-tan-03-287" class="reading-anchor"></span>

千万别把悟跟认知活动等同起来。随时可能等同，等同以后就进入名相的理解中了，那么终于远离了修行。很多人都这样，许多我的朋友、中学同学就这样。他读经文，也听了课，也很用功。然后跟我讲许多佛教的道理，讲得真是很好的，头头是道的。

<span id="p-tan-03-288" class="reading-anchor"></span>

朋友先说自己怎样得到启发，然后说：我现在知道检查我生命情感的毛病，这个是病，那个也是病，知道得很多。我说，你就继续检查下去。他说，你这话什么意思？也就是你没悟呀。你灵魂没革命过，你就一直检查吧。拿经文的标准，来检查这个毛病、那个毛病。

<span id="p-tan-03-289" class="reading-anchor"></span>

我说这样人生倒也蛮苦的，就不断地检查，不断地检查。检查是需要的，是一个阶段，叫渐修。查一查自己的生命情感的毛病，必要啊，一定是必要的。但是终于要准备好那一刻的到来。这一切的渐修，是为了准备什么？顿悟啊。

<span id="p-tan-03-290" class="reading-anchor"></span>

顿悟之后呢，要修吗？要修的。这不是检查，而是什么？护念。什么叫护念？不被外境所染，只是这件事情。你还在现实世界中，你还在生活中，你的处境也不断在改变，不再为它所染，这是你的护念。

<span id="p-tan-03-291" class="reading-anchor"></span>

到一定的程度，连这个护念都不需要了。不是有个词叫保任吗？悟了之后要保，这就护念。保到后面，终于不需要保，叫任。从心所欲不逾矩。终于到这个份上了，到这个份上什么事都行，那叫千百亿化身佛。

<span id="p-tan-03-292" class="reading-anchor"></span>

底下惠能说到自己了，“善知识，我于忍和尚处”，忍和尚就是弘忍法师，“我于忍和尚处，一闻言下便悟”。也就是我们前面讲到了，《坛经》第一篇里边讲，弘忍法师在方丈室里，那天半夜三更时分，在灯下给惠能讲《金刚经》。惠能闻说之后，言下大悟，又一个顿字吧。

<span id="p-tan-03-293" class="reading-anchor"></span>

他不是说跟弘忍法师说，我现在基本上有点懂了，你不急，我慢慢再悟出来啊。没这件事吧，马上就是接着说话了。这是顿悟啊，不是渐悟啊。连说五个何期吧。因为弘忍法师就说，你现在可以做天人师了吧，大丈夫、天人师、佛。你做六祖吧。

## 大善知识怎样示导

**回看 02:52:01—02:55:39**

<span id="p-tan-03-294" class="reading-anchor"></span>

“是以将此教法流行，令学道者顿悟菩提，各自观心，自见本性。”如果还不能悟呢？“须觅大善知识，解最上乘法者”，要找到这样的人，这是正路。是这样的善知识，有大因缘，“所以化导令得见性”。这个因缘谁发现的？大善知识发现这个人悟缘成熟了。

<span id="p-tan-03-295" class="reading-anchor"></span>

《坛经》第七品是什么品？《机缘品》。抓住那个机，抓住那个已经成熟了的悟缘，说话，让那个人悟了。《机缘品》里，这就是禅宗祖师的本领。在禅宗祖师的化导之下，我们见了自己的佛性，是吧？这是大因缘。

<span id="p-tan-03-296" class="reading-anchor"></span>

“一切善法，因善知识能发起故。”佛法为什么会有呢？因为我们这些善知识是有能力的，能发起。“三世诸佛，十二部经，在人性中本自具有。”但是我们不能自悟，怎么办？“须求善知识”，实际上是大善知识，“指示方见”。

<span id="p-tan-03-297" class="reading-anchor"></span>

这时候你如果能自悟，就“不假外求”，不要到外面去求。“若一向执谓”，执谓就是执着地说，“须他善知识方得解脱者”，没有他善知识，我就不能解脱，就忘了本心自悟了。这样的人叫“无有是处”，这样的人不对了。“何以故？自心内有知识自悟。”这个知识就是灵觉，妙性。这句话不就是本心自悟嘛？

<span id="p-tan-03-298" class="reading-anchor"></span>

“若起邪迷，妄念颠倒，外善知识虽有教授，救不可得。若起正真般若观照”，若起了般若观照，我们本有般若智的，“一刹那间，妄念俱灭”。还是顿字，还是一个顿字啊，叫一刹那间。“若识自性，一悟即至佛地。”这一悟还是顿悟啊。

## “内外明彻”与无念行

**回看 02:55:39—03:00:32**

<span id="p-tan-03-299" class="reading-anchor"></span>

我们再看下去，“善知识，智慧观照，内外明彻”。内外为什么能明彻？对外把相扫了吧，对内把执着破了吧。内心的执着也破了，外相也扫掉了吧。这就叫什么？内外明彻。“识自本心”，这自本心就是如如之心了。如如之心是唯一的真实，一真一切真。所以不就内外明彻了吗？

<span id="p-tan-03-300" class="reading-anchor"></span>

“若识本心，即本解脱。”我们多次提到即本解脱。即本解脱，换一个说法是什么？对了，即心即佛。同一个意思，两种表达式，那叫同义语。佛就是解脱的意思，本就是我们的心。即心即佛，也就是即本解脱。

<span id="p-tan-03-301" class="reading-anchor"></span>

“若得解脱，即是般若三昧，即是无念。”无念不是绝念。这段最后一句话说了，“若百物不思，当令念绝”，就绝了念了，这叫搞错了。“即是法缚”，你学佛法学错了，“即名边见”。你是一边之见，落了其中一边了，叫边见。也就是通常所说的偏见，一偏之见，一隅之见。

<span id="p-tan-03-302" class="reading-anchor"></span>

禅宗是般若法门，修的是般若行。般若行也可以称为无念行。因为般若是领会空，无念就是无二相，念真如自性。实际上是一个意思。我们能够离了二相，我们就领会空这个本体了。这时候我们仍然起念，那叫真如自性起念。

<span id="p-tan-03-303" class="reading-anchor"></span>

什么叫真如自性？就是我们每个人本有的佛性。从佛性中起念，从佛性中起念什么意思？就是把我们所做的所有的事情，不管你在什么处境、做什么事情，第一，把它这个结果空掉。第二，让事情成为佛性的呈现。佛性是什么？不生不灭的，是实性，不在相中取义。

<span id="p-tan-03-304" class="reading-anchor"></span>

我们做事情都在相中取义；现在要不于相中取义。现在的当下这个社会不是内卷吗？各个部门都在考核，叫 KPI。这样的普遍的考核，让每一个工作者都于相中取义了，要考核业绩呀，是吧？比方说现在这个经济暂时困难，那么银行它怎么再按照原来的标准考核呢？恐怕不行了吧。

<span id="p-tan-03-305" class="reading-anchor"></span>

然后今天的银行行长就有很深刻的失败感，这叫于相中取义。银行还在继续存在。你以前赚钱赚得快，利润高，是吧？你别忘了你还是为实体经济服务。这叫实性。不于相中取义，从真如自性起念。

<span id="p-tan-03-306" class="reading-anchor"></span>

在这娑婆世界当中，万事万物都生生灭灭，但是生生灭灭里边有常，叫佛性常啊。佛性不可能脱离具体的事物单独存在的。所以在生生灭灭的事物中，你看到佛性了，你让佛性呈现了，这叫做事情呀，是吗？那么后来到了阳明心学那里，那就让所做的事情成为天理的呈现，也是不在相中取义的。

## “同见同行”才传付

**回看 03:00:32—03:05:16**

<span id="p-tan-03-307" class="reading-anchor"></span>

“悟无念法者”，有人领悟到无二相，领悟到真如自性起念，是吧？这样的人，“万法尽通”。“悟无念法者，见诸佛境界”，佛的各种高妙的境界，你都能见到。“悟无念法者，至佛地位。”底下就说了，因为惠能此刻等于也在说自己的使命。

<span id="p-tan-03-308" class="reading-anchor"></span>

“后代得吾法者”，得了我惠能这个法的人，“将此顿教法门，于同见同行，发愿受持，如事佛故”。当我们受持这样的顿教法门时，就好像在跟佛打交道，叫如事佛故。“终身而不退者，定入圣位。”

<span id="p-tan-03-309" class="reading-anchor"></span>

“然须传授”，你们以后教人怎么教？“须传授从上以来”，从达摩以来，“默传分付”。传的是心法吧。“不得匿其正法”，不要跟着世俗讲佛法的路走。我们禅宗就是传心法的，从达摩开始的。

<span id="p-tan-03-310" class="reading-anchor"></span>

“若不同见同行”，有的人也修佛，跟禅宗见解不一样，实践的路也不一样，这叫什么？不同见同行。他们“在别法中”，是吧？有的人修密宗去了吧，有的人修天台宗了吧，有的人修华严宗了吧，在别法中吧。那么你们该怎么办？“不得传付”。

<span id="p-tan-03-311" class="reading-anchor"></span>

人家在他的路上修得好好的，你也不要把禅宗唯我独尊，不要妨碍别人。“损彼前人”，他们都有传承的吧，你损害了，“究竟无益”，没什么好处嘛，对别人也没什么帮助嘛。“恐愚人不解，谤此法门，百劫千生，断佛种性。”

<span id="p-tan-03-312" class="reading-anchor"></span>

当然我们会担心什么？愚人不解，谤此法门，就毁谤禅宗这个法门。其实他们的回报对他们是绝不利的啊。《金刚经》倒有意思的，《金刚经》里边讲这样一句话，假如你现在持诵《金刚经》，别人诋毁你，免了你什么？累世累劫的罪业。本来你应该入地狱的，你知道吧？因为你诵《金刚经》，他诽谤你，把你前世的罪业消了。

<span id="p-tan-03-313" class="reading-anchor"></span>

惠能这里没说这层意思，我想应该补充才好，让别人诽谤禅宗吧，消了我们自己的罪孽啦。那么若无人诽谤呢，表明我们没那个下地狱的罪业，也证明这一点，是吧？反正左右都行。

<span id="p-tan-03-314" class="reading-anchor"></span>

讲了这一大堆话，惠能真是苦口婆心了，无非强调的是本心自悟。在大善知识的示导下，我们本心自悟，本心自悟就得了解脱，叫即本解脱。那叫顿悟，否则就没完没了。

## 神秀的境界和弘忍的抉择

**回看 03:05:16—03:08:38**

<span id="p-tan-03-315" class="reading-anchor"></span>

如果没有经过顿悟这个环节的话，那就是神秀所说的了，“时时勤拂拭，勿使惹尘埃”。我们每天都会发现自己生命情感的毛病，那去擦吧，一直擦下去，而且还不知道用什么擦的。用经文来擦？怎么擦？或者等上帝来擦，那是基督教，上帝能救赎我们的罪。

<span id="p-tan-03-316" class="reading-anchor"></span>

佛教没有这种上帝的。每个人都是佛，因为每个人都是佛，我们就相信自己本心自悟呀。你天天擦有什么用呢？不悟没用。现在有许多人还是站在神秀一边，为神秀辩护的。我觉得为神秀辩护呢，也可以吧。就说神秀的境界，要比他的其他同伴们、同修们，就都在弘忍法师底下修的，比其他同修境界高。这是弘忍承认的吧。从弘忍法师的这层承认来说，可以为神秀辩护。

<span id="p-tan-03-317" class="reading-anchor"></span>

但是禅宗若无惠能呢？想想看，历史证明了什么？北宗开出什么花来吗？结出什么果来嘛？没有嘛。就是南面的惠能嘛，一花开五叶，临济宗、曹洞宗、沩仰宗、云门宗、法眼宗嘛，都开出来了嘛。于是禅宗大行天下，盛化各方。这是惠能带来的，不是神秀带来的，这是历史事实。

<span id="p-tan-03-318" class="reading-anchor"></span>

神秀有他的好处啊，惠能也承认的。惠能不是跟从北面来的志诚这么说嘛，你们的师父讲的是为上乘人说的，我是为最上乘人说的，还是承认的啊。神秀的功绩也是承认的，否则神秀也不会被武则天、唐中宗迎到宫中供养吧，成为国师也有道理的，也有道理的。

<span id="p-tan-03-319" class="reading-anchor"></span>

但是不究竟，你知道吧？还是不究竟吧。究竟是在惠能这里嘛。那么惠能为什么能究竟呢？因为听了弘忍法师的话，受持《金刚经》啊。用中国人理解的话来说，一部《坛经》就来了。所以我想来想去，惠能功不可没，但是惠能之前的弘忍法师，一样的功不可没。他让禅宗的发展建立在《金刚经》的基础上了，这是了不起的一个抉择。说完这一切之后，惠能就说，我还是给大家一个颂吧。
