2. 更高的信以人生是苦及不朽的佛性为前提；法喜不同于欲望被满足时的暂时欢乐。

## 对佛道的两种信

**回看 01:43:16—01:50:44**

<span id="p-tan-06-181" class="reading-anchor"></span>

那么对佛道起一个信心，是前提。这个信心来自哪里呢？来自科学解决不了人生最根本的问题，你体验到了。或者常理无法说明一个人的处境和他的遭遇，会让这样一个普通的人领会到，另外有一种力量主宰着世界。比方说佛家所说的这个世界。

<span id="p-tan-06-182" class="reading-anchor"></span>

那么佛家在说人生的时候，又说了一条，叫三世因果。你若不信三世因果，你不用修佛。为什么？道理非常简单，我们就过一辈子。这一世是唯一的一世，短暂得很。长命一点，一百多岁也很短，也就这一辈子。既然我们没有前世，也没有来世，我们就只是这一世，干嘛修佛？

<span id="p-tan-06-183" class="reading-anchor"></span>

你若不承认曾经有过的那个你，你若不承认未来还有可能有一个那个你，你不需要修佛，不需要修行。这辈子该怎样就怎样了，尽我们之所能来满足我们的欲求吧。什么手段都可以做嘛。我死后，管它洪水滔天。每个人就一世。

<span id="p-tan-06-184" class="reading-anchor"></span>

佛家跟我们讲三世了，过去世、现在世、未来世。这三世之间有关联，叫因果。这一世成为怎样的一个人，首先是由前世所规定的。前世的业力，前世种下的因，成了今世的果。受这个果报的同时，我们还活着做事情呢，又在造新业。这造的新业，就是为未来世种下的因，果报将在未来世。

<span id="p-tan-06-185" class="reading-anchor"></span>

这样一个三世因果，向来被认为是迷信，可以据此批判佛教。曾经相当长时间以来，是这么做的，批判佛教，批判三世因果这种迷信的说法。那么我们能否信佛教，这件事情真成了一个问题了。我们相信我们眼见为实的当下世界。佛教说这叫阎浮提，这叫娑婆世界。我们认其为真，其余的都是假的。

什么过去世、未来世，什么涅槃的境界，什么西方净土，那个世界都是假的。

<span id="p-tan-06-186" class="reading-anchor"></span>

好处是一个，通过让我们恐惧未来得的恶报，所以我们这辈子做好人吧，那叫畏于因果。不敢做坏事，有这个好处。问题是许多人不畏这个因果，因为它不存在，以为它不存在，何畏之有？有人相信存在了，他当然不做坏事了，因为他想到因果报应。

<span id="p-tan-06-187" class="reading-anchor"></span>

所以信心有两个层面。修佛的信心，一个层面就是畏于因果。他倒是相信了有来世的，并且由此来解释这一世为什么多苦多难的，因为前一世造了许多恶业。那么这种相信，是第一个信，对佛教相信的第一个层面。

<span id="p-tan-06-188" class="reading-anchor"></span>

但是第二个层面，很难有人信。这第二个层面意味着什么呢？意味着我们相信自己能够摆脱生死轮回，出离生死苦海。假如我们有这一个信，那就是个真正的佛教徒了。不简单的。前一种是因为畏于因果的缘故……这后一种信是真正的信，很难达到。

<span id="p-tan-06-189" class="reading-anchor"></span>

我们贪生怕死，我们认为死是一种绝对的灾难。我们要守住这个唯一无二的自我，让它始终待在这个世界，赖在这个世界不走。而佛家跟我们讲，这是他乡，不是你的故乡。那么我们真想问佛教，我们的故乡在哪里？很真实的问题。

<span id="p-tan-06-190" class="reading-anchor"></span>

达到第二种信的境界的，也不是靠知识多、人聪明。有的人知识很多，人很聪明，就坚决不信因果报应的。比方说王熙凤。王熙凤自己说过这样的话，我才不信那些因果报应之类的话，我该干嘛干嘛。这她原话啊，读读《红楼梦》就知道了。王熙凤聪明嘛。有的人远不如王熙凤聪明，但他就信。

信我们通过努力，可以超脱生死的。

<span id="p-tan-06-191" class="reading-anchor"></span>

第一个前提是什么？人生是苦。不要在这个根本上是苦的人生，图那种短暂的欢乐，还抓住它不肯放，如王熙凤那样。王熙凤的贪，很厉害吧。所以达到第二种信念的境界的，就更高一层的，不是因为仅仅畏于因果。那么达到第二层更高一层的信，它的第一个前提是什么？人生无一不是苦。

<span id="p-tan-06-192" class="reading-anchor"></span>

就是佛陀第一次说佛法，说的苦、集、灭、道。第一个叫苦谛吧，生老病死皆是苦。每一份欢乐的背后就是苦，这一点自己体会。那么有人又认为，佛教这么看待人世间，太悲观，太消极。We live for joy，我们为欢乐而生，这是人生本来的主题。你把这主题否定掉了。这就是佛教彻底的地方。

你能不能直面人生的苦，而赢得一种真正的属人的欢乐，而不是跟动物没有很多差别的欢乐？

## 永恒的欢乐

**回看 01:50:44—01:59:46**

<span id="p-tan-06-193" class="reading-anchor"></span>

属人的欢乐是不朽的。佛教给它一个名称，叫法喜。佛法是不朽的，法喜。一个艺术家创作出了一部艺术作品，这部艺术作品的价值是不朽的。这位艺术家完成他的工作了，用佛教的话说，法喜充满。

<span id="p-tan-06-194" class="reading-anchor"></span>

确实，we live for joy, but we live for eternal joy。Eternal joy，永恒的欢乐。Eternal joy，有没有永恒的欢乐？That's a question, a fundamental question，一个根本的问题。

在这个问题上得一个解决，自然信了佛教，真正地相信了佛教。我们修佛，不是为了拿佛教严厉的、严酷的修行来惩罚自己的罪恶，不是这件事。

<span id="p-tan-06-195" class="reading-anchor"></span>

佛陀本人当年是相信苦行的，后来才悟道的。所以有一个重要的观念，用英语来表达叫 eternal joy。有还是没有？在生活中找例子，信手可得。For example，比方男女爱情，只要它是真正的爱情，它就属于什么？Eternal joy，它是不朽的欢乐。

<span id="p-tan-06-196" class="reading-anchor"></span>

这个永恒的、不朽的，不要在时间上理解为没完没了的，那不可能。具体的那份现实中的爱，就像所有的事物一样，都生生灭灭的。如此这般的一男一女相爱了，两个人，具体的那份情感联系吧，很具体的吧。此人与彼人，某某与某某相爱了。它跟一个苹果是一样的。

苹果会成熟吧，成熟了，终于腐烂，开始腐烂，腐烂到后面什么痕迹都没了。

<span id="p-tan-06-197" class="reading-anchor"></span>

说爱情是不朽的，不是使它没完没了的，没这种事。那两个人可能感情很好，而且还成功地把爱情转化为恩爱。但也是有终点的。但只要这份爱是真实的，它哪怕只发生一瞬间，它已经是 eternal joy 了，它已经不朽，跟时间长短没关系的，它超越时间。

<span id="p-tan-06-198" class="reading-anchor"></span>

为什么？爱是佛性的一个方面，佛性就是不朽的，它不是时间长短。不朽这个词，永恒这个词，跟时间无关，而是这个事情的性质。各位都做一点哲学思考。

<span id="p-tan-06-199" class="reading-anchor"></span>

“你见或者不见我，我就在那里，不悲不喜。你念或者不念我，情就在那里，不来不去。你爱或者不爱我，爱就在那里，不增不减。”我读到这首诗的第一反应是：把爱情收归了佛门。它属于佛性的一个方面。你爱我，曾经爱我，过去式了。现在不爱了，爱就在那里。由此会懂佛学的基本原理了。

<span id="p-tan-06-200" class="reading-anchor"></span>

佛学跟我们讲的是某种不朽的东西，也不能叫东西。我们来到这世界上的每一个男人和女人，都注定要爱一次的。这不是他们个人选择的结果。如果是个人选择的结果，这世界非常奇怪，一部分人决定去爱，另一部分人决定不爱。有这种事吗？有人决定自己不爱吗？

<span id="p-tan-06-201" class="reading-anchor"></span>

换句话说什么？爱情表面上只是两个个人的情感联系，其实它来自哪里啊？来自某种不朽的存在。换句话说，我们来到世界上的每一个男人跟女人，还没来到这个世界上之前，已经有东西等着我们所有的人了。其中有一项就是什么？爱情。

<span id="p-tan-06-202" class="reading-anchor"></span>

在这一点上，爱就是不朽的。它规定了我们，而不是我们选择了它。请注意，是它规定了我们，而不是我们选择了它。可以不选择吗？如果是你选择的，你也可以不选择嘛，对吗？当我们个人进入这佛性的不朽的一个方面，我们只要进去过，我们已经获得了 eternal joy，永恒的欢乐。

Eternal joy，就是跟时间没关系的 joy。哪怕在实际的时间长度上还那么短，没关系。

<span id="p-tan-06-203" class="reading-anchor"></span>

所以这个世界是苦的，但同时另一方面是有 eternal joy。这就是我们所在的世界。如果这世界里边根本不存在 eternal joy，这世界是彻底无聊的。但是惠能已经告诉我们了，所谓娑婆世界，只是海水的海面，浪花起伏。每一朵浪花，就其个别的存在来说，它就生生灭灭。

但浪花是海水本身啊，同时是海水吧，它就是不朽的。

<span id="p-tan-06-204" class="reading-anchor"></span>

生生灭灭的浪花，发现自己是不朽的海水，那叫修佛达到的境界。佛学来到中国，让中国思想有一个进步，有一个向上的翻转呢。因为它是什么？它让中国思想能够领会那些不朽的东西了，用不朽的东西来解释速朽的存在，解释具体的生生灭灭的事物，来理解它。

<span id="p-tan-06-205" class="reading-anchor"></span>

我们在一个非常小的事情上，这个事情也许稍纵即逝，但是我们做了这件事，让它达到跟不朽的关联。这件事本身过去了，我们已经跟不朽在一起了。这是最高的欢乐，不朽的欢乐。什么叫做事情？让这件事情成为佛性的体现。我们就在欢乐中，这种欢乐叫法喜。

<span id="p-tan-06-206" class="reading-anchor"></span>

不是跟我们个人的欲求有关的乐和苦、欢乐或不欢乐。我们平时的欢乐和不欢乐，都是跟我们的欲求关联的。欲求得到满足，如意。因如意而得的乐，跟与不朽在一起的乐不一样。

<span id="p-tan-06-207" class="reading-anchor"></span>

关于这种不一样，有人认为也是不存在的，没有什么不朽的、永恒的欢乐，这个不信的人也有。比方说某人恋爱了几次，假定五次，五次他都失恋了，终于得出个结论。什么结论？在这世界上根本不存在真正的爱情。若有人跟我说，这世界上有真正的爱情，那简直是天大的笑话。

<span id="p-tan-06-208" class="reading-anchor"></span>

这样的人，由失恋的打击，让他终于认为没有真正的爱情。他错了。证据在哪里？为什么说他错了？他从此再也没有爱的能力了，他真的远离了爱了。想一想这一切吧。

## 在形而下的现实中过形而上的生活

**回看 01:59:46—02:05:17**

<span id="p-tan-06-209" class="reading-anchor"></span>

我们既然讲佛家的修行了嘛，禅宗的修行了嘛，不讨论到这一个层面是不行的。佛家的修行，正是过一种形而上的生活，虽然在形而下的世界里。过着形而上的生活——在形而下的现实中过着形而上的生活。伟大的艺术家在创作的时候，就是这样的。否则没有真正的艺术作品。

<span id="p-tan-06-210" class="reading-anchor"></span>

伟大的艺术作品、文学作品，就启迪我们的心灵，让我们在形而下的现实中，在精神上达到形而上。这样的作品是不朽的。因为有形而上的存在，所以我们对现实构成了一种批判的能力。否则我们只能承认事实，对事实毫不作任何批判。我们如果要批判现实的话，我们根据在哪里？根据在形而上。

<span id="p-tan-06-211" class="reading-anchor"></span>

现在开始把形而上拿掉了，很多人认为它也是空的，压根是幻想，于是不能批判现实。你可以批评现实，我马上跟你讲，我有我的想法，青菜萝卜，各人喜欢，不要争论。在人生的意义和生命的价值问题上，陷入相对主义。大家说仁者见仁、智者见智吧，何必讨论呢？但人生就是不断地被讨论。

最好的讨论，是以文学艺术的方式出现，而后才以哲学的方式出现。

<span id="p-tan-06-212" class="reading-anchor"></span>

伟大的艺术，同时就是对现实的批判，而不是赞美。为什么要批判现实呢？并不是脱离现实、拒绝现实，仍然在现实中生活，但要批判。因为人是人的存在，人的存在是种精神的存在。否则我们就是经济动物，始终在谋求着物质财富的增长。

<span id="p-tan-06-213" class="reading-anchor"></span>

但人意识到自己是人。为什么意识到？有痛苦。我讲的不是肉体痛苦，精神的痛苦。因为动物不需要回答自己生命的意义问题，它从来也不会提这个问题。人会提的。即使给予否定的回答，就人生毫无意义，它仍然是因为有意义问题。因为有意义问题嘛。

<span id="p-tan-06-214" class="reading-anchor"></span>

这些恐怕要讲透，然后才能明白我们从佛经中得到了什么，受到了怎样的教益。然后才能理解为什么中国古代文人，特别是禅宗起来之后，有许多文人的艺术作品跟禅宗关联了，你才能理解这件事。

<span id="p-tan-06-215" class="reading-anchor"></span>

这样我们就讨论了一种信，更高的信念，对佛教的更高的信。那最初的信是畏惧，畏于因果报应嘛，于是信了。那么这是低水平的。那么最高水平的，第一，确认人生就是苦。第二，确认有不朽的存在，那就是佛家说的佛性。

<span id="p-tan-06-216" class="reading-anchor"></span>

然后我们跟佛性一致了，我们的生活跟佛性一致，我们获得的都是 eternal joy，永恒的欢乐。那叫法喜，法喜不增不减、不生不灭。世俗的欢乐，总是生生灭灭、增增减减，同意吧？所以佛学不是让我们否定生活，而是在生活中活出人的样子来。真正的人性就是佛性。

<span id="p-tan-06-217" class="reading-anchor"></span>

这样我们就排除了对佛教的许多误解。第一，你要求它论证它的说法，那你要求佛教成为科学。但科学不解决人生观问题，佛教要解决人生观问题，这种误解要排除掉。我们不能要求佛教像科学一样存在。就像我们要求哲学像科学一样存在，那么哲学就结束了。

<span id="p-tan-06-218" class="reading-anchor"></span>

第二个排除，就是佛教并不仅仅停留在对空的领会上，仅仅停留在人生是苦这一件事情上。而是在这个基础上，我们的心灵要升华。这个升华被称为解脱。解脱了才自在无碍。自在无碍，它是最高的欢乐。你可以不再爱我了，但我不把爱当成是相，而是不朽的。

## 爱情、婚姻和财色

**回看 02:05:17—02:13:21**

<span id="p-tan-06-219" class="reading-anchor"></span>

有一种说法很奇怪，要经营好爱情。爱情是经营的对象吗？要经营好婚姻，我倒同意的。那大家互相要理解对方，互相要感恩对方。关于经营好婚姻，这件事情儒家给我们足够的指导。那个礼在吧，相敬如宾吧，举案齐眉吧，夫妇有别吧，分工合作，讲得好好的。你去读儒家的，婚姻就经营好了。

<span id="p-tan-06-220" class="reading-anchor"></span>

男人做好男人的事情，要担当，要能挡风挡雨的。女人把家庭照看好。男女有别，夫妇有别嘛，这一套不要违背就够了。经营好婚姻也不是心理学问题。有人说去读那本书叫《婚姻心理学》，我又觉得好笑。这是伦理的问题，不是心理学的问题，儒家讲得清楚。

<span id="p-tan-06-221" class="reading-anchor"></span>

至于爱情，哪是经营的？你开始的时候都不知道，就开始了，还经营什么呢？你是 fall in love，跌进去的嘛。跌进去之后你想经营了，很荒谬。读一点佛学的书，知道自己早晚要爱的，然后真爱了，爱了你就法喜充满。你仿佛拥有整个世界。佛性拥有整个世界，你跟佛性在一起，不拥有整个世界吧？

<span id="p-tan-06-222" class="reading-anchor"></span>

哪怕你地位低微，你就是摆地摊的，但是你爱了，足够地强大，足够地自信。你跟不朽在一起，你还害怕什么？爱情是伟大的，因为它不朽。就这样，你通过爱情这个例子可以明白佛学。

<span id="p-tan-06-223" class="reading-anchor"></span>

后面讲这个皈依佛啊，皈依法，皈依僧。那皈依佛法僧三宝，那么皈依佛就是皈依觉悟，这是惠能讲的。皈依觉悟，意味着我们是两足尊。人有两条腿，一个腿代表福，幸福的福，还有一个腿代表智慧的慧，福慧双全叫两足尊。

<span id="p-tan-06-224" class="reading-anchor"></span>

那么福来自哪里？福来自我们正确地对待财产。智慧来自哪里？来自我们正确地对待男女之爱。讲得太清楚了，人生最重要的两件事情了。我们还没进入共产主义。没有钱是万万不能的。财重要吧，财是养身之资啊，财重要，正确地对待财产、钱财。还有一件事情重要不重要？男女之间的情感，男女之爱。

正是在男女之爱中，我们长了智慧呢，爱情是座伟大的学校。

<span id="p-tan-06-225" class="reading-anchor"></span>

我们先看这一段，就明白了。“佛者，觉也”，看到吗？“法者，正也。僧者，净也。自心皈依觉，邪迷不生，少欲知足，能离财色。”请注意，不是不要财色，于财离财，于色离色。这就叫两足尊了。哪两足？福和慧。

<span id="p-tan-06-226" class="reading-anchor"></span>

人在这世界上要有点福气吧。你天天挣扎在生死线上，那就谈不上做人了，动物也会挣扎在生死线上。所以人要福，是不可少的。人有男女之分，便有男女之爱。男女之情，也是不可少的。中国人讲，“食色，性也”。食，就吃饭，食物是不是钱买来的？色，就是男女之分和男女之爱，人性本身。

<span id="p-tan-06-227" class="reading-anchor"></span>

这两件事情最大，各位同意吗？就第一件事情来说，叫柴米油盐。第二件事情，叫男女之爱。天道之极致，即柴米油盐。人情冷暖之极致，无非男女爱情。这两件事最根本。修佛皈依佛，释迦牟尼老早圆寂了，你哪里去找到他？惠能说，就在我们身上，皈依觉吧。佛就是觉悟的意思。

梵文这个单词叫 Buddha，本意就是觉嘛。我们皈依自己的觉悟吧。

<span id="p-tan-06-228" class="reading-anchor"></span>

那么觉悟皈依了，体现为什么？两足尊。合适地面对了财、钱财，合适地面对了男女之爱。什么叫合适地面对？于财离财，于色离色。这个到后面会讲，我们先提出来。这样就达到了对佛教的一个信，真的信，对佛教的最高层面的信念。是因为认识到，一，人生是苦。二，人世间有不朽的佛性，两条。

<span id="p-tan-06-229" class="reading-anchor"></span>

意识到人生是苦，比较容易一点。一个人活到七八十岁，回顾自己的一生，发现从小苦到现在。基本的判断、感受就是这样，只有短暂的欢乐。如叔本华说的，叔本华读过佛经的，他后来说了句什么话？人生总体上是一部悲剧，只有在个别的细节上有一点喜剧的成分，叔本华。

这一点他领会到了吧，我们大多数人都能领会到，但是比较晚一点。

<span id="p-tan-06-230" class="reading-anchor"></span>

不可能很早，五岁、七岁就说人生是苦。然后你跟他说，“色不异空，空不异色，色即是空，空即是色”，他说对对对，不可能的。小孩童正向往着未来呢，憧憬着未来，每天都欢乐。昨天晚上还被他父亲打了一个巴掌，没关系的，第二天早晨醒过来，又想到跟小伙伴去玩什么了。马上把昨天忘了。这正常的。

<span id="p-tan-06-231" class="reading-anchor"></span>

那么人生积累了越来越多的经历，到了五六十岁、七八十岁了，回顾这些经历，不免叹一口气，人生真是苦，佛陀说得真对。这点容易。说这个苦的人生有不朽的佛性，明白这一点的实在太少，于是他就在苦中了。如果一个修佛的人呢，他在苦中得什么？Eternal joy，永恒的欢乐。

所以人生就是修行，得真正的欢乐。在这个意义上人要修行嘛，否则就被具体的苦和乐所支配嘛。

## 解脱之后还在生活

**回看 02:13:21—02:20:03**

<span id="p-tan-06-232" class="reading-anchor"></span>

好，关于信，我们说了那么多话，因为信是最难的。理解一件事情，我们发挥我们的理解能力。信一种看来是子虚乌有的话，你读佛经，不是一大堆子虚乌有的话吗？你去读那个《法华经》嘛，一大堆子虚乌有的事情，许多比喻，《譬喻品》啊，说这个世界怎么样怎么样，我一看，不就你想象出来的嘛？总而言之叫子虚乌有。

<span id="p-tan-06-233" class="reading-anchor"></span>

让我们去信子虚乌有的一大堆佛经，能信吗？太难。它不是根据我们的知识和经验的积累就能信的。知识和经验怎么交流，都不可能让我们信什么。所以信是第一步。那么对于有经历、有悟性的人，他能进去了。就是表达这个信吧，传香，传五分香，戒香、定香、慧香、解脱香、解脱知见香。

<span id="p-tan-06-234" class="reading-anchor"></span>

解脱我们明白了，就解脱二相对我们的束缚，特别是解脱生死二相对我们的束缚。所以解脱就是佛的意思了。为什么还来第五分呢？解脱知见呢？看惠能怎么讲。“五解脱知见香，自心既无所攀缘善恶。”攀缘就是趋避啊，趋善避恶。心里明白这一条了吧。

<span id="p-tan-06-235" class="reading-anchor"></span>

但也不可什么？“沉空守寂”。把解脱理解为进入空寂的状态中去，那又错了。我们活在这世界上，我们在人世间生活，我们要做各种各样的事情。“须广学多闻，识自本心，达诸佛理，和光接物，无我无人”，人我别去掉了。“直至菩提”，直至觉悟，“真性不易”。真性就真如自性。这分香给它个名称，解脱知见香。

<span id="p-tan-06-236" class="reading-anchor"></span>

换句话说，第四分香让我们领会空了。第五分香，又把这空再空一次，叫空空，解脱知见。于是我们修行者立下了这五分香的信心。一，我们能戒。二，我们能定。三，我们能慧。四，我们能解脱。五，解脱之后仍活在这世界上，做了各种事情，都让佛性在我们所做的事情中得到呈现。我们始终法喜充满。

<span id="p-tan-06-237" class="reading-anchor"></span>

哪怕我们经受了苦难，在苦难中我们仍然法喜充满。我们对苦难又采取另外的态度。这种苦难不是我们心里边在二相中生起来的苦难，它是现实的考验。有许多苦难是我们自己心造出来的，有一些不是。患了严重的疾病。这种病痛，这是苦难，你能不能忍呢？

<span id="p-tan-06-238" class="reading-anchor"></span>

一开始是忍的境界，叫安忍波罗蜜。你还要达到智慧才好。即使在病痛之中，我们的内心还是充满法喜。听上去很矛盾，很奇怪，实在来说，就是境界，很难达到而已。那个禅宗祖师患了病，病得很重。半夜里，他在寺庙里，半夜里他的弟子们听到他的呼喊，痛得厉害。

<span id="p-tan-06-239" class="reading-anchor"></span>

第二天问他了，师父，你昨天叫喊了？是不是太痛了？这禅宗祖师说：“昨天他叫喊了，就是我没叫喊。”这种精神，斯多葛学派也有。康德在他的《实践理性批判》里边，引用了斯多葛学派的思想境界。

<span id="p-tan-06-240" class="reading-anchor"></span>

他说，一个斯多葛学派的成员，他患了严重的痛风病。当痛风病发作的时候，他呼喊了。疼痛啊，不管你怎样地折磨我，我都不承认你是个邪恶的东西。康德这么评价的，他的呼喊说明他真痛了。他所忍受的这个病痛，通过他的呼喊透露出来。但他呼喊的内容是什么？不管你怎样地折磨我，我始终不会承认你是邪恶。

<span id="p-tan-06-241" class="reading-anchor"></span>

想一想，邪恶或者不邪，只跟我们的心灵有关，跟我们的实际的处境没关系。我们的病痛降低了我们的实际的处境的价值，却丝毫没有损害我们灵魂的价值。法喜属于灵魂。吃到了上等的红烧肉，这个欢乐属于肉体，是吗？

<span id="p-tan-06-242" class="reading-anchor"></span>

所以伟大的思想是相通的。中国的禅宗、古希腊晚期的斯多葛学派，对人生的领会。斯多葛学派的主题就是人生。斯多葛学派一再强调，我们每一个人的生命的价值，取决于他的灵魂的内在的圆满。禅宗也是，“何期自性本自具足”。我们本有的佛性是什么？圆满的，毫无欠缺的。

任何事情都撼动不了它，“何期自性本不动摇”。跟斯多葛学派的精神完全一致，这是不同的语言罢了，意思一样。

## 祸福与不改其乐

**回看 02:20:03—02:28:02**

<span id="p-tan-06-243" class="reading-anchor"></span>

所以惠能一定反对算命的，那叫妄说祸福。我们在祸中呢，我们仍然法喜充满。什么叫祸？什么叫福？是外在的东西。但老子说了第一步，“福兮祸之所伏，祸兮福之所倚”。它们会转化，这是第一步。第二步，超出祸福的对立，也超出它们的相互转化，超越了。

<span id="p-tan-06-244" class="reading-anchor"></span>

我们今天就这么来讨论人生，按照禅宗的精神和境界来讨论人生。我们可以面对一切人生的变故，这是最根本的。一切人的人生都无常，这不用怀疑。人生无常，就是多变故吧。我们修佛，终于像颜回一样，“贤哉，回也”，“不改其乐”。在儒家这叫君子真乐，在佛家叫法喜，eternal joy，永恒的欢乐。

这个欢乐来自他的内心本身的。

<span id="p-tan-06-245" class="reading-anchor"></span>

我们平时欢乐，都来自我们所获的条件和所处的境遇，因我们所遇到的事情而转移。就像我儿子小的时候一样。在幼儿园中班还是大班，我忘了。独生子女。每家每户都是独生子女。我儿子当时最欢乐的事情，是同他的表哥可以在一起玩。

<span id="p-tan-06-246" class="reading-anchor"></span>

那么有一天呢，他们家打电话给我们，本周六啊，我们两家聚会啊。我儿子在边上听到了，开心得不得了啊。这电话是礼拜一打的，到礼拜六。我发现我儿子从礼拜一到礼拜五天天都很开心的，就等着礼拜六啊，跟表哥一起玩呢。

<span id="p-tan-06-247" class="reading-anchor"></span>

结果礼拜五晚上，一个电话又来了，由于某种缘故，我们改日再聚吧。我们成年人很自然吧，好好好，改日再聚。电话挂掉了，当时是座机嘛。我回头一看，我儿子呆在那里。这个样子像什么？仿佛五雷轰顶啊。我说，你怎么了？他说明天他们不来了。我说不来了。

<span id="p-tan-06-248" class="reading-anchor"></span>

那么我明天怎么过？这问题大，这是人生问题，明天怎么过。我跟他讲，明天呢我陪你去玩。我才不要你陪我的。可以看电视嘛。我要跟表哥在一起才看电视，他们要玩游戏啊，什么诸如此类。

<span id="p-tan-06-249" class="reading-anchor"></span>

我想这事情比较严重，要讨论一下，虽然他是幼儿园的孩子。我说：“你坐下，我跟你讲。”你明天怎么过，成了个问题。那我告诉你，我们人生的幸福，不取决于外部环境，不取决于外部加给我们的条件。我们人生的幸福来自我们内心。他不知道我在说什么。

<span id="p-tan-06-250" class="reading-anchor"></span>

那么我就举了个例子给他听。我说，假如某一天，假定啊，你被……听说过判刑吗？大家听说过判刑，不是关到牢里吗？你关到牢里之后，你问一下自己还能不能幸福？他马上问我，牢里怎么关的？我说一个房间，一个人一个房间，有一个窗口，一日三餐从窗口里塞进来给你吃的。门是不开的，不让你出来的。

<span id="p-tan-06-251" class="reading-anchor"></span>

他接着再问我一个问题：“这一个人的房间里边有电视机吗？”我说：“没有。”他说：“没有的话，我怎么可能开心呢？”哎，我说问题就在这里。你哪怕被关在牢里了，就你一个人，没人陪你玩，连电视机都没有。每天除了睡觉就吃饭，不能出门，你还应当能够欢乐，因为真正的欢乐来自我们的内心。

<span id="p-tan-06-252" class="reading-anchor"></span>

后来我想讲得太早了，这斯多葛学派。后来长大了嘛，我请他看部电影，《肖申克的救赎》。他去看了。看了以后，我说怎么样？哎，我想起来我小时候你跟我讲过，一个人关在牢里，仍然有内心的欢乐。那个主人公就这样的。他是被冤枉的，银行家，冤枉了，又被关进牢里，判了无期徒刑，这辈子出不去的。

<span id="p-tan-06-253" class="reading-anchor"></span>

一般犯人进去的第一天就发疯了，发疯给了狱卒打他的口实。那天他不是关进来了吗？边上狱卒都等着呢，看你怎么发疯呢，我可以狠狠地揍你一顿。结果他很平静，狱卒就不能打他了。然后他积累了好多。他后来不是到图书室去管理嘛，有唱片的，莫扎特的音乐，他播放了。

<span id="p-tan-06-254" class="reading-anchor"></span>

这电影这个场面是非常感人的。他是被冤枉的。那么许多其他被判了无期徒刑的、终身囚禁的，是犯了罪的，一个个面露横肉。都在这儿，正好在院子里放风嘛，兜圈子。高音喇叭播出了音乐，莫扎特的。他们脚步放缓了，他们仰望着天空。莫扎特的音乐让他们的灵魂插上了自由的翅膀，飞出去了。

<span id="p-tan-06-255" class="reading-anchor"></span>

电影这部分的情节，就是斯多葛学派它的这个人生哲理的体现。在人生许多情况下，我们都面对这样的问题。我们过分依赖于外部降临到我们头上的东西。我们恰好是聪明睿智，也不能归功于自己的灵魂，这是遗传而已。我们恰好身强力壮，我们性格诙谐幽默，我们的地位很高，让别人不能瞧不起我们。

这一切都是从外部降临到我们头上的，它并不能提升我们人生的价值。

<span id="p-tan-06-256" class="reading-anchor"></span>

去读一读奥勒留的《沉思录》，就罗马那个皇帝，罗马时期的斯多葛学派的重要代表人物。温家宝总理曾经提倡我们读这本书，听说过吧？《沉思录》。我们去仰望一下星空吧。

<span id="p-tan-06-257" class="reading-anchor"></span>

好，这样我们就讲了一个基本问题，就是如何树立起来对佛家修行的信心。这信心来自哪里？来自对人生的根本认识。第一，是苦。第二，佛性到处都在。有这一条，然后才讲解悟，解悟佛理。那么这个阶段就是要读佛经的。然后如果我们还足够幸运的话，那么有大禅宗祖师跟我们讲经说法。这是第二阶段。

<span id="p-tan-06-258" class="reading-anchor"></span>

行，就是要修行，要实践。在修行的过程当中，终于达到能够什么？用自己的生命实践来印证佛理，那叫证，实证。信解行证。传香就意味着第一步，信。讲完了传香之后，便讲忏悔。

## 本节总结｜整理附录

这一节把“信”作了较长的层次区分。课堂先保留三世因果与出离生死的宗教前提，再讨论苦、佛性和永恒的欢乐。爱情、艺术、形而上的生活及婚姻伦理都是这一论证实际经过的旁支，没有另行删成“保持乐观”。

第五分解脱知见香说明不能止于空寂。之后病痛中的祖师与斯多葛学派、祸福的转化、儿子盼望与表哥玩耍，以及《肖申克的救赎》的音乐场景，逐步分辨外在欢乐与不因处境而失去的精神价值，最后收回信解行证。
