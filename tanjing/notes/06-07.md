## 一分钟速读｜整理附录

1. 前两个愿加“自心”，后两个加“自性”，把四愿都放回明心见性与自性自度。
2. 度众生与度自己在具体人际关系中统一；不能把自己置于众生之外，等待或扮演唯一救世主。
3. 断烦恼用自性般若智除去虚妄思想心，不能只靠外部问题一次次被解决。
4. 法门无尽与尘劳无尽相连，学法门不等于背一本法门大全，而是须自见性、常行正法。
5. 成佛道从常能下心开始，继续离迷离觉、除真除妄；常念修行把四愿落实到整个人生。

## 四个愿为什么加“自心”与“自性”

**回看 03:34:19—03:40:00**

<span id="p-tan-06-374" class="reading-anchor"></span>

我们特别注意到，惠能在讲这四弘誓愿的时候，在表达上，比方说众生无边誓愿度。在众生前面，他加自心。自心烦恼无边誓愿断。在第三个弘愿，学法门，法门之前加什么？在无上佛道前面加什么？自性，也是自性。前两个愿前面都加自心，后两个愿前面都加自性。

<span id="p-tan-06-375" class="reading-anchor"></span>

自心、自性。自性就是我们本有的佛性，自心就是我们的自本心。“识自本心，见自本性”，这话弘忍法师说，跟神秀讲，“言下须识自本心，见自本性”。识自本心就是明心，见自本性就是见性。明心见性。

<span id="p-tan-06-376" class="reading-anchor"></span>

所以惠能讲发愿，发四个弘愿，不离自性。不离自性，这是一条非常重要的原则。禅宗是修心的法门，每个人要修自己的心。人归根到底的毛病，都出在人自己身上，出在人的生命情感的毛病上，也就是出在心的毛病上。

<span id="p-tan-06-377" class="reading-anchor"></span>

所以众生前面加自心。我们能把自己跟众生区分开来吗？不能区分的。众生会有种种的愚迷、嫉妒、骄诳，我们每个人都有。度众生，不要从这个字面上来理解，我们就是救世主了。我们发一个弘愿，去度天下众生，那么我们成了救世主了。没这件事。

<span id="p-tan-06-378" class="reading-anchor"></span>

禅宗反对把佛尊奉为救世主。禅宗的原则是主体性原则。我们每个人其实都是佛，所以这条原则在那里的。这是禅宗对中国思想发展的极大的贡献，众生是佛，于是每个人相信他自己。什么叫度众生？也就是度自己。这两者是一回事，度人就是度己，度己就是度人。

<span id="p-tan-06-379" class="reading-anchor"></span>

众生的罪过，也是我们的罪过。哪怕你实际上没犯那个罪过，但你那个心还在的，骄诳心、恶毒心、嫉妒心、愚迷心都在。只是你实际上没做，有人做了，那么你把自己跟他区分开来，你比他好，他很糟糕，你是善人，他是恶人。殊不知众生引起他们罪过的那些妄念、妄心，我们也具备，其实都有。

<span id="p-tan-06-380" class="reading-anchor"></span>

这一点就能理解中国社会的许多现实状况。我们中国人为什么直到今天总在防范他人呢？想过这问题吗？我们不相信别人，原因是什么？本就不相信自己的。假如我们发现有人，社会热血人士，为社会公益而努力，旁人会怎么想？他借这个社会公益来图自己的利益呢。立刻这么想过去了。

<span id="p-tan-06-381" class="reading-anchor"></span>

其实我们不相信别人的，他哪怕为公共利益作出个人的奋斗，我们还说他恐怕还另有所图呢。这很可怕。因为我们就从未相信过自己。因为我们不相信自己，我们就不可能是独立的人格，于是也不把别人看成是独立的人格。禅宗在这一点上揭示了这一条。

禅宗是讲修行的法门，但这个思想我们推而广之，如果被普遍地意识到中国社会的毛病，那么禅宗实际上会推动中国社会的进步。

<span id="p-tan-06-382" class="reading-anchor"></span>

即心即佛，就是主体性原则。后来阳明说什么？我们每一个中国人，无论是贩夫走卒，还是引车卖浆者流，都要做收拾精神、自作主张的大英雄。每个人相信他自己，度自己，也就是度他人、度众生。

## 度众生怎样也是度自己

**回看 03:40:00—03:48:57**

<span id="p-tan-06-383" class="reading-anchor"></span>

因为你怎么度自己的？你把自己关在房间里度吗？我们怎么可能把自己关在房间里度呢？我们总是在跟他人打交道吧。我们活在这世界上，总是跟他人打交道，处在与他人的关系中。

<span id="p-tan-06-384" class="reading-anchor"></span>

在人与人的交往和关系当中，产生许多的烦恼，甚至罪恶。你面对这种关系，你怎么跟人打交道？你跟人打交道，每一步都在度自己，同时也就在度他人。不可能脱离社会关系来度的。众生的烦恼、众生的罪过，就在社会关系中展开的嘛。我们只要在其中，我们就度自己，度他人。

<span id="p-tan-06-385" class="reading-anchor"></span>

你对待别人的罪过，你怎么看待？你面对别人出于自私的考虑，而伤害了他人或者伤害了一个集体，你又怎么跟这个人打交道？你不要以为你很干净，他全是问题。你要知道他的问题，你也有。所以在这点上，我是非常佩服巴金。

<span id="p-tan-06-386" class="reading-anchor"></span>

文化大革命结束之后，他写了《随想录》了。在《随想录》里边，巴金忏悔。我心里想，你巴金为什么忏悔？在文革当中，你是遭罪的人，你从未伤害过别人，你仍然忏悔了。巴金认为，文革这样一个普遍的灾难，每个人其实都有责任。

<span id="p-tan-06-387" class="reading-anchor"></span>

他主张成立什么？文革纪念馆。在文革当中，那些反人道的行为，证据都在，陈列在纪念馆里吧，让大家都一起来看一看，我们当时都做了些什么事。别把文革的灾难推给一个人承担，我们都得承担。这是一种非常彻底的态度。我非常感动。众生的罪过，也是自己的罪过。什么叫度众生？因此也就是度自己。

<span id="p-tan-06-388" class="reading-anchor"></span>

所以我们看惠能怎么说，“善知识，大家岂不道‘众生无边誓愿度’？恁么道”，那么就这样，“恁么道，且不是惠能度”。这话说得好。我们大家都在说这句话，众生无边誓愿度。既然这么说，不是我惠能来度吧。你们都说要度众生的，哪是我惠能一个人的事啊？

<span id="p-tan-06-389" class="reading-anchor"></span>

你们发了第一个愿。度众生。每个人都想要度众生了，你们肯定不是期待我一个人惠能吧，这是你们自己的愿。否则第一个愿就没了。度众生交给一个人，他是佛或是菩萨，就行了。比方说这里就交给惠能吧，别的人不要发这个愿，轮不到你度众生，惠能来度众生。不是。我们每一个修行者第一个愿，就是度众生。

<span id="p-tan-06-390" class="reading-anchor"></span>

这多好的意思啊。你不就是众生之一吗？你还发了个愿要度众生。这意味着什么呢？意味着一，人人都有罪过。二，每个人都应当觉悟。当每个人觉悟，就要度自己的时候，因为他处在与他人的关系中，他不也就是度着他人嘛？别把度众生狭义地理解为，有许多苦难的众生等着你去救他们。你也等着被救。

<span id="p-tan-06-391" class="reading-anchor"></span>

我们都想自我得救，小乘佛教。我们想到救自己跟救众人是一回事，大乘佛教。让我们大家都坦率地承认自己的罪过，让我们大家一起来承担共同的社会责任。这是我把惠能说的第一个弘愿作了一个解读，我就这么解读的。

<span id="p-tan-06-392" class="reading-anchor"></span>

所以第四个自然段落这么讲了，“善知识，心中众生”，众生在你心里的，“所谓邪迷心、诳妄心、不善心、嫉妒心、恶毒心，如是等心，皆是众生”。我们自己有没有如此等心呢？有。有这些心啊，就都是众生。“各须自性自度，是名真度。”

<span id="p-tan-06-393" class="reading-anchor"></span>

《国际歌》的歌词有这样的唱词吧，从来没什么救世主，也不靠神仙皇帝。马克思的学说，共产主义的理想，用佛家的话，就是普度众生。每一个众生都要普度众生啊，不是众生等救世主来度。要达到禅宗的境界。

<span id="p-tan-06-394" class="reading-anchor"></span>

“何名自性自度？”那要下功夫了。怎么下功夫，惠能底下说了，“即自心中”，我们每个人的自心，“即自心中邪见烦恼愚痴众生，将正见度”。起了邪见，正见来度。“既有正见”，就是要运用什么？“般若智”，智慧，“打破愚痴迷妄众生，各各自度。邪来正度，迷来悟度，愚来智度，恶来善度。如是度者，名为真度。”

<span id="p-tan-06-395" class="reading-anchor"></span>

所以禅宗是佛教中的心学。当然遇到了愚痴迷妄，遇到了罪恶，人世间的罪恶，法律可以惩罚，这是对的，我们必须法治。但是光靠法治，这个社会的精神基础并没有建立起来。一个社会的精神基础在什么？众生的本心起来。

<span id="p-tan-06-396" class="reading-anchor"></span>

现代法律当然是一套保护社会安定的方法，而原则就是预先防范不可信之他人。一旦发生行为，法律的惩罚就来。这是一种制约，这是一种警告，让人们因为害怕受刑罚的缘故而不为恶。但为恶的根源在哪里？没解决。于是也会利用法律规则的漏洞、空白处来行恶，对吗？归根到底还是世道人心的问题。

<span id="p-tan-06-397" class="reading-anchor"></span>

道不行，百世无善治。一要依法治国，二要人心为本。在人心为本这件事情，儒、道、佛三家的智慧，是我们民族的希望。这讲了第一个弘愿了。在众生前面加自心，就每个人都有份。自心众生叫心中众生，每个人都有份，别推脱。

## 以般若智断烦恼

**回看 03:48:57—03:54:49**

<span id="p-tan-06-398" class="reading-anchor"></span>

底下要讲第二个弘愿，烦恼无边。烦恼前面也应该加自心。前面加过，这里没说，其实应该加上去。“又自心烦恼无边誓愿断。”如何断呢？我们关心的是这件事吧。我们承认我们都有烦恼。我们也真诚地希望这些烦恼断了，问题是如何断。

<span id="p-tan-06-399" class="reading-anchor"></span>

“将自性般若智，除却虚妄思想心”，这就是如何断。我们前面讨论过，般若智慧就是领会空的智慧。既然领会空的智慧，我们就能离二相。虚妄思想心来自什么？趋高避低，趋贵避贱，趋福避祸，趋乐避苦，如此等等嘛。这叫虚妄思想。

<span id="p-tan-06-400" class="reading-anchor"></span>

我们真能趋而得之、避而免之吗？一时得了，一时免了，后来它又转化了。由高变成低了，由贵变成贱了，向来在转化。我们看一看人类的历史，看看中国的社会的历史，还少见嘛？一部《红楼梦》，讲那个贾氏家族如此的富贵，终于什么？崩塌了嘛。不就是由高到低了吗？由贵到贱了嘛？由富到贫了嘛？

整个贾氏家族开始流浪。

<span id="p-tan-06-401" class="reading-anchor"></span>

虽然《红楼梦》最后四十回没把这个彻底的悲剧写出来，本来就隐藏在前八十回里了。后四十回在这件事情上有问题的，还要来一个家道中兴，其实没有。贵以贱为本，高以低为基，它们向来上上下下。这几十年我们改革开放、市场经济的实践，我们还看得少吗？多少富豪落马了？

我们不讲别的原因，我们讲人类社会的常态如此。

<span id="p-tan-06-402" class="reading-anchor"></span>

所以要破除什么？虚妄思想心。要领会空，空是世界之本体，是万事万物之实性。我们从相里边出来，回归实性吧。这叫般若智慧。空不是什么都没有。我们再重复一遍，它是什么？不生不灭，不垢不净，不增不减。我们在相中，什么事情都是增增减减、生生灭灭。

<span id="p-tan-06-403" class="reading-anchor"></span>

昨天的富贵，今天的贫贱，那个富贵就灭了吧？贫贱生了，不断生灭呢。要经历过一段人生，才能懂一点佛理，大多数人如此，因为大多数人是小根之人。你得经历一番人间的梦幻，如贾宝玉。历经人间梦幻，终于看破了。

<span id="p-tan-06-404" class="reading-anchor"></span>

还有一个不需要历经人间梦幻，那是惜春。惜春就是上根之人啊。王国维说她叫天然神明。她也没谈过恋爱吧，她没经历过大起大落，好像是她的天性，就亲近禅宗，总要跟妙玉谈禅呢，别的事情没啥兴趣的。人分两类吧，我们大多数人还在经历这红尘梦幻啊。历经一番梦幻之后，终于明白了，终于领会空了，起了般若智。

本有般若智，遮蔽了，现在重启。

<span id="p-tan-06-405" class="reading-anchor"></span>

“以般若智，除却虚妄思想心”，惠能就用一句话来说明了第二大弘愿。关键是如何断烦恼，靠什么断？烦恼别人没办法帮你断，你自己断。因为烦恼本从你心里生出来的，别人怎么帮你呢？别人可能帮你解决一些具体问题，具体的麻烦、具体的苦恼，可能帮你一下。但烦恼总是不断从你心里生出来。

<span id="p-tan-06-406" class="reading-anchor"></span>

人生就这样一个过程。大多数的人生，旧的问题解决了，新的问题随之而来。旧的苦恼解决了，新的苦恼又随之而来。于是人生变成这样一个过程，不断地以新烦恼取代旧烦恼，以新问题取代旧问题。那就没完没了，这样的人生未免可怜。所以还要发这个愿，是不是？

烦恼无边，几十年没停过呢，新烦恼取代旧烦恼啊，叫无边的。关键能不能断。

## 法门无尽，怎么学

**回看 03:54:49—03:58:52**

<span id="p-tan-06-407" class="reading-anchor"></span>

讲第三个愿，前面还应该加自性二字。“又自性法门无尽誓愿学。”为什么法门无尽？因为尘劳无尽。天下人天天都在做事情，叫劳，都带着烦恼做事情。尘劳实在是无尽，说是八万四千种尘劳。尘劳无尽，便要有无尽之法门来对付，说是有八万四千种法门，来对付八万四千种尘劳。佛教喜欢用大数字说话的，蛮好的。

所以法门无尽，是因为尘劳无尽。

<span id="p-tan-06-408" class="reading-anchor"></span>

学吧，学法门，如何学？下面又来回答了。就像前面说断烦恼，我们都愿意，关键是如何断。然后你又立了一个愿，要学法门。关键是什么？如何学。“须自见性，常行正法”，这叫真学。真有八万四千种法门，都写下来了？真有八万四千种法，都写下来了？然后等大家一条条背下来，最后背了八万四千种法门，是这样吗？

这样的学法门还在相中呢，叫相学。

<span id="p-tan-06-409" class="reading-anchor"></span>

我们中国人道德规则列了好多了吧，我们一条条学，记住它。不是这条路。就像朱熹想要把天理说得清清楚楚，成体系地给出，能解决问题吗？陆象山、王阳明对了，那叫心即理。本心就是良知，良知就是天理。良知，你能说它应该有几条吗？良知是随感随应啊，遇到事情它起来了，只是你别欺瞒它。

<span id="p-tan-06-410" class="reading-anchor"></span>

你本知道该怎么做的，但是出于私欲之遮蔽，又把它遮盖掉了。遮盖掉可以的，你遮盖吧，良知在的，结果是什么？心不安。良知自有不可自昧处，不能自己隐瞒的，否则它就不叫良知了。良知自有不可自昧处，昧就是隐瞒的意思，在这里。

<span id="p-tan-06-411" class="reading-anchor"></span>

惠能的意思，也就这个意思。“须自见性”，你自见本有的佛性，你就常行正法。正法不是一条条教给你。我们编一个正法大全，怎么样？你自见佛性，你就在真如自性中起念，你的实践就是正法。所以这个法门前面加两个字，自性。自性法门，从你自性中来。

<span id="p-tan-06-412" class="reading-anchor"></span>

男女授受不亲。一条道德规则。你嫂子掉水里了，你救还是不救？你遵守道德规则吧，那叫嫂子溺水而不援，豺狼。就这个道理。给孩子们讲思想品德课，可以吧？可以的，你怎么讲呢？编个课本，有的几条都写好了。所以没有法门大全，自性法门就来自自己本有的佛性。叫什么？“须自见性，常行正法”。

你只要见性，你行的全是正法。这叫真学。

## 从常能下心说成佛道

**回看 03:58:52—04:04:25**

<span id="p-tan-06-413" class="reading-anchor"></span>

又讲第四个弘愿了，“又自性无上佛道誓愿成”。无上佛道也在我们的自本性中的。我们本有的真如自性，其实它就是无上佛道，关键还是如何成佛道。关于这个 how 最重要，what 可以先说出来。What 说出来了。那我们最关心的是 how。

就像你学哲学，你老说哲学是什么，这叫老是 about philosophy，我们最关心的是 into philosophy。

<span id="p-tan-06-414" class="reading-anchor"></span>

关键是这个如何成佛道。底下来了，“常能下心，行于真正，离迷离觉，常生般若，除真除妄，即见佛性，即言下佛道成”。这一段他说得比较多一点，而且每句都很重要。“常能下心”，这叫什么？内心谦下是功，外行于礼。我们能否常常是内心谦下的呢？

<span id="p-tan-06-415" class="reading-anchor"></span>

我们每个人总要确认自己是什么？卑微的、渺小的，许多方面不如人的。别以为自己能呼风唤雨。就像我们前面讨论过，某一个行业里边呼风唤雨的人，他患上绝症了，动了手术了，束手无策，生死未卜。他还会认为自己强大吗？他认为周围的人个个都比他强，他是最糟糕的一个人。我们要保持这个心态。

无论我们获得多少的成功，我们总得要相信自己是卑微的、渺小的。这叫真正的内心谦下。

<span id="p-tan-06-416" class="reading-anchor"></span>

如乔布斯说的，stay foolish，保持愚笨，stay hungry，保持饥饿。你永远要记得自己是 foolish and hungry，那就对了。常能下心，自然行于真正。我们迷误，然后觉悟，然后又把迷和觉对立起来，又错了。所以迷和觉都要离了。

<span id="p-tan-06-417" class="reading-anchor"></span>

先是由迷转为觉悟吧，这很好了。然后说我觉悟了，老是想着自己觉悟了，那叫骑驴不肯下。第一个错误，是骑着毛驴找毛驴。我们本有佛性的，到外面去求了，你本来骑着毛驴的嘛，这叫骑驴觅驴。好了，这个病终于除掉了，后来发现自己觉悟了，老想着自己觉悟了，那叫骑驴不肯下。又是两边，迷和觉又是对立的两边。

<span id="p-tan-06-418" class="reading-anchor"></span>

“离迷离觉，常生般若，除真除妄”，也是不落两边的意思。我们去妄念，起正念。然后老想着自己这个是正念，还不行。把真妄的对立也消解掉了，也除掉了，这叫“即见佛性”。讲了这四个愿，最后来一句，“常念修行是愿力法”。佛法多了，最根本的是愿力法。

<span id="p-tan-06-419" class="reading-anchor"></span>

什么叫常念修行？把整个人生看成是修行，这就叫常念修行。人生就是修行。记住，这叫常念修行。修行不是苦行。我们前面讨论过了，佛教的修行是什么？在形而下的现实中过形而上的生活，获得那个 eternal joy。这就是人生，就是修行。

<span id="p-tan-06-420" class="reading-anchor"></span>

我们做的事情都生生灭灭，但是我们每一次做事情，都让它跟佛性关联了。佛性是不朽的，于是法喜来了。法喜就是 eternal joy，永恒的欢乐。所以关于最后一个愿，他说了几句话，如何成佛道？我们通常都不敢想象自己能成佛道。高不可攀。其实没有，成佛道第一条是什么？常能下心。这是根本的出发点。

这就是发愿，你愿都发了啊。

## 本节总结｜整理附录

本节逐愿回答“如何”。自心众生并不是把别人抹去，而是在社会关系中认出自己也具备众生的妄心与罪因；由此接入巴金的忏悔、共同责任和自性自度。断烦恼则由般若智破除在高低、贫富、贵贱二相中的无尽趋避。

学法门与成佛道的讲解继续从自性出发。道德条文、嫂溺援手、良知和骑驴的例子都保留在原来位置；最后强调先能下心，再连迷觉、真妄的对立也不执着，使人生的具体行动与不朽佛性关联。
