## 三无的次序

**回看 01:26:41—01:27:58**

<span id="p-tan-05-149" class="reading-anchor"></span>

「善知识，我此法门，从上以来」，从达摩以来，「先立无念为宗，无相为体，无住为本」。提到三个「无」了，然后要分别加以说明。「无相者，于相而离相；无念者，于念而无念；无住者，人之本性。」先简要地说明了一下。无相是于相离相，无念是于念无念，无住是人之本性。

<span id="p-tan-05-150" class="reading-anchor"></span>

简要地说明之后，然后具体地说明。这个具体的说明呢，他先说明的是无住为本，然后再说无相为体，最后说无念为宗。他把第三个无住为本放到一开始说明。「于世间善恶好丑，乃至冤之与亲，言语触刺欺争之时，并将为空，不思酬害。」这一段话非常好。

## 无住为本与人与人的关系

**回看 01:27:58—01:30:49**

<span id="p-tan-05-151" class="reading-anchor"></span>

什么叫无住？我们的心不住到外部事物上去，这个事物叫法吧。「于诸法上，念念不住」，就我们的心不停留在外法、外部事物上。这叫什么？无缚，就不被外物所束缚。那么前面那段话我们要关注。在这人世间生活，也就在社会交往中、人与人的关系中生活。人与人的关系是我们人生的绝大多数烦恼的根源。

<span id="p-tan-05-152" class="reading-anchor"></span>

关系叫缘吧，烦恼叫尘吧，所以叫尘缘。你在这个社会生活中越来越难过了，觉得不能这么办了，有一条路，寺庙、空门，你这叫斩断尘缘，遁入空门。缘就是关系嘛。

<span id="p-tan-05-153" class="reading-anchor"></span>

我们跟父母亲有缘，所以我们做了他们的儿女。我们跟妻子或丈夫有缘，成了配偶。我们跟儿女有缘，跟他们之间成了这样一个母子或者父子、母女父女的关系。这些都是缘。同事之间也是缘，交上了朋友，朋友也是缘。种种的缘，就是关系。

<span id="p-tan-05-154" class="reading-anchor"></span>

这些关系带给我们烦恼了，于是叫尘缘。这烦恼来自哪里呢？来自住。所以他说我们在人世间，遇到善的、恶的、好的、丑的，乃至冤之与亲，有人跟我们亲，有人是我们的冤家。然后每每要言语触刺吧，我们对抗了，言语触刺、欺争，人与人的关系达到这个冲突的程度。

<span id="p-tan-05-155" class="reading-anchor"></span>

这一切都不要停留在上面，它们很快就空掉了，「并将为空」，所以不思酬害。前念过去了，不要跟着这个念走，不要耿耿于怀，这叫无住了。这话在佛教来说，修行的人一定要认真地听取。

## 三世因果、冤亲债主与养育子女

**回看 01:30:49—01:35:40**

<span id="p-tan-05-156" class="reading-anchor"></span>

因为佛家讲三世因果的。三世因果，我们前世、再前世都来过这世界。各位，我在讲迷信了啊。来过这世界，累世的一切，都跟人打过交道，都曾经伤害或者得罪过人。所以佛家就有个词叫冤亲债主。

<span id="p-tan-05-157" class="reading-anchor"></span>

现在有许多人到寺庙里也懂这个道理，烧香拜佛、做佛事。做佛事就是要跟冤亲债主打招呼，跟他们表示抱歉，回向给他们。据说这样的佛事是有效果的。有一种佛事叫大拜忏，忏就忏悔，大拜忏专是做这样的事的。

<span id="p-tan-05-158" class="reading-anchor"></span>

我们一定要确认，也要相信，自己得罪过人、伤害过人，而且这种伤害你无法挽回的，就成了你的业。跟着你就到这世来了，种种的业把你再次抛到这世界，你带着业来的。所以中国人后来就相信佛教了，老百姓都说这样的话。

<span id="p-tan-05-159" class="reading-anchor"></span>

父母与儿女的关系是什么？无债不成父子。你们两个人结婚了，不是冤家不聚头，那真有点道理。若你信这一套，信这个佛家讲的三世因果，你就要随遇而安。谁让你欠他的？自己的事，你的罪业自己消，不要斗争，消完了也就好了嘛。

<span id="p-tan-05-160" class="reading-anchor"></span>

孩子有两类了，一类是来讨债的，一类是来还债的。他上辈子欠你的，你知道？你都没想到，你也没怎么花精力，你自己也不像个样子，他倒是考取北大的、哈佛的了。你给他请过家教吗？根本没有啊。

<span id="p-tan-05-161" class="reading-anchor"></span>

我带过好多研究生，有的来自非常穷的山区，母亲还不识字，父亲字也识得不全，在工地上干活的。他就考进复旦，最后到我这里来读博士。毕业以后，他的博士论文得全国优秀博士论文奖。他父母都傻掉了，这孩子怎么这样的啊？那么家里虽然穷，他是贷款读书的，付学费的，工作了以后，把银行的贷款都还掉了，不用他父母操什么心呢。你怎么解释呢？

<span id="p-tan-05-162" class="reading-anchor"></span>

这是许多大城市的人不懂这个道理的，拼命地为孩子创造条件，花多少钱，千万不能输在起跑线上。然后择校、请家教，费用极高。我看都很傻，没啥用。所以这就是佛教讲的三世因果。所以冤之与亲，冤亲债主，这是人与人的关系。「并将为空，不思酬害。」这是真的。

<span id="p-tan-05-163" class="reading-anchor"></span>

你若有一个孩子实在让你操碎了心，他还是不像个样子，你别难过，也不要指责他。这辈子能做母子或者父子、母女或者父女，就是那个缘是在的。不要用理想的标准来要求孩子。这辈子就这样了，下辈子再也不见面，就这件事。

你这辈子你还好了嘛，还好了嘛，就业障消掉了呀。下辈子怎么见呢？见不了了，想明白嘛就好了呀。

<span id="p-tan-05-164" class="reading-anchor"></span>

当然我们还是儒家，有责任感。儒家让我们中国人最关心下一代，这一点也没错。但关心要关心在点子上，不要安排他的人生道路。让我们的孩子成长为一个正直的人，这是一。第二，成长为一个自食其力的人，这是二。这两条做到了，就是你家长尽了责任了。

他成龙还是成凤，不归你管。这是他自己的人生道路，他有他前世的业。每个人都带着业来了嘛。

## 念念不住与安住心舍

**回看 01:35:40—01:38:53**

<span id="p-tan-05-165" class="reading-anchor"></span>

所以这里就讲这个无住为本。我们看下去，倘若我们还是执念，那叫什么？「若前念今念后念，念念相续不断，名为系缚」，就自己束缚住自己了，被过去的事情束缚住了手脚。过去的都空掉了嘛，烟消云散，你还在自己束缚自己。

<span id="p-tan-05-166" class="reading-anchor"></span>

「于诸法上，念念不住。」住就是停留的意思，不要停留在那些事情上。你不停留，就是没有束缚，「此是以无住为本」。这个本是指什么？本性。我们住外物，我们就不能安住心舍。《金刚经》讲对内破执，对外扫相。对外扫相，就把相都扫掉。对内不执着于自己这个小我，这叫对内破执，把这个执着破掉。

<span id="p-tan-05-167" class="reading-anchor"></span>

破掉，我们的心才安住了，安住在它自己。我们的心就是个家，心舍。中国先秦的哲人孟子，老早说了这件事了，心老放出去了，不把它叫回来？「学问之道，无他，求其放心而已。」这个放心就是放出去的心，再把它叫回来，叫回来叫安住心舍。你怎么安住心舍？对外不住法。

<span id="p-tan-05-168" class="reading-anchor"></span>

你的心在外面，停留在那些事物上了，就不回来嘛。一旦回来了，就是无住了，不住外法，那叫本，本心吧。让我们的心自己跟自己在一起，这叫本心。把心叫回来，让它跟上帝在一起，基督徒。把心从外面叫回来，让它跟真主在一起，穆斯林。

<span id="p-tan-05-169" class="reading-anchor"></span>

中华民族不是个宗教的民族，我们如孟子所说的，把心叫回来了，让它跟谁在一起？跟自己在一起。这叫「应无所住而生其心」。这是第一个「无」，无住。

## 无相为体，承认相而离相

**回看 01:38:53—01:42:47**

<span id="p-tan-05-170" class="reading-anchor"></span>

然后再讲无相。「善知识，外离一切相，名为无相。能离于相，即法体清净。」相是客观存在的吧。我们生活在任何一种文明类型当中，每一种文明类型都是一种价值体系，有高低贵贱。博士一定比学士高，银行行长肯定比银行职员要高，比银行柜台上的营业员要高。这些就是文明的价值体系，它一定是等级。

<span id="p-tan-05-171" class="reading-anchor"></span>

这是客观的，你要承认。你没有到涅槃境界里去，不生不死，你就在娑婆世界。娑婆世界，种种文明构成的。所以你要承认，承认就叫于相。于相这件事情不要否定。

<span id="p-tan-05-172" class="reading-anchor"></span>

比方说你读大学，那么叫求学去了。求学是不是一个不断进步的阶梯呀？你拿了学士学位，你还想进一步研究这个学问吧，那么你就要考研了。考研，然后终于考上了，最后作一篇论文，做硕士，得了一个硕士学位，比学士学位高了。

<span id="p-tan-05-173" class="reading-anchor"></span>

如果你还要研究，要进一步深造，这个目标没什么错吧，于是考博。终于拿了博士学位，博士学位一定比学士要高，比硕士也要高。它代表你在某一个领域里边，已经是有研究能力的人了。硕士未必有研究能力，但是他是个能手，master，在这个行当里面可以干得很熟练，那叫 master。

那么学士嘛，就是入了这个学问的门啊，就这三个等级，你得承认这叫相。

<span id="p-tan-05-174" class="reading-anchor"></span>

你拿了博士学位，你自己感到高兴，对的。为什么高兴？我可以去研究这门学问了，我可能为这门学问的进步做出贡献了。这是相。假如你就在这相中了，把它仅仅看成是高低贵贱，著了相，住了相，要离。

<span id="p-tan-05-175" class="reading-anchor"></span>

你拿博士学位也好，拿学士学位也好，其实也无非是要研究这门学问。结果你硕士没考取，不等于你不能研究这门学问。你结果研究了这个学问，还做出贡献来，虽然你只是学士。那个博士学位拥有者，他倒一点贡献都没做出来，这完全可能。

<span id="p-tan-05-176" class="reading-anchor"></span>

想想看，梁漱溟先生在北大做教授了吧，他口袋里的毕业文凭是什么？初中。他一辈子初中毕业文凭啊，绝不妨碍他对中国近现代哲学的研究做出他的贡献，是当代新儒家的代表人物之一。很说明问题，这叫于相离相。你离相，才归于什么？实性。

实性就是佛性，就是法体，法体清净啊。「能离于相，即法体清净。」此谓无相为体，这才叫无相。

## 银行效益与为实体经济服务

**回看 01:42:47—01:45:21**

<span id="p-tan-05-177" class="reading-anchor"></span>

比方说世间法跟佛法的统一吧，世间法本身就确认了相的存在，否则没有什么世间法了。你做银行行长，在世间法中，你一定要追求银行本年度的效益吧，这是不是相？今年本年度的效益比上一年度的效益低好多，是不是这样一件事情就被评价了？今年银行的营业、经营不如去年了，某种意义上我们失败了。

<span id="p-tan-05-178" class="reading-anchor"></span>

这就是相。我们学世间法，就是要避免，所谓趋利避害吧，趋得避失吧。所以世间法都承认相的，没有相就没世间法。我们用世间法，同时突破相对我们的束缚。我们争取银行的效益提高，但是我们不把效益提高看成是我们的真实目标。

<span id="p-tan-05-179" class="reading-anchor"></span>

银行如果效益提高了，它意味着什么？它真的有效地帮助了实体经济的，否则它效益怎么会提高？如果实体经济没有得到它的帮助，它效益提高了，那是件什么事啊？掠夺实体经济。要能离吧，有相，但不停留在这相里，不住相的。住相就忘了实性了。什么是银行业的实性呢？为实体经济服务。

<span id="p-tan-05-180" class="reading-anchor"></span>

当然服务得好的话，它自己效益提高了，有效服务。把为实体经济服务这个实性去掉，银行只要效益提高，那就意味着什么呢？中国经济过分金融化，让实体经济不是得到发展，而是得到压抑。

<span id="p-tan-05-181" class="reading-anchor"></span>

所以这些事情都是生活中的事。要有于相离相的禅宗境界去做事情，世间法是为佛法的实现服务的。如果停留在世间法里，没有佛法，我们就在相中了。这就是无相为体。无相并不是说不在生活中了，还在生活中，还有种种的区别，但它不重要，重要的是什么？我们回归了实性，实性就是清净的。

## 假如我以讲师退休

**回看 01:45:21—01:48:30**

<span id="p-tan-05-182" class="reading-anchor"></span>

假定我王德峰被评上讲师之后，几十年下来，副高职称都没评到，最终以讲师退休了。我该怎么评价我自己的几十年的学者和教师生涯呢？能够判断为我这个学者生涯是失败的吗？不能。除非我讲课的时候误人子弟了，除非我在研究我所热爱的学问方面没有做出任何贡献，那我是失败了。

<span id="p-tan-05-183" class="reading-anchor"></span>

如果我从不误人子弟，我每发表一篇学术论文，都是对学术事业做出那么一点贡献的，我以讲师退休，我仍然对自己的几十年学者生涯给予肯定的评价。我很满意，这就叫清净，这就是清净。能否做到这一点？现在有人说，你已经教授拿好了，博导也拿到，现在说那个轻松的话。你真拿不到，讲师退休，你会怎么样？

<span id="p-tan-05-184" class="reading-anchor"></span>

我也问我自己。许多人以副教授退休了，引为终生的遗憾。这样的人很多的吧。我不是在说风凉话。想来应该是真的，只是我当初难过过，没评上副教授难过，后来没评上教授也难过。这叫觉悟得太晚。觉悟得早一点，做讲师一直做到底也没事，不枉我做学问一场，不枉我做教书匠一场。

<span id="p-tan-05-185" class="reading-anchor"></span>

什么叫法体清净？法体本来就清净，你在相中，就不清净了呀。有的人评为院士了嘛，那么我离开院士还远着呢，你该怎么想这件事呢？所以于相离相，那就是法体清净。

<span id="p-tan-05-186" class="reading-anchor"></span>

有的人对某一个学问，或者某一个领域做出贡献，跟文凭一点关系都没有。像韩寒，这种人不是大学能培养的，他跟大学没什么关系。那你问韩寒，你有学士学位吗？他说我没有，他就写作就是了。哪一个作家、文学家是大学的文学系培养出来的？哪一个真正的将军、常胜将军是军校里培养出来的？不，他打仗打出来的。于相离相，这是讲第二个「无」。

## 本节总结｜整理附录

三无的解释在这里从无住为本开始。课堂把人与人的关系、对过往冲突的停留，以及三世因果的信念连起来讲，并谈到对子女的责任。不能把这一段只概括为放下烦恼，丢掉实际讲出的宗教解释。

无相不是否认学位、职务、经营效益等区别。课堂先承认这些相，再以学问贡献、银行服务和教师生涯追问它们本来的意义。“假如以讲师退休”保留假设语气，也保留自己过去曾为评职称难过的反省。
