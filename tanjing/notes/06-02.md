## 外离相为禅，内不乱为定

**回看 00:43:10—00:48:18**

<span id="p-tan-06-078" class="reading-anchor"></span>

“善知识，何名禅定？”说得非常简明，“外离相为禅”。外离相为禅，就是什么？你在法体中了吧，无相为体吧。你就在法体中了，也就在佛性中了，这叫禅。“内不乱”，那个内是指心，心不乱为定。外面是相，里面是心。对外扫相，对内破执。我执去掉，你就不乱。

<span id="p-tan-06-079" class="reading-anchor"></span>

我执难以去掉，我执每每怎么起来？于境上起心的时候，我执就在起作用。这是顺境，那是逆境，这是乐境，那是苦境，不是我执在起作用吗？所以离相这功夫下来以后，我执也就去掉了。因为离相意味着什么？不再是求如意的心了吧。在二相中，我们一定求如意嘛。求如意就是我在起作用了，这个小我在起作用啊。

<span id="p-tan-06-080" class="reading-anchor"></span>

我们能离相的话，我们看清楚了，这全是相，虚妄不实。它同时的效果就是什么？我执放掉了。比如说，这是我终于花了钱买下的一辆豪华轿车，它是我的，我执不是来了吗？这个豪华轿车被人砸了，被人偷掉了，愤怒了。这都在相中。

<span id="p-tan-06-081" class="reading-anchor"></span>

如果你发现轿车就是轿车，虽然是我花钱买的，是我为了方便生活用的，但它不是我的。那为什么？它只是相。看到事物的虚妄不实，这是天台宗修的观门。其实相当于禅宗讲的对外扫相，这就是观。

<span id="p-tan-06-082" class="reading-anchor"></span>

底下惠能说得很清楚，“外若著相，内心即乱”，就我执不能息掉，不能降伏其心了。“外若离相”呢，“心即不乱”。这里边是因果关系吧，外离相是因，心不乱是果。我们自本性，也就是佛性，本来是自净自定的吧。“只为见境思境即乱。”

<span id="p-tan-06-083" class="reading-anchor"></span>

我们见境思境，我们就脱离我们的本性了，脱离我们的佛性了，这个心一定是乱的。“若见诸境心不乱者，是真定也。”见诸境，为什么能达到心不乱呢？不在相中看这个境。那叫什么？万境自如如。弘忍法师说的，“一真一切真，万境自如如”。

<span id="p-tan-06-084" class="reading-anchor"></span>

不管怎样变化的、多种多样的境，不把它放到相中去了，那就是如如了。所以万境自如如，是离相的结果。“如如之心，即是真实。”如意之心一直在乱，因为不如意十之八九。如如之心就不乱，如如不倒啊。这叫真定也。

<span id="p-tan-06-085" class="reading-anchor"></span>

底下又重复一下，“外离相即禅，内不乱即定”。简要地说，“外禅内定”。再合起来，“是为禅定”。说得很好，很妙。从长句子到短句子，最后两个字，禅定。从外离相即禅、内不乱即定，说到外禅内定，再说到禅定。现在明白何为禅定了。看来下的功夫就是什么？外离相。这是功夫下手处。

## 停一停，问因何而怒

**回看 00:48:18—00:54:02**

<span id="p-tan-06-086" class="reading-anchor"></span>

不要提醒自己，心别乱，心别乱。你在提醒自己要镇定。已经乱了嘛。否则你要说什么镇定呢？我们经常注意一下自己，比方说愤怒了，提醒自己制怒。有的人很容易生气嘛，那么要制怒，提醒他，请书法家写了两个字，制怒，放在桌子上或者挂在墙上。

<span id="p-tan-06-087" class="reading-anchor"></span>

那么我走进去一看，哦，你大概这个人很容易生气。所以提醒自己制怒。很好的啊。其实你怒了，说别怒，你已经怒了，你知道。问题是为什么怒，这个原因要解决。怎么解决？引起你怒的原因呢，还是在你心里，在相中吧。离相了嘛，就不怒了，不会怒了。怒嘛，就心乱了吧。

<span id="p-tan-06-088" class="reading-anchor"></span>

怒起来了，很正常的啊。别跟着怒走，跟着怒走，你就在怒中了，就在怒之中了吧。你不跟它走，怎么不跟它走呢？停一停，问一问自己因何而怒。有时候我们会怒，喜怒哀乐，人之常情。要我不喜不怒，不可能的。问题是你怒起来了，或喜起来，总得停一停，问自己因何而喜，因何而怒。

<span id="p-tan-06-089" class="reading-anchor"></span>

不是去克制它。你喜就喜了嘛，然后你想一想，哎哟，我为什么喜的？这一想就好了，你就不跟这个喜念走。你怒了，很正常。停一停，问自己因何而怒，你就不跟着那个怒念走。跟着怒念走，被怒本身束缚住了，你后面的行为，是要出大问题的。

<span id="p-tan-06-090" class="reading-anchor"></span>

假如你孩子今年期末考试成绩出来，班上倒数第一名，你怒不怒？当然怒了，因为他是你的孩子，你爱他呢，是不是啊，是不是人之常情啊？怒了就怒了。孩子就在你面前，你也装不出笑脸，同意吧？我要爱护他啊，别怒啊，让他看到我愉色啊、婉容。我愉色不了。我这时什么愉色呢？

<span id="p-tan-06-091" class="reading-anchor"></span>

怒了就怒了呀，你干嘛要骂他。停一停，问一问，为什么怒了？成绩不好，成绩不好你怒干嘛呢？想着他健康成长，这样一想又好说。停一停，不是限制这个怒，而是问自己怒的根源。这个怒是有它的根源的，这个根源出于你对他的爱。别偏离这个爱去怒，然后你跟他说话就合适了。

<span id="p-tan-06-092" class="reading-anchor"></span>

你在怒中给他一个巴掌，没用的家伙，我怎么生出你这种孩子来？好了，完了，你完全被怒控制住了。这时候要外离相，怒是怒了啊，哎呀，一次考试就证明我儿子就最差吗？这是个相啊。但是成绩不好是真实的，找找原因，帮助他找原因就可以了。然后终于心平气和，也不是怒被制下来了，而是找到它的原因。

找到了原因以后，你就离相了嘛。

<span id="p-tan-06-093" class="reading-anchor"></span>

你希望你的孩子健康成长。他这件事情出来，叫考试倒数第一名，不等于他没健康成长。只是要补他的短处，或者他性格上的弱点，或者贪玩啊，或者懒散。那么你去帮助他、提醒他，就可以了。我随便举生活中的例子，都一样。

<span id="p-tan-06-094" class="reading-anchor"></span>

夫妻之间吵架也一样的，也是怒嘛。停一停，问问为什么生气了呢？你怎么不符合我的要求了？找到这原因，自己的问题。凭什么他要符合你的要求？怒了，然后很开心，为什么？缘分在，否则咱也不怒了。夫妻吵架是很正常的，吵架就是那个缘在嘛。当缘结束会吵吗？不会吵，大家等着分手吧。

<span id="p-tan-06-095" class="reading-anchor"></span>

每天用纸条传递话，因为还住在一个空间嘛，就没办法。我写张纸，今天有什么事，你去看。彼此不交一语，那就缘分尽了。吵一吵，然后又好了。好了以后，大家批评与自我批评相结合，夫妻关系上升到一个很好的境界，OK了呀。

## 自见本性清净

**回看 00:54:02—00:58:55**

<span id="p-tan-06-096" class="reading-anchor"></span>

离相，我们的喜怒哀乐都跟相关联在一起的，然后再离了就好。然后内不乱即定。这就是生活，生活就是外禅内定。然后惠能在这里引用了《菩萨戒经》，“我本元自性清净”。“善知识，于念念中，自见本性清净。自修、自行，自成佛道。”

<span id="p-tan-06-097" class="reading-anchor"></span>

话说得非常好，因为他引用了这个经，经里边的话，就说得对。其实我们每个人，就是相信自己本来都是清净的。就是因为有相嘛，我们在生活中就生活在二相中了嘛。在二相中之后，我们就不清净了嘛。那么你离相，又回归你本来的清净嘛。

<span id="p-tan-06-098" class="reading-anchor"></span>

外离相，是心要下的功夫。心就是生命情感的居所。喜怒哀乐忧惧起来，我们都停一停、问一问。比方说你忧虑，你惧怕，停一停，问自己因何而忧、因何而惧。这一停，就是离相的功夫。相由心生啊，各位。

<span id="p-tan-06-099" class="reading-anchor"></span>

钻石的高贵和茅坑里石头的低贱，这种区分不是它们的实性吧。谁作的区分？我们的心作的区分嘛。所以根源还在你的心嘛。你找到根源，不是回归自己的本心嘛？这个相就自然离了嘛。离相是心的功夫，不是头脑的认识。

<span id="p-tan-06-100" class="reading-anchor"></span>

你愤怒了就是愤怒了，头脑的正确认识压制不了你的愤怒的。你喜悦了就是喜悦了，用头脑中的理性来把这个喜悦消解掉，是不可能的。愤怒消解掉也不可能，忧虑消解掉，用头脑认识来消解，不可能的。惧怕就惧怕了。你用头脑中的认识来消解它，是不可能。而是问一问惧怕本身的原因，一问就知道了。

因为你这个相就是你生的。

<span id="p-tan-06-101" class="reading-anchor"></span>

然后在相中呢，你喜悦了或恐惧了。那你就离呀，离这个你心所生的相嘛。比如说你考大学就考大学了，你读大学就读大学了。然后你读大学了以后，你的心就自然生出相来。因为你在这种社会里边，那么博士要比硕士高，硕士要比学士高。名牌大学要比一般大学高。这些全是你生出来的相，常人都如此。

<span id="p-tan-06-102" class="reading-anchor"></span>

实际上你到了高中毕业的时候，你考一个大学，考进去读书，不管它是什么大学，其实你应该满心地欢喜。为什么？我可以继续求学，就OK了呀。偏说我是北大的，我是清华的，我是复旦的，才了不起。相中。有书可读，很好了。你有书可读嘛。没书可读也没办法了，只能什么？社会是我的大学，高尔基呀。

在社会生活中读大学嘛。就说要求学嘛，别无其他呀。

<span id="p-tan-06-103" class="reading-anchor"></span>

我们总在相中做事情，然后喜怒哀乐忧惧全来。读书、求学这件事情本身充满意义，让我们足以开心的事情了。这叫如如之心嘛，一真一切真，相的区分就消解掉了，就离了嘛。

<span id="p-tan-06-104" class="reading-anchor"></span>

有的人总跟我讲，哎呀，我当初就想考复旦的，这辈子最大的遗憾，就是只考了那个工程技术大学，引为憾事。我说，不，你在该读书、该求学的年龄，有机会读书了。Enjoy，享受。他说，你别安慰我。他认为我是说了安慰他的话，因为我是复旦的。然后我要安慰他。没有这个意思。

其实我如果读你一样的大学，我也很开心，四年不会浪费的，因为 enjoy 了，享受。

## 念念禅定

**回看 00:58:55—01:06:28**

<span id="p-tan-06-105" class="reading-anchor"></span>

在生活中，我们有时候恐怕不得不前念不生了。前念不生，我们就发现自己的心了，那叫本心了。跟着前念走的心全是假的，那叫求如意的心、趋避的心，其实就是妄念，不是心本身。“应无所住而生其心”，本心起来。在生活中始终要如此，那叫念念禅定。

<span id="p-tan-06-106" class="reading-anchor"></span>

我们总是要起念的，心在就起念。做事情，事情在变化中，有许多意想不到的因素闯入进来，我们的念就不断在改变。但每一个念，我们都要禅定。因为这个念不是 idea，不是头脑中的观念，是那份情感、情绪，喜怒哀乐忧惧，这些就是念。

<span id="p-tan-06-107" class="reading-anchor"></span>

念起来，不用害怕，也不要认为自己修得不好。念起来很正常。禅定的意思是什么？不跟着念走。不跟着念走，你自然离相。离相就回归什么体？法体。无相为体，这就是禅的境界。所以要下的功夫就是什么？追问我们每一个念的根源。

<span id="p-tan-06-108" class="reading-anchor"></span>

在这种对根源的追问中，我们自然就发现了那个相了吧。原来我们这个念是由二相引起的，发现二相，等于离了相。明白这层意思吧？我们通常在二相中，我们并不知道自己在二相中。我们认为我们很正常，大家都这样嘛，趋利避害，趋乐避苦，趋顺避逆嘛。

<span id="p-tan-06-109" class="reading-anchor"></span>

我们受不了苦，受不了逆，我们只要乐，只要顺。我们也害怕祸，只想永远在福中。其实我们这么想，就在二相中。我们向来在二相中并不自觉。念起来以后能停一停、问一问，一问就发现这个念是二相起的念，从二相中来。你发现从二相中来，自然离了，因为它是二相，你知道了，它只是相。

<span id="p-tan-06-110" class="reading-anchor"></span>

我们的通病，把相当真了，从中获取生命的意义、生命奋斗的目标。殊不知我们许多目标，都是因相而生啊，是吗？所以要下日常的渐修的功夫。我们念头起来，就得停一停，停一停。这样发现了二相之后，久而久之，我们起的念不再从二相中起念。

<span id="p-tan-06-111" class="reading-anchor"></span>

这是种积累的功夫，并没有积累悟啊，只是积累一种功夫。久而久之成了习惯，成了习惯，我们对自己的喜怒哀乐，就有一份自由了。我们在自己的情感面前没自由，我们只是被情感控制住了，这通常的情况就这样。对我们自然要生出来的喜怒哀乐忧惧这份情感，我们能否建立与这些情感的自由的关系？这就平时的渐修。

<span id="p-tan-06-112" class="reading-anchor"></span>

渐修到一定程度，积累了这样的功夫之后，我们常常能做到什么？真如自性起念。真如自性起念，还是喜怒哀乐忧惧。这时候这念不是 idea 了，观念。积累到这个份上，这个境界上的喜怒哀乐，都是在实性中起，而不在相中起。

<span id="p-tan-06-113" class="reading-anchor"></span>

比方说做学问，不是为了评上教授。为了评上教授，就是相。做学问本身充满意义。那么在这个过程当中，我们会有顺利的时候，也会有挫折的时候，也会很不顺的时候，也会处在困境中。在困境中，我们也会忧，我们也会惧。唉，这个难题我能攻破吗？这种喜怒忧惧，都很自然，叫真如自性起念。

<span id="p-tan-06-114" class="reading-anchor"></span>

喜怒忧惧是动力。没有情感作动力，你活在这世界上，你干嘛？让我们去行动的，都是情感推动的，只是这份情感要本真，不要有毛病。不要因相而喜怒哀乐，因实性而喜怒哀乐。我们可以克服种种的困难，终于在我们自己的领域里边做出成就来。

<span id="p-tan-06-115" class="reading-anchor"></span>

这个成就也不是等待大家的赞美，而是什么呀？让佛性呈现了。有这种境界，这就是一个修行，到了一定程度会有的。我们看历史上的大德高僧，当民族危难的时候，他们也急，他们也忧，他们也惧。虚云大和尚，是嘛。没有喜怒忧惧吗？有。但不是小我，不是从我执出发的喜怒忧惧。

<span id="p-tan-06-116" class="reading-anchor"></span>

所以虚云大和尚一生对佛教作出多大的贡献。他也历经磨难，这些磨难绝不会动摇他的意志。生活就是坐禅的地方。禅宗是修心的法门，终于让我们达到了真正的自信、勇敢、宁静。那叫天不怕、地不怕。天地也会变色，沧海会变成桑田，所谓长久的山脉也会倒塌，涅槃境界才不动呢。

<span id="p-tan-06-117" class="reading-anchor"></span>

所以这就是了不起，真正的所谓天人师、佛、大丈夫。讲到修行，自然要讲各家各派，佛教的各种宗派都会有的几个修行的基本功课。这个内容呢，就放在第六品了，《忏悔品》。

## 本节总结｜整理附录

本节围绕“外离相为禅，内不乱为定”展开，并持续追问离相的实际下手处。豪车失窃、制怒、孩子成绩、夫妻争执不是可有可无的插话，而是分辨外境、我执、情感和压制四者关系的连续例子。

随后经由“我本元自性清净”，以及钻石与茅坑中石头的贵贱区分、大学名牌的讨论，继续追问相如何由心生起。最后把念理解为生命情感的活动，分辨渐修、悟与真实行动；宁静、自信并不被写成对现实无所作为。
